# Sample Spring Vue Project

这是一个用于上下文分析器测试的前后端分离示例项目。

## 技术栈

- Backend: Java 17, Spring Boot 3, Spring Web, Spring Data JPA, PostgreSQL, Redis
- Frontend: Vue 3, TypeScript, Vite, Element Plus

## 目录

```text
sample-spring-vue-project/
├─ backend/
│  ├─ pom.xml
│  └─ src/
└─ frontend/
   ├─ package.json
   └─ src/
```
