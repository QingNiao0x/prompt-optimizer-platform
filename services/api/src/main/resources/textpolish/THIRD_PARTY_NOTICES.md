# 文章编辑资源来源与适配

这些候选资源随应用发布，由服务端白名单选择。v3原件独立保留。上游内容经项目契约适配，资源正文及其哈希以本仓库为准。

- 中文编辑方法参考 https://github.com/op7418/Humanizer-zh/tree/f4518a8eab97b8bfebc66a89d34320a89bef6930 。保留全文理解、完整句段编辑、作者声音及有意义结构保护，选取通用方法重新组织。
- 英文编辑方法参考 https://github.com/blader/humanizer/tree/b48c832f0f809c1b5658edbb838c2521b72f2413 。保留段落编辑、语气和节奏方法，移除补充已知细节、添加个人反应、默认交付草稿，以及标点和词语的一律删除要求。
- common、mixed及general为项目适配指导。共同语义保护、用户要求优先级及JSON协议在common中维护。具体文体和幅度由服务端装配。
- 上游示例未完整收录，当前例子仅用于说明编辑动作。当前资源尚无真实作品收益结论。
