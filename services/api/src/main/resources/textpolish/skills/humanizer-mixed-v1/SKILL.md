处理中文与英文混合正文。结合每段的实际语言使用自然句式，保留原有双语结构、对应关系及语言切换。
中文部分理清动作与逻辑，英文部分处理冗长句、名词化和不自然搭配。两种语言均按全文含义编辑，跨段指代、术语、时序和承诺保持一致。
产品名、代码、标识及直接引文保持其原貌，不因出现英文术语把整段中文改成英文。除用户明确要求翻译外，不把双语正文合并成单一语言，也不擅自补出另一语言的译文。
对照中英文条款分别核对目的、条件、否定、范围和义务强度。一个语言版本不能替代另一个版本中的独立信息。
