原稿
为推动跨环节的信息协同和备料效率提升，试点把采购组的到货清单与厨房的验收记录并放在每日交接表中。采购组记录货物是否按时到，厨房记录已验收数量，两组都可查看交接表。试点期间，晚班少打了几次核对数量的电话，但尚未统计采购成本。下一步建议同时考虑缺料情况、计划用量与实际领用量，让后续备料更贴合使用情况。

改写
试点期间，采购组和厨房共用一份每日交接表。采购组记录是否按时到货，厨房记录已经验收的数量，两组都能查看。把两份记录放在一起，是为了让两个环节更容易核对信息、提高备料效率。

晚班少打了几次核对数量的电话，采购成本尚未统计。下一步，建议先看哪些东西缺料、原先计划用多少，再对照实际领用量，据此调整备料，让准备的材料更贴合实际使用。

核对：两组记录的内容、共享方式、信息协同和备料效率目的均有对应表述。电话减少是试点观察，不能由此推出采购成本下降。缺料、计划用量、实际领用量各有作用，用来支持下一步备料建议。
