整段编辑示范（自然流畅，个人叙事）
原文
关于第一次自己包馄饨这件事，我印象最深的其实不是做得怎么样。当时我把馅装得太多，第一张皮没有捏上。我奶奶没有接过去替我包，只把自己的那张皮举给我看，说边上要留一圈空。

我照着试，还是包得有点歪，但这只没有散开。我把它放在她包的那几只旁边，等水开。

改写
第一次自己包馄饨，我把馅装得太多，第一张皮没捏上。奶奶没有接过去替我包。她举起自己那张皮，说边上要留一圈空。我最记得的是她举起皮给我看的那一下。

我照着试。这只还是有点歪，倒没有散开。我把它放到奶奶包的那几只旁边，等水开。

含义核对
从第一次尝试写起，保留馅太多、皮没捏上、奶奶示范却没有代劳，以及作者在意示范多过成品的感受。后段保留照着试、包歪但未散、放在奶奶包好的几只旁边和等水开的动作。
