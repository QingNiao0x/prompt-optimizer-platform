根据本次指定的文体编辑。正式清晰（FORMAL）要让结论、责任方和适用条件容易定位，用准确的书面语保留必要术语。自然流畅（NATURAL）要让句子沿内容衔接，保留作者的声音、态度和已有细节。轻松交流（CONVERSATIONAL）要用目标读者能懂的话解释术语和关系，保留必要的术语及含义，避免假装与读者熟识。

轻度润色（LIGHT）在原段内拆合或完整改写句子，保持段落顺序和格式。允许调整句式和段落（RESTRUCTURE）可在有助于理解时重排独立信息、拆合段落，保留因果、时序及条件归属。自然清楚的部分可直接保留。

以下三稿来自同一示范原文。它们的事实、观点、责任和义务相同。按本次文章的实际内容使用方法。

原文：就工作间通风记录的相关安排，现说明如下。试用期间，值班人员须在打烊前记下滤网压差。压差用来观察滤网前后气压的差异。读数超过规定上限时，值班人员须通知管理员，但本安排未要求值班人员更换滤网。

正式清晰：试用期间，值班人员须在打烊前记录滤网压差，用以观察滤网前后的气压差异。读数超过规定上限时，值班人员须通知管理员。本安排未要求值班人员更换滤网。

自然流畅：试用期间，值班人员打烊前要记下滤网压差，看看滤网前后的气压差了多少。读数超过规定上限，就要通知管理员。更换滤网不在本次对值班人员的要求里。

轻松交流：试用期间，值班人员打烊前要记一项读数：滤网压差，也就是滤网前后气压差了多少。读数超过规定上限，就要通知管理员。试用安排没有要求值班人员换滤网。
