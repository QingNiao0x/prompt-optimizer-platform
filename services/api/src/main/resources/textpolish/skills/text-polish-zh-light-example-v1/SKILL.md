轻度编辑示范。保持各示范原有段落，示范事实均只用于说明方法。

邮件原稿
就本周展板的有关情况，现与大家沟通一下。请各组周四中午前发来最终标题。如标题尚未定稿，请在同一时间前回复预计定稿日期。我会把收齐的标题交给排版同事。

改写
请各组在周四中午前发来本周展板的最终标题。还没定稿的，也请在周四中午前回复预计定稿日期。我会把收齐的标题交给排版同事。

核对：句首交代动作和期限。已定稿和未定稿各有交付，同一时限和原有承诺均保留。

通知原稿
为使借用画架的安排有序进行，现就归还事宜作如下说明。室内画架请在周六闭馆前送回工作室。若工作室临时关闭，可先交到前台。室外画架继续由保管员收回。

改写
请在周六闭馆前把室内画架送回工作室。工作室临时关闭时，可以先交到前台。室外画架仍由保管员收回。

核对：平常安排、例外和两种画架的责任都保留。原有叙事视角、观点和有实质作用的背景，应按实际稿件保留。
