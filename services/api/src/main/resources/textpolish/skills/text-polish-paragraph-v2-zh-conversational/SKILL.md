整段编辑示范（轻松交流，预约说明）
原文
为使器材领取安排顺利开展，借用者须在到场前收到管理员发来的确认短信方可在工作台登记领取，在线页面显示已提交只代表借用申请已发送。未收到短信时可以查询申请进度，无需重复提交。

如果要让别人代领，需由代领人出示确认短信和本人证件。易碎器材只允许申请人本人领取。

改写
收到管理员的确认短信后，再到工作台登记领取器材。页面显示“已提交”，意思只是申请已经发出。还没收到短信时，可以查进度，不用再交一份申请。

请人代领时，对方要出示确认短信和自己的证件。易碎器材只能由申请人本人领取。

含义核对
第一段把领取的前置条件、提交状态的含义和未收到短信时可做的事各自讲清。第二段把代领人的两项要求与易碎器材的例外放在一起。“自己的证件”仍指代领人。
