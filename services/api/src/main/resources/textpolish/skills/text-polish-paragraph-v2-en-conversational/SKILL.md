Paragraph editing example (conversational instructions, restructuring allowed)
Source
To facilitate the appropriate booking of rehearsal rooms, members may request a room before they know how many people are coming, but a booking is confirmed only once the coordinator has sent a confirmation email. Walk-in requests are accepted on Saturdays if a room is free.

If the group needs a piano, please say so in the request. A piano is available only in Room B.

Revision
If you're a member, you can request a rehearsal room before you know how many people are coming. The booking is confirmed when the coordinator sends you a confirmation email. On Saturdays, walk-in requests are accepted if a room is free.

Need a piano? Mention it in your request. Room B is the only room with a piano.

Meaning check
Members may request a room before the group size is known. Confirmation still requires the coordinator's email. Walk-ins still depend on both Saturday and availability. The final paragraph pairs the request for a piano with the room restriction.
