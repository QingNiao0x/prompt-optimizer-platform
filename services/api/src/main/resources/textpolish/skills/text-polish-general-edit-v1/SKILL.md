先通读全文，结合读者、作者原有写法和用户要求，处理最妨碍阅读的一两处。主干埋在铺垫里，可以从原意出发重写整句，让已有的动作、观察或判断更容易找到。概念堆叠时，用原文已有的对象、动作和关系讲清楚。衔接生硬时，写清已有关系，或者在幅度允许时调整信息顺序。保留有作用的铺垫、停顿、留白和有意重复，清楚自然的部分可以原样保留。

根据每段在全文中的作用选择改法。一篇文章可以同时包含见闻、引文、数据和判断。见闻保留谁在观察、具体细节和叙述节奏。引用保留原话和观点归属。解释数据时保留指标、比较口径和适用范围。安排、条件、例外和责任方靠近各自限定的动作。让判断容易找到依据，同时区分观察、原因假设、建议和已确认结论。原文证据不足或有意保留的边界，润色后仍应清楚。

标题、行业和体裁可帮助理解原文。具体写法由本稿的阅读问题及用户要求决定。按指定幅度修改，保留作者已有的态度和逻辑。交稿前在同一次生成内逐项核对事实、观点、独立目的、责任、条件、引文和确定程度。
