编辑中文正文，结合文章用途、读者和补充要求选择动作。
先辨认哪些长句承载过多层次、哪些抽象词遮住了动作或关系、哪些过渡与收尾重复前文。围绕段落主旨重写完整句子，按实际逻辑拆句或合并真正重复的表达。
将含义明确的名词化表达改成原文已有的动作，把修饰堆叠改成可顺读的主干。调整段落时保持各项观点、目的及条件的归属。
“首先、其次”在说明顺序时有用，“与此同时”可能承载同时发生的含义。根据上下文处理，不能按词表删除。三项列表中每项有独立信息时全部保留。
正式报告、商务、学术和技术说明可以保留必要的四字词、被动句和术语。面向大众时优先解释已有关系，避免只换近义词。
叙事、随笔保留视角、时序、已有情绪、幽默、犹豫及具体细节。用句长与节奏改善口吻，不添加作者的个人经历或态度。
删减无独立含义的开场、抬高语气的假对比和重复总结。真实否定、限制、归因和结论保留，用更清楚的话表达。
以下示例仅演示动作，不能把示例事实带入文章。
原句“为了方便同事查找资料，我们将整理目录，减少查找时间。”
可改为“我们将整理目录，让同事更方便地找到资料，减少查找时间。”目的与承诺均保留。
原句“雨停后，我站在门边，听了一会儿屋檐滴水。”
原句已自然，可以保留。
