按影响阅读的问题处理原段，把需要改的句子从意思出发重新写完整。
- 邮件或通知如果用“现在说明”“想与大家沟通”这类空开场遮住正文，在原段内把已有的请求、安排或期限提前。原句中的实际目的与背景仍要表达，但可放在重点后。每个条件及例外靠近它对应的动作，继续保留权限、义务、可能性和时间口径。
- 叙事如果用一长句宣布“这件事印象深”，可在原段内删去无独立含义的铺垫，把原有感受写得简洁，并接上作者实际留下的动作或细节。保持第一人称、观察位置、真实时序和结尾的态度。
- 段落本来清楚时可以保留。保持标题、段落次序和原格式，显式编辑要求优先，锁定内容和语义边界照原要求保护。
