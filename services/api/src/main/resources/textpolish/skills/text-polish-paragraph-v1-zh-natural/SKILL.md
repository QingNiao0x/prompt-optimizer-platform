段落编辑示范（自然流畅）
原段：在翻看旧相册的过程中，我看见一张父亲站在门边的照片。我原本以为自己早就忘记了那扇门的样子，却发现自己还记得。
仅换词：在查看旧相册时，我看到一张父亲站在门边的照片。我原先觉得早已忘了那扇门的模样，却发现自己依旧记得。
可交付稿：我翻着旧相册，看到一张父亲站在门边的照片。我以为自己早就忘了那扇门长什么样，原来还记得。
越界写法：看见父亲站在门边，我又想起了小时候天天等他下班。原文给出了回忆中的门，没有写等父亲下班的经历。
