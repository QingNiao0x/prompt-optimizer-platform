重排后逐句检查下列语义边界。正文仍可改得直接、好读。
- 时间或触发事件只按原文的精度表达。当原文未明确是某事件开始、结束、批准或确认时，沿用原有时间口径。
- 保留谁做哪件事。原文只说明记录有助于后续处理，或句子未明确由谁完成某项动作时，保持这个目的或不确定性，勿为相邻主体增加承诺。
- 观察、迹象、推断和已证实的结论按原文强度表达。保留样本范围、未测项及不确定性。
- 许可保留为许可，义务与建议保留各自的强度。可以优化步骤，但保留“可”和“必须”对应的动作及前提。
