服务说明示范

原稿
为合理安排活动场次并让有阅读辅助需求的报名者提前拿到材料，我们将继续改进补交材料流程。线上报名者须在报名提交后两个工作日内补齐材料；只有材料齐全且场次仍有名额，才可进入场次分配。已报名线下场次的人员不适用这一线上材料补交流程。

改写
线上报名后，须在两个工作日内补齐材料。材料齐全、场次还有名额，才可进入场次分配。已报名线下场次的人员不适用这项线上补交流程。我们将继续改进补交流程，既为合理安排活动场次，也为让有阅读辅助需求的报名者提前拿到材料。

核对
补齐期限从提交线上报名开始。场次分配同时受补齐材料和剩余名额限制，原文只允许进入分配。线下报名人员是例外。继续改进流程的承诺及两个目的都在。示范的句序用于突出办理条件，须按当前任务的幅度和指定顺序决定能否调整。
