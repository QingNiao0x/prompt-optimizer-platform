## 设计原则

- 隐私优先：项目源码默认只在本次请求中使用。
- 契约优先：前端、后端和 IDE 插件围绕稳定的 API 契约协作。
- 模块化单体优先：先控制复杂度，再根据真实流量拆分服务。
- 可计量：每次模型调用都应能关联租户、模型、Token、耗时和成本。
- 可替换：模型供应商和上下文解析器都通过接口隔离。
