# Prompt Optimizer Platform 用户介绍材料

本套材料包含 **17 页、九个章节**，采用用户指定的浅蓝 Glassmorphism 视觉体系。身份为个人开发者项目，阶段为 **MVP 本地联调与内部试用**。身份来自作者本次明确要求，阶段同时依据当前 README 核对。

## 交付文件

| 文件 | 用法 |
| --- | --- |
| `Prompt-Optimizer-用户介绍.pptx` | 可编辑幻灯片；每页演讲者备注包含核心文案、讲稿、演示动作和事实依据。 |
| `Prompt-Optimizer-用户介绍.html` | 单文件离线放映版；字体、截图、样式和脚本均已内嵌，可独立复制到另一台设备。 |
| `逐页脚本与大纲.md` | 九章目录、17 页详细脚本、视觉安排及逐页事实来源。 |
| `母版设计规范.md` | 浅色实施参数与深色备选令牌；同样写入 PPT 母版扩展备注和第 1 页演讲者备注。 |
| `全部页面预览.jpg` / `封面预览.png` | 从交付 PPTX 实际导入渲染后制作的预览。 |
| `source/` | 共用文案、布局、构建脚本、来源文件摘要和核验记录。 |
| `assets/` | 工作台截图、截图生成来源、字体子集和字体许可。 |

技术章节仅有第 14 页架构图与第 15 页请求流程图。没有“当前进展与未来规划”章节；未开放能力只在第 16 页独立标注，未给出上线日期承诺。

## HTML 放映

直接用浏览器打开 HTML 文件，无需启动项目或联网。

- `← / →`、`Page Up / Page Down`：翻页；`Home / End`：首尾页。
- `O`：九章目录；`N`：本页讲稿与来源；`F`：全屏；`Esc`：关闭讲稿或目录。
- 点击目录中的章节可直接跳转；结尾按钮返回示意案例。
- 手机可左右滑动；竖屏时建议点击“打开讲稿阅读”，或横屏查看幻灯片。
- 字体和截图已内嵌，不依赖 CDN、外部图片地址或工作台服务。

## PPT 编辑与字体

主内容包含 **286 个原生文本框**。玻璃卡片、色球、图标、渐变、流程箭头和架构图均保留为 PowerPoint 对象。第 12 页使用一张实际界面截图，未将整页转换为图片。

标题字形来自 Noto Serif SC 900；正文为 Noto Sans SC 400/500/700；数字与参数使用 Consolas。PPT 内嵌本材料所用字形的字体子集；如需大量改写、加入原文没有的汉字，建议使用完整 Noto 字体。`assets/fonts/manifest.json` 保留原字体版权和许可信息，OFL 原文与字体子集放在同一目录。

设计文件中“13.333 × 7.5 英寸”和“1024 × 576 pt”并非同一物理尺寸。本套按明确的英寸尺寸制作，保持 16:9；实际为 960 × 540 pt，HTML 画布为 1280 × 720 CSS px。

## 事实与能力边界

- 一键增强、可选 Plan、项目上下文、历史和基础认证按已核对的实现说明。
- Plan 的推荐项不是默认答案；有效回答后由用户主动生成；未知信息与新冲突仍可保留。
- 输出为必需四要素，当前会补齐验收标准；示例默认关闭，待确认信息按实际情况保留。没有宣传已支持任意输出形态切换。
- 模型接入按 Mock / OpenAI 兼容路线表述，没有按品牌虚构专用模板。
- 代码目录本地索引与文档后端临时索引分开解释；不宣称整份材料全部进入模型或全程离线。
- OCR、图片语义、插件、团队协作和额度计费未写成当前能力；自动执行代码、发送消息及生产部署不属于当前产品能力。
- 所有演示均为人工编写的示意样例；未编造公司背景、资质、客户成果、效率百分比、Token 节省或生产 SLA。
- 当前 README 推荐技术栈中的 JWT 属可选项；讲解以实际的服务端会话身份及 CSRF 保护为准。
- 来源清单包含 24 个已确认文件，`source/sources-snapshot.json` 保存本轮 SHA-256，便于后续发现代码或文档变化。该清单记录本次核对时的事实，不代表后续版本自动保持一致。

最终核对时，待办文档新增了真实补验及后续候选验收记录，正式门禁仍未关闭。第 9 页讲稿明确补充：重复追问、推荐范围和确认后的信息合并仍在验证，使用时需要用户核对。没有将新增本地回放或成功调用数写成全面质量通过。

第 12 页来自当前工作台实际 UI，所有 `/api` 请求被浏览器隔离为人工夹具；没有登录真实账户、调用真实 Provider 或向后端写入演示数据。截图里的 Mock、耗时和结果不能用作质量或性能证明。

## 本轮核验

| 范围 | 结果 |
| --- | --- |
| PPT 结构 | 17 页、17 份完整备注、四个嵌入字体文件、仅一张界面素材图片；XML 和包内引用完整。 |
| 内容一致性 | PPT 原生文本与共同布局数据逐项比对通过；每页都有核心文案、演讲备注、演示动作及来源。 |
| PPT 视觉 | 从实际 PPTX 导入渲染所有页面，并由两个独立复核者检查；修复页签换行、流程箭头对比、选中状态、截图标注和示例要求保留后，相关页复核通过。 |
| HTML 加载 | Edge 本地 `file://` 打开，四个内嵌字重加载成功；无远程 HTTP 请求、页面脚本错误或检测到的文字框溢出。 |
| HTML 交互 | 15 项检查通过：首尾页、方向键、目录、章节跳转、讲稿、事实来源、关闭、全屏、CTA、手机与平板横向溢出、手机阅读入口、模拟滑动及减少动态效果偏好。 |

核验记录位于 `source/structure-report.json`、`source/html-check-report.json` 和 `source/visual-review.md`。本轮没有运行应用业务回归，也没有重新完成真实 Provider、生产容量或正式发布验收；这些不属于宣讲文件制作的验证范围。

**实际桌面 PowerPoint / WPS 放映尚未验证。** 当前检查使用 PPTX 解析与渲染工具，以及 Edge 浏览器。不同桌面软件的字体、透明度和嵌入字体处理可能有差异；HTML 已作为独立离线放映版本交付。

## 构建说明

`source/content.cjs` 是事实和讲稿的共同来源，`source/build-deck.cjs` 生成 PPT、HTML 与逐页脚本，`source/finish-pptx.py` 写入原生渐变、柔化与字体，`source/prepare-fonts.py` 从系统 Noto 字体生成本材料所需子集。素材、代码和源文件分开存放，现有应用源码未因本次制作而修改。

字体关系和嵌入方式参考 [Microsoft PresentationML 字体说明](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.presentation.embeddedfontlist?view=openxml-3.0.1)；EOT 容器按 [Embedded OpenType 格式说明](https://www.w3.org/submissions/EOT/) 编写。字体许可来自 [Noto Sans SC OFL](https://github.com/google/fonts/blob/main/ofl/notosanssc/OFL.txt) 与 [Noto Serif SC OFL](https://github.com/google/fonts/blob/main/ofl/notoserifsc/OFL.txt)，并保留安装字体内的版权元数据。
