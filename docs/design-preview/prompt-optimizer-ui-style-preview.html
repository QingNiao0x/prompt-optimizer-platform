QingNiao Midnight Workbench

推荐融合方案：为长文本和开发者工作流保留稳定的阅读秩序。

查看 Refero 来源 ↗

适合本项目的地方

  • 深灰画布适合长时间阅读提示词和代码。
  • 蓝紫色突出一键增强，不和 GitHub 绿色混淆。
  • 输入、输出、项目上下文三块区域职责清楚。

落地时需要控制

  • 不要把渐变和发光铺满长文本区域。
  • 复杂文件树和表单使用 10–14px 圆角。
  • 成功、警告、错误需要独立功能色。
说明：本页面使用 Refero 公开案例中可核验的颜色、字体、间距和组件描述进行风格比较。推荐方案是针对 Prompt Optimizer Platform 的重新组合，不复制原网站的 Logo、插画、文案、完整页面结构或受限制的字体文件。
