# 文章祛AI味：实现与真实评测

日期：2026-10-25。范围来自本会话明确授权：实现独立“文章祛AI味”，完全沿用现有设计，在模型管理统一配置，真实模型调用总上限 50 次。不含提交、生产部署或其他待办开发。

**结论：工程实现与限定本机业务验证完成；真实评测 48/50 次已闭批，未用 2 次结算释放。**一般说明有小幅去冗余收益，不能据此宣称全面“去 AI 味”或稳定优于原文。旧版 Pro 删除服务承诺的问题部分修正，最终 Pro 仍省略独立目的，专业语义质量未通过；未正式部署。

## 交付与隔离

- `/text-polish` 独立页面、Pinia store、API 与 `textpolish` 后端包。三栏、Element Plus、现有玻璃主题及顶栏；桌面和窄屏均显示三档全部说明，默认自然流畅，切档不调用模型。真实深浅主题截图见下方。
- 一次生成加本地检查，最多一次 JSON 协议修复；没有检测分数、自动质量重试、候选重排或新增 Agent 链路。文体和改写幅度分别设置，待处理材料不取得指令权限。
- 原文对照、纯文本差异、编辑／取消／保存／复制、继续润色和返回上一稿。原文重新生成与已保存当前稿继续分别绑定，服务端核对来源和修订；返回上一稿同时恢复原文与设置。超长粘贴完整保留并阻止生成，不静默截断。
- 独立私有历史、不可变生成快照、编辑修订号、逻辑删除和用户／租户／工作区过滤。操作恢复、重试保存和来源读取同样排除已删除数据；网络、模型或保存失败不覆盖原文及上一稿。
- “模型管理 → 文章润色模型”维护模块允许列表及独立默认项，引用同一平台目录，全局停用／删除优先。不会改变增强或图像模块的默认模型；清空允许列表可停止本模块调用。管理员接口重新核对权限，不授权查看其他用户正文。
- 复用受限模型路由、账号并发、CSRF 和逐次调用审计，受控操作码 `text.polish` 已接入统计筛选。V40 新表、字段、JSON 和归属注释随前向迁移交付；已在本机应用，未回改历史迁移。
- 产品术语、README、待办、使用条款和隐私说明已同步独立正文润色边界及 24 小时私有操作暂存。完整使用及 API 见[说明](../development/文章祛AI味实现与使用说明.md)。

真实业务使用 `tmp/local-acceptance/account.json` 既有合成账号，经正常 CSRF、验证码和密码登录。本机 PostgreSQL／Redis 使用现有配置，凭据只在临时进程环境解密传递，未打印或写入证据。

真实页面证据为 [business.json](./evidence/text-polish-2026-10-25/business.json)：实际编辑保存后，当前稿继续润色的服务端输入与编辑稿一致、左栏与实际输入一致；请求重放没有新增调用；旧修订返回 409；普通用户访问模块模型设置返回 403；只删除此次新建子记录，详情、操作查询、重试保存均返回 404；父记录正文已恢复。该阶段唯一生成计入 48 次总账。真实管理员登录保存未单独执行，管理界面使用受控接口检查，实际配置写入和权限分别由数据库及 Spring 测试覆盖。

首次业务脚本将剪贴板检查记为 false：专用 CDP 浏览器的读取权限被拒绝，该失败留在原件。通过 Chrome 实际上下文权限设置后，[clipboard.json](./evidence/text-polish-2026-10-25/clipboard.json) 确认原生剪贴板与可见正文规范化 CRLF 后一致；不是字节完全相同。Windows `Get-Clipboard` 的跨会话尝试未验证成功，原件同样保留，结论以浏览器原生读取为准。

本机运行的是既有 Windows Redis 3.2.100；目标 Redis 7 的部署环境未在本轮验证。续接时该进程已停止，先恢复既有配置后完成正常登录，没有重建账号、弱化登录校验或改用 Docker。早期无效验证码、测试定位器及沙箱进程错误未产生真实模型调用。编译与运行曾共享被清理的 class 目录，后改为先结束自有验收进程、顺序编译测试、再启动专用服务；最终数据库与工程结果以上述成功运行记录为准。

## 内容结论与保留失败

1. **一般说明有有限收益。**通知、服务说明和引文说明中的重复修饰、连接可以缩短，安排、条件和锁定句可保留。例如默认模型将通知中“切实满足广大读者的阅读需求”简化为“满足读者阅读需求”。未形成用户采用率、检测通过率或跨领域胜率。
2. **文风收益仍弱。**叙事样本虽然保留面馆、筷子等具体细节和作者感受，通用升华仍存在；医学摘要多数只是小幅改词。Pro 的叙事和医学 v2 候选原文返回，计为保真持平，不算实质增益。
3. **已有自然表达应少改。**自然短文的 Formal／Pro 原样返回；Flash Natural／Conversational 仅将“热了一碗汤”改为“热了碗汤”。这是轻微改词，不算去除套话的实质收益。
4. **v2 Pro 丢失承诺，不能通过。**[首次失败原件](./evidence/text-polish-2026-10-25/v2-legal-NATURAL-pro.json) 删除“我们将持续不断地优化服务流程”等最后一句，数字及锁定句仍一致，说明确定性检查不能代替语义检查。
5. **v3 仅部分修正。**共用指导明确压缩重复措辞须保留观点、感受、计划、承诺的独立含义，没有按模型、题目或关键词新增分支。[v3 Pro 原件](./evidence/text-polish-2026-10-25/v3-legal-NATURAL-pro.json) 恢复持续优化服务的承诺，但仍省略“保障用户权益”的独立目的；三份 Flash 服务说明保留该目的。停止继续修改指导／同义采样，专业保真门禁保持开放，不将这一次恢复写成问题全面消失。
6. **最终默认模型回归范围明确。**v3 医学摘要保留无对照、自述、可能关联、不能认定治疗效果及三类适用性未知；指令式引文逐字保留且未执行。最终 v3 没有重采叙事全文三档，因此 v2 的叙事结果不冒充最终版本完整覆盖。
7. **AI 评审不是质量裁决。**模型名称对评审隐藏，但 A/B/C/D 顺序固定，属于匿名 AI 辅助审阅，不是随机双盲专家评审。法律题 D 的 `meaningPreserved=true` 与同一摘要“承诺性内容缺失”自相矛盾；自然短文把轻微改词算收益，部分说明误称原文或改词。保留全部六份评审原件，未采用其总胜率或据此放行专业质量。
