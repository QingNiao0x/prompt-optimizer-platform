# 通用自然增强与 Plan 改造及真实评测

本轮已实现通用任务理解、必要补充、自然正文和 Plan 来源协议，并按功能分开提交。真实评测使用新增授权中的58/60次，已关闭；整体增强质量仍未通过。短文案在两个候选中继续追加说明，已执行停止条件，未继续采样或叠加新指导。

## 1. 最终实现

| 边界与历史 | 固定条款由平台组装，完整相同的独占行才参与归并，代码、引文及独立条件保留。旧 NATURAL/1 指导冻结，历史再次增强按已保存的字符串版本分发；未知或错误类型先拒绝再重建输入。 |
| 源码交付 | 肯定、整体否定和局部附加物共用代码交付物规则，修复“完整源码”漏认；源码说明、引用动作及未来条件不建立工程义务。自然内容仍不复用旧业务模板。 |
| 持久化 | 新增V17仅更新版本注释，V1—V16不回改。内部理解和文件引文不进入历史或日志，原历史正文不重写，租户、工作区和逻辑删除保持。 |

具体实现与兼容说明见[开发文档](../development/独立自然增强与Plan链路.md)。范围说明曾作为候选试验，但未改善短文案交付，已撤回；任务内容优先、比较属性保真及充分需求少改的生成指导保留。

| 证据 | 结论及边界 |

| 材料简报 | 新自然作品全文非空白388、纯汉字309；保留原定简报和原因未知，没有执行材料中的采购指令。不能推广为所有材料隔离或专业报告通过。 |
| 查询类增强 | 部分比较依据改善，但任务内容展开、职业/行业覆盖和紧凑度仍不稳定，不能宣称达到用户提供的Qoder样例水平。查询题只核对优化提示词，未执行联网研究。 |

平台确定缺陷为未知实际值误推荐及明确源码交付漏认，均已修复并验证。源码缺导入首次发生在下游，增强提示词已要求完整可编译源码，尚不足以归为平台唯一根因。短文案中固定事实条款可能诱导分类说明，但在候选明确限制附加说明后仍发生，保持增强指导与下游执行的混合或未定归因。没有为该题新增专业模板、导入清单或按题命中的补丁。

短文案同类失败已持续两个候选，停止扩大采样；未证明收益的附加范围说明撤回。终版仅对3份冻结模型候选作实际服务组装回放，保留正文、出处与固定边界，新增真实调用0；不冒称终版实际作品重新通过。

## 4. 成本与本机验证

初轮同题8对：旧自然输入6098、输出1629 Token，新自然输入9088、输出5115 Token；平均上游耗时约1.98秒与3.54秒，正文平均356.5与403.6字符。任务理解记录仍为同次调用，但输入约1.49倍、输出约3.14倍，质量收益尚未证明能抵消成本；不能只以没有增加调用轮数认定成本不变。详见[成本观测](./evidence/natural-task-generalization-2026-10-19/cost-observations.json)。

- 本轮受影响Java最后报告去重合并350项通过，分多批执行，并非全仓库回归；首次预期失败及环境/夹具失败另存，没有抹去。
- 前端4文件13项通过，覆盖自然正文编辑、固定边界恢复、V2请求和Plan草稿；预算预留器另有5项离线边界核对。
- 真实本机PostgreSQL及Redis验证了接口、会话、历史、CAS、逻辑删除和旧版本再次增强；V17注释在事务内验证并回滚，没有应用Flyway迁移。
- 本机实际使用已有Redis 3.2.100，非目标Redis 7验收。首次Redis未运行和新增记录影响列表断言分别作为环境及夹具问题修正，未修改业务结果凑通过。
- 使用本机源码及独立回环9002进程，无Docker；正常验证码和密码登录，没有改认证保护。凭据、会话Cookie和私有历史不导出。日常前后端未接管，本轮自建进程在收口时清理。
- 本轮未重新执行完整浏览器复制/编辑流程、全模型矩阵、专业人员验收、并发容量或生产部署。历史验证不当作本轮通过。

机器汇总见[验证记录](./evidence/natural-task-generalization-2026-10-19/validation-summary.json)，终版来源见[源码清单](./evidence/natural-task-generalization-2026-10-19/final-source-manifest.json)。整体质量、ME与G1—G8继续开放。
