# 正文、提醒和低价值问题定向修复（2026-10-06）

## 已完成

- 最终正文中的已确认现状或交付选择若已有完整等值行，不再附写第二份“用户已确认的信息”。只忽略空白与句末标点差异；否定、版本、对象、数值、运算符和条件仍参与比较。可复制正文继续由最终结构化段落生成。
- 同一完整主体的简单“未确定／尚未明确／未知”提醒只展示一条。不同医院、年份、条件或带解释的提醒继续独立保留；Plan 绑定答案、服务端冲突及展示限额流程不变。
- 文件部分解析时，已有明确的文件解析警告不再叠加泛化状态警告。来自不同阶段而仅有空白、全半角或句末标点差异的同一警告只显示一次；目录截断等不同问题继续展示。
- 用户已要求并列对照差异，且候选只改变表格或段落排版时，由执行者处理，不再占用 Plan 问题。版本归属、适用范围、生效状态、专业口径、用户主动要求选择及候选里的新增决定仍保留。

完整测试受工作区另一份未跟踪测试和本机网络／日志环境影响，先保留失败记录，不删除测试或放宽断言。下一步针对医院复合提醒、科研呈现、新闻篇幅和大段正文的真实模型改写构建未参与本轮规则设计的新样例；同一对象、属性、条件和来源均可核实时才继续归并。随后用拟开放的两个 DeepSeek 模型重跑 Plan、直接增强及下游实际作品，检查规则完整性、未决条件保留和阅读负担。历史失败不得由成功重跑覆盖。
