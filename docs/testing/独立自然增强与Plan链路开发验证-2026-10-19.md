# 独立自然增强与 Plan 链路开发验证（2026-10-19）

本次完成代码实现及受影响功能验证。默认直接增强与 Plan 已进入独立自然链路，结构化模式显式返回五个模块；新自然正文的编辑、复制、历史保存和同记录撤销已接通。**尚未验证真实模型的增强收益或专业质量，不作为上线通过结论。**

## 1. 实际改动

- 新增 NaturalPromptProvider、独立输入 / 正文协议、版本化指导及 OpenAI 兼容 / Mock 适配器。自然链不调用旧 Provider、旧业务规则追加器或四要素组装器，框架按任务语义选一个适用组织参考。
- V2 默认 / COMPACT 返回 TEXT，正文不伪造 sections；STRUCTURED 保留原生成器并适配为背景、任务、输出要求、约束条件、验收标准。旧独立待确认事项和示例要求完整保留。
- Plan 重新设计提问协议，支持零问题和完整题答，最多 64 题是容量而非凑题目标。服务端继续校验所有者、TTL、任务、模型、上下文及真实选项，历史保存权威题干。
- 首次资料与二次检索分别传入，旧资料按当前权限复核；权限收紧时不复用无法归属的聚合摘要。不新增凭据暴露或客户端模型密钥配置。
- 新增自然文本编辑接口和 SQL 版本比较，保存与复制保持同一实际正文；保留首次生成快照，保存失败保留草稿，同记录撤销也落库。
- V2 历史读取新旧结果，V1 列表在分页前排除非段落形态。未知生成版本和 V1 读取自然正文返回稳定的 RESULT_VERSION_UNSUPPORTED；逻辑删除与租户 / 工作区范围保持。
- V16 仅更新现有列的数据库注释，不回改 V1—V15，不重写历史。同步更新领域语言、README、待办与[实现说明](../development/独立自然增强与Plan链路.md)。

源文件及测试哈希见[代码快照](./evidence/natural-chain-2026-10-19/source-manifest.json)；脱敏测试汇总见[验证摘要](./evidence/natural-chain-2026-10-19/validation-summary.json)。会前已有的 AGENTS.md 修改保留，未计入本次代码改动。

## 3. 验证期间发现并处理的问题

- 五模块投影最初可能遗漏旧 CLARIFICATIONS，现保留在背景中的待确认事项；EXAMPLES 保留在输出要求。覆盖所有七类旧段落的回归检查每项内容保留一次。
- 发现自然历史可能存入客户端题干，现保存服务端绑定后的权威题答；不会在推理完成后重新消耗模型或伪造短期会话。
- 旧历史在 SQL 列表投影中缺失版本会变成 JSON null，现统一回退 LEGACY/1；实际旧格式记录已在真实数据库验证。未知版本先被拒绝，不按旧 DTO 解析其确认数据。
- 初轮新自然浏览器用例有 2 项定位器冲突：同一错误文案同时出现在全局提示和编辑器内。草稿实际保留，定位器收窄到编辑错误区域后，6 项完整复验通过。
- 新 MVC 流程最初按默认 ISO-8859-1 读取无 charset 的 JSON 响应，中文断言失败；测试改用 UTF-8，未改产品响应或放宽断言。
- 本机 JDK 21.0.12 的内部 selector pipe 遇到 AF_UNIX 回环连接错误，影响受控 HTTP 和 Redis Session 测试。依据本地 JDK 源码及[OpenJDK PipeImpl](https://raw.githubusercontent.com/openjdk/jdk21u/master/src/java.base/windows/classes/sun/nio/ch/PipeImpl.java)，仅在测试 JVM 中指定不存在的 socket 临时目录，使内部 pipe 回退 TCP；相关 HTTP 四项与真实 Redis / 数据库流程随后通过。未修改产品代码、系统全局配置或关闭 Redis / CSRF / 认证保护。

中间失败日志保留在本机 tmp/natural-chain-20261019；最终汇总只取各受影响测试类的最新结果，不删除历史失败，也不把工具问题归咎模型。

## 4. 复验入口

在 services/api 运行定向 Maven 测试，完整类名见验证摘要。涉及本机 HTTP / Redis 时，本机测试 JVM 使用：

    -DargLine=-Djdk.net.unixdomain.tmpdir=E:\MyProject\prompt-optimizer-platform\tmp\natural-chain-20261019\jdk-sockets

这是当前机器的测试参数；该目录须保持不存在以触发 JDK 的 TCP 回退，不是应用配置或普通部署前提。

在 apps/web 执行 npm run test、npm run build；浏览器涉及 e2e/natural-prompt.spec.ts、e2e/structured-prompt.spec.ts、e2e/history.spec.ts、e2e/prompt-copy.spec.ts、e2e/p0-workbench.spec.ts。已有认证 fixture 与真实模型测试脚本仅调整了 V2 路径，本次没有执行会消耗真实模型的 auth-real 用例。

本次未启动或重启日常前后端服务，测试进程由测试框架结束；本机验收使用源码和本机 PostgreSQL / Redis，没有 Docker。前后端投入使用时须一起更新至 V2，V16 注释迁移随正常前向迁移流程应用。
