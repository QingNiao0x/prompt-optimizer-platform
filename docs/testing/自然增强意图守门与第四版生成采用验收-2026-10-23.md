# 自然增强意图守门与第四版生成采用验收

本轮完成用户授权的“任务动作与成果要求混用、下游组件重复推断”修复，并通过优化提示词和实际作品对照决定局部采用。**新自然请求默认 NATURAL/31，本机9000已经应用；明确要求成果的写作沿用冻结第四版。** 目标缺陷已有可观察收益，不能据此宣称全部领域的增强质量、所有语义歧义或完整发布门禁均已通过。

证据集中在 [natural-guarded-fourth-2026-10-23](./evidence/natural-guarded-fourth-2026-10-23/)。先前192次的失败与未采用结论继续保留于[阶段报告](./自然增强动作与成果边界阶段验收-2026-10-23.md)，不追认为通过。

## 1. 根因与实际修改

用户截图使用 `NaturalEnhancementService → OpenAiCompatibleNaturalPromptProvider`，不经过旧链的 Mock、交付组装器或 `TaskIntentResolver`。因此，仅删除 Mock 中的“项目熟悉说明”不能修复运行中的自然增强。

旧链中，`TaskIntentResolver` 的当前写作动作与 `DraftDeliveryContract` 的交付推断原本各自判断。现由共享动作解析提供依据：否定、引用、既成动作和未来条件使用同一边界，模板画像不能独立授权写文档。该兼容修复已提交 `2f0d9807`，不是自然链的语义分类器，也不宣称有限规则能够理解所有语言。

自然链的共同问题是把“现在做什么”与“必须新增什么作品”放在一起补全，辅助范围记录仍会被后续写作重新解释。27—30的真实失败说明，仅增加禁止语或把范围当辅助材料不足以解决。本次31按以下职责分开处理：

1. **识别范围。** `NaturalTaskScope` 从完整原始提示词、授权材料、对话和全部实际题答识别当前动作、条件动作、背景描述，以及回应依据。来源引文须存在，当前及条件动作需要用户来源；这些检查只证明出处，不证明语义一定正确。
2. **没有独立成果要求时保留请求。** 未指定回应，或仅推定需要准备就绪反馈时，由 `NaturalPreservedRequest` 承载原请求、每份实际题答和已允许材料，不进入可能补造作品的写作阶段。只沿用既有请求边缘空白处理；用户条件、题答与材料正文不作同义重写。助手建议单独标注，不能升级为用户确认。
3. **明确成果时沿用原生成。** 调用冻结 `NATURAL/4` 的完整写作输入、system、响应协议及原有覆盖保护，不将范围协议混入写作提示词。范围阶段决定是否需要生成，不能把“有行动”自动推成“写一份文档”。自然模式仍可按实际缺口补全，并保留第四版的充分需求少改策略。
4. **Plan复用范围。** 先识别范围再判断重要未知；没有指定独立作品不成为追问下一任务的理由。生成仍使用全部真实题答，所有权、期限、来源与组装前后覆盖保护继续有效。

没有新增职业、题目或“熟悉项目”关键词分支。冻结第四版及旧历史继续按保存版本兼容；开启结构化提示词的旧链没有切到31。自然正文不自动增加此前用户取消的五条固定约束。

此外，树解析拒绝重复JSON键与尾随对象，防止后一个空 `questions` 覆盖真实问题；协议失败最多修复一次，不进行质量重试。来源存在与正文引文匹配仍不能当作语义质量保证。

## 2. 如何检验质量

先冻结31及对照协议，再开启新拟题。最终十题包含六道准备／理解类请求、四道明确成果正常变体。每题使用相同原始信息、材料、模型和参数生成4／31提示词，下游各执行两次，共40份实际作品；两次内部AI评审匿名比较、左右互换。具体模型及参数、原始传输、作品、实际来源检查均保留在证据目录。

这是一组**内部前瞻题**，不是完全独立外部专家留出。独立AI作者没有看到候选与旧结果，但开发者在任何生成和作品出现之前校准了材料完整性：移除背景中的预期行为提示、将不可读媒体转换为文本材料、补足合成原件，并更正一处评分顺序矛盾。原稿及修改清单保存在 [fixture-calibration.json](./evidence/natural-guarded-fourth-2026-10-23/heldout/fixture-calibration.json)。没有根据结果修改产品指导或为失败题增加禁令。

事前采用标准针对本次机制：至少三题提示词有具体收益、至少两题在两次实际作品中稳定减少错误／修改、正常成果不中断且不新增严重违约。充分需求允许持平，协议可靠性另行统计，不把HTTP成功或字数增加当作质量改善。

## 5. 采用结论与范围

本次以 **ADOPT_LOCAL_MECHANISM_WITH_RECORDED_LIMITS** 局部采用31，修复目标是减少无依据的新交付物、减少用户修改；明确成果的正文能力保留第四版，不能宣称普通写作全面超过第四版。

仍存在回应依据语义误分类、含糊“整理”是否要求成果的边界；原文承载路径带入材料较多时也可能偏长。本轮没有按个别措辞加分支，没有靠继续采样掩盖G02，也没有把原文完整保留称为实质扩写收益。完整G1—G8、跨模型与专业用户验收未完成。上述边界记录后收口，不自动开启历史待办。
