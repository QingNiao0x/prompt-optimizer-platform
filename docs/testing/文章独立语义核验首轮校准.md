# 文章独立语义核验首轮校准

首轮使用固定的原稿、成稿和人工标定结果回放核验协议。校准版 `text-polish-semantic-review-v1` 先应用现有硬检查，再把原稿和成稿按段编号交给独立核验方。返回的每项判断需带所在段和可唯一定位的逐字引文。跨段含义可由多处证据共同支持。

## 回放结果

| 题组 | 样本 | 工程回放结果 |
| --- | --- | --- |
| 已归档失败段 | v4 服务稿遗漏体验目的、同稿将「应在」改成「会在」、段落候选添加「自确认之日起」、通用候选自然稿倒置闹钟叙述顺序 | 4/4 保留语义差异 |
| 人工构造的不等义稿 | 数字不变但两个期限被换到错误动作、可能原因写成确认因果 | 2/2 保留语义差异 |
| 人工标定的等义稿 | 两个目的合并表达仍分别保留、跨段合并条件与期限、不同段落重复相同文字 | 3/3 通过工程核验 |
| 人工标定的争议稿 | 图纸交接中接收与归档责任原稿未明确 | 标记待核 |

锁定文字被改动或额外重复时沿用业务拒绝。缺少段落覆盖、引文无法定位、错误侧段号、同段重复而无有效定位及不合法 JSON 均无法获得通过结论。

18 项核验测试通过，文章及试用相关回归共 631 项通过。

## 验证边界

本批真实调用为 0。回放证明 Java 在收到已标定的判断后，能正确校验证据，并保留差异、不确定和证据不足等状态。段落覆盖只检查协议声明，模型仍可能漏列同段的独立目的或误判证据。真实校准需将原稿和成稿发送给待测核验模型，人工标定仅用于评分，分别记录漏检、误拒和无法判断。一篇稿有多个已知问题时，逐项核对问题是否命中。校准入口与工作台生成彼此独立。

在 `services/api` 目录运行回放。

```powershell
mvn -q "-Dtest=TextPolishSemanticReviewTest" test
```
