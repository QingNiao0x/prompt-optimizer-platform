## 实际简化

| 项目 | 修改 |
| --- | --- |
| 指令组织 | 将重复的意图、事实、来源及权限说明集中管理，增强和Plan各有完整、可直接阅读的指导，不再通过多层替换形成新指导 |
| 补全边界 | 可以完善原成果内部的内容与拟议做法，不另加交付义务；阅读等待与明确报告、复述、验证证据分别保留 |
| 增强协议 | 复用既有 `NaturalPromptPhasePayloads`；要求与 `bodyQuotes` 放在同一条记录，服务端产生原内部覆盖下标 |
| Plan协议 | 提问依据放在所属问题的 `decisionBasis` 中；服务端建立题号关联，不填写尚未生成的正文覆盖 |
| 框架 | 十二框架仍为可选参考；省略或无法识别的普通文本标签使用既有APE兼容标记，不声称模型已选中APE；非文本、超容量及敏感字段继续拒绝 |
| 保护 | 完整输入、真实题答、上下文边界、来源与最终正文引文继续校验；不接受跨阶段字段或任意诊断字段，不静默返回原文 |
