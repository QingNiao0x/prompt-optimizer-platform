## 二、时间序列分析（长期趋势 + 季节性）

### 2.1 长期趋势
**方法选择：**
- **年度粗死亡率（CMR）与标化死亡率（ASMR）** 计算
- **Joinpoint回归**（推荐）：识别趋势转折点，计算APC（年度变化百分比）和AAPC
  - 软件：Joinpoint Regression Program（NCI）
  - 模型：对数线性模型 $\ln(y) = \beta_0 + \beta_1 x$
- **灰色预测GM(1,1)** 或 **ARIMA** 用于趋势外推

**报告指标：**
- APC（95%CI）、AAPC（95%CI）
- 趋势检验：Z检验，P<0.05

### 2.2 季节性趋势
**方法选择：**
- **月度/季度死亡率** 计算
- **季节分解**：STL分解（趋势+季节+残差）
- **圆形分布法**：计算发病/死亡高峰日及角均数
- **X-13-ARIMA-SEATS**（美国普查局）或 **Cosinor分析**
- **季节指数**：$SI = \frac{\text{某月均值}}{\text{全年月均值}} \times 100\%$

**注意：** 心脑血管疾病冬季高发，需控制温度、流感等混杂因素。

## 三、分组比较分析

### 3.1 性别差异
- 男女ASMR比较，计算**率比（RR）** 及95%CI
- 趋势差异：Joinpoint平行性检验

### 3.2 地区差异
- 城乡/区域ASMR比较
- **空间分析**（可选）：Moran's I、热点分析（Getis-Ord Gi*）
- **集中指数（Concentration Index）** 衡量经济相关不平等

### 3.3 年龄/人群差异
- 年龄别死亡率曲线
- **年龄标化**后比较
- 重点关注35-64岁劳动力人群

### 3.4 亚类比较
- 各亚类构成比、ASMR趋势
- **竞争风险**视角：某亚类占比变化

**统计方法：**
- 率差检验：Poisson回归、负二项回归
- 率比：RR = ASMR₁/ASMR₂
- 趋势：Cochran-Armitage趋势检验

## 四、减寿分析（YLL & YLL率）

### 4.1 核心指标
- **YLL（潜在减寿年数）**：
$$YLL = \sum_{i} d_i \times (L - a_i)$$
其中 $d_i$ 为某年龄组死亡数，$L$ 为目标生存年龄（建议75岁或期望寿命），$a_i$ 为死亡年龄组中值

- **YLL率**：$YLL率 = \frac{YLL}{人口数} \times 1000‰$

- **AYLL（平均减寿年数）**：$AYLL = YLL / 死亡数$

### 4.2 分层计算
| 分层 | 输出 |
|------|------|
| 年度 | 2015-2025各年YLL、YLL率、AYLL |
| 性别 | 男/女分别计算 |
| 年龄组 | 各年龄组YLL贡献 |
| 亚类 | 各亚类YLL及构成比 |

### 4.3 趋势分析
- YLL率的Joinpoint回归
- 性别间YLL率差异检验

**软件：** Excel、R（`epitools`、`DALY`包）、SPSS

## 五、Arriaga分解方法

### 5.1 方法原理
Arriaga分解用于**量化各年龄组/死因对期望寿命差异的贡献**，将两组（如2015 vs 2025，或城乡）期望寿命差分解为：
- **直接效应**：某年龄组死亡率变化对期望寿命的贡献
- **间接效应**：存活人数变化带来的后续贡献
- **交互效应**

### 5.2 分解公式（简版）
$$\Delta e_0 = \sum_{i} \left[ \text{直接效应}_i + \text{间接效应}_i \right]$$

**直接效应：**
$$DE_i = \frac{l_i}{l_0} \times \left( \frac{L_i^{2}}{l_i^{2}} - \frac{L_i^{1}}{l_i^{1}} \right)$$

**间接效应：**
$$IE_i = \sum_{j>i} \frac{l_j^{1}}{l_0^{1}} \times \left( \frac{L_i^{2}}{l_i^{2}} - \frac{L_i^{1}}{l_i^{1}} \right) \times \frac{l_i^{2}}{l_i^{1}}$$

（具体公式参考 Arriaga 1984, *Population Index*）

### 5.3 应用场景
1. **时间维度**：2015 vs 2025年期望寿命差分解 → 各年龄组/死因贡献
2. **性别维度**：男女期望寿命差分解
3. **地区维度**：城乡期望寿命差分解
4. **亚类维度**：各心脑血管亚类对期望寿命变化的贡献

### 5.4 软件实现
- **R**：`DemoDecomp`包（`arriaga`函数）
- **Excel**：手工构建生命表后按公式计算
- **Stata**：`arriaga`命令

### 5.5 结果呈现
- 贡献值（年）及百分比
- 正贡献（死亡率下降延长寿命）vs 负贡献
- 分年龄组堆叠图

## 七、关键注意事项

1. **数据质量**：死因漏报、编码错误、人口基数准确性
2. **标化率**：必须报告95%CI
3. **多重比较**：Bonferroni校正
4. **混杂控制**：年龄、时期、队列（APC模型可选）
5. **敏感性分析**：不同标准人口、不同YLL目标年龄
6. **可视化**：趋势图、热力图、分解堆叠图、地图
