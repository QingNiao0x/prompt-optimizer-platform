## 背景
用户希望使用 Python 的 requests 库爬取网页标题。原始需求未给出目标网页地址、标题的交付形式，也未说明解析工具与异常处理约定。

## 任务
编写一段使用 requests 库爬取网页标题的 Python 代码。
- 接受一个或多个网页 URL 作为输入。
- 使用 requests 发起请求获取页面内容，并提取每个页面的 title 文本。
- 按 URL 顺序输出抓取到的标题。
- 对请求失败、页面无 title 标签、非 HTML 响应等情况作常规处理，单个 URL 失败不影响其余 URL 的抓取。
- 请求头、超时、编码解析等执行细节由执行者按常规做法补全。

## 输出
一段可直接运行的 Python 代码，包含使用 requests 库抓取网页标题的完整逻辑，并附带最简运行说明（如何传入 URL、如何查看结果）。

## 约束
- 必须使用 requests 库发起请求。
- 不得把猜测写成事实：目标地址、输出格式等未由用户确认的信息，按常规做法处理并说明其为默认处理方式。
- 不增加用户未要求的说明、报告或额外交付物。

平台强制约束（不得删除或弱化）：
- 明确区分已知事实、用户确认信息和必要假设，不得把猜测写成事实。

## 验收
- 代码使用 requests 库完成页面获取，并正确提取 title 文本。
- 多个 URL 时按输入顺序输出标题，单个 URL 失败不中断其余抓取。
- 代码可直接运行，运行说明与代码行为一致。
