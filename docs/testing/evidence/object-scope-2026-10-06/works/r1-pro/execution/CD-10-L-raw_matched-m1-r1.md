## 三、分优先级的律师复核问题

### 高优先级

1. **主文本选择**：两版租赁草稿中哪一份作为本次律师复核的主文本？当前暂不确定。未确定前，不得写最终合同摘要，只能保留并列差异清单。  
2. **复核优先侧重**：本次复核优先侧重持续履约还是可能提前退出？当前暂不确定。未选定前，不得把任一分支的专属约束扩散到另一分支。  
3. **押金差异**：草稿A为两个月租金，草稿B为三个月租金，邮件未确认。请核对两版原文、邮件往来及付款安排附件，确认是否存在后续确认文件；未确认前不得采用其中一项作为确定付款义务。  
4. **维修范围**：一版为承租方承担日常维护，另一版新增全部设施故障费用。请核对两版维修条款、设施清单及邮件，确认最终责任范围；不得把两版拼接为对承租方更不利的统一条款。  
5. **提前解约条款**：涉及通知形式、提前量和费用，可能存在条件关系。请逐项核对通知形式、提前量、费用及附加前提，不能仅取最短通知天数。  
6. **签署、送达、接受状态**：文档日期仅表示编辑时间。请核对是否存在签署页、邮件回执、送达凭证或其他接受证据；不得根据签名占位图认定已签署。  
7. **出租方权属与授权链**：给定材料未提供房屋权属和授权链证据。请请求补充核验，但不先判定出租方无权出租。  
8. **协商邮件定性**：邮件中“愿意再讨论”不等于接受草稿，也不等于拒绝履约。请保留条件、时间和发送角色，逐封核对，不把意向话语改为明确承诺。  
9. **示例判决标题**：往来附件引用的示例判决标题无核验出处。请核对判决原文、案号及出处；在核实前不得作为法院普遍立场或现行判例依据。

### 中优先级

1. **租金条款来源**：请逐条核对租金金额、支付周期、调整机制及对应附件；不得凭通行惯例补成合同事实。  
2. **押金退还条件**：请核对押金退还条件、扣减情形及时间节点；未签署材料不能直接产生确定付款义务。  
3. **维修费用分担边界**：请区分日常维护、设施故障、第三方原因等不同情形，核对各版对应条款。  
4. **解除通知形式**：请核对书面、邮件或其他通知形式是否被明确约定，以及通知送达地址和生效条件。  
5. **文档日期与编辑时间**：请列示各版文档日期，但不得将文件排序当成法律事实。  
6. **附件与主文对应关系**：请核对往来附件是否被主文引用、是否构成合同组成部分。  
7. **合成编号与匿名化**：请使用合成编号说明材料关系，复制后仍应保持匿名，不输出联系地址和身份证件内容。

### 低优先级

1. **排版与章节顺序**：常规排版顺序由编写者确定，无需提问。  
2. **材料相对路径**：可保留相对路径用于来源识别，不输出真实本机路径或敏感身份信息。  
3. **测试示例排除**：`layout-example.txt` 中的 CSV、Python、收入100万元、准确率99%等与本题无关，不进入事实清单。  
4. **内部核查记录**：采用的资料、排除的无关示例、尚缺证据和明确冲突仅作内部核查，不增加本题交付清单以外的交接摘要。
