## 一、研究方案主文

**研究问题** 本研究比较三种提示词整理条件对下游任务输出的影响：原始需求（A）、直接增强（B）、交互式计划确认增强（C），并设信息量匹配对照（D）。研究不评价任何产品的绝对优劣，只考察条件差异。交互式计划确认指系统先提问、实验操作者按预先制定答案卡作答，再生成最终提示词，不是静态任务分解列表。

**实验设计** 固定二十个任务，每个条件独立重复三次，共二百四十次运行。所有条件获取相同初始材料。A组接收原始需求与初始材料；B组接收由同一初始信息得到的优化提示词；A、B两组均不得接触C组后来回答的业务选择。C组在问答后生成最终提示词，并记录每个问题、选项、推荐依据和答案；错误推荐即使被答案纠正，仍计入交互阶段风险。D组获得与C组相同的已确认事实，但不经历问答过程，用于分离新增信息与交互组织方式的混淆。每次重复开启隔离会话，随机化运行顺序，记录模型版本、日期和参数；失败后的重试不得替代第一份失败样本。

**主要指标** 评价覆盖五个维度：需求保真、业务规则、输出可用性、阅读负担、执行边界。开发任务要求下游模型只输出方案，不实际修改仓库；写作任务要求交付文本。因此跨任务不以代码测试通过率作为统一质量指标。工具生成速度属过程指标，质量分为结果指标；无计费日志时不估算真实Token成本，不以字符数换算费用。评分由两名盲评者独立完成，评审仅见匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源，也不得查看另一名评审先前评分。

**统计方法选择流程** 候选方法取决于分数是否有序、是否连续、是否重复测量。方案先完成变量测量属性确认，再据此选择统计方法，不在变量尚未确定时锁定某一显著性检验。

**限制** 实验尚未运行，无准确率、显著性、成功案例数量或用户结论。任务材料保留真实实现、用户说明、测试示例与待办等来源标签，人工评分前不得删除不利的测试污染反例。三个模型结论相似不构成研究完成证据；专业领域判断尚需专家参与。交互式计划确认的最大轮次与终止规则、两名评审的分歧处理与一致性评价方式尚未决定，列入预注册待确认清单。

## 二、变量与分组附表

| 组别 | 接收信息 | 是否经历问答 | 是否可见已确认事实 | 关键约束 |
|---|---|---|---|---|
| A 原始需求 | 原始需求＋初始材料 | 否 | 否 | 不得接触C组业务选择 |
| B 直接增强 | 同一初始信息得到的优化提示词 | 否 | 否 | 不得接触C组业务选择 |
| C 计划确认增强 | 问答后生成的最终提示词 | 是 | 是（自身产生） | 记录问题、选项、推荐依据、答案；错误推荐计入交互风险 |
| D 信息量匹配对照 | 与C相同的已确认事实 | 否 | 是 | 不经历问答过程 |

**变量** 自变量：提示词整理条件（A/B/C/D）。因变量：需求保真、业务规则、输出可用性、阅读负担、执行边界。控制变量：任务集、初始材料、模型版本、参数、会话隔离、运行顺序随机化。过程指标：生成速度。结果指标：质量分。

**材料来源标签** 真实实现、用户说明、测试示例、待办，四类标签在评分前均保留。
