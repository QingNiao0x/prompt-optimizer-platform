# 合成医院门诊预约到诊与爽约内部运营分析方案

**分析对象**：某合成门诊二〇二六年第一季度预约事件
**资料基础**：合成汇总字典与流程材料；无真实患者信息，无完整逐条数据
**方案性质**：内部运营资料分析与写作方案，不涉及诊断、处方、分诊优先级、医嘱或个体治疗

| 患者去重 | 按患者标识去重后的人数；与预约事件数分列，不混同 | current-brief.md | 已明确 |

### 1.2 流程图说明（文字描述）

**预约事件状态流转（合成资料口径）**：

```
预约创建（渠道：电话/网页/窗口）
    │
    ├── 渠道变更（电话↔网页可能为同一预约的不同操作事件）
    │        └── 需记录首次渠道与变更渠道，不把操作次数当预约量
    │
    ├── 用户主动取消（记录取消时间，本地时区）
    │        └── 取消免责边界：旧24小时 vs 新12小时（争议并列，不采用任一）
    │
    ├── 到诊（ARRIVED）
    │
    └── 未到诊/状态未知（UNKNOWN）
             └── 原因未细分；可能为同步延迟、漏登记、记录缺项
             └── 观察窗口未确定前，只展示待核验事件，不计入爽约率
```

**渠道比较流程**：

```
预约事件 → 识别首次渠道 → 识别是否发生渠道变更
    │
    ├── 主统计单位未定：预约事件 或 去重患者（待确认）
    │
    └── 小渠道样本：保留数量并加限制说明；无完整数据不报告显著渠道差异
```

**爽约判定流程（当前不可执行完整版）**：

```
预约事件 → 到诊状态
    ├── ARRIVED → 到诊
    ├── CANCELLED → 核对取消时间与免责边界（边界争议未决）
    └── UNKNOWN → 待核验（观察窗口未定，不归为爽约）
```


## 二、流程问题清单

|---|---|---|---|
| 1 | 电话与网页可能记录相同一次预约的不同操作事件，操作次数不能当成预约量 | current-brief.md | 须先定义首次渠道和变更渠道；渠道比较主统计单位待确认 |
| 2 | 取消免责边界存在争议：旧流程提前24小时不计爽约；新会议草稿建议提前12小时，尚未批准 | legacy-note.md | 差异并列呈现，不擅自采用其中一项 |
| 3 | 观察窗口未确定，预约事件何时可归为最终状态不明 | 用户确认 | 待确认；窗口未定前只展示待核验事件 |
| 4 | UNKNOWN 状态原因未细分，可能来自设备同步延迟、现场漏登记或记录缺项 | current-brief.md | 不得解释为患者责任，不得直接计为爽约 |
| 5 | 当前汇总表没有时区转换证据 | current-brief.md | 分析不引入时区换算；如需跨时区比较须先补充证据 |
| 6 | 小渠道样本量较少时百分比波动大 | current-brief.md | 保留数量并加限制说明；无完整数据不报告显著渠道差异 |
| 7 | 取消行为不能附加临床解释 | current-brief.md | 报告不将取消与病情、疗效关联 |
| 8 | 医生代码仅为流程角色示例，非个人绩效评估范围 | current-brief.md | 不追加医生排行榜或个体能力评价 |
| 9 | 科室类型可能影响预约提前量和到诊行为，但本题材料只有一个门诊 | current-brief.md | 不推断跨科室、跨医院或全市表现 |
| 10 | 拟议采集表实施前需合规评估 | current-brief.md | 仅作建议，不写成已建表或已获授权 |
| 11 | 改进建议不得默认采取罚款、降低预约资格或公开患者记录 | current-brief.md | 优先考虑清楚提示取消规则、核对登记质量与便捷改约 |
| 12 | 短信提醒方案需另行确认通知授权和退订流程 | current-brief.md | 本次不扩成发送短信的实施任务 |


## 三、拟议数据采集表（合成数据采集字段建议）

> 以下仅为建议字段，未声称已建表或已获授权；实施前需合规评估。

| 字段名 | 类型 | 说明 | 必要性 |
|---|---|---|---|
| 预约事件编号 | 文本/去标识化 | 唯一标识一次预约 | 必需 |
| 患者去标识化编号 | 文本/去标识化 | 用于去重计数，不含可识别信息 | 必需 |

| 渠道变更记录 | 文本/枚举 | 记录是否发生渠道变更及变更前后渠道 | 建议 |
| 预约创建时间 | 日期时间（本地时区） | 预约事件创建时间 | 建议 |
| 就诊时间 | 日期时间（本地时区） | 预约的就诊时间 | 必需 |
| 到诊状态 | 枚举：ARRIVED/CANCELLED/UNKNOWN | 当前记录状态 | 必需 |
| 状态更新时间 | 日期时间（本地时区） | 状态最后更新时间，用于观察窗口判定 | 建议 |
| 取消时间 | 日期时间（本地时区，可空） | 仅 CANCELLED 状态填写 | 条件必需 |
| 来源系统 | 文本 | 记录来源系统，便于核对同步延迟或漏登记 | 建议 |

**字段边界**：不包含患者姓名、身份证号、联系方式、住址等可识别信息；不包含诊断、处方、医嘱、检查结果等敏感诊疗明细。
