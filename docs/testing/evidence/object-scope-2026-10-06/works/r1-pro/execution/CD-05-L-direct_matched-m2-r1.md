# 提示词整理工具对照研究方案

## 1 研究方案主文

**研究问题**  
本方案比较三种提示词准备方式对下游任务输出质量的影响：原始需求直接输入、基于同一初始信息的直接增强、以及交互式计划确认增强。核心问题为：交互式计划确认是否在需求保真、业务规则、输出可用性、阅读负担和执行边界五个维度上带来可归因的改进；若存在改进，其来源是新增已确认信息本身，还是交互式组织方式。研究不评价任何产品绝对优劣。

**实验设计**  
采用二十个任务，每个条件独立重复三次，共二百四十份下游输出。四个条件分别为：原始组、直接增强组、计划确认组、信息量匹配对照组。原始组接收原始需求与初始材料；直接增强组接收由同一初始信息生成的优化提示词；计划确认组经历系统提问、实验操作者按预先制定答案卡作答后生成最终提示词；信息量匹配对照组获得与计划确认组相同的已确认事实，但不经历问答过程。原始组与直接增强组均不得接触计划确认组后续回答的业务选择。信息量匹配对照用于分离新增信息与交互组织方式的效应。

每个条件的三次重复开启隔离会话，随机化顺序，记录模型版本、日期和参数。失败后的重试不替代第一份失败样本。任务材料保留真实实现、用户说明、测试示例与待办来源标签，评分前不人为删除不利反例。开发任务要求下游模型只输出方案，不实际修改仓库；写作任务要求交付文本，跨任务不采用代码测试通过率作为统一质量指标。

**主要指标**  
结果指标为两名盲评者在五个维度上的质量评分。过程指标仅记录工具生成速度，不估算 Token 成本。评分表记录主错误与关联维度，避免同一问题重复计为独立失败。盲评材料匿名化，不展示产品名称、标志和生成来源；评审可查看任务事实，但不能查看另一名评审的先前评分。

**统计方法选择流程**  
候选统计方法取决于评分是否有序、是否连续及是否重复测量。待评分工具与数据分布确定后，按以下顺序选择：先判断评分尺度性质，再判断重复测量结构，最后选择相应模型。方案不在此阶段锁定任何显著性检验。

**限制**  
实验尚未运行，无准确率、显著性、成功案例数量或用户结论。专业领域判断尚需专家参与，人工评阅与可复核任务标准为必要安排。交互式计划确认的最大轮次与终止规则、两名评审的分歧处理与一致性评价方式尚未确定，须在预注册阶段明确后方可执行相应流程。

## 2 变量与分组附表

| 变量 | 类型 | 取值/定义 | 记录方式 |
|---|---|---|---|
| 提示词准备方式 | 自变量 | 原始、直接增强、计划确认、信息量匹配对照 | 分组记录 |
| 任务编号 | 控制变量 | 1–20 | 任务清单 |
| 重复次数 | 控制变量 | 每条件每任务 3 次 | 隔离会话记录 |
| 模型版本 | 控制变量 | 执行时记录 | 会话日志 |
| 执行日期与参数 | 控制变量 | 执行时记录 | 会话日志 |
| 需求保真评分 | 因变量 | 盲评量表分 | 评分表 |
| 业务规则评分 | 因变量 | 盲评量表分 | 评分表 |
| 输出可用性评分 | 因变量 | 盲评量表分 | 评分表 |
| 阅读负担评分 | 因变量 | 盲评量表分 | 评分表 |
| 执行边界评分 | 因变量 | 盲评量表分 | 评分表 |
| 工具生成速度 | 过程指标 | 秒 | 执行日志 |
| 交互阶段风险 | 过程记录 | 错误推荐被答案纠正的次数 | 计划确认组记录表 |

**分组说明**  
- 原始组：原始需求与初始材料，不附加优化。  
- 直接增强组：同一初始信息生成的优化提示词。  
- 计划确认组：系统提问，操作者按答案卡作答后生成最终提示词；记录每个问题、选项、推荐依据和答案。  
- 信息量匹配对照组：获得与计划确认组相同的已确认事实，但不经历问答过程。具体呈现格式尚未选定，执行前需确定。
