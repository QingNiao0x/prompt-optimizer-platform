# 商业租赁往来材料复核备忘录（承租方视角·合成示例）

**性质与限制**：本备忘录为资料整理与问题清单草稿，不是法律意见，不构成对任何一方权利义务的结论。适用地点为合成项目所在中国大陆甲市，具体法律适用与条款效力须由执业律师核验。全部主体、地址、金额、编号均为合成示例。合同草稿未签署，往来邮件仅为协商材料，不得视为已生效协议。本备忘录不输出具体条文编号、现行效力判断、赔偿数额或胜诉概率，不承诺诉讼、律师函或执行催告。

**读者与用途**：供承办律师在核验真实材料前，快速定位矛盾点、缺失证据与需核实条款范围。

## 三、分优先级的律师复核问题

**风险级别含义**：高、中、低代表律师核查优先顺序，不是系统计算的违法概率。高优先项因直接影响承租方资金安排、责任范围或退出条件，故优先核查。

### 高优先级

| 序号 | 复核问题 | 影响目标 | 所需证据/输入 | 边界 |
|---|---|---|---|---|
| H1 | 押金应为两个月还是三个月租金？邮件是否确认？ | 直接影响承租方资金安排 | 两版草稿原文、邮件原文及发送角色与时间 | 未签署不产生确定付款义务；不擅自采用其中一项 |
| H2 | 维修范围两版差异如何对应到草稿A/B？ | 影响责任范围与费用承担 | 两版草稿完整文本、版本标识 | 版本对应待核实；不得拼接为统一规则 |
| H3 | 提前解约条款的通知形式、提前量、费用各自条件关系为何？ | 影响退出安排与成本 | 两版草稿解除条款全文 | 不得仅取最短通知天数而删附加前提 |
| H4 | 租金条款来源与两版差异为何？ | 影响持续履约成本 | 两版草稿租金条款、邮件 | 须逐条核对来源，不凭惯例补全 |

### 中优先级

## 四、明确限制的备忘录草稿

**结论（仅说明材料充分程度与后续核验事项）**：

1. 现有材料可支持制作并列差异清单与复核问题清单，但不足以形成最终合同摘要。
2. 押金、维修范围、租金、提前解约条款均存在版本差异或来源待核，须由律师逐条核对。
3. 房屋权属与授权链证据缺失，可请求核验，但不先判定出租方无权出租。
4. 协商邮件须保留条件、时间与发送角色，不自动解释为承诺或违约。
5. 示例判决标题仅作待核资料，不作为法院普遍立场或现行判例依据。

**明确不做**：

- 不输出具体条文编号、现行效力或确定的法律结论（未核实法律来源时）。
- 不根据签名占位图认定已经签署，不把协商邮件自动解释为承诺或违约。
- 仅给律师复核问题与材料索引，不承诺执行诉讼、发送律师函或替代专业判断。
- 不追加发送律师函、公开争议或执行催告。
- 不评价某方一定胜诉或一定违法。

**三种状态区分**：

- 已有充分依据可直接使用：S1 口径规则、S2 押金差异记录、S3 已排除。
- 仅作为候选建议需选择：主文本选择、复核侧重选择（均未决）。
- 因缺少关键资料暂不能执行：最终合同摘要、权属与授权链结论、解除条款统一规则。

**后续执行者须知**：可先开始的工作为整理两版草稿全文与邮件原文、建立可追溯位置索引；必须等待确认的工作为主文本选择与复核侧重选择。
