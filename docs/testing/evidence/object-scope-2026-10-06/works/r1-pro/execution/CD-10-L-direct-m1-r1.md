# 合成商业租赁材料律师复核备忘录（草稿）

**性质**：资料整理与文书草稿，非法律意见；不构成对任何真实当事人的结论。
**视角**：承租方。
**适用地点**：合成项目所在中国大陆甲市；具体法律适用与条款效力须由执业律师核验。
**风险级别含义**：高/中/低仅代表律师核查优先顺序，不是违法概率或胜诉判断。
**合成与匿名边界**：材料中主体、地址、金额均为合成示例；本备忘录不输出真实当事人信息、联系地址或身份证件内容。

## 五、明确限制的备忘录草稿

**结论范围**：本备忘录仅说明材料充分程度和后续核验事项，不评价任何一方一定胜诉或一定违法；如需法律适用，由律师按真实事实与现行依据另行处理。

**可以开始的工作**：
- 按本备忘录材料对应表、事实与证据来源表、两版条款差异表，逐项核对来源。
- 对已记录的事实条目进行索引和补充标注。
- 对高优先级问题准备核验清单。

**必须等待确认的工作**：
- 确定两版租赁草稿中哪一份是本次律师复核的主文本。
- 确定复核优先侧重持续履约还是可能提前退出。
- 对押金两个月与三个月差异，等待律师核验，不擅自采用其中一项。
- 对维修条款一版／另一版与草稿B／草稿A的对应关系，等待补充依据，不按材料顺序绑定版本，不拼接为统一规则。
- 对解除条款的通知形式、提前量和费用，等待逐项核验，不取最短通知天数而删掉附加前提。
- 对房屋权属和授权链证据，等待补充材料，不推断出租方有完整处置权，也不先判定其无权出租。

**明确不做**：
- 不生成起诉状、法条引文、赔偿数额或胜诉概率。
- 不承诺执行诉讼、发送律师函或替代专业判断。
- 不把合同草稿当作双方已生效的协议。
- 不把协商邮件自动解释为承诺或违约。
- 不根据签名占位图认定已经签署。
- 不输入或输出真实当事人敏感信息、联系地址和身份证件内容。
- 不查询真实个人信息、不发送外部消息、不执行数据更改、不替用户进行生产发布。
- 不读取或输出受保护路径：`.env`、`**/*.pem`、`**/*.key`、生产环境配置。

**未解决的关键条件**：
1. 主文本未确定：两版租赁草稿中哪一份是本次律师复核的主文本，当前尚未决定。
2. 复核方向未确定：优先侧重持续履约还是可能提前退出，当前尚未决定。
3. 押金差异未解决：草稿A两个月租金与草稿B三个月租金，邮件未确认，须律师核验。
4. 维修条款版本对应未建立：一版／另一版内容已有依据，但与草稿B／草稿A的完整对应关系未建立，标注“版本对应待核实”。
5. 解除条款条件关系未核验：通知形式、提前量和费用可能存在条件关系，须逐项核验。
6. 权属与授权链证据缺失：给定材料没有房屋权属和授权链证据，须请求核验。
7. 租金具体值缺失：材料未提供具体金额、支付周期和调整条件，保持空值。
8. 示例判决标题无可核验出处：只能作为待核资料，不能作为法院普遍立场或现行判例依据。

**状态区分**：
- 已有充分依据可以直接使用：材料对应表、事实与证据来源表中已确认条目、两版条款差异表中已记录内容。
- 仅作为候选建议需要选择：主文本选择、复核方向选择。
- 因缺少关键资料暂不能执行：押金差异采用、维修版本对应、解除条款条件核验、权属授权链核验、租金具体值核对、示例判决出处核验。

**逆向核对记录**：本备忘录每个关键结论均回连至 `current-brief.md`、`legacy-note.md` 或执行前须确认事项；测试例子已排除；未加入真实当事人信息；未输出法条编号、赔偿数额或胜诉概率；未承诺诉讼、律师函或催告操作。
