**标题一：把模糊需求说清楚：清笺启动受控内测招募**
**标题二：清笺内测招募：面向开发者、研究生与办公人员**

清笺即日起启动受控内测招募，开放时间为2026年10月20日。本次内测旨在收集真实工作与学习场景中的使用反馈，帮助团队检验产品在需求澄清、资料关联和结构化结果方面的实际表现。需要说明的是，清笺目前处于本地MVP阶段，属于受控内测，并非正式商业上线，也不直接执行代码或替用户完成正式报告。

清笺主要面向开发者、研究生和普通办公人员三类用户。开发者可借助它整理功能需求与兼容条件；研究生可用它澄清研究材料与方法前提；办公人员则能通过它组织报告要求。产品关注的是把模糊、零散的需求转化为更清晰的提示词，而不是替代用户完成下游工作。

在需求澄清方面，清笺会针对真正影响任务的缺口提出问题。若用户提供的信息已经完整，系统不会强制追问。在资料关联方面，用户主动提供材料后，系统会选取相关片段作为参考，不会自动读取用户电脑、长期存储整份源码，也不承诺识别所有文件且无遗漏。在结构化结果方面，清笺输出的提示词可以编辑、复制，并交给其他AI工具使用，但这不代表AI已经完成开发、论文或其他正式成果。

本次内测不承诺生成论文、诊断疾病、提供投资收益或自动部署系统，也不对各类用户保证同样的专业准确率。内测资料与输出结果仍需使用者自行核查。我们希望通过真实场景中的反馈，了解清笺在需求整理环节的可用性与边界。

欢迎开发者、研究生和办公人员关注内测页面，并在页面内提交意见。反馈方式仅限内测页面提交，不提供手机号、邮箱或外部链接。
