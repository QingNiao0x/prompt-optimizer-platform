# 提示词整理工具对照研究方案

## 一、研究方案主文

**研究问题。** 本研究比较三种提示词整理条件对下游任务输出的影响：原始需求（A组）、直接增强（B组）、交互式计划确认增强（C组）。研究不评价任何产品的绝对优劣，只考察条件差异。交互式计划确认指系统先提问、实验操作者按预先制定答案卡作答，再生成最终提示词，不是静态任务分解列表。

**实验设计。** 固定二十个任务，每个条件独立重复三次，共180次运行。每次运行开启隔离会话，随机化运行顺序，记录模型版本、日期和参数。失败后的重试不能替代第一份失败样本，首轮失败样本必须保留。A组接收原始需求与初始材料；B组接收由同一初始信息得到的优化提示词；A、B两组均不得接触C组后来回答的业务选择。C组在生成最终提示词前经历问答，须记录每个问题、选项、推荐依据和答案，错误推荐被答案纠正后仍计入交互阶段风险。

**公平比较条件。** C组因问答额外获得已确认事实，其收益不能直接归因于模型能力。因此另设信息量匹配对照（D组）：D组获得与C组相同的已确认事实，但不经历本平台问答过程，用于分离新增信息与交互组织方式的混淆。A、B两组与C、D两组的信息条件不同，比较时须分别说明。

**主要指标。** 评价同时覆盖五个维度：需求保真、业务规则、输出可用性、阅读负担、执行边界。开发任务要求下游模型只输出方案，不实际修改仓库；写作任务要求交付文本。跨任务不能用代码测试通过率作为统一质量指标。工具生成速度是过程指标，质量分是结果指标；没有计费日志时不估算真实Token成本，不把字符数换算成实际费用。

**盲评。** 两名盲评者独立评分，看到匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源；可看任务事实，但不得看另一名评审先前评分。评分表须记录主错误和关联维度，避免同一问题多次计成不同独立失败。

**限制。** 实验尚未运行，无准确率、显著性、成功案例数量或用户结论。即使三个模型给出相似结论也不是研究完成证据，须安排人工评阅与可复核任务标准；专业领域判断尚需专家参与。候选统计方法依赖分数是否有序、是否连续和是否重复测量，方案只说明选择流程，不锁定显著性检验。任务材料保留真实实现、用户说明、测试示例与待办来源标签，人工评分前不得删除不利的测试污染反例。

## 二、变量与分组附表

| 组别 | 接收信息 | 是否经历问答 | 用途 |
|---|---|---|---|
| A 原始需求 | 原始需求+初始材料 | 否 | 基线 |
| B 直接增强 | 同一初始信息得到的优化提示词 | 否 | 增强效果 |
| C 计划确认 | 问答后生成的最终提示词 | 是 | 交互增强 |
| D 信息量匹配 | 与C相同的已确认事实 | 否 | 分离信息与交互 |

**答案卡记录字段：** 问题编号、问题文本、选项、推荐依据、实验操作者答案、是否纠正错误推荐、交互阶段风险标记。

**运行记录字段：** 任务编号、条件、重复序号、会话隔离标识、随机化顺序、模型版本、日期、参数、首轮输出、是否失败、重试记录（不替代首轮）。

**材料目录：** 真实实现、用户说明、测试示例、待办四类来源标签分别标注；测试污染反例保留原样。
