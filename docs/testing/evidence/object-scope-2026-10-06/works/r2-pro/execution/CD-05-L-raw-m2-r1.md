# 提示词整理工具对照研究方案

## 1. 研究问题

本研究考察提示词整理工具在三种输入条件下对下游任务输出质量的影响：原始需求直接使用、经工具直接增强、经交互式计划确认后增强。核心问题不是“哪家产品更好”，而是：在初始信息相同的公平前提下，交互式计划确认带来的新增信息与交互组织方式各自贡献了什么。

## 2. 实验设计

采用单因素三水平被试内设计，固定二十个任务，每个条件独立重复三次，共一百八十次下游生成。条件如下：

- **原始组**：下游模型直接接收原始需求与初始材料。
- **直接增强组**：下游模型接收由同一初始信息经工具生成的优化提示词，不经历问答。
- **计划确认组**：工具先提问，实验操作者按预先制定的答案卡作答，工具再生成最终提示词；记录每个问题、选项、推荐依据和答案。
- **信息量匹配对照**：不经历问答，但获得与计划确认组相同的已确认事实，以分离“新增信息”与“交互组织方式”的效应。

原始组与直接增强组不得接触计划确认组后续回答的业务选择。每个条件的三次重复开启隔离会话，随机化顺序，记录模型版本、日期和参数。失败后的重试不替代第一份失败样本。

## 3. 材料与任务

二十个任务覆盖开发方案类与写作交付类。开发任务要求下游模型只输出方案、不实际修改仓库；写作任务要求交付文本。因此跨任务不采用代码测试通过率作为统一质量指标。任务材料保留真实实现、用户说明、测试示例与待办等来源标签，不在人工评分前删除不利的测试污染反例。

## 4. 盲评与指标

两名盲评者独立评分，看到匿名化下游输出和等量任务信息，不展示工具名称、标志和生成来源；可查看任务事实，但不能查看另一名评审的先前评分。评分覆盖五个维度：需求保真、业务规则、输出可用性、阅读负担、执行边界。一个错误可能同时影响多个维度，评分表记录主错误和关联维度，避免同一问题重复计为独立失败。

工具生成速度作为过程指标单独记录，质量分为结果指标。无计费日志时不估算真实 Token 成本，不以字符数换算费用。

## 5. 统计与限制

统计方法的选择取决于分数是否有序、是否连续及是否重复测量，方案仅规定选择流程，不预先锁定显著性检验。即使三个条件结果相似，也不构成研究完成证据；需安排人工评阅与可复核任务标准，专业领域判断尚需专家参与。

本方案尚未执行，不含准确率、显著性、成功案例数量或用户结论。

| 原始组 | 相同 | 无 | 无 | 原始需求+初始材料 |
| 直接增强组 | 相同 | 无 | 无 | 工具优化提示词 |
| 计划确认组 | 相同 | 有，按答案卡 | 有 | 问答后生成的最终提示词 |
