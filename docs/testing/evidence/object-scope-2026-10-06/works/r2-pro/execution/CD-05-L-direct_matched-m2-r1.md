# 提示词整理工具对照研究方案

## 1. 研究方案主文

### 1.1 研究问题

本研究比较三种提示词整理条件对下游任务输出的影响：原始组接收原始需求与初始材料；直接增强组接收基于同一初始信息生成的优化提示词；计划确认组接收交互式计划确认增强后的提示词，并记录每个问题、选项、推荐依据和答案。研究不评价任何产品绝对优劣，仅考察不同整理方式对输出质量的影响。

由于计划确认组会额外获得实验操作者按预先制定答案卡提供的业务选择，本研究另设信息量匹配对照组：该组获得与计划确认组相同的已确认事实，但不经历问答过程。该设计用于区分“新增信息”与“交互组织方式”各自的影响，避免将多获得答案带来的收益误判为单纯模型能力。

### 1.2 实验设计

固定设计为二十个任务，每个条件独立重复三次，共六十个有效样本。每个条件的重复开启隔离会话，随机化顺序，并记录模型版本、日期和参数。失败后的重试不能替代第一份失败样本；首轮失败样本保留并记录失败原因。

任务材料保留真实实现、用户说明、测试示例与待办四种来源标签。不得在人工评分前人为删除不利的测试污染反例。原始组和直接增强组均不得接触计划确认组后来回答的业务选择；信息量匹配对照组仅获得已确认事实的书面整理，不经历问答交互。

计划确认组记录每个问题、选项、推荐依据和答案，不只保存最终提示词。错误推荐被答案纠正后仍计入交互阶段风险记录。

### 1.3 主要指标

结果指标为质量分，由两名盲评者独立评分。评分维度覆盖需求保真、业务规则、输出可用性、阅读负担和执行边界。评分表记录主错误和关联维度，同一问题不重复计为多个独立失败。过程指标为工具生成速度，单独记录，不纳入质量分。无计费日志时不估算真实 Token 成本，不以字符数换算实际费用。

盲评材料为匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源。评审可查看任务事实，但不能查看另一名评审的先前评分。

### 1.4 限制

实验尚未运行，无准确率、显著性、成功案例数量或用户结论。候选统计方法依赖分数是否有序、是否连续和是否重复测量，方案仅说明选择流程，不在变量未确定时锁定显著性检验。即使三个条件给出相似结论也不构成研究完成证据；人工评阅与可复核任务标准为必要环节，专业领域判断尚需专家参与。

交互式计划确认的最大轮次和终止规则尚未确定；两名评审的分歧处理与一致性评价方式尚未确定。两者均列入预注册待确认清单，未决前不默认补全。
