# 提示词整理工具对照研究方案（主文）

## 一、研究问题与目标

本研究比较三种提示词整理条件对下游任务输出的影响：原始需求（A组）、直接增强（B组）、交互式计划确认增强（C组），并增设信息量匹配对照（D组）。目标不是评价某家产品绝对优劣，而是分离“新增已确认信息”与“交互组织方式”两类效应。所有工具获得相同初始材料；A、B两组不得接触C组后续回答的业务选择。

## 二、设计

固定二十个任务，每条件独立重复三次，共240次运行。每次开启隔离会话，随机化运行顺序，记录模型版本、日期与参数。失败后的重试不得替代第一份失败样本，首轮失败与工具失败均保留。

C组按预先制定答案卡进行问答：系统先提问，实验操作者按答案卡作答，再生成最终提示词。须记录每个问题、选项、推荐依据和答案；错误推荐被答案纠正后仍计入交互阶段风险。D组获得与C组相同的已确认事实，但不经历本平台问答过程，用于减少“新增信息”与“交互组织方式”的混淆。

任务材料保留真实实现、用户说明、测试示例与待办四类来源标签；人工评分前不得删除不利的测试污染反例。开发任务只要求下游模型输出方案，不实际修改仓库；写作任务交付文本。因此跨任务不以代码测试通过率作为统一质量指标。

## 三、主要指标

评价覆盖五个维度：需求保真、业务规则、输出可用性、阅读负担、执行边界。两名盲评者独立评分，看到匿名化下游输出和等量任务信息，不展示产品名称、标志与生成来源，也不查看另一名评审先前评分。一个错误可同时影响多个维度，评分表记录主错误与关联维度，避免同一问题重复计为独立失败。

工具生成速度是过程指标，质量分是结果指标。没有计费日志时不估算真实Token成本，不把字符数直接换算为费用。

## 四、统计与限制

候选统计方法取决于分数是否有序、连续及是否重复测量；本方案只说明选择流程，不在变量未定时锁定显著性检验。三个模型给出相似结论不构成研究完成证据，须安排人工评阅与可复核任务标准；专业领域判断尚需专家参与。实验尚未运行，本方案不报告准确率、显著性、成功案例数量或用户结论。

## 五、待确认事项

1. C组最大轮次与终止规则：暂不确定，不指定3轮或5轮，不把建议写成已确认参数。
2. 两名盲评者分歧处理与一致性评价：暂不确定，不预设平均、共识或第三评审。

上述两项影响执行与统计流程，须在预注册中明确后方可运行。
