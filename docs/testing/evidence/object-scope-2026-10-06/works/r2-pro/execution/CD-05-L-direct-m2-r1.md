# 提示词整理工具对照研究方案

## 1. 研究方案主文

**研究问题**

本研究比较三种提示词整理条件对下游任务输出的影响：原始组接收原始需求与初始材料；直接增强组接收基于同一初始信息生成的优化提示词；计划确认组接收交互式计划确认增强后的提示词，并记录每个问题、选项、推荐依据和答案。研究不评价任何产品绝对优劣，只考察条件间差异。

**实验设计**

采用二十个任务、每个条件独立重复三次、两名盲评者独立评分的固定设计。所有工具获取相同初始材料。每个条件的三次重复开启隔离会话，随机化顺序并记录模型版本、日期和参数；失败后的重试不能替代第一份失败样本。

关键公平比较设置：计划确认组会额外得到答案，因此另设信息量匹配对照组，该组获得相同已确认事实但不经历本平台问答过程，用于区分新增信息与交互组织方式各自的影响。原始组和直接增强组均不得接触计划确认组后来回答的业务选择。

任务材料保留真实实现、用户说明、测试示例与待办来源标签；不在人工评分前人为删除不利的测试污染反例。开发任务要求下游模型只输出方案，不实际修改仓库；写作任务要求交付文本，因此跨任务不使用代码测试通过率作为统一质量指标。

**主要指标**

结果指标为质量分，由两名盲评者按统一评分表独立评定，覆盖需求保真、业务规则、输出可用性、阅读负担和执行边界五个维度。过程指标为工具生成速度，单独记录，不并入质量分。没有计费日志时不估算真实 Token 成本，不把字符数换算为实际费用。

**统计方法选择流程**

候选统计方法依赖分数是否有序、是否连续、是否重复测量。方案不预先锁定某个显著性检验；待评分工具和维度定义确定后，按以下流程选择：先判断各维度分数为有序分类还是连续值，再确认是否同一任务在多个条件下重复测量，据此在相应非参数或混合效应方法中选择，并在预注册中写明。

**限制**

实验尚未运行，无准确率、显著性、成功案例数量和用户结论。即使三个条件给出相似结论也不构成研究完成证据；方案安排人工评阅与可复核任务标准，专业领域判断尚需专家参与。盲评不得暴露工具名称、标志和生成来源。两名评审的分歧处理与一致性评价方式尚未决定，需在预注册阶段明确。交互式计划确认的最大轮次和终止规则尚未决定，需在预注册时明确，否则无法确定交互阶段何时结束及失败样本如何界定。

## 2. 变量与分组附表

| 变量 | 类型 | 取值/状态 | 说明 |
|---|---|---|---|
| 提示词整理条件 | 自变量 | 原始组 / 直接增强组 / 计划确认组 / 信息量匹配对照组 | 计划确认组经历交互问答；信息量匹配对照组获得相同已确认事实但不经历问答过程 |
| 任务 | 控制变量 | 二十个固定任务 | 所有条件使用相同任务 |
| 重复次数 | 控制变量 | 每条件三次独立重复 | 隔离会话，随机化顺序 |
| 模型版本 | 记录变量 | 文本 | 每次会话记录 |
| 日期 | 记录变量 | 日期 | 每次会话记录 |
| 参数 | 记录变量 | 文本 | 每次会话记录 |
| 首轮失败 | 记录变量 | 是/否 | 失败后的重试不能替代第一份失败样本 |
| 工具生成速度 | 过程指标 | 秒 | 单独记录，不并入质量分 |
| 质量分 | 结果指标 | 按评分表各维度计分 | 两名盲评者独立评分 |
| 需求保真 | 评分维度 | 分值待定 | 见评分表 |
| 业务规则 | 评分维度 | 分值待定 | 见评分表 |
| 输出可用性 | 评分维度 | 分值待定 | 见评分表 |
| 阅读负担 | 评分维度 | 分值待定 | 见评分表 |
| 执行边界 | 评分维度 | 分值待定 | 见评分表 |
| 主错误 | 记录变量 | 文本 | 每个主错误记录关联维度 |
| 关联维度 | 记录变量 | 多选 | 同一主错误可关联多个维度，避免重复计分 |
| 交互问题 | 记录变量 | 文本 | 仅计划确认组记录 |
| 选项 | 记录变量 | 文本 | 仅计划确认组记录 |
| 推荐依据 | 记录变量 | 文本 | 仅计划确认组记录 |
| 答案 | 记录变量 | 文本 | 仅计划确认组记录 |
| 错误推荐被纠正 | 记录变量 | 是/否 | 仅计划确认组；纠正后仍计入交互阶段风险 |

**分组信息对照**

| 组别 | 接收内容 | 是否经历问答过程 | 是否获得确认答案 |
|---|---|---|---|
| 原始组 | 原始需求与初始材料 | 否 | 否 |
| 直接增强组 | 基于同一初始信息的优化提示词 | 否 | 否 |
| 计划确认组 | 交互式计划确认增强后的提示词 | 是 | 是 |
| 信息量匹配对照组 | 相同已确认事实整理后的提示词 | 否 | 是 |

## 3. 评分表及失败记录模板

**评分表**

| 维度 | 定义 | 评分范围 | 评分说明 |
|---|---|---|---|
| 需求保真 | 输出是否忠实反映原始需求，未擅自增删或改变已明确要求 | 待定（有序或连续，预注册时确定） | 偏离原始需求记为主错误 |
| 业务规则 | 输出是否遵守任务材料中给定的业务规则和约束 | 待定 | 违反规则记为主错误 |
| 输出可用性 | 输出是否可直接用于下游任务，格式和内容满足任务要求 | 待定 | 不可用记为主错误 |
| 阅读负担 | 输出是否冗余、混乱或过度冗长，影响理解和使用 | 待定 | 明显冗余或结构混乱记为主错误 |
| 执行边界 | 输出是否明确区分可执行操作与只读边界，未越权建议 | 待定 | 越权或边界不清记为主错误 |

**主错误与关联维度记录**

| 字段 | 说明 |
|---|---|
| 样本编号 | 条件-任务-重复次数的匿名编号 |
| 主错误描述 | 简要描述错误内容 |
| 关联维度 | 勾选受影响的维度（可多选） |
| 是否首轮失败 | 是/否 |
| 备注 | 补充说明 |

**失败记录模板**

| 字段 | 说明 |
|---|---|
| 样本编号 | 条件-任务-重复次数 |
| 失败类型 | 工具失败 / 输出不合格 / 交互阶段失败 |
| 失败描述 | 具体说明 |
| 是否首轮 | 是/否 |
| 重试编号 | 如适用 |
| 是否计入分析 | 首轮失败必须保留，重试不替代 |

## 4. 预注册待确认清单

| 待确认事项 | 状态 | 影响 | 所需决定 |
|---|---|---|---|
| 交互式计划确认的最大轮次 | 未决定 | 无法确定交互阶段何时结束及失败样本如何界定 | 预注册时明确最大轮次和终止规则 |
| 交互式计划确认的终止规则 | 未决定 | 同上 | 同上 |
| 两名评审的分歧处理方式 | 未决定 | 无法保证评分结果可靠性和可复核性 | 预注册时明确分歧处理流程 |
| 两名评审的一致性评价方式 | 未决定 | 同上 | 预注册时明确一致性指标和阈值 |
| 各评分维度的分数类型 | 未决定 | 影响统计方法选择 | 预注册时确定有序分类或连续值 |
| 各评分维度的具体评分范围 | 未决定 | 影响评分可操作性 | 预注册时确定 |
| 统计方法 | 未决定 | 依赖上述分数类型和重复测量结构 | 按选择流程在预注册中写明 |
