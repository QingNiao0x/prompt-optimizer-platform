# 提示词整理工具对照研究方案

## 1. 研究问题

本研究比较三种提示词准备方式对下游任务输出质量的影响：原始需求直接输入、直接增强提示词、交互式计划确认后生成的提示词。核心问题为：在相同初始信息条件下，交互式计划确认是否比直接增强带来可归因于交互组织方式本身的质量差异，而非仅因获得更多已确认事实而产生差异。研究不评价任何产品绝对优劣，不推断模型能力排名。

## 2. 实验设计

**任务集。** 固定二十个任务，覆盖开发方案类与写作交付类。开发任务要求下游模型只输出方案文本，不实际修改仓库；写作任务要求交付文本。跨任务不使用代码测试通过率作为统一质量指标。

**条件与分组。** 设四个条件：

- **A 原始组**：接收原始需求与初始材料。
- **B 直接增强组**：接收由同一初始信息生成的优化提示词，不额外获得计划确认阶段的答案。
- **C 计划确认组**：系统先提问，实验操作者按预先制定答案卡作答，再生成最终提示词。记录每个问题、选项、推荐依据和答案。
- **D 信息量匹配对照组**：接收与 C 组相同的已确认事实，但不经历本平台问答过程，用于分离新增信息与交互组织方式的效应。

A、B 两组不得接触 C 组后来回答的业务选择。每个条件对每个任务独立重复三次，共 240 次下游生成。每次重复开启隔离会话，随机化任务顺序，记录模型版本、日期和参数。失败后的重试不替代第一份失败样本。

**材料与来源标签。** 所有任务材料保留真实实现、用户说明、测试示例与待办来源标签。不得在人工评分前人为删除不利的测试污染反例。

**盲评。** 下游输出匿名化后交两名盲评者独立评分。评审可见等量任务信息与任务事实，但看不到产品名称、标志、生成来源，也看不到另一名评审的先前评分。

## 3. 主要指标

评分表覆盖五个维度：需求保真、业务规则、输出可用性、阅读负担、执行边界。每个维度采用有序等级评分。评分表记录主错误与关联维度，避免同一问题在多个维度重复计为独立失败。工具失败与首轮失败均保留记录。工具生成速度作为过程指标单独记录，不纳入质量分；无计费日志时不估算真实 Token 成本，不将字符数换算为实际费用。

## 4. 统计与推断

候选统计方法取决于分数是否有序、是否连续及是否重复测量。方案不预先锁定某个显著性检验；待评分工具与数据分布确定后，按预注册选择流程确定方法。三名模型给出相似结论不构成研究完成证据，需以人工评阅与可复核任务标准为准，专业领域判断尚需专家参与。

## 5. 限制

本研究为方案设计，实验尚未运行，不含准确率、显著性、成功案例数量或用户结论。计划确认组的最大轮次与终止规则尚未预注册；两名盲评者的分歧处理与一致性评价方式尚未确定。信息量匹配对照只能控制已确认事实的增量，无法完全消除交互过程带来的时间与注意力差异。任务集固定为二十个，结论不自动推广到其他任务类型或领域。


## 附表 A：变量与分组

| 变量 | 类型 | 取值/说明 |
|---|---|---|
| 条件 | 分组变量 | A 原始组；B 直接增强组；C 计划确认组；D 信息量匹配对照组 |
| 任务 | 固定因素 | 二十个任务，编号 T01–T20 |
| 重复 | 重复测量 | 每条件每任务三次，R1–R3 |
| 下游模型版本 | 记录变量 | 每次会话记录 |
| 日期与参数 | 记录变量 | 每次会话记录 |
| 任务类型 | 分层变量 | 开发方案类 / 写作交付类 |
| 材料来源标签 | 记录变量 | 真实实现 / 用户说明 / 测试示例 / 待办 |
| 计划确认问答记录 | 过程记录 | 问题、选项、推荐依据、答案（仅 C 组） |
| 信息量匹配事实清单 | 过程记录 | 与 C 组相同的已确认事实（仅 D 组） |
| 工具失败 | 结果记录 | 是/否，失败类型 |
| 首轮失败 | 结果记录 | 是/否，是否重试 |
| 生成速度 | 过程指标 | 秒，单独记录，不纳入质量分 |
| 质量分 | 结果指标 | 五维度有序评分 |

**分组信息流控制：**

| 组 | 接收内容 | 不接收内容 |
|---|---|---|
| A | 原始需求 + 初始材料 | 任何增强或确认答案 |
| B | 同一初始信息生成的优化提示词 | C 组确认答案 |
| C | 初始材料 + 问答过程 + 最终提示词 | — |
| D | 初始材料 + 与 C 组相同的已确认事实（非问答形式） | 本平台问答过程 |
