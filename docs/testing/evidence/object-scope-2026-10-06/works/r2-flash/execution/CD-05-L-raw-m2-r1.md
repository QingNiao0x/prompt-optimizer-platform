# 提示词整理工具对照研究方案

## 1. 研究问题

本研究考察提示词整理工具在“原始需求—最终提示词”转化环节中，不同信息获取方式对下游任务输出质量的影响。比较对象为三个条件：原始需求直接输入（A组）、同一初始信息经工具直接增强（B组）、交互式计划确认后生成（C组）。由于C组额外获得操作者按答案卡提供的业务确认信息，另设信息量匹配对照（D组），获得与C组相同的已确认事实但不经历问答过程，以分离“新增信息”与“交互组织方式”的效应。研究不评价任何产品绝对优劣，仅比较条件间差异。

## 2. 实验设计

**任务集**：二十个任务，覆盖开发方案类（下游只输出方案、不修改仓库）与写作交付类（交付文本），两类任务不共用代码测试通过率等统一指标。

**条件与分组**：四组均使用相同初始材料。A组直接提交原始需求；B组提交由工具基于同一初始信息生成的优化提示词；C组先经交互式计划确认，操作者按预先制定答案卡作答，系统再生成最终提示词；D组不经历问答，直接获得与C组相同的已确认事实并据此生成提示词。A、B两组不得接触C组后续回答的业务选择。

**重复与隔离**：每个条件对每个任务独立重复三次，共240次运行。每次重复开启隔离会话，随机化顺序，记录模型版本、日期与参数。失败样本保留，重试不得替代首份失败样本。

**盲评**：两名盲评者独立评分，看到匿名化下游输出与等量任务信息，不展示工具名称、标志或生成来源；可查看任务事实，但不得查看另一名评审的先前评分。

## 3. 评价指标

评分覆盖五个维度：需求保真、业务规则、输出可用性、阅读负担、执行边界。每维度采用有序等级评分。同一错误若同时影响多个维度，记录主错误与关联维度，避免重复计为独立失败。工具生成速度作为过程指标单独记录，不计入质量分；无计费日志时不估算真实Token成本，不以字符数换算费用。

## 4. 统计与一致性

候选统计方法的选择取决于分数是否有序、是否连续及是否存在重复测量，待变量性质确定后按预注册流程选定，不在本方案中锁定具体检验。两名评审的分歧处理与一致性评价方式需预注册，当前未定。

## 5. 限制

实验尚未运行，无任何结果数据。专业领域判断需专家参与人工评阅，模型相似结论不构成研究完成证据。交互式计划确认的最大轮次与终止规则尚未确定，须在预注册中明确后方可执行C组与D组流程。


## 附表一：变量与分组

| 组别 | 初始信息 | 交互问答 | 已确认事实 | 最终提示词来源 |
|---|---|---|---|---|
| A 原始组 | 相同初始材料 | 无 | 无 | 原始需求直接提交 |
| B 直接增强组 | 相同初始材料 | 无 | 无 | 工具基于初始信息优化 |
| C 计划确认组 | 相同初始材料 | 有，按答案卡作答 | 有 | 问答后由工具生成 |
| D 信息量匹配组 | 相同初始材料 | 无 | 与C组相同 | 基于已确认事实生成 |

**固定变量**：任务集（20个）、每条件重复次数（3次）、盲评者人数（2名）、评分维度（5项）、材料来源标签（真实实现、用户说明、测试示例、待办）。

**记录字段**：组别、任务编号、重复序号、会话ID、模型版本、日期、参数、首轮是否失败、失败后重试次数、生成耗时、输出文本。

**材料目录**：每个任务包含原始需求、真实实现片段、用户说明、测试示例、待办事项，按来源标签分列，不得在评分前删除不利反例。
