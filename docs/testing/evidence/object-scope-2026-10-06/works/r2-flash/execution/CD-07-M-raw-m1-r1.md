### 口径使用说明

1. **事件数与人数分离**：所有涉及“率”的展示，必须同时标注分子分母是事件还是去重患者；在统计单位未决定前，不输出单一渠道排名结论。
2. **UNKNOWN 单独列示**：在待核验事件中单独展示，不并入爽约，也不并入到诊。
3. **取消规则争议单独呈现**：旧流程说明与新会议草稿并列展示，标注“旧版说明”“新会议草稿（尚未批准）”，不合并为一条规则。
4. **时区证据缺失**：当前汇总表没有时区转换证据，涉及跨系统时间比对时只做本地时区内的字段核对，不做跨时区换算推断。
5. **小样本限制**：电话、网页、窗口三类渠道的事件量若差异较大，百分比需附绝对数量和“样本较少，仅供讨论”说明。

## 二、流程图说明

### 2.1 预约事件流转（文字版）

```
预约产生
  │
  ├─ 渠道记录：电话 / 网页 / 窗口
  │     └─ 同一次预约可能产生多个操作事件
  │           └─ 需区分：首次渠道、变更渠道
  │
  ▼
预约状态
  │
  ├─ ARRIVED（到诊）
  ├─ CANCELLED（系统记录到用户主动取消）
  │     └─ 取消时间与就诊时间均为医院本地时区
  │     └─ 取消提前量规则存在争议：24小时 / 12小时（未批准）
  │
  └─ UNKNOWN（到诊状态未知）
        └─ 可能来源：设备同步延迟、现场漏登记、记录缺项
        └─ 缺少来源核查时，不解释为患者责任
  │
  ▼
观察窗口
  │
  ├─ 窗口未确定前：只展示待核验事件
  └─ 窗口确定后：方可归为最终状态
        └─ 不得将尚未到期的预约算入爽约率
```

### 2.2 渠道比较流程（文字版）

```
确定比较目的
  │
  ▼
选择统计单位
  ├─ 预约事件（当前未决定）
  └─ 去重患者（当前未决定）
  │
  ▼
定义渠道归属
  ├─ 首次渠道
  └─ 变更渠道
        └─ 不能把操作次数当成预约量
  │
  ▼
分组展示
  ├─ 电话
  ├─ 网页
  └─ 窗口
        └─ 小渠道样本较少时保留数量和限制说明
  │
  ▼
输出限制
  └─ 没有完整数据不能报告显著的渠道差异
```

### 2.3 取消规则争议展示流程
