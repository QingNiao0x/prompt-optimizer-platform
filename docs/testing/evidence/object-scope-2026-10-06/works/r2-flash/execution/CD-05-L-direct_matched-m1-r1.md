# 提示词整理工具对照研究方案（尚未执行）

## 一、研究方案主文

### 1. 研究问题

本研究比较三种提示词整理方式对下游任务输出的影响：原始需求（原始组）、直接增强（直接增强组）、交互式计划确认增强（计划确认组）。交互式计划确认指系统先提问、实验操作者按预先制定答案卡作答，再生成最终提示词，不是静态任务分解列表。由于计划确认组额外获得已确认事实，另设信息量匹配对照组，用于区分“新增信息带来的收益”与“交互组织方式带来的收益”。研究不评价某家产品绝对优劣。

### 2. 实验设计

**任务与样本**：二十个任务，每个条件独立重复三次，两名盲评者已确定，不再重新选择样本数量。任务材料保留真实实现、用户说明、测试示例与待办四种来源标签，人工评分前不得删除不利的测试污染反例。

**分组与信息边界**：原始组接收原始需求与初始材料；直接增强组接收同一初始信息得到的优化提示词；两组均不得偷看计划确认组后来回答的业务选择。计划确认组记录每个问题、选项、推荐依据和答案，不只保存最终提示词；错误推荐被答案纠正后仍计入交互阶段风险。信息量匹配对照组获得相同已确认事实，但不经历本平台问答过程。

**执行控制**：每个条件的三次重复开启隔离会话，随机化顺序并记录模型版本、日期和参数；失败后的重试不能替代第一份失败样本。开发任务要求下游模型只输出方案，不实际修改仓库；写作任务要求交付文本，跨任务不能用代码测试通过率作为统一质量指标。

**盲评**：评审看到匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源；为了评分可以看任务事实，但不能看另一名评审先前评分。

### 3. 主要指标

评价覆盖五个维度：需求保真、业务规则、输出可用性、阅读负担和执行边界。一个错误可能同时影响完整性与可执行性，评分表记录主错误和关联维度，避免将同一问题多次计成不同独立失败。工具生成速度是过程指标，质量分是结果指标；没有计费日志时不能估算真实 Token 成本，不能把字符数直接换算成实际费用。

统计方法选择流程：候选评价统计方法依赖分数是否有序、是否连续和是否重复测量；方案说明选择流程，不在变量尚未确定时锁定某个显著性检验。

### 4. 限制

实验尚未运行，没有准确率、显著性、成功案例数量和用户结论。即使三个模型给出相似结论也不是研究完成证据；方案安排人工评阅与可复核任务标准，专业领域判断尚需专家参与。交互式计划确认的最大轮次和终止规则、两名评审的分歧处理与一致性评价方式尚未确定，见预注册待确认清单。

## 二、变量与分组附表

| 条件 | 变量定义 | 分组方式 | 初始信息 | 额外信息 |
|---|---|---|---|---|
| 原始组 | 自变量：无提示词整理 | 独立组 | 原始需求+初始材料 | 无 |
| 直接增强组 | 自变量：直接优化提示词 | 独立组 | 同一初始信息得到的优化提示词 | 无 |
| 计划确认组 | 自变量：交互式计划确认 | 独立组 | 原始需求+初始材料 | 系统提问+答案卡作答后的已确认事实 |
| 信息量匹配对照组 | 控制变量：相同已确认事实，无问答过程 | 独立组 | 原始需求+初始材料 | 相同已确认事实（不经历本平台问答） |

**共同控制**：三次重复隔离会话；随机化顺序；记录模型版本、日期、参数；失败重试不替代首份失败样本。

**信息边界**：原始组与直接增强组不得接触计划确认组后来回答的业务选择。
