### 1.2 流程图说明（文字版）

```
[预约事件产生]
   │
   ├─ 渠道记录：电话 / 网页 / 窗口
   │     └─ 同一预约可能有多个操作事件 → 需先定义首次渠道与变更渠道
   │
   ├─ 状态流转：
   │     ARRIVED（到诊）
   │     CANCELLED（系统记录用户主动取消；不附加临床解释）
   │     UNKNOWN（原因未细分；不得解释为患者责任）
   │
   ├─ 时间字段：
   │     预约就诊时间（医院本地时区）
   │     取消时间（医院本地时区）
   │     ⚠ 汇总表无时区转换证据
   │
   └─ 最终状态判定：
         ├─ 观察窗口未确定 → 只展示“待核验事件”，不纳入爽约率
         ├─ 取消免责边界未确定 → 旧24h与新12h并列，不擅自采用
         └─ 渠道比较主统计单位未确定 → 事件口径与去重患者口径并列展示
```

**流程问题清单：**

1. **同一预约多操作事件**：电话与网页可能记录同一预约的不同操作事件，渠道比较前必须定义首次渠道和变更渠道，不能把操作次数当预约量。
2. **UNKNOWN 原因未细分**：可能来自设备同步延迟、现场漏登记或记录缺项；缺少来源核查时不能归为患者责任。
3. **观察窗口未定**：窗口未确定前只展示待核验事件，不将尚未到期预约算入爽约率。
4. **取消免责边界存在资料差异**：旧流程说明提前24小时不计爽约；新会议草稿建议提前12小时，尚未批准。材料权威性未建立，不能按文件修改时间断定新规则生效。
5. **时区证据缺失**：取消时间与就诊时间均为医院本地时区，但汇总表无时区转换证据，跨时区或系统同步场景下需谨慎。
6. **小渠道样本少**：百分比波动大，应保留数量和限制说明，不报告显著渠道差异。
7. **医生代码误用风险**：仅为流程角色示例，不能追加医生排行榜或个体能力评价。
8. **科室范围限制**：本题材料只有一个门诊，不推断跨科室、跨医院或全市运营表现。

- 只展示合成汇总信息，不含患者、医生可识别信息或敏感诊疗明细。
