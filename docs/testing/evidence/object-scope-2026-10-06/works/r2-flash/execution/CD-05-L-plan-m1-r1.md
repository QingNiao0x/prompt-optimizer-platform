## 1. 研究方案主文

**标题：提示词整理工具三种增强条件对下游任务输出的对照研究方案（未执行）**

**研究问题。** 本方案比较三种提示词整理条件对下游任务输出的影响：原始需求（直接使用原始需求与初始材料）、直接增强（对同一初始信息生成优化提示词）、交互式计划确认增强（系统先提问，实验操作者按预先制定答案卡作答，再生成最终提示词）。交互式计划确认在本题中指“先问答、后生成”的流程，不是静态任务分解列表。研究不评价任何产品的绝对优劣。

**关键混淆与对照。** 计划确认组会额外获得已确认事实，若仅与原始组、直接增强组比较，可能把“新增信息”的收益误判为“交互组织方式”的收益。因此另设信息量匹配对照：获得与计划确认组相同的已确认事实，但不经历本平台问答过程。该组用于分离新增信息与交互组织方式两种来源。

**实验设计。** 二十个任务，每条件独立重复三次，共四组（原始、直接增强、计划确认、信息量匹配对照）。每次重复开启隔离会话，随机化执行顺序，记录模型版本、日期与参数。原始组与直接增强组不得接触计划确认组后来回答的业务选择。计划确认组须记录每个问题、选项、推荐依据与答案，不只保存最终提示词；错误推荐被答案纠正后仍计入交互阶段风险。任务材料保留真实实现、用户说明、测试示例与待办等来源标签，人工评分前不得删除不利的测试污染反例。失败后的重试不替代第一份失败样本。

**主要指标。** 质量分为结果指标，覆盖需求保真、业务规则、输出可用性、阅读负担、执行边界五个维度；工具生成速度为过程指标。开发任务要求下游模型只输出方案、不实际修改仓库；写作任务要求交付文本，因此跨任务不以代码测试通过率作为统一质量指标。没有计费日志时不估算真实 Token 成本，不把字符数换算为实际费用。两名盲评者看到匿名化下游输出与等量任务信息，不展示产品名称、标志与生成来源，不看另一名评审先前评分。

**限制。** 实验尚未运行，无准确率、显著性、成功案例数量或用户结论。候选统计方法依赖分数是否有序、是否连续、是否重复测量，方案只说明选择流程，不预先锁定显著性检验。即使多个模型给出相似结论也不构成研究完成证据；须安排人工评阅与可复核任务标准，专业领域判断尚需专家参与。本方案不声称已完成论文或研究设计业务验收。

## 2. 变量与分组附表

| 条件 | 接收信息 | 是否经历问答 | 是否获得已确认事实 | 重复次数 | 随机化安排 |
|---|---|---|---|---|---|
| 原始组 | 原始需求＋初始材料 | 否 | 否 | 3 | 与其他条件共同随机化顺序 |
| 直接增强组 | 同一初始信息生成的优化提示词 | 否 | 否 | 3 | 同上 |
| 计划确认组 | 原始需求＋初始材料＋问答后生成的最终提示词 | 是（按预先制定答案卡作答） | 是 | 3 | 同上 |
| 信息量匹配对照 | 原始需求＋初始材料＋与计划确认组相同的已确认事实 | 否（不经本平台问答） | 是 | 3 | 同上 |

补充说明：原始组与直接增强组不得接触计划确认组后来回答的业务选择。计划确认组须逐题记录问题、选项、推荐依据与答案。每次重复开启隔离会话，记录模型版本、日期与参数；失败重试不替代第一份失败样本。
