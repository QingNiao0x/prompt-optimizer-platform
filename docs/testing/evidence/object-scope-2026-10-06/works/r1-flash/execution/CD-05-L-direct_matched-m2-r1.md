# 提示词整理工具对照研究方案

## 1. 研究方案主文

**研究问题**

本方案比较三种提示词准备条件对下游任务输出质量的影响：原始需求条件（A）、直接增强条件（B）、交互式计划确认增强条件（C）。研究问题为：在相同初始任务信息下，直接增强与交互式计划确认增强是否在下游输出质量上产生可区分差异；当信息量被匹配后，交互组织方式本身是否仍带来额外差异。研究不评价任何工具或产品的绝对优劣。

**实验设计**

采用二十个合成任务，每个条件独立重复三次，共二百四十次下游生成（20任务 × 4条件 × 3重复）。四组条件如下：

- A组（原始需求）：仅接收原始需求与初始材料。
- B组（直接增强）：接收由同一初始信息生成的优化提示词，不接触计划确认组后来回答的业务选择。
- C组（交互式计划确认）：系统先按预先制定的答案卡提问，实验操作者按答案卡作答，再生成最终提示词。记录每个问题、选项、推荐依据和答案；错误推荐被答案纠正后仍计入交互阶段风险。
- D组（信息量匹配对照）：接收与C组相同的已确认事实，但不经历本平台问答过程。该组用于分离“新增信息”与“交互组织方式”的效应。

A、B两组不得接触C组答案。每个条件的三次重复开启隔离会话，随机化任务与条件顺序，记录模型版本、日期和参数。失败后的重试不能替代第一份失败样本；工具失败与首轮失败均保留记录。

任务材料保留真实实现、用户说明、测试示例与待办来源标签，不在人工评分前人为删除不利的测试污染反例。开发任务要求下游模型只输出方案，不实际修改仓库；写作任务要求交付文本，因此跨任务不采用代码测试通过率作为统一质量指标。

**主要指标**

两名盲评者独立评分，评分维度为需求保真、业务规则、输出可用性、阅读负担和执行边界。评审看到匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源；可查看任务事实，但不能查看另一名评审先前评分。一个错误可能同时影响多个维度，评分表记录主错误和关联维度，避免同一问题重复计为不同独立失败。工具生成速度作为过程指标单独记录，质量分为结果指标；没有计费日志时不估算真实Token成本，不将字符数换算为实际费用。

**统计方法选择流程**

候选统计方法依赖分数是否有序、是否连续及是否重复测量。方案在变量类型和分布经预注册确认后选择检验方法，不在当前阶段锁定某个显著性检验。即使三个模型给出相似结论也不构成研究完成证据；安排人工评阅与可复核任务标准，专业领域判断尚需专家参与。

**限制**

本方案为尚未执行的研究设计，不含实验结果、准确率、显著性、成功案例数量或用户结论。合成资料不代表任何真实单位、患者、当事人、市场或平台运行数据。两名盲评者的分歧处理与一致性评价方式、交互式计划确认的最大轮次和终止规则均未确定，列入预注册待确认清单。研究结论仅适用于所设条件与任务类型，不推广至其他工具或场景。


## 2. 变量与分组附表

| 变量 | 类型 | 取值/状态 | 说明 |
|---|---|---|---|
| 条件 | 自变量，四水平 | A原始需求 / B直接增强 / C交互式计划确认 / D信息量匹配对照 | A、B不接触C组答案；D获得C组相同已确认事实但不经历问答过程 |
| 任务 | 固定因素 | 20个合成任务 | 已确定，不重新选择样本数量 |
| 重复 | 固定因素 | 每条件3次独立重复 | 隔离会话，随机化顺序 |
| 模型版本 | 记录变量 | 文本 | 每次重复记录 |
| 日期 | 记录变量 | 日期 | 每次重复记录 |
| 参数 | 记录变量 | 文本 | 每次重复记录 |
| 工具失败 | 记录变量 | 是/否 | 失败后的重试不能替代第一份失败样本 |
| 首轮失败 | 记录变量 | 是/否 | 保留记录 |
| 生成速度 | 过程指标 | 秒 | 单独记录，不进入质量分 |
| 质量分 | 结果指标 | 各维度评分 | 两名盲评者独立评分 |
| 需求保真 | 评分维度 | 待定评分刻度 | 盲评 |
| 业务规则 | 评分维度 | 待定评分刻度 | 盲评 |
| 输出可用性 | 评分维度 | 待定评分刻度 | 盲评 |
| 阅读负担 | 评分维度 | 待定评分刻度 | 盲评 |
| 执行边界 | 评分维度 | 待定评分刻度 | 盲评 |
| 主错误 | 记录变量 | 文本 | 记录主错误及关联维度 |
| 关联维度 | 记录变量 | 多选 | 避免同一问题重复计为不同独立失败 |
| 交互阶段风险 | 记录变量 | 是/否 | C组错误推荐被答案纠正后仍计入 |
| 来源标签 | 材料属性 | 真实实现/用户说明/测试示例/待办 | 评分前不得人为删除 |

**比较口径说明**：A、B、D三组在相同初始信息、相同时间范围和相同样本口径下比较；C组额外获得确认答案，因此D组作为信息量匹配对照。无法可比的情况（如C组交互过程本身的时间消耗）单独记录，不并入质量分比较。
