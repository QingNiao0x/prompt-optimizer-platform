# 合成门诊预约到诊与爽约情况——内部运营分析方案（讨论版）

**材料性质声明**：本方案基于 `materials/hospital_operations/current-brief.md`、`materials/hospital_operations/legacy-note.md` 两份合成材料编写，属方法草案与口径梳理，**不是**已实现的报表、不是已批准的制度，须经运营、数据治理与合规专业评审后方可应用。`materials/hospital_operations/tests/layout-example.txt` 仅为排版与来源识别测试样例，其中数字、工具、格式均**不是**本题事实，不进入任何口径或结论。

**范围声明**：分析对象仅为某合成门诊 2026 年第一季度的预约事件；资料无真实患者信息、无完整逐条数据。本方案不涉及诊断、处方、分诊优先级、医嘱或个体治疗，不给出临床判断或医疗建议，不建议减少任何患者服务权益。

### 1.2 指标口径表（分母、分子、缺失值、时间边界）

| 指标 | 分子 | 分母 | 缺失值处理 | 时间边界 | 状态 |
|---|---|---|---|---|---|
| 预约事件总量 | — | 观察期内全部预约事件编号 | 不剔除，单列 | 2026Q1，医院本地时区 | 可先出，但须标注时区未转换 |
| 到诊率 | ARRIVED 事件数 | 已归为最终状态的事件数 | UNKNOWN 不计入分子，单列 | 依赖观察窗口 | **待确认**（窗口未定） |
| 爽约率 | 未到诊且已最终判定的事件数 | 已归为最终状态的事件数 | UNKNOWN **不得**计入爽约 | 依赖观察窗口 | **待确认** |
| 取消率 | CANCELLED 事件数 | 已归为最终状态的事件数 | 同上 | 依赖取消免责边界 | **待确认** |
| 待核验事件量 | 尚未到期或状态未定的事件数 | — | 单独展示 | 观察窗口内 | 可先出 |
| 渠道分布 | 各渠道事件数 | 全部事件数 | 单列未知渠道 | 依赖首次/变更渠道定义 | **待确认**（主单位未定） |

**口径硬约束（来自用户与材料，不得违反）**：
1. UNKNOWN **不**计为爽约，也不解释为患者责任（可能来自同步延迟、漏登记、记录缺项）。
2. 观察窗口未确定前，只展示待核验事件，**不**把尚未到期的预约算入爽约率；到期也**不**自动视为最终状态。
3. 取消状态仅表示系统记录到用户主动取消，**不**附加临床解释（不代表治疗结束、病情缓解或不再需要服务）。
4. 预约事件与去重患者两种主统计单位**不得混同**；未选定前，任何渠道比较结论只能以“事件口径”或“患者口径”分别标注，不得合并表述。
5. 时区：取消时间与就诊时间均为医院本地时区，当前汇总表**无时区转换证据**；跨时区或跨系统汇总前须先补时区字段，否则只能按本地时区口径报告并标注限制。

### 1.3 流程图说明（文字版，不画图）

```
[预约事件产生]
   │  渠道：电话 / 网页 / 窗口
   │  可能产生多个操作事件（同一预约）
   ▼
[渠道归属判定] ── 需先定义：首次渠道 vs 变更渠道
   │  未定义前：只统计操作事件数，不称“预约量”
   ▼
[状态流转]
   ├─ ARRIVED ──────────────► 计入到诊（分子）
   ├─ CANCELLED ────────────► 计入取消；是否免责取决于取消提前量规则（24h/12h 待定）
   └─ UNKNOWN ──────────────► 单列待核验，不计爽约、不归责
   ▼
[观察窗口判定] ── 窗口未定：全部标“待核验”
   │  窗口确定后：仅对已到期且状态明确的事件归为最终状态
   ▼
[主统计单位选择] ── 预约事件 / 去重患者（待定）
   ▼
[指标计算] ── 到诊率、爽约率、取消率、渠道分布
   │  小渠道样本少：保留数量 + 限制说明，不报显著差异
   ▼
[报告输出] ── 标注合成材料、方法草案、待确认项
```

**流程问题清单**（现状与目标分别核对，不代表已实现）：

| 编号 | 问题 | 依据 | 影响 |
|---|---|---|---|
| P1 | 同一预约可能被电话与网页记录为多个操作事件 | current-brief.md | 渠道比较分母失真，须先定义首次/变更渠道 |
| P2 | 观察窗口未定，无法判定事件是否最终状态 | 用户明确未决 | 爽约率分母、待核验范围、结论口径均受影响 |
| P3 | 取消免责边界 24h vs 12h 未决，材料权威性未建立 | legacy-note.md | 取消率与爽约率口径分歧 |
| P4 | UNKNOWN 原因未细分 | current-brief.md | 无法区分同步延迟/漏登记/缺项，不能归责 |
| P5 | 汇总表无时区转换证据 | current-brief.md | 跨系统汇总可能错位，须先补时区字段 |
| P6 | 主统计单位未选（事件/患者） | 用户明确未决 | 渠道比较分母与结论表述不一致 |
| P7 | 小渠道样本量可能不足 | current-brief.md | 百分比波动大，不能报显著差异 |
| P8 | 医生代码仅为流程角色示例 | current-brief.md | 不得做医生排行榜或个体能力评价 |
| P9 | 科室类型可能影响预约提前量与到诊行为，但本题仅一个门诊 | current-brief.md | 不推断跨科室、跨医院、全市表现 |
