# 合成商业租赁材料复核备忘录（承租方视角·律师复核用）

**性质与限制**：本备忘录为资料整理与文书草稿，不是法律意见，不评价任何一方是否胜诉或是否违法。合同草稿未签署，往来邮件仅为协商材料，均不能视为已生效协议。所有主体、地址、金额均为合成示例。适用地点为合成项目所在的中国大陆甲市，具体法律适用与条款效力须由执业律师核验。

**三种状态说明**：
- **可直接使用**：已有明确来源依据，可直接进入复核底稿。
- **候选建议**：有来源但需选择或确认，尚未定案。
- **暂不能执行**：缺少关键资料或业务决定，须等待补充。

**两项待确认的前置决定**（不得默认补全）：
1. 两版租赁草稿中哪一份是本次律师复核的主文本——**暂不能执行**，当前尚未决定。
2. 复核优先侧重持续履约还是可能提前退出的安排——**暂不能执行**，当前尚未决定。

## 四、明确限制的备忘录草稿

### 1. 材料充分程度

本次整理的合成商业租赁往来材料，在以下方面已有充分依据可直接使用：
- 承租方视角、资料整理目标和高中低三级优先级已确定（F-01、F-02）。
- 合同草稿未签署、文档日期仅表示编辑时间、邮件仅为协商材料等状态描述已有明确来源（F-03、F-04）。
- 押金两个月与三个月的差异、维修条款两版差异、解除条款涉及通知形式／提前量／费用的结构描述已有来源（F-05、F-06、F-07）。

在以下方面材料尚不充分，暂不能执行：
- 房屋权属和授权链证据缺失（F-08）。
- 示例判决标题无可核验出处（F-09）。
- 租金具体金额、周期、调整机制无可核验内容（F-12）。
- 草稿A与草稿B分别对应的完整条款版本未建立（维修条款版本对应待核实）。
- 两版租赁草稿中哪一份是本次律师复核的主文本尚未决定（F-13）。
- 复核优先侧重持续履约还是可能提前退出尚未决定（F-14）。

### 2. 后续核验事项

- 由执业律师核验两版草稿中哪一份作为主文本，并据此核对押金、维修、解除条款的具体内容。
- 由执业律师核验出租方房屋权属和授权链证据。
- 由执业律师核验往来附件所引示例判决标题的可核验出处，不将其作为法院普遍立场或现行判例依据。
- 由执业律师核验租金条款的具体金额、周期和调整机制。
- 由执业律师核验解除条款中通知形式、提前量和费用的条件关系，不遗漏附加前提。
- 由执业律师核验协商邮件中发送角色、时间和条件，保留原意，不将意向话语改为明确承诺。

### 3. 限制

- 本备忘录仅说明材料充分程度和后续核验事项，不评价任何一方一定胜诉或一定违法。
- 本备忘录不输出具体条文编号、现行效力或确定的法律结论。
- 本备忘录不生成起诉状、法条引文、赔偿数额或胜诉概率。
- 本备忘录不承诺执行诉讼、发送律师函或替代专业判断。
- 本备忘录不追加发送律师函、公开争议或执行催告。
- 本备忘录不把“文件未提供”写成“项目中不存在”，不把“草稿建议”写成“已批准制度”，不把“测试通过”写成“真实业务准确”。
- 本备忘录不声称已经完成实际法律与律师文书业务验收，资料整理和方法草稿不等于专业有效性认证。
