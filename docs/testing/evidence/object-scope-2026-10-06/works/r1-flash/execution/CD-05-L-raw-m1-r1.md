# 提示词整理工具对照研究方案（未执行）

## 一、研究问题与目标

本研究比较三种提示词整理条件对下游任务输出的影响：原始需求（A组）、直接增强（B组）、交互式计划确认增强（C组）。研究不评价任何产品的绝对优劣，只估计整理方式与输出质量、过程指标之间的关系。所有工具获得相同初始材料；A、B两组不得接触C组后续回答的业务选择。

交互式计划确认指系统先提问、实验操作者按预先制定答案卡作答，再生成最终提示词，不是静态任务分解列表。因C组额外获得答案，必须设置信息量匹配对照（D组）：D组获得相同已确认事实，但不经历本平台问答过程，用于区分新增信息与交互组织方式的作用。

## 二、实验设计

固定设计：20个任务×4个条件×3次独立重复，共240个下游输出。每条件三次重复开启隔离会话，随机化运行顺序，记录模型版本、日期与参数。失败后的重试不能替代第一份失败样本；首轮失败与工具失败均保留。

任务材料保留真实实现、用户说明、测试示例与待办四类来源标签，人工评分前不得删除不利的测试污染反例。开发任务要求下游模型只输出方案，不实际修改仓库；写作任务要求交付文本。因此跨任务不能用代码测试通过率作为统一质量指标。

## 三、主要指标

结果指标为质量分，覆盖五个维度：需求保真、业务规则、输出可用性、阅读负担、执行边界。过程指标包括生成速度、交互轮次与失败类型。工具生成速度是过程指标，质量分是结果指标；没有计费日志时不估算真实Token成本，不把字符数换算为实际费用。

两名盲评者独立评分，看到匿名化下游输出和等量任务信息，不展示产品名称、标志与生成来源，也不查看另一名评审先前评分。评分表记录主错误与关联维度；同一错误影响多个维度时只计一次主错误，避免重复计为独立失败。

## 四、公平比较与限制

A、B组仅接收原始需求与初始材料；B组接收由同一初始信息得到的优化提示词。C组记录每个问题、选项、推荐依据与答案，不只保存最终提示词；错误推荐被答案纠正后仍计入交互阶段风险。D组获得相同已确认事实但不经历问答过程。

本研究尚未运行，无准确率、显著性、成功案例数量或用户结论。候选统计方法依赖分数是否有序、是否连续及是否重复测量，方案只说明选择流程，不预先锁定显著性检验。即使多个模型给出相似结论，也不构成研究完成证据；专业领域判断尚需专家参与。
