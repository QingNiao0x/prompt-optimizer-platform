# 提示词整理工具对照研究方案

## 1. 研究问题与设计

本研究比较三种提示词获取方式对下游任务输出的影响：原始需求、直接增强、交互式计划确认增强。交互式计划确认指系统先提问、实验操作者按预先制定答案卡作答，再生成最终提示词，不是静态任务分解列表。研究不评价任何产品绝对优劣。

固定设计：二十个任务，每个条件独立重复三次，两名盲评者独立评分。所有工具获取相同初始材料。任务覆盖开发任务（下游模型只输出方案，不实际修改仓库）与写作任务（交付文本），因此跨任务不能用代码测试通过率作为统一质量指标。

## 2. 实验设计

**分组**：设四个条件。原始组接收原始需求与初始材料；直接增强组接收由同一初始信息得到的优化提示词；计划确认组经历交互式问答后获得最终提示词；信息量匹配对照获得与计划确认组相同的已确认事实，但不经历本平台问答过程。原始组与直接增强组不能接触计划确认组后来回答的业务选择。信息量匹配对照用于分离“新增信息”与“交互组织方式”的效应，避免把多得到答案带来的收益误判为单纯模型能力。

**材料与来源标签**：任务材料保留真实实现、用户说明、测试示例与待办四种来源标签。人工评分前不得人为删除不利的测试污染反例。

**重复与记录**：每个条件的三次重复开启隔离会话，随机化顺序，记录模型版本、日期和参数。失败后的重试不能替代第一份失败样本；工具失败和首轮失败均须保留。

**盲评**：评审看到匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源。评审可查看任务事实，但不能查看另一名评审先前评分。

## 3. 主要指标

结果指标为质量分，由两名盲评者按评分表独立评定。评分维度覆盖需求保真、业务规则、输出可用性、阅读负担和执行边界。一个错误可能同时影响多个维度，评分表记录主错误与关联维度，避免将同一问题多次计成不同独立失败。过程指标为工具生成速度。没有计费日志时不能估算真实 Token 成本，不能把字符数直接换算成实际费用。

统计方法选择流程：先判断分数是否有序、是否连续、是否重复测量，再据此选择候选评价方法；在变量尚未确定时不锁定某个显著性检验。

## 4. 人工评阅与限制

即使三个模型给出相似结论也不是研究完成证据。方案安排人工评阅与可复核任务标准；专业领域判断尚需专家参与。

限制：实验尚未运行，无准确率、显著性、成功案例数量和用户结论。交互式计划确认组的最大提问轮次和终止规则尚未预注册；两名盲评者的分歧处理及一致性评价方式仍未确定。以上缺口列入预注册待确认清单，不预设默认值。
