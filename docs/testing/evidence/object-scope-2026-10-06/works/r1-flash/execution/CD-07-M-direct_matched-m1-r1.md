**口径要点：**
- UNKNOWN 不得直接计为爽约；在缺少来源核查时，不能把该状态解释为患者责任。
- 观察窗口未确定前，只应展示待核验事件，不应将尚未到期的预约算入爽约率。
- 预约事件量不同会影响百分比波动，小渠道样本较少时应保留数量和限制说明；没有完整数据不能报告显著的渠道差异。
- 取消状态表示系统记录到用户主动取消，不意味着治疗结束、病情缓解或不再需要服务；分析报告不能给取消行为附加临床解释。

### 1.3 渠道比较口径（首次渠道与变更渠道）

电话预约与网页预约可能记录相同一次预约的不同操作事件，渠道比较必须先定义首次渠道和变更渠道，不能把操作次数当成预约量。

| 概念 | 定义草案 | 说明 |
|---|---|---|
| 首次渠道 | 某预约事件编号下，最早记录的操作事件所属渠道 | 用于渠道归属 |
| 变更渠道 | 同一预约事件编号下，首次渠道之后发生的操作事件所属渠道 | 单独统计，不并入首次渠道 |
| 操作事件数 | 所有渠道操作记录条数 | 仅用于流程分析，不作为预约量 |
| 预约事件数 | 按预约事件编号去重后的数量 | 渠道比较的基础单位之一（待确认） |

**待确认：** 比较渠道时使用预约事件还是去重患者作为主统计单位？当前尚未决定，不得默认补全。该选择直接影响渠道比较的分母和结论口径。
