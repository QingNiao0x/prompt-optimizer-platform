## Python 快速排序函数代码

```python
def quick_sort(nums):
    """
    对整数列表进行升序快速排序。

    参数:
        nums: list[int] —— 待排序的整数列表

    返回:
        list[int] —— 升序排序后的新列表

    说明:
        - 空列表返回空列表，不报错。
        - 重复元素保留，且按升序排列。
        - 不修改原列表，返回新列表。
    """
    # 递归终止条件：空列表或单元素列表天然有序
    if len(nums) <= 1:
        return nums[:]

    # 选择中间位置元素作为基准值，避免对已排序列表的极端不平衡划分
    pivot = nums[len(nums) // 2]

    # 按基准值划分为三部分：小于、等于、大于
    # 使用“等于”分区可正确处理重复元素，并减少递归深度
    left = [x for x in nums if x < pivot]
    middle = [x for x in nums if x == pivot]
    right = [x for x in nums if x > pivot]

    # 递归排序左、右分区，再与中间分区拼接
    return quick_sort(left) + middle + quick_sort(right)
```
