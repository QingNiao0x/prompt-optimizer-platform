## 一、研究总体设计

**研究目的**：描述2015—2025年某地区心脑血管疾病（CVD）死亡率的长期趋势、季节性特征、人群与亚类差异，量化减寿负担，并采用Arriaga分解法解析死亡率变化的年龄与死因贡献。

**数据来源（需据实填写）**：
- 死因监测系统（如全人群死因登记报告信息系统），死亡日期、根本死因ICD-10编码（I00—I99，含缺血性心脏病I20—I25、脑血管病I60—I69、高血压性心脏病I10—I15等亚类）。
- 人口数据：分年度、性别、年龄组、地区（城乡/区县）常住人口数。
- 若涉及寿命表：需分年度、分性别的年龄别死亡数。

**质量控制**：根本死因编码完整性、漏报率、死因不明比例（R00—R99）需报告；建议采用《疾病和有关健康问题的国际统计分类》第十版（ICD-10）统一编码。

**统计分析工具**：R（`demography`、`MortCast`、`seasonal`、`mgcv`）、Stata、SPSS、Joinpoint Regression Program、Excel（Arriaga分解可用R或Excel实现）。


## 二、指标定义

| 指标 | 公式/说明 |
|---|---|
| 粗死亡率（CDR） | 某年CVD死亡数 / 同年平均人口数 × 100000 |
| 年龄别死亡率（ASMR） | 某年龄组死亡数 / 该年龄组人口数 × 100000 |
| 标化死亡率（SMR） | 以标准人口（如2010年全国普查人口或Segi世界标准人口）加权 |
| 潜在减寿年数（YLL） | Σ(各年龄组死亡数 × 该年龄组剩余寿命) |
| 减寿率（YLL率） | YLL / 人口数 × 1000‰ 或 × 100000 |
| 标化减寿率 | 以标准人口年龄结构加权 |

**YLL计算**：
\[
YLL = \sum_{i} d_i \times e_i
\]
其中 \(d_i\) 为第 \(i\) 年龄组死亡数，\(e_i\) 为该年龄组剩余期望寿命（可用当地寿命表或标准寿命表）。

**YLL率**：
\[
YLL率 = \frac{YLL}{P} \times 1000\%
\]
\(P\) 为对应人口数。


## 三、时间序列长期趋势与季节性趋势

### 3.1 长期趋势

**方法**：
1. **年度变化百分比（APC）与平均年度变化百分比（AAPC）**：采用Joinpoint回归（对数线性模型），识别趋势转折点。
   \[
   \ln(率) = \alpha + \beta \cdot 年份 + \varepsilon
   \]
   \[
   APC = (e^{\beta} - 1) \times 100\%
   \]
2. **趋势检验**：Cochran-Armitage趋势检验或Mann-Kendall检验。
3. **年龄-时期-队列（APC）模型**（可选）：分离年龄、时期、队列效应。

### 3.2 季节性趋势

**方法**：
1. **月度/季度死亡率**：计算各月CVD死亡数占全年比例。
2. **季节性分解**：STL（Seasonal-Trend decomposition using Loess）或X-13-ARIMA-SEATS，分离趋势项、季节项、残差项。
3. **季节性强度指标**：
   - 季节指数 = 某月平均死亡率 / 全年平均死亡率 × 100%
   - 集中度（集中趋势M、集中度D）
4. **循环分布法**（圆分布）：检验死亡月份是否均匀分布，计算平均角与集中度。
5. **广义相加模型（GAM）**：控制长期趋势后，拟合月份/气温与死亡率的关系。

## 六、Arriaga分解方法

### 6.1 方法原理

Arriaga分解用于将两个时点（或两个人群）间期望寿命（或死亡率）差异，分解为**年龄组别**与**死因别**的贡献。核心思想：

\[
e_0^2 - e_0^1 = \sum_i \text{直接效应}_i + \sum_i \text{间接效应}_i + \text{交互效应}
\]

**直接效应**：某年龄组死亡率变化对期望寿命的直接贡献。
**间接效应**：某年龄组死亡率变化通过存活人数影响后续年龄组的贡献。
**交互效应**：年龄组间死亡率变化的交互作用。

**死因别分解**：在年龄组分解基础上，进一步将各年龄组贡献按死因（CVD亚类）拆分。

### 6.2 分析步骤

1. 构建2015年与2025年（或首末年）分性别、分年龄组、分死因的寿命表。
2. 计算两时点期望寿命差 \(e_0^{2025} - e_0^{2015}\)。
3. 按年龄组分解：计算各年龄组直接效应、间接效应、交互效应。
4. 按死因分解：将各年龄组效应按CVD亚类及其他死因拆分。
5. 汇总：得到各年龄组、各死因对期望寿命变化的贡献值（年）及贡献率（%）。

## 八、注意事项与局限性

1. **数据质量**：死因漏报、编码错误、人口基数偏差会影响所有指标。
2. **标化人口选择**：需明确标准人口（全国普查、Segi世界标准等），不同标准结果不可直接比较。
3. **YLL剩余寿命来源**：当地寿命表 vs 标准寿命表，结果解释不同。
4. **Arriaga分解前提**：需完整寿命表，年龄组划分需一致；交互效应解释需谨慎。
5. **季节性分析**：需控制长期趋势和气温等混杂因素。
6. **因果推断**：生态学设计，不能推断个体因果。
7. **2025年数据**：若为部分年份或预测值，需明确标注。
