## 1. Python 快速排序函数代码

```python
def quick_sort(nums):
    """
    对整数列表进行升序快速排序。

    参数:
        nums: List[int] —— 待排序的整数列表

    返回:
        List[int] —— 升序排列后的新列表

    说明:
        - 空列表返回空列表。
        - 重复元素会被完整保留。
        - 采用经典分治思路：选择基准值，将列表划分为
          小于基准、等于基准、大于基准三部分，再递归排序。
    """
    # 递归终止条件：空列表或单元素列表天然有序
    if len(nums) <= 1:
        return nums[:]

    # 选择中间位置的元素作为基准值，避免对已排序输入产生极端划分
    pivot = nums[len(nums) // 2]

    # 将元素按与基准值的大小关系分成三组
    # 等于基准值的元素单独成组，保证重复元素被正确处理
    less = [x for x in nums if x < pivot]      # 小于基准值
    equal = [x for x in nums if x == pivot]    # 等于基准值（含重复元素）
    greater = [x for x in nums if x > pivot]   # 大于基准值

    # 递归排序左右两部分，中间部分已就位，直接拼接
    return quick_sort(less) + equal + quick_sort(greater)
```

## 3. 关键逻辑说明

| 关键点 | 处理方式 |
|---|---|
| 空列表 | `len(nums) <= 1` 时直接返回副本，不会进入递归 |
| 重复元素 | 使用 `equal` 分组收集所有等于基准值的元素，全部保留 |
| 升序 | 拼接顺序为 `less + equal + greater` |
| 基准选择 | 取中间位置元素，降低对已排序输入退化的风险 |
| 返回值 | 返回新列表，不修改原输入 |

以上代码满足：按整数值升序排序、正确处理空列表、正确处理重复元素、包含必要注释，并提供覆盖空列表与重复元素场景的输入输出示例。
