# P1 原始评测证据

本目录用于追溯本次有限评测，结论见[报告](../../P1共享任务视图Plan融合与示例契约-2026-10-11.md)。材料仅为获准的八个合成测试输入；没有真实患者数据、生产附件、账号密码或模型密钥。实际供应商调用已结束，本目录的核查工具不调用模型。

- `execution-audit-final.json`：105 次实际 HTTP 尝试、55 份作品、实际模型与用量；最终九组输入/参数/哈希对应关系。离线重放不计为新供应商请求。
- `quality-review.json`：逐组原件定位、改善、失败及 AI 辅助核查边界；不能作为独立人工盲评或专业认证。
- `candidate-v5-source.json`、`tracked-source-changes.patch`、`source-changes/`：冻结主源码摘要、相对 `51d0536` 的已跟踪文件补丁及完整变更源码（包括新类、测试）；未提交、未发布。
- 各 `*-trace-*.json` 保留供应商请求正文和响应原文，不含鉴权头；各 `*-generation.json` 是平台实际组装结果，各 `*-work.json` / `*-work.md` 是真实执行作品。旧结果、首次失败及错误开关结果原样保留。
- `candidate-v5-replay-*/`：最终主源码对录制响应的离线重放。只有完整供应商请求相同才允许重放；再次组装的复制正文 SHA256 必须与已生成作品的实际输入相同。它证明兼容等价，不代表新增真实调用或重新抽样。
- `invalid-tooling-v1.json`：首版工具构造参数位置错配，四份旧增强/作品不纳入有效对照，但仍计成本。`revision-protocol-v*.json` 保留迭代前登记的预算和失败；总上限最终为 115 次请求、55 次作品，停止继续采样。
- `final-test-summary.json`、`final-test-reports/`：当前相关模块 1718 用例中 1711 通过、1 失败、6 条件跳过；百并发本机 HTTP 测试失败单列，不能称全仓库通过。中止轮次的进程退出码不作通过证据。
- `code-work-checks.json`：实际生成排序代码共 324 项独立检查通过；网页标题函数 15 项中 14 项通过，失败来自旧增强作品。检查使用假请求，不是访问真实网页或完整 CLI 验收。
- `archive-provenance.json`：原件复制清单及哈希。`artifact-index.json` 对本目录每份原件/工具/源码登记大小与 SHA256；自身不进入清单。`verify-archive.py` 仅执行本地完整性、JSON、最终九组输入和冻结源码核查。

原始评测工具中的路径沿用当轮 `tmp/p1-task-view-20261011`。复现真实采集须从记录的基线/补丁重建源码与类、安装依赖，并在服务端环境提供获授权的模型配置；不能把归档直接视为一键可运行发行包，也不能凭本报告追加未经授权的外发材料。本轮真实调用使用生产 Provider 和编排组件、合成服务端身份及已绑定 Plan 问题；普通账号登录、真实数据库/Redis、上传大文件的完整浏览器链路未在此批完成。
