## Python 快速排序函数代码

```python
def quick_sort(nums):
    """
    对整数列表进行升序快速排序。

    参数:
        nums: list[int] —— 待排序的整数列表，允许为空，允许包含重复元素。

    返回:
        list[int] —— 按整数值升序排列的新列表。

    说明:
        - 空列表直接返回空列表。
        - 重复元素会被保留，不会去重。
        - 采用原地分区思路的简化实现：以中间元素为基准，递归排序左右两部分。
    """
    # 基本情况：空列表或单元素列表已经有序，直接返回
    if len(nums) <= 1:
        return nums[:]

    # 选择基准值：取列表中间位置的元素
    pivot = nums[len(nums) // 2]

    # 分区：小于基准、等于基准、大于基准
    left = [x for x in nums if x < pivot]    # 严格小于基准的元素
    middle = [x for x in nums if x == pivot] # 等于基准的元素（保留重复元素）
    right = [x for x in nums if x > pivot]   # 严格大于基准的元素

    # 递归排序左右两部分，再与中间部分拼接，得到升序结果
    return quick_sort(left) + middle + quick_sort(right)


# ============ 示例演示 ============
if __name__ == "__main__":
```
