# 2015—2025年中国心脑血管疾病死亡率特征分析：研究设计框架

**说明**：以下为基于您确认口径撰写的研究设计框架。由于死亡率与死因数据的具体来源尚未确定，本文不填入任何具体数值，所有涉及数据结果的单元格均以待填占位符标注。实际撰写时需以正式数据来源（如《中国死因监测数据集》《中国卫生健康统计年鉴》等）核实后填入。


## 一、研究背景与目的

心脑血管疾病（ICD-10：I00—I69）是中国居民首位死因。本研究旨在系统描述2015—2025年中国心脑血管疾病死亡率的长期趋势、季节性特征、人群与亚类差异，并通过减寿年数（YLL）和Arriaga分解方法量化其健康损失与预期寿命差异的来源，为精准防控提供依据。

**研究地区**：中国。
**地区分层**：具体层级或城乡依据暂不确定，待数据来源确定后明确（建议至少区分城乡，视数据可及性可进一步分东、中、西部）。
**疾病口径**：ICD-10 I00—I69。
**亚类**：缺血性心脏病、脑卒中、高血压性心脏病。
**人群分组**：0—14岁、15—44岁、45—64岁、65岁及以上。
**死亡率比较**：均采用年龄标准化。

## 三、分析框架

### 3.1 时间序列的长期趋势与季节性趋势

**长期趋势**：
- 计算2015—2025年各年度年龄标准化死亡率（分总人群、分性别、分地区、分亚类）。
- 采用Joinpoint回归模型识别趋势转折点，计算年度变化百分比（APC）和平均年度变化百分比（AAPC）。
- 若数据粒度允许，可补充年龄-时期-队列（APC）模型分析。

**季节性趋势**：
- 若数据具备月度或季度粒度，采用时间序列分解方法（如X-13ARIMA-SEATS或STL分解）分离趋势项、季节项和随机项。
- 计算季节指数，识别心脑血管疾病死亡的高发月份/季节。
- 若数据仅为年度粒度，则季节性分析不可行，需在报告中明确说明。

**待确认**：时间序列的具体数据粒度（年度/季度/月度）暂不确定，直接决定季节性分析能否开展。


### 3.2 分性别、地区、人群、亚类的比较

**分性别**：
- 比较男女年龄标准化死亡率的水平与趋势差异。
- 计算性别死亡率比值（男/女）。

**分地区**：
- 按确认的地区分层（城乡或区域）比较年龄标准化死亡率。
- 若数据允许，计算地区间死亡率比值或率差。

**分人群（年龄组）**：
- 按0—14、15—44、45—64、65+岁四组分别计算死亡率。
- 比较各年龄组的死亡率水平、趋势及性别差异。

**分亚类**：
- 分别计算缺血性心脏病、脑卒中、高血压性心脏病的年龄标准化死亡率。
- 比较各亚类的死亡率水平、趋势及相对构成比。
- 分析亚类间的死亡率比值变化。

**统计方法**：
- 率的时间趋势检验采用Cochran-Armitage趋势检验或Joinpoint回归。
- 组间比较采用率差、率比及其95%置信区间。
- 必要时采用Poisson回归或负二项回归调整过离散。


### 3.3 减寿分析：年度、性别的YLL和YLL率

**YLL计算**：
- 采用WHO/GBD标准期望寿命表。
- YLL = Σ(死亡数 × 剩余期望寿命)，按年龄组和性别分别计算。
- 需明确使用的期望寿命表版本（如GBD 2019标准期望寿命表）及具体参数。

**YLL率**：
- YLL率 = YLL / 对应人口数 × 100,000（或按GBD惯例以每1000人计）。
- 按年度、性别分别计算YLL和YLL率。

**分析内容**：
- 描述2015—2025年YLL和YLL率的年度变化趋势。
- 比较男女YLL和YLL率的差异及变化。
- 若数据允许，可按亚类分解YLL贡献。

**待确认**：YLL计算中是否进行年龄标准化、是否截尾（如仅计算0—69岁或0—74岁），需在方案中明确。


### 3.4 Arriaga分解方法

**分解对象**：
- 预期寿命差异：比较2015年与2025年、城乡之间、男女之间。
- 死亡率差异：比较亚类贡献。

**Arriaga方法原理**：
将两个人群（或两个时期）的预期寿命差异分解为：
1. **直接效应**：某年龄组死亡率变化对预期寿命的直接贡献。
2. **间接效应**：某年龄组死亡率变化通过存活人数变化对其他年龄组的间接贡献。
3. **交互效应**：各年龄组死亡率变化的联合效应。

**分析步骤**：
1. 构建各比较组（年份、城乡、性别）的简略生命表。
2. 计算预期寿命差异。
3. 按年龄组分解直接效应、间接效应和交互效应。
4. 汇总各年龄组贡献，识别关键年龄组。
5. 若数据允许，进一步按亚类分解死亡率差异的贡献。

**待确认**：时间序列的具体数据粒度暂不确定，影响生命表构建的年龄组划分精度。

## 六、方法学注意事项

1. **年龄标准化**：所有死亡率比较均采用年龄标准化，需明确标准人口（如中国2010年普查人口、WHO世界标准人口或GBD标准人口），并在全文中保持一致。
2. **数据质量**：死因监测数据的完整性和准确性直接影响结果可靠性，需报告数据质量评估指标（如不明原因死亡比例、漏报率等）。
3. **ICD编码一致性**：需确认2015—2025年间ICD编码版本是否一致（ICD-10 I00—I69），若存在版本变化需进行映射和说明。
4. **亚类定义**：缺血性心脏病（I20—I25）、脑卒中（I60—I69）、高血压性心脏病（I11—I13）的ICD编码范围需在方案中明确列出。
5. **Arriaga分解的适用性**：需确保比较组间的生命表构建方法一致，年龄组划分相同。
6. **不确定性**：若数据存在抽样或报告偏差，需在结果中报告不确定性范围（如95%置信区间）。
