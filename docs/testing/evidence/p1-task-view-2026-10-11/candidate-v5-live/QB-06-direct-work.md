# 论文方法部分写作提示词

你是一名正在协助导师完成论文方法部分写作的研究生。请根据以下要求，撰写论文方法部分的**写作提纲**（不是论文正文，不是完整方法章节，不是研究报告，不是代码）。

## 一、写作目标

撰写论文方法部分的写作提纲，研究主题为：**研究 Plan 问答对提示词质量的影响**。

你需要围绕这一主题，组织方法部分应包含的内容要点、结构顺序和写作注意事项，供后续扩展为完整方法章节使用。

## 二、研究当前状态

本研究目前**仅处于拟定阶段，尚未实施**。所有样本、任务、评审、比较条件均为拟定设计，尚未实际纳入、执行或采集数据。写作中必须始终使用“拟”“计划”“将”“本研究设计为”等表述，不得使用“已纳入”“已采集”“已发现”“结果表明”等已完成时态或结论性表述。

## 三、必须完整保留的研究设计约束

写作提纲中必须原样保留以下设计约束，不得增删、改写或弱化：

1. **任务设计**：4 类任务，每类 5 个，共 20 个任务。
2. **重复设计**：每模式每任务独立重复 3 次。
3. **评审设计**：两名独立评审盲评。
4. **比较条件**：比较直接增强与 Plan。
5. **公平对照**：另设两组获得同样确认信息的公平对照。

## 四、篇幅要求

方法提纲**不超过 1200 字**，附表另计，不计入 1200 字限制。

## 五、禁止事项

写作过程中必须严格遵守以下禁止事项：

1. 不得把拟定样本写成已纳入样本。
2. 不得编造效应量、P 值、参考文献或显著性结论。
3. 具体检验依据未来数据分布选择，不预设必然显著。
4. 不得把猜测、假设或示例写成已确认事实。
5. 必须明确区分已知事实、用户确认信息和必要假设。

以下为**虚构演示**，仅用于说明本提示词应如何被使用，不得充当正式事实、统计口径或研究结论。

## 七、写作要求

请按照以下要求组织方法部分写作提纲：

1. 先列出方法部分应包含的模块（如研究设计、任务与材料、重复与评审、比较条件与对照、拟采用的检验思路、篇幅与附表安排等）。
2. 每个模块下写出应说明的要点，使用“拟”“计划”“将”等表述。
3. 在涉及统计检验时，只写“依据未来数据分布选择具体检验方法”，不写具体检验名称、不写预期显著性、不写效应量或 P 值。
4. 在涉及样本时，只写“拟定任务”“计划纳入”，不写“已纳入”“实际样本”。
5. 全文控制在 1200 字以内，附表内容另计。
6. 不撰写论文正文、不撰写完整方法章节、不撰写研究报告、不编写代码。
