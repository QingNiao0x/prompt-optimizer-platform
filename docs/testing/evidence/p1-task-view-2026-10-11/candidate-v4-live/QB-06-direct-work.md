# 论文方法部分写作提示词（供研究生直接使用）

## 一、你的角色与任务

你是一名正在撰写学位论文的研究生。请根据以下研究设计信息，撰写论文**方法部分初稿**。你的任务是完成方法部分的文字撰写，不是执行研究、不是分析数据、不是生成代码，也不是撰写结果或讨论部分。

请直接依据本提示词中给出的研究设计框架写作，无需自行补充或改动设计要素。若你认为某些信息不足，应在文中以“必要假设”方式明确标注，而不是自行编造。

## 二、研究设计要素（写作时必须完整保留）

本研究主题为“Plan 问答对提示词质量的影响”。方法部分须包含以下设计要素：

1. **任务设计**：共 4 类任务，每类 5 个，合计 20 个任务。
2. **重复设计**：每一模式下的每一任务独立重复 3 次。
3. **评审设计**：由两名独立评审进行盲评。
4. **比较组设计**：比较直接增强与 Plan 两种模式；另设两组获得同样确认信息的公平对照。
5. **当前阶段**：本研究当前仅为研究设计阶段，尚未实施。所有任务、样本、评审安排均为拟定方案，不得写成已纳入、已完成或已获得数据。

## 三、写作要求

1. 方法部分应清晰描述：任务、模式、重复、评审与对照安排。
2. 必须明确说明：当前仅为研究设计，尚未实施。
3. 不得把拟定样本写成已纳入样本。例如，应写“拟设置 20 个任务”，不得写“已纳入 20 个任务”。
4. 不得编造效应量、P 值、参考文献或显著性结论。
5. 具体统计检验将依据未来数据分布选择，不得预设必然显著，也不得提前指定某一种检验并断言其适用。
6. 方法部分应区分以下三类信息：
   - **已知事实**：本提示词中明确给出的设计约束；
   - **用户确认信息**：研究主题、比较组设置、评审方式等已确认内容；
   - **必要假设**：若写作中需要补充但尚未确认的信息，须明确标注为假设，不得写成事实。

## 四、篇幅要求

- 方法提纲不超过 1200 字。
- 附表另计，不计入 1200 字限制。
- 请先完成方法提纲初稿，再根据需要整理附表。

## 五、禁止事项（必须遵守）

1. 不得把拟定样本写成已纳入样本。
2. 不得编造效应量、P 值、参考文献或显著性结论。
3. 不得预设具体检验必然显著。
4. 不得把猜测写成事实。
5. 不得写成研究已完成或数据已收集。
6. 不得自行增删或改动以下设计要素：4 类任务、每类 5 个、共 20 个任务；每模式每任务独立重复 3 次；两名独立评审盲评；直接增强与 Plan 比较；另设两组获得同样确认信息的公平对照。

## 六、输出格式

请以自然语言段落或列表形式撰写方法部分初稿，便于直接复制到论文中。输出应包含：

- 研究设计概述；
- 任务与模式说明；
- 重复与评审安排；
- 比较组与公平对照说明；
- 当前研究阶段声明；
- 统计检验选择原则；
- 必要假设标注（如有）。

请勿输出代码，请勿撰写结果或讨论部分，请勿生成参考文献列表。
