# 45分钟分数大小比较课：教案、学生练习页与答案页

## 一、教师教案

### 材料准备与课前安排（不占用固定教学时间）
- 黑板：课前画好一条 0 到 1 的数轴，标出 0 和 1，预留等分刻度位置。
- 纸条：每组 3 张等长纸条，用于组内折分与口头说明；纸条只作为组内操作材料，不作为不同长度整体之间的比较依据。
- 卡片：教师准备 6 张分数卡，分别写基础层与应用层题目中的分数。
- 分组：按 30 人分为 10 个三人小组，每组设轮换角色：定位员、记录员、说明员。
- 练习页：学生练习页与答案页分开印制；学生页只印题目，不印结论。

### 固定流程与时间安排
| 环节 | 时间 | 累计 |
|---|---:|---:|
| 导入 | 5 分钟 | 5 分钟 |
| 示范 | 10 分钟 | 15 分钟 |
| 合作活动 | 15 分钟 | 30 分钟 |
| 练习 | 10 分钟 | 40 分钟 |
| 总结 | 5 分钟 | 45 分钟 |

合计：5 + 10 + 15 + 10 + 5 = 45 分钟。

### 1. 导入：5 分钟
**目标**：由同分母分数复习引出异分母分数比较的新问题。

**教师问法**：
1. 黑板写：\(\frac{3}{7}\) 与 \(\frac{5}{7}\)，问：“哪个大？为什么？”
   - 预期：分母相同，表示每一份一样大，分子大的分数大。
2. 黑板写：\(\frac{1}{2}\) 与 \(\frac{1}{3}\)，问：“这两个分数分母不同，还能直接看分子吗？”
   - 引导学生说出：不能只看分子，因为每一份的大小不一样。
3. 教师点题：“今天我们用两种办法说明异分母分数谁大谁小：一种放到同一条 0 到 1 的数轴上看位置，一种通过通分变成同分母再比较。”

**边界**：只使用正真分数；不引入负数、假分数或代数分式。

### 2. 示范：10 分钟
**示范题**：比较 \(\frac{2}{3}\) 与 \(\frac{3}{4}\)。

#### 方法一：同一条 0 到 1 的数轴
- 教师在黑板同一条 0 到 1 的数轴上操作。
- 说明：这条数轴表示同一个整体 1。
- 为 \(\frac{2}{3}\) 定位：把 0 到 1 这段平均分成 3 份，取其中 2 份。
- 为 \(\frac{3}{4}\) 定位：把 0 到 1 这段平均分成 4 份，取其中 3 份。
- 关键要求：两个分数的分母刻度必须对应相同整体，也就是都从同一条 0 到 1 的数轴上等分；不能拿长度不同的纸条分别代表整体来比较。
- 观察位置：\(\frac{2}{3}\) 在 \(\frac{3}{4}\) 的左边，所以 \(\frac{2}{3} < \frac{3}{4}\)。

#### 方法二：通分
- 找公分母：3 和 4 的公分母可以是 12。
- 变换：
  \[
  \frac{2}{3}=\frac{2\times4}{3\times4}=\frac{8}{12}
  \]
  \[
  \frac{3}{4}=\frac{3\times3}{4\times3}=\frac{9}{12}
  \]
- 等值理由：分子和分母同时乘同一个不为 0 的数，分数表示的大小不变，只是把每一份分得更细、份数更多。
- 比较同分母：\(\frac{8}{12}\) 与 \(\frac{9}{12}\) 分母相同，分子 8 < 9，所以 \(\frac{8}{12}<\frac{9}{12}\)。
- 回到原题：因此 \(\frac{2}{3}<\frac{3}{4}\)。

**教师强调**：通分不是只记交叉相乘，而是先说明两个分数变成了与原来相等的分数，再比较同分母的分子。

### 3. 合作活动：15 分钟
**组织方式**：10 个三人组，每组使用纸条与口头解释。不得改成大班全体抢答。

**组内角色轮换**：
- 定位员：在纸条或本组画出的 0 到 1 数轴上指出分数位置。
- 记录员：写下比较符号与简短理由。
- 说明员：向组内说明“为什么这样比”。

**活动任务**：
每组从教师给出的分数对中选择一组进行比较，例如：
- \(\frac{1}{2}\) 与 \(\frac{1}{3}\)
- \(\frac{2}{5}\) 与 \(\frac{3}{5}\)
- \(\frac{3}{4}\) 与 \(\frac{5}{6}\)

**轮换要求**：
- 第 1 轮：A 定位，B 记录，C 说明。
- 第 2 轮：B 定位，C 记录，A 说明。
- 第 3 轮：C 定位，A 记录，B 说明。

**教师巡视追问**：
- “你们比较的是同一个整体吗？”
- “通分后这两个分数和原来相等吗？为什么？”
- “数轴上谁在左边？这说明了什么？”

**边界**：活动围绕大小比较与理由表达；不排名，不公开个人成绩。

### 4. 练习：10 分钟
学生独立完成练习页 6 题：基础层 3 题、应用层 3 题。答案页单独存放，学生页题目后不附结论。

**基础层**：
1. 同分母比较。
2. 单位分数比较。
3. 简单通分比较。

**应用层**：
4. 解释比较理由。
5. 解释比较理由。
6. 解释比较理由。

**教师处理**：练习期间只做个别提示，不把两级练习扩写为三档测评或长作业。

### 5. 总结：5 分钟
- 请 2 至 3 名学生用自己的话说：
  - 数轴法看什么？
  - 通分法先做什么，再做什么？
- 教师归纳：
  - 数轴法：在同一条 0 到 1 数轴上定位，位置靠左的分数小。
  - 通分法：先变成与原来相等的同分母分数，再比较分子。
- 强调：不能只比较分子，也不能只比较分母；比较时必须对应相同整体。

### 常见误解追问
| 常见误解 | 教师追问 | 纠正方向 |
|---|---|---|
| 只比较分子 | “分母不同时，每一份一样大吗？” | 分母不同，每一份大小不同，不能只看分子。 |
| 只比较分母 | “分母大就一定大吗？请放到同一条数轴上看。” | 分母大表示每份更小，还要看取了几份。 |
| 使用不同整体 | “这两个分数是在同一个 1 里面比较吗？” | 必须对应相同整体；数轴都用同一条 0 到 1。 |

**注意**：不将错误回答解释为学生能力低或学习态度差；只针对比较依据进行追问。

### 评价要点
- 以学生能否解释比较理由为主。
- 可观察行为：
  - 能在同一条 0 到 1 数轴上指出分数位置。
  - 能说明通分后分数值不变。
  - 能用“同分母比分子”说明结论。
- 不制作排名，不公开个人成绩。

## 三、单独答案页

**说明**：本页为教师答案页，不与学生练习页合并。解析可体现数轴与通分两种思路；不引入负数、假分数或超纲代数。

### 基础层答案
1. \(\frac{2}{7} < \frac{5}{7}\)  
   简解：分母相同，每一份一样大，分子 2 < 5，所以 \(\frac{2}{7}<\frac{5}{7}\)。

2. \(\frac{1}{4} > \frac{1}{6}\)  
   简解：分子相同，分母越大，每一份越小，所以 \(\frac{1}{4}>\frac{1}{6}\)。也可在 0 到 1 数轴上看出 \(\frac{1}{4}\) 在 \(\frac{1}{6}\) 右边。

3. \(\frac{1}{2} > \frac{2}{5}\)  
   简解：通分，\(\frac{1}{2}=\frac{5}{10}\)，\(\frac{2}{5}=\frac{4}{10}\)，所以 \(\frac{5}{10}>\frac{4}{10}\)，即 \(\frac{1}{2}>\frac{2}{5}\)。  
   数轴思路：在同一条 0 到 1 数轴上，\(\frac{1}{2}\) 在 \(\frac{2}{5}\) 右边。

### 应用层答案
4. \(\frac{2}{3} > \frac{3}{5}\)  
   简解一：通分，\(\frac{2}{3}=\frac{10}{15}\)，\(\frac{3}{5}=\frac{9}{15}\)，因为 \(\frac{10}{15}>\frac{9}{15}\)，所以 \(\frac{2}{3}>\frac{3}{5}\)。  
   简解二：在同一条 0 到 1 数轴上定位，\(\frac{2}{3}\) 在 \(\frac{3}{5}\) 右边。  
   理由要点：通分后分数值不变，再比较同分母分子。

5. \(\frac{3}{4} > \frac{5}{8}\)  
   简解一：通分，\(\frac{3}{4}=\frac{6}{8}\)，\(\frac{5}{8}=\frac{5}{8}\)，因为 \(\frac{6}{8}>\frac{5}{8}\)，所以 \(\frac{3}{4}>\frac{5}{8}\)。  
   简解二：在同一条 0 到 1 数轴上定位，\(\frac{3}{4}\) 在 \(\frac{5}{8}\) 右边。  
   理由要点：\(\frac{3}{4}\) 与 \(\frac{6}{8}\) 相等，只是分母和分子同时乘 2。

6. \(\frac{2}{5} < \frac{3}{7}\)  
   简解一：通分，\(\frac{2}{5}=\frac{14}{35}\)，\(\frac{3}{7}=\frac{15}{35}\)，因为 \(\frac{14}{35}<\frac{15}{35}\)，所以 \(\frac{2}{5}<\frac{3}{7}\)。  
   简解二：在同一条 0 到 1 数轴上定位，\(\frac{2}{5}\) 在 \(\frac{3}{7}\) 左边。  
   理由要点：通分后两个分数与原来相等，再比较同分母分子。
