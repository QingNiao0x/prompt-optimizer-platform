# 45分钟分数大小比较课（异分母分数）

**适用对象**：初一，30人，10个三人小组  
**本节边界**：只使用正真分数；不涉及负数、假分数、代数分式或超纲内容。  
**教学条件**：黑板、纸条、教师口头提问；无投影、无个人电子设备。  
**固定流程**：导入5分钟 + 示范10分钟 + 合作活动15分钟 + 练习10分钟 + 总结5分钟 = 45分钟。

---

## 一、教师教案

### （一）材料准备与课前安排（不占用固定教学时间）

1. 黑板左侧预留“同分母复习”区域，中间预留一条0到1的数轴，右侧预留“通分比较”区域。
2. 准备10组纸条，每组3张。每张纸条长度相同，均代表同一个整体“1”。纸条上可预先折出等分刻度，但同一组内所有纸条必须等长。
3. 准备10张小组任务卡，每张写一个比较任务，例如：比较 \(\frac{1}{2}\) 与 \(\frac{1}{3}\)、\(\frac{2}{3}\) 与 \(\frac{3}{4}\)、\(\frac{3}{5}\) 与 \(\frac{1}{2}\) 等。任务卡只使用正真分数。
4. 准备学生练习页30份，答案页教师单独保存，不发学生页结论。
5. 课前将10个三人小组编号为第1组至第10组，每组内设三个轮换角色：定位员、记录员、说明员。

### （二）45分钟固定流程

#### 1. 导入：5分钟

**目标**：由同分母分数复习引出异分母分数比较的新问题。

**教师提问**：
- “比较 \(\frac{3}{5}\) 和 \(\frac{4}{5}\)，哪个大？为什么？”
- 学生回答后，教师追问：“分母相同，说明每一份大小相同，所以直接比分子就可以。”
- 再问：“如果分母不同，比如 \(\frac{1}{2}\) 和 \(\frac{1}{3}\)，还能直接比分子吗？”
- 引导学生说出：分母不同，每一份的大小可能不同，不能只比分子。

**板书**：
- 同分母：\(\frac{3}{5} < \frac{4}{5}\)，因为每份相同，分子大的分数大。
- 新问题：\(\frac{1}{2}\) 与 \(\frac{1}{3}\) 怎么比？

**过渡语**：“今天我们用两种办法说明异分母分数谁大：一种放到同一条数轴上，一种通过通分变成同分母。”

#### 2. 示范：10分钟

**示范题**：比较 \(\frac{1}{2}\) 和 \(\frac{1}{3}\)。

**方法一：同一条0到1数轴定位**

1. 教师在黑板上画一条0到1的数轴，标明0和1。
2. 说明：“这条数轴上的0到1表示同一个整体。”
3. 在数轴上把0到1平均分成2份，找到 \(\frac{1}{2}\) 的位置。
4. 在同一条数轴上把0到1平均分成3份，找到 \(\frac{1}{3}\) 的位置。
5. 强调：“两次分的是同一条0到1，整体相同，所以位置可以直接比较。”
6. 观察数轴：\(\frac{1}{3}\) 在 \(\frac{1}{2}\) 的左边，所以 \(\frac{1}{3} < \frac{1}{2}\)。

**方法二：通分比较**

1. 找分母2和3的公分母6。
2. \(\frac{1}{2} = \frac{1 \times 3}{2 \times 3} = \frac{3}{6}\)。
3. \(\frac{1}{3} = \frac{1 \times 2}{3 \times 2} = \frac{2}{6}\)。
4. 说明等值理由：“分子和分母同时乘同一个不为0的数，分数大小不变，只是把每一份再细分。”
5. 比较同分母分数：\(\frac{2}{6} < \frac{3}{6}\)，所以 \(\frac{1}{3} < \frac{1}{2}\)。

**教师小结**：
- 数轴法看位置：同一条0到1上，左边的分数小。
- 通分法看等值变换：变成同分母后，分子大的分数大。
- 两种方法结论一致。

#### 3. 合作活动：15分钟

**组织形式**：10个三人组，每组使用纸条与口头解释。不得改为大班全体抢答。

**角色轮换**：
- 定位员：在纸条或数轴上指出两个分数的位置。
- 记录员：写下比较符号和简短理由。
- 说明员：向组内说明“为什么这样比”。

**活动步骤**：
1. 教师给每组发一张任务卡和一组等长纸条。
2. 第1轮：定位员操作，记录员记录，说明员说明。比较任务卡上的两个分数。
3. 第2轮：角色轮换，换一个比较任务，确保每人至少担任一次不同角色。
4. 第3轮：再次轮换，组内互相检查理由是否清楚。
5. 教师巡视，随机抽2至3组口头汇报，但不搞全班抢答。

**活动要求**：
- 纸条必须等长，代表同一个整体。
- 说明理由时，必须说清“整体相同”或“通分后分数值不变”。
- 不评价学生聪明与否，只反馈理由是否完整。

#### 4. 练习：10分钟

学生独立完成练习页6题：基础层3题，应用层3题。  
教师巡视，不公开排名，不宣读个人成绩。  
练习页题目后不附结论，答案单独成页。

#### 5. 总结：5分钟

**教师引导回顾**：
- 异分母分数比较不能只比分子，也不能只比分母。
- 数轴法：在同一条0到1数轴上定位，整体相同，看左右。
- 通分法：变成同分母，分数值不变，再比分子。
- 比较时要说理由，不背口诀。

**出口问题**：
- “比较 \(\frac{2}{5}\) 和 \(\frac{1}{2}\)，你会用哪一种方法？理由是什么？”
- 学生口头回答，教师只评价理由是否清楚。

### （三）常见误解追问

1. **只比较分子**  
   学生说：“\(\frac{1}{3}\) 和 \(\frac{1}{2}\)，分子都是1，所以一样大。”  
   追问：“分子相同，分母不同，每一份的大小一样吗？请在同一条数轴上指一指。”  
   纠正方向：分母不同，分数单位不同，不能只看分子。

2. **只比较分母**  
   学生说：“分母3比2大，所以 \(\frac{1}{3}\) 比 \(\frac{1}{2}\) 大。”  
   追问：“分母大表示平均分的份数多，每一份是更大还是更小？在数轴上看看位置。”  
   纠正方向：分母越大，单位分数越小，但比较其他分数还要看分子。

3. **使用不同整体**  
   学生用一张短纸条表示 \(\frac{1}{2}\)，用一张长纸条表示 \(\frac{1}{3}\)，然后直接比长度。  
   追问：“这两张纸条代表的是同一个整体吗？如果整体不同，比较还公平吗？”  
   纠正方向：必须使用同一个整体，数轴也要在同一条0到1上。

**注意**：以上追问只针对数学理由，不归因于学生能力低或学习态度差。

### （四）评价要点

- 主要看学生能否解释比较理由：是否提到整体相同、分数单位、通分后分数值不变、同分母比分子。
- 不制作排名，不公开个人成绩。
- 可用口头追问和练习页书面理由作为评价依据。
- 对理由不完整的学生，追问“你是根据什么判断的”，帮助补充依据。

## 三、单独答案页（教师用）

**说明**：本页单独成页，不发学生页。解析可体现数轴与通分两种思路，不引入负数例子。

### 基础层答案

1. \(\frac{2}{7} < \frac{5}{7}\)  
   理由：同分母分数，每份大小相同，分子5大于2，所以 \(\frac{5}{7}\) 大。

2. \(\frac{1}{4} > \frac{1}{6}\)  
   理由：分子相同，分母越大，每一份越小。\(\frac{1}{4}\) 表示把同一个整体平均分成4份取1份，\(\frac{1}{6}\) 表示平均分成6份取1份，所以 \(\frac{1}{4}\) 大。  
   数轴思路：在同一条0到1数轴上，\(\frac{1}{6}\) 在 \(\frac{1}{4}\) 左边。

3. \(\frac{1}{2} > \frac{2}{5}\)  
   通分思路：\(\frac{1}{2} = \frac{5}{10}\)，\(\frac{2}{5} = \frac{4}{10}\)，所以 \(\frac{1}{2} > \frac{2}{5}\)。  
   数轴思路：在同一条0到1数轴上，\(\frac{2}{5}\) 在 \(\frac{1}{2}\) 左边。

### 应用层答案

4. \(\frac{2}{3} < \frac{3}{4}\)  
   通分思路：\(\frac{2}{3} = \frac{8}{12}\)，\(\frac{3}{4} = \frac{9}{12}\)，所以 \(\frac{2}{3} < \frac{3}{4}\)。  
   数轴思路：在同一条0到1数轴上，\(\frac{2}{3}\) 在 \(\frac{3}{4}\) 左边。  
   理由要点：通分后分数值不变，同分母比分子。

5. \(\frac{3}{5} > \frac{1}{2}\)  
   通分思路：\(\frac{3}{5} = \frac{6}{10}\)，\(\frac{1}{2} = \frac{5}{10}\)，所以 \(\frac{3}{5} > \frac{1}{2}\)。  
   数轴思路：在同一条0到1数轴上，\(\frac{1}{2}\) 在 \(\frac{3}{5}\) 左边。  
   理由要点：整体相同，通分后比较分子。

6. \(\frac{5}{8} < \frac{2}{3}\)  
   通分思路：\(\frac{5}{8} = \frac{15}{24}\)，\(\frac{2}{3} = \frac{16}{24}\)，所以 \(\frac{5}{8} < \frac{2}{3}\)。  
   数轴思路：在同一条0到1数轴上，\(\frac{5}{8}\) 在 \(\frac{2}{3}\) 左边。  
   理由要点：通分后分数值不变，同分母比分子。
