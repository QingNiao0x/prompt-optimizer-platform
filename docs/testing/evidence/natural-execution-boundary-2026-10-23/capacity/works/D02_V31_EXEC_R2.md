# 甲市2015—2025年心脑血管疾病死亡率特征分析报告

> **资料性质声明**：本报告全部内容基于“甲市2015—2025心脑血管死亡分析_合成资料字典”及其配套合成数据表。甲市为**虚构地区**，全部人口、死亡数、率、YLL及Arriaga分解结果均为**演练用合成资料**，不代表任何真实地区、真实患者或真实医疗结论。报告仅使用所提供材料，未进行外部检索、联网或个体数据逆推。

## 一、数据来源与统计口径

### 1.1 数据来源

本报告数据来自合成资料包中的五类预计算表：

| 数据表 | 内容 | 用途 |
|---|---|---|
| annual_rates_合成.csv | 2015—2025年全人群死亡数、粗率、年龄标准化率 | 时间序列分析 |
| monthly_distribution_合成.csv | 2015—2025年11年各月合并死亡数及相对月指数 | 季节性分析 |
| four_dimension_comparisons_合成.csv | 性别、地区、人群、疾病亚类四维度分组死亡数与粗率 | 分组比较 |
| annual_and_sex_yll_合成.csv | 年度及分性别YLL与YLL率 | 减寿分析 |
| arriaga_age_and_cause_合成.csv | 2015与2025年e0差异的年龄及死因贡献分解 | Arriaga分解 |

### 1.2 统计口径

- **研究地区与期间**：虚构甲市，2015—2025年，共11个年度。
- **人口结构**：每年总人口100000人，男女各50000人，东区、西区各50000人；年龄组0—44岁40000人、45—64岁40000人、65岁及以上20000人。各年人口恒定。
- **疾病范围**：心脑血管疾病 = 心血管疾病 + 脑血管疾病，两亚类互斥，相加等于心脑血管疾病总死亡数。
- **率的口径**：年度及分组粗率单位为每10万人；亚类率分母为同年全地区人口（100000），**不可将两个亚类人口相加**。
- **年龄标准化**：采用固定演练标准人口SIM-STD-01（0—44岁权重0.50、45—64岁权重0.35、65岁及以上权重0.15），直接法预计算。
- **季节性指标**：相对月指数 = 该月11年合并死亡数 ÷（2750/12），仅描述本资料的月分布，**不是季节原因或因果效应的估计**。
- **YLL口径**：由固定演练参考寿命表SIM-YLL-01逐年龄预计算，所有年份与性别口径一致；YLL率 = YLL ÷ 对应人口 × 100000，单位为人年/10万人。
- **Arriaga分解**：对象为全死因寿命表2015与2025年出生时预期寿命e0差异，对比方向固定为“2025减2015”，单位为年；正值表示对e0差异的正贡献。**该表不是把粗死亡率差直接分解成年数，也不证明干预因果效应。**

### 1.3 资料局限

资料未提供病因因果信息、现实标准人口、现实寿命表、置信区间或显著性检验结果；人口各年恒定、分组结构完全均衡，属于高度理想化的演练设定。因此，本报告所有“趋势”“差异”“贡献”均为**描述性**结论，不涉及统计显著性推断，也不能外推至真实人群。

**趋势方向与幅度**：

- 粗率由2015年300.0/10万降至2025年200.0/10万，**11年间下降100.0/10万，降幅33.3%**，年均下降约10.0/10万（年均相对降幅约3.9%）。

- 粗率与标准化率均呈**近似线性匀速下降**：各年粗率逐年减少10.0/10万，标准化率逐年减少7.75/10万，未见加速、减速或平台期。
- 由于各年人口总量与年龄结构恒定，粗率与标准化率的下降幅度接近（33.3% vs 32.6%），说明本资料中率的变化**并非由人口年龄结构变化驱动**，而是死亡数本身逐年减少（300→200，减少100例，降幅33.3%）。

### 5.2 贡献程度分析

**（1）全人群：e0增加2.0年，心脑血管贡献0.80年（40.0%），其他死因贡献1.20年（60.0%）**

- 心脑血管疾病死亡变化对e0提升的贡献为**0.80年，占总e0增幅2.0年的40.0%**；其余60.0%来自其他死因。
- 按年龄组，心脑血管贡献随年龄递增：0—44岁0.05年（占该组全死因贡献的16.7%）、45—64岁0.25年（41.7%）、65岁及以上0.50年（45.5%）。**65岁及以上组是心脑血管贡献的最大来源**（0.50年，占心脑血管总贡献0.80年的62.5%）。
- 全死因贡献亦以65岁及以上组最大（1.10年，占2.0年的55.0%），45—64岁0.60年（30.0%），0—44岁0.30年（15.0%）。

**（2）男性：e0增加2.2年，心脑血管贡献0.90年（40.9%），其他死因1.30年（59.1%）**

- 男性心脑血管贡献0.90年，略高于全人群的0.80年；其中65岁及以上组0.55年（占男性心脑血管贡献的61.1%），45—64岁0.30年（33.3%），0—44岁0.05年（5.6%）。
- 男性e0增幅（2.2年）大于女性（1.8年），且心脑血管贡献绝对值（0.90 vs 0.70年）与占比（40.9% vs 38.9%）均高于女性。

**（3）女性：e0增加1.8年，心脑血管贡献0.70年（38.9%），其他死因1.10年（61.1%）**

- 女性心脑血管贡献0.70年，为三组中最低；65岁及以上组0.45年（占女性心脑血管贡献的64.3%），45—64岁0.20年（28.6%），0—44岁0.05年（7.1%）。
- 女性其他死因贡献占比（61.1%）高于男性（59.1%），说明女性e0提升相对更多来自非心脑血管死因。

**（4）贡献结构要点**

| 比较维度 | 心脑血管贡献（年） | 占e0增幅比例 | 主要来源年龄组 |
|---|---:|---:|---|
| 全人群 | 0.80 | 40.0% | 65+（0.50年） |
| 男 | 0.90 | 40.9% | 65+（0.55年） |
| 女 | 0.70 | 38.9% | 65+（0.45年） |

- 三组中**65岁及以上组均为心脑血管贡献的绝对主体**（占62.5%—64.3%），45—64岁次之，0—44岁贡献极小（均0.05年）。
- 心脑血管疾病对e0提升的贡献约占四成，**其余约六成来自其他死因**；本资料不能据此判断心脑血管与其他死因的相对重要性排序在真实世界是否成立。
- 需再次强调：Arriaga结果为**e0差异的贡献分解**，正值表示对2025年相对2015年e0提升的正贡献，**不表示心脑血管死亡率下降“导致”了e0提升的因果量**，也不等同于粗率下降的贡献。

## 六、主要发现与结论

1. **时间趋势**：2015—2025年甲市心脑血管疾病粗率由300.0降至200.0/10万（降33.3%），标准化率由237.5降至160.0/10万（降32.6%），呈近似线性匀速下降；因人口结构恒定，率下降由死亡数减少驱动，非年龄结构变化所致。

2. **季节性**：11年合并月分布呈冬春高、夏秋低的U型，1月相对月指数最高（1.3091），7—8月最低（0.7855），峰谷比约1.67倍；该分布为描述性，不涉及因果机制，且无法判断年际变化。

3. **分组差异**：男性死亡率恒高于女性120/10万（率比1.50→1.86）；东区恒高于西区40/10万（率比1.14→1.22）；年龄梯度陡峭，65+组为45—64组的约7.5—7.7倍，0—44岁组恒为25/10万不变；心血管疾病恒占70%、脑血管占30%，两亚类同步等幅下降。总体呈“全面下降、绝对差恒定、相对差距略扩、结构稳定”格局。

4. **减寿负担**：合计YLL由7200降至5400人年（降25.0%），降幅小于死亡数降幅（33.3%）；男性YLL率约为女性1.40—1.45倍且比值缓扩，男性贡献约六成YLL。

5. **Arriaga分解**：2025相对2015年e0提升全人群2.0年、男2.2年、女1.8年；其中心脑血管疾病贡献全人群0.80年（40.0%）、男0.90年（40.9%）、女0.70年（38.9%），65岁及以上组为各人群心脑血管贡献的主体（约62%—64%），其余约六成e0提升来自其他死因。

## 七、资料局限与结论适用性说明

1. **合成资料属性**：甲市为虚构地区，全部数据为演练合成，**不可用于任何真实地区疾病负担判断、政策制定或临床结论**。
2. **无统计推断**：资料未提供置信区间与显著性检验，本报告所有趋势、差异、贡献均为描述性，未做统计显著性判断；匀速线性变化为资料设定特征，不代表真实世界必然如此。
3. **人口结构理想化**：各年总人口、性别、地区、年龄构成完全恒定，排除了人口老龄化等混杂，故粗率与标准化率变化接近；真实人群中年龄结构变化可能显著改变粗率与标准化率的背离程度。
4. **季节性局限**：仅有11年合并月数据，无年份×月份交叉，无法评估季节性年际稳定性，相对月指数不构成因果或机制证据。
5. **YLL局限**：YLL由固定演练寿命表SIM-YLL-01预计算，未提供年龄别YLL，无法定位YLL降幅小于死亡数降幅的年龄来源；YLL率与YLL数值相同仅因人口恒为100000。
6. **Arriaga局限**：分解对象为e0差异而非粗率差，正值贡献不等于因果效应；未提供年龄别死亡率、死因别寿命表细节，无法复核或扩展分解；其他死因未细分，无法判断其内部构成。
7. **亚类口径**：心血管与脑血管率为互斥亚类且分母均为全地区人口，两亚类人口不可相加；本报告未将亚类率误作分人群率使用。

**综上**，在本合成演练资料设定下，甲市2015—2025年心脑血管疾病死亡率呈全面、匀速、结构稳定的下降，冬春为相对高发月，男性、东区、高龄人群负担更重，减寿负担下降慢于死亡数下降，心脑血管疾病对e0提升贡献约四成且集中于65岁及以上人群。上述结论**仅限于本合成资料内部**，外推需谨慎。
