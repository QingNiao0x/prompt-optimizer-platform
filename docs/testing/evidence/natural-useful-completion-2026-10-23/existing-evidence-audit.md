# 有用补全既有原件审查

本次只读复核已有原始提示词、优化提示词及实际作品；没有调用真实模型、重跑历史批次或修改产品代码。本文给出候选假设及其反证边界，不代表候选采用或正式发布通过。

结论：保留31的意图守门，将补全实验限定为**把原任务已有条件落实为同一任务内可执行的关系**，观察是否减少下游需要重新推断或用户修改的地方。不能以新增功能、字段、确认流程或检查报告增加“具体性”。31的明确成果路径沿用冻结4，因此31既有守门收益不等于补全能力已经提高。

## 五组具体原件

### 1. 31聚会：已经可用，不能把更多活动与物品当作必需补全

- 原件：[G10原始输入](../natural-guarded-fourth-2026-10-23/heldout/cases.json)；[31优化提示词](../natural-guarded-fourth-2026-10-23/heldout/prompts/G10_V31_GEN.md)，第1行；[第一次作品](../natural-guarded-fourth-2026-10-23/heldout/works/G10_V31_EXEC_R1.md)，第35、44—46、69、87行。
- 观察：用户要求在家、约十人、有大人小孩的下午可用方案；提示词保留时间、环节、准备物品及拟议状态。作品已有流程和物品，手工给“选1—2种”，合作游戏给“选一个”，物品清单又列出多种备选材料。它存在选择与采购清单对应不够直接的局部编辑空间，但现有证据不足以判定严重缺陷。
- 可检验补全：仅在用户委托直接可用方案且选择尚未落定时，使所选环节、时段、参与方式和所需物品相互对应，避免把所有备选都变成必须购买。不是要求再新增活动。
- 允许变体与误伤：开放设计允许合理选择和少量备选；不能把每项备选都判为逃避设计，也不要求固定游戏、固定人数比例或逐分钟脚本。此题已经基本可用，允许候选持平。
- 归因：这是作品与提示词之间可观察的具体性空间，未证明平台独有缺陷，更未证明增加指导必然改善作品。

### 2. 工作坊：同一设计的角色与人数关系需要落实，框架仍可保持框架

- 原件：[N08优化提示词](../natural-action-contract-2026-10-23/unseen-followup/prompts/N08_V30_GEN.md)；[第一次作品](../natural-action-contract-2026-10-23/unseen-followup/works/N08_V30_EXEC_R1.md)，第5、16行；[第二次作品](../natural-action-contract-2026-10-23/unseen-followup/works/N08_V30_EXEC_R2.md)，第6、20行。
- 观察：材料约20人、3.5小时含茶歇、至少一个跨部门混合环节，用户只要流程框架。第一次作品按每组4人安排两对演练，同时要求组内观察员记录，未说明观察与参与如何兼任或轮换；不能武断断言一定需要第5人。第二次作品由20人改三人组，未说明余下2人的组织方式。
- 可检验补全：若方案已有角色、分组或同时进行的任务，交代其与现有人数、轮换及余人的关系，使原定练习能进行。共享人员、时间、物料不应被互相冲突地重复占用。
- 允许变体与误伤：主持人兼观察、四人轮换、最后一组多一人等都可能合理。不强制某个组数，不因未附场景卡全文而判框架不完整，不升级成详细讲稿或材料制作项目。
- 归因：这些缺口首次出现在下游具体设计；提示词缺少更具体的联动要求可能参与其中，现有原件不足以认定其为唯一原因，也不能把一次作品差异当作模型普遍能力结论。

### 3. 报名表：已有条件的组合推导曾带来实际局部收益，原始臂也必须比较

- 原件：[完整HTTP原件](../natural-completion-preparation-2026-10-22/http-results.json)：`ACTIVITY_SIGNUP_FORM_V4_GEN`正文第252行、`ACTIVITY_SIGNUP_FORM_V15_GEN`正文第123行、`ACTIVITY_SIGNUP_FORM_V4_EXEC`作品第213行、`ACTIVITY_SIGNUP_FORM_V15_EXEC`作品第84行、`ACTIVITY_SIGNUP_FORM_RAW_EXEC`作品第41行。
- 观察：输入已有“人数1或2”“未满16岁须成年人陪同”“成人计入人数”。4保留各条并提示陪同计人数；15进一步写出“未满16岁情形下参与人数应为2且其中一名为陪同成年人”。15作品据此对“未成年且1人”显示纠正提示并阻止提交。这里的增量是现有条件的操作化，没有新增报名功能。
- 重要反证：原始臂作品已经自行给出相同冲突校验。因此，这是15相对4的局部收益，不能宣称15超过原始臂或证明额外准备阶段有效。
- 允许变体与误伤：可使用条件选项、提交校验或纸质提示；不强制所有方案采用交互表单，也不新增年龄证明、所有人手机号、身份证等收集要求。短信选择的两个分支、剩余名额未知与结果待确认仍需保留。
- 归因：优化提示词中已有可追踪的条件推导，并在作品里落实，因果链比单纯标题或篇幅变化更明确；但样本小且原始臂同样完成，仍不构成采用证明。

### 4. 家用预算：数额增加与步骤增加不能代替时间和条件闭合

- 原件：[完整HTTP原件](../natural-completion-preparation-2026-10-22/http-results.json)，`HOUSEHOLD_BUFFER_V15_EXEC`作品第919行；对应`HOUSEHOLD_BUFFER_V15_GEN`由第924行开始。
- 观察：作品把伙食日用品1500元拆为4周、每周375元，未交代月内剩余日期；前文允许应急金用于真实突发开销，月底却要求“应急预留是否≥1150元（含结转）”，没有排除已正当动用的情形。主预算6200元加总正确，未计入未确认奖金，不能因此将整份作品判为无用。
- 可检验补全：原任务的月度范围需与分次额度覆盖范围对应；检查标准需与允许动用后的状态相容。若金额、期间或异常条件互相依赖，落实相互关系即可，不增加财务报表或审批步骤。
- 允许变体与误伤：按自然周、固定周期、日额度或月底余日预留均可；合法应急动用不等于预算失败。具体资金分配属于用户委托的拟议设计，不把所有新数额都误判为事实编造。
- 归因：矛盾首次发生于下游作品；两版既有相似局限，不能把它写成15独有缺陷。关系指导的价值需要同信息重复作品比较，不能仅据该原件确认平台应加规则。

### 5. 简便交接：把“可执行”变成更多必经流程会增加负担

- 原件：[完整HTTP原件](../natural-completion-preparation-2026-10-22/http-results.json)，`TEAM_HANDOVER_V15_GEN`正文第2130行、`TEAM_HANDOVER_V15_EXEC`作品第2097行。
- 观察：原始请求要求“简便”，使接手人知道先做什么。15优化提示词指定多个字段、交接双方确认签字及日期、负责人知晓，并将签字与负责人知晓作为完成标志。作品形成十列表格，重复签字和知晓记录，还增加紧急请假后24小时补表等义务。所需投入扩大直接可见。
- 可检验补全：真正缺口是事项到下一步、时限、责任及优先次序的关系。保留能支持接手的最少信息即可，不能把签字、审批或负责人介入普遍规定为必要条件。
- 允许变体与误伤：用户已授权AI设计流程，签字本身不是绝对禁止，也不等于捏造事实；应按“简便”与实际交接作用衡量必要性。存在既有制度时可以衔接，不凭缺资料断言制度不存在。
- 归因：强制字段与完成条件在优化提示词阶段已经出现，下游继续落实，增强阶段的干预关联较明确；但证据证明的是可观察维护负担，不证明任何含负责人或签字的流程均越界。

## 共同机制与旧假设的区别

既有任务覆盖能证明原有要求和引用被保留，不能单独证明条件组合、共享资源或输入输出关系已经落实。另一方面，以“更具体”为目标可扩大字段、角色与步骤，反而偏离用户对简便、框架或短文的要求。两者需要共同处理：补全的是已有任务内缺失的关系，不是扩张内容清单。

旧13/14已尝试“从目标作品反推缺口、强调具体与取舍”；旧15的真实准备system也已经要求寻找“关键内容、对象关系、动作或完成标志”，并使用`additions.gap/benefit`。因此，换成“关系补全”四字、另加准备调用或重复一轮普通具体性指导，不构成新假设。

本次可以区别的最小实验范围是：**在31已决定需要明确成果后，保留现有一次生成流程，仅对能指认的已有关系按需落实：已有条件到操作分支，动作到其材料用途，输入到输出及判断，组合安排到同一时间、人数、金额或资源的可兼容使用。** 充分输入可零新增；没有实际关系缺口就不增加该类要求。继续保留全部原始来源、实际题答、独立条件和前后覆盖保护，不新增面向用户的强制检查报告，不把未提供信息改成现实状态。

## 可行性、成本与验证边界

对纯下游问题，先判断是否可通过一句贴近原任务的关系说明减少重复推断；需要大量领域规则、独立裁判或多轮修订才能影响的部分，当前证据不支持投入。候选若复用一次生成，名义调用数可不增加，但Token、协议失败率及延迟仍需实测，不能预先承诺同成本或更低成本。

离线可复用以上原件核对条件与允许变体；新真实对照必须保留原始、31、候选三个同信息臂，并检查实际作品。已见报名题只作机制回归，不能计入新题收益；本次可用的31守门和充分格式题应保持。收益按减少具体错误、减少必要补写或删除来判断，不能用关系字段数量、篇幅、更多材料或检查项计分。若作品已经能正确自行推导，候选持平是合理结果。

候选尚无真实收益证据。本文不改变历史失败、既有采用判据或停止条件，不将下游错误改判为平台唯一根因，也不自动打开历史闭批余额。
