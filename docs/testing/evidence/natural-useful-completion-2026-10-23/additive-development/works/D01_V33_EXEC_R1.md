# 设备借用值班操作说明

## 一、借出设备

1. **先查设备状态**
   - 已在借的设备，不能借给其他人。
   - 有人排队等待，不等于预约成功，不能据此交付。

2. **按设备类型办理**
   - **普通设备**：可当天直接借走。
   - **精密设备**：必须先提交管理员审批；**审批结果出来前，不能交付设备**。

3. **交付前确认**
   - 精密设备：确认审批已通过。
   - 设备当前可借，且未借给他人。

## 二、归还设备

按以下顺序操作，不要跳步：

1. **先登记“已收回”**。
2. **再检查配件**。
3. **根据检查结果处理**：
   - 配件齐全、检查无误 → 设备变为**可借**。
   - 有缺件 → 设备保持**待处理**，不要改为可借。

## 三、值班同事记住三句话

- 精密设备：**没审批，不交付**。
- 归还设备：**先登记收回，再查配件，无误才可借**。
- 已在借的设备：**不能再借给别人**；排队等待**不是预约成功**。
