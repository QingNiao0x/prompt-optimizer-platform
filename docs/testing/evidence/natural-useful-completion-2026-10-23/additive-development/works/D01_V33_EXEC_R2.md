# 设备借用值班操作说明

## 一、借出设备

1. **确认设备当前状态**
   - 已在借的设备，不能借给其他人。
   - 仅“可借”状态的设备可以办理借出。

2. **判断设备类型**
   - **普通设备**：当天可直接借走。
   - **精密设备**：必须先提交管理员审批；审批结果出来前，不能交付设备。

3. **精密设备审批**
   - 审批未出结果：告知借用人在等待审批，设备不能拿走。
   - 审批通过：按流程交付。
   - 审批未通过：不交付，并告知原因。

4. **排队说明**
   - 排队等待不等于预约成功，不能按“已预约”交付设备。

## 二、归还设备

1. **先登记“已收回”**
   - 设备归还时，第一步登记已收回。

2. **再检查配件**
   - 核对配件是否齐全。

3. **按检查结果处理**
   - 检查无误：将设备状态改为“可借”。
   - 有缺件：设备保持“待处理”，不要改为“可借”。

## 三、值班同事记住三句话

- 普通设备当天可借；精密设备没审批不交付。
- 归还先登记收回，再查配件；无误才可借，缺件留待处理。
- 已在借的设备不再借；排队不等于预约成功。
