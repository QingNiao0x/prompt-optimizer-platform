# 设备借用值班操作说明

## 一、普通设备
1. 确认设备当前状态为“可借”。
2. 当天直接办理借出，登记借用人信息。
3. 设备已在借的，不得再借给他人。

## 二、精密设备
1. 确认设备当前状态为“可借”。
2. 提交管理员审批。
3. **审批结果出来前，不得交付设备。**
4. 审批通过后再办理借出；未通过则告知借用人不能借。

## 三、归还设备
1. 先登记“已收回”。
2. 再检查配件是否齐全。
3. 检查无误后，设备才改为“可借”。
4. 有缺件的，设备保持“待处理”，不得改为可借。

## 四、注意
- 已在借设备不能再借给别人。
- 排队等待不等于预约成功，不得按已预约交付。
