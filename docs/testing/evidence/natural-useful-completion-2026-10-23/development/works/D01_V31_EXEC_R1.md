# 设备借用值班操作说明

## 一、借出

1. **普通设备**：确认设备状态为“可借”后，当天直接办理借出。
2. **精密设备**：
   - 先查管理员审批结果。
   - **审批未出结果：不得交付**。
   - 审批通过后，再办理借出。
3. **已在借设备**：不得借给其他人。
4. **排队等待**：不等于预约成功，不得按已预约交付。

## 二、归还

1. 先登记“已收回”。
2. 再检查配件。
3. **检查无误**：改为“可借”。
4. **有缺件**：保持“待处理”，不得改为“可借”。

## 三、值班口诀

- 普通直接借，精密等审批。
- 在借不转借，排队不算约。
- 归还先登记，查件再定状态。
