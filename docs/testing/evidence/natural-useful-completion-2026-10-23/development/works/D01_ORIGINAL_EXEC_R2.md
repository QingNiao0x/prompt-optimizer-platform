# 设备借用操作说明（值班同事用）

## 一、借出前先查状态
- 已在借的设备，**不能再借给别人**。
- 排队等待**不等于预约成功**，不能按已预约交付。

## 二、普通设备
- 可当天直接借走。
- 借出时登记：借用人、设备、借出时间。

## 三、精密设备
- **必须先经管理员审批**。
- 审批没出结果前，**不能交付**。
- 审批通过后再按普通设备流程登记借出。

## 四、归还流程（顺序不能乱）
1. **先登记“已收回”**。
2. **再检查配件**。
3. 检查无误 → 设备状态改为**可借**。
4. 有缺件 → 状态保持**待处理**，不要改为可借。

## 五、一句话记住
> 普通设备直接借；精密设备等审批；在借设备不再借；归还先登记、再查件，无误才可借，缺件留待处理。
