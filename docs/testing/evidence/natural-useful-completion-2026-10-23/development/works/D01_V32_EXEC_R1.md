# 设备借用值班操作说明

## 一、借用流程

**第1步：查设备状态**
- 设备显示“在借” → **不能借给任何人**，告知对方需等待归还。
- 设备显示“可借” → 继续第2步。

**第2步：判断设备类型**
- **普通设备** → 当天可直接办理借出，登记后交付。
- **精密设备** → 必须提交管理员审批。

**第3步：精密设备审批**
- 审批**未出结果前，一律不交付**。
- 告知借用人：排队等待**不等于预约成功**，以审批结果为准。
- 审批通过 → 登记后交付；审批未通过 → 不交付。

## 二、归还流程（按顺序执行）

1. **先登记“已收回”**（此时设备不能借出）。
2. **再检查配件**。
3. 检查结果：
   - **配件齐全无误** → 将设备状态改为“可借”。
   - **有缺件** → 设备保持“待处理”，**不得改为可借**。

## 三、一句话判断

| 情况 | 处理 |
|---|---|
| 普通设备、状态可借 | 直接登记借出 |
| 精密设备、审批未出结果 | 不交付 |
| 设备在借 | 不借给他人 |
| 排队等待 | 不算预约成功 |
| 归还 | 先登记收回 → 再查配件 → 无误才可借，缺件保持待处理 |
