以下是一份可直接打印/夹在主持夹板上的40分钟现场流程。核心设计：**全程不分组、不换房间、不用投影和手机**，用“纸笔+座位编号+举手/站立”保证14位新同事每人都至少发言一次、参与两轮互动。

---

## 活动基本信息

- **名称**：新同事40分钟交流会
- **人数**：14位新同事 + 1位主持人（主持人不计入参与者）
- **场地**：同一间会议室
- **物料**：A4纸15张、笔15支、座位号1–14小纸条（贴在椅背或桌上）、计时器（手机计时即可，仅主持人看）、白板或大白纸1张（可选，用于主持人记录关键词）
- **总时长**：40分钟
- **参与保障**：每人有座位号；每人写1张卡片；每人至少被点名/轮答1次；每人都要起立参与“一分钟认识你”环节

---

## 详细流程（主持人现场版）

### 0:00–0:03 开场与规则说明（3分钟）

**主持人动作：**
1. 站在会议室前方，确认14位新同事已按座位号1–14落座。
2. 开场白（可直接念）：
   > “接下来40分钟，我们做一次不用投影、不用手机的交流会。目标很简单：让每个人被听见，也让彼此知道以后可以找谁。全程只有一间会议室，我们不分小组、不换房间。每人会拿到一张纸和一支笔，最后每个人都会至少发言一次。”
3. 说明三条规则：
   - 发言控制在约30秒；
   - 别人说话时不打断；
   - 卡片上不写批评人的话，只写“我能帮什么”和“我想问什么”。
4. 请所有人检查桌上是否有：A4纸1张、笔1支、座位号。

**参与方式：** 全员听，主持人确认无遗漏。

**主持人提示：** 若有人迟到，直接安排到空座位号，并在轮答时补上。

---

### 0:03–0:10 座位号轮答：姓名+一个标签（7分钟）

**主持人动作：**
1. 说明规则：
   > “按座位号1到14依次来，每人30秒以内。说三件事：我叫什么、我来自哪个部门/岗位、用一个词形容我现在最想了解的事。比如：‘我是3号，小王，做运营，最想了解跨部门怎么配合。’”
2. 主持人先做10秒示范（只示范格式，不占参与者名额）。
3. 从1号开始，依次点到14号；每人说完，主持人用一句话回应或复述关键词（如“好，3号小王关注跨部门配合”）。
4. 主持人可在白板/大白纸上快速记下关键词，便于后面归类；没有白板就用自己纸上记。

**参与方式：** 14人每人至少发言1次，每次约25–30秒；其他人倾听。

**时间控制：** 7分钟 ÷ 14人 ≈ 每人30秒。若某人超时，主持人温和说“好，先记下，后面卡片继续写”。

**主持人提示：** 不要展开追问，保持轮转；此环节目标是“人人开口”。

---

### 0:10–0:18 纸笔卡片：写“我能帮什么/我想问什么”（8分钟）

**主持人动作：**
1. 请每人把A4纸对折成两栏，左上写“我能帮”，右上写“我想问”。
2. 说明：
   > “用5分钟独立写。左边写1–2条你愿意帮别人的事，比如‘我会做表格’‘我熟悉报销流程’；右边写1–2条你目前最想问的问题，比如‘找谁审批’‘周会怎么开’。不写名字也可以，但建议写座位号，方便后面互读。”
3. 主持人计时5分钟写作；最后3分钟提醒：
   - 第1分钟：“还有1分钟，写关键词即可。”
   - 写完后请每人把纸折一下，只露出座位号。
4. 主持人自己也写一张“主持人能帮什么”，但不计入14人。

**参与方式：** 14人全员独立书写；不讨论、不换座。

**物料：** 纸笔即可；无需投影。

---

### 0:18–0:28 卡片漂流与同桌互读（10分钟）

**主持人动作：**
1. 说明“漂流规则”：
   > “现在把折好的纸放到桌面上，只露座位号。听到‘开始’后，每个人把纸传给右边的人，传3次。每次拿到后看30秒，不写字、不涂改，只在纸背面用铅笔点一个点表示‘我读过了’。传3次后停下。”
2. 主持人喊“开始”，每约1分钟喊一次“传”；共传3轮（约3–4分钟）。
3. 停止后，请每人看自己手里最后那张纸，与左右邻座两人低声互读1分钟：说出“这张纸上哪一条对你最有启发”。
4. 最后请3–4位志愿者举手，向全场说一句“我读到的一条有用信息”。主持人控制每人20秒。

**参与方式：** 全员传递、全员阅读、邻座互读；志愿者举手补充。确保不分组、不离开座位。

**主持人提示：** 若有人不愿写名字，尊重匿名；漂流只看内容，不追查作者。此环节保证“人人被读到、人人读到别人”。

---

### 0:28–0:35 全场汇总：主持人归类+举手补充（7分钟）

**主持人动作：**
1. 主持人快速把刚才轮答和卡片中听到的高频词归为3类，写在白板/大白纸或直接口述：
   - **找人类**：审批、报销、跨部门对接；
   - **流程类**：周会、汇报、工具使用；
   - **融入类**：午餐、座位、常用群。
2. 每类用1分钟说明：“这类问题，现场谁有经验？请举手。”
3. 对每个举手者，主持人点名1–2人用一句话回答（每人20秒），不展开成长篇。
4. 主持人最后补一句：“没被现场回答的问题，请把纸留在桌上，我会后统一转给对应同事。”

**参与方式：** 全员可举手；被点到者一句话回应。主持人确保至少覆盖3类、每类至少1人发言。

**主持人提示：** 此环节不是培训，不追求解决所有问题；重点是让新同事知道“问题可以被提出”。

---

### 0:35–0:40 收束：每人一句承诺+主持人收尾（5分钟）

**主持人动作：**
1. 说明：
   > “最后5分钟，每人用一句话说：接下来一周我准备做的一件小事，比如‘我准备找邻座问一次报销流程’‘我准备参加一次午餐’。按座位号1到14，每人10–15秒。”
2. 从1号开始快速轮一圈；主持人只回应“好，记下了”，不点评。
3. 主持人收尾（30秒）：
   > “今天14位都发了言，也互相读了卡片。纸可以带走，问题我会后跟进。散会后请把笔放回桌上。”
4. 主持人确认计时结束，宣布结束。

**参与方式：** 14人每人一句；主持人收尾。

**时间控制：** 14人 × 15秒 ≈ 3.5分钟，留1.5分钟缓冲。

## 主持人现场检查清单

- [ ] 座位号1–14已贴好
- [ ] A4纸15张、笔15支
- [ ] 计时器可用（仅主持人看）
- [ ] 白板/大白纸可选，用于记关键词
- [ ] 开场时确认14人到齐
- [ ] 轮答环节按号点人，不跳过
- [ ] 卡片环节明确“左帮右问”
- [ ] 漂流环节只传3次，不涂改
- [ ] 汇总环节每类至少1人举手
- [ ] 收束环节14人每人一句
- [ ] 结束时提醒带走个人物品、留下问题纸

---

## 风险与应对

| 风险 | 主持人应对 |
|---|---|
| 某人发言超时 | 温和打断：“好，先记下，后面卡片继续写。” |
| 有人不愿发言 | 允许先说“我暂时没有”，但收束环节再补一句；不强迫展开 |
| 卡片内容负面 | 主持人现场不点名批评，收束时说“问题我会后统一跟进” |
| 时间超时 | 压缩汇总环节的追问，保留收束轮答；轮答每人严格30秒 |
| 有人迟到 | 安排空座位号，轮答时补入；不重新开始 |

## 交付说明

以上流程满足：**40分钟内、14位新同事全员参与、仅一间会议室、不分房间、纸笔完成、无投影、无手机投票**。主持人按时间表逐段执行即可；每段都标明了主持人动作和参与者参与方式。
