# 设备借用值班操作说明

## 一、借用流程（按顺序执行）

1. **查设备状态**
   - 状态为“在借”：**不能借给别人**，告知对方不可借。
   - 状态为“可借”：继续下一步。

2. **判断设备类型**
   - **普通设备**：当天可直接办理借出。
   - **精密设备**：必须提交管理员审批。

3. **精密设备审批**
   - 审批**没出结果前不能交付**。
   - 告知对方“排队等待”**不是预约成功**，需等审批结果。

4. **交付**
   - 普通设备：确认可借后直接交付。
   - 精密设备：**审批通过后**才能交付。

## 二、归还流程（按顺序执行）

1. **先登记“已收回”**（不要先检查配件）。
2. **再检查配件**。
3. **按检查结果处理**：
   - 配件齐全无误 → 设备变为**可借**。
   - 有缺件 → 设备保持**待处理**，不能变为可借。

## 三、值班速判

| 情况 | 怎么做 |
|---|---|
| 普通设备、状态可借 | 当天直接借出 |
| 精密设备、审批未出结果 | 不交付，等审批 |
| 设备在借 | 不能再借给别人 |
| 对方说“已排队” | 不算预约成功，按流程办 |
| 归还 | 先登记已收回 → 再查配件 |
| 配件无误 | 变为可借 |
| 有缺件 | 保持待处理 |
