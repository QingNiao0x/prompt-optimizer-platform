# 共享旧索引阻塞新导入的验证证据

- `candidate.json`：基线与最终实现源文件 SHA-256。
- `results.json`：原 Edge 同站点存储诊断事件、两次真实目录完整运行摘要、30 份正文/尾部哈希及首轮校验脚本误报的补验。实际目录路径清单和源码不入库。
- `units.txt`：107 项共享回归；`timeout-unit-final.txt` 补 1 项打开超时反例；`storage-unit-final.txt` 补 2 项设置页清理反例，去重共 110 项。
- `edge-tests.txt`：6 项原有检查通过、新增检查首轮因 JSON 对象字段顺序比较误报；`edge-isolation-final.txt` 为改用逐字段等价后的通过结果。7 项不同用例均已通过，失败原件保留。
- `build-final.txt`：类型检查与生产构建，既有警告保留。

原用户 Edge 上的诊断只验证相同旧库阻塞条件下新路径的可用性，没有替用户完成原页面的挂起请求。整目录运行使用 Edge 独立持久磁盘配置和实际目录原生句柄，未暂停于局部文件。两次耗时受现场存储负载影响，不作为稳定速度承诺。
