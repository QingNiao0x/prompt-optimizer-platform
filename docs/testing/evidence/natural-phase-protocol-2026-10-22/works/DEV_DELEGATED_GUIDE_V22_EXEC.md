下面是一份可直接用于内部分享的 20 分钟介绍安排，以及一页式交接清单模板。内容按“小组日常交接”的通用实际做法设计，你可把方括号处替换成你们组的真实系统名、群名、文档路径和角色名。

---

## 一、20 分钟介绍安排

**目标**：新同事听完能说清交接的触发场景、标准流程、关键节点、常见坑，并知道清单怎么用。

| 时间 | 环节 | 讲解要点 | 过渡方式 |
|---|---|---|---|
| 0–2 min | 开场：为什么交接要标准化 | 用 1 个真实小案例说明交接不清的后果（如漏改配置、找不到负责人、重复排查）。明确今天只讲三件事：流程、节点、注意事项。 | “先看我们组最常见的三类交接场景。” |
| 2–5 min | 场景与角色 | 三类场景：①日常轮值/请假代班；②项目阶段移交；③人员变动/长期接手。角色：交方、接方、确认人（组长或指定负责人）。说明每类场景用同一张清单，但确认人不同。 | “场景清楚了，下面走一遍标准流程。” |
| 5–12 min | 标准流程五步走 | ①发起：交方在[交接群/工单]建交接记录，写明原因、时间窗、涉及系统。②盘点：按清单逐项填，标“已确认/待补/不适用”。③面对面过一遍：重点过未完成事项、定时任务、外部依赖、权限。④接方复述：接方用自己的话复述关键操作和风险点，交方纠偏。⑤确认归档：确认人签字/在记录中确认，清单存入[共享文档路径]，后续问题在记录下追加。 | “流程里最容易出问题的是几个关键节点，单独拎出来说。” |
| 12–16 min | 关键节点与常见注意事项 | 关键节点：权限与账号、定时任务/脚本、未闭环工单、外部对接人、监控告警接收人、文档与配置位置。常见坑：只交文档不交“活口”；权限没转移导致接方无法操作；定时任务漏改接收人；口头交接无记录；交接后原负责人仍被默认@。每条配一句组内实际做法。 | “这些都会落到清单上，下面看清单怎么用。” |
| 16–19 min | 清单使用演示 | 现场打开清单模板，演示一次填写：哪些必填、哪些可标不适用、确认人怎么签、归档到哪里。强调清单不是一次性表格，每次交接复制一份新记录。 | “最后留一分钟确认大家记住三个动作。” |
| 19–20 min | 收尾与三个动作 | 记住：先建记录、按清单过、接方复述后确认人归档。告知清单位置和有问题找谁。 | 结束。 |

**控场提示**：5–12 分钟是核心，若前面超时，压缩开场案例；12–16 分钟每条注意事项只讲一句组内做法，不展开故事。

## 二、一页式交接清单模板（可复用）

> 使用方式：每次交接复制一份新记录，文件名建议“交接_交方_接方_日期”。状态填“已确认 / 待补 / 不适用”，待补项必须写补全时间和责任人。

**基本信息**
- 交接编号：________　日期：________
- 交方：________　接方：________　确认人：________
- 交接类型：□轮值/代班　□项目阶段移交　□人员变动/长期接手　□其他________
- 交接时间窗：________ 至 ________

**1. 职责与范围**
- [ ] 当前负责的业务/系统/模块清单（附路径或链接）：________
- [ ] 明确不在此次交接范围的事项：________
- [ ] 日常节奏（例会、报表、巡检时间）：________

**2. 权限与账号**
- [ ] 系统/平台账号已开通或转移：________
- [ ] 群组、邮件组、告警接收人已变更：________
- [ ] 密钥/令牌/证书保管方式与位置：________
- [ ] 权限验证：接方已实际登录/操作验证　状态：________

**3. 进行中事项**
- [ ] 未闭环工单/任务清单（编号、状态、下一步、截止时间）：________
- [ ] 待审批/待回复事项及对接人：________
- [ ] 近期风险或已知问题：________

**4. 定时任务与自动化**
- [ ] 定时任务/脚本清单及位置：________
- [ ] 执行账号、失败告警接收人已确认：________
- [ ] 最近一次执行结果与异常处理方式：________

**5. 文档与配置**
- [ ] 操作手册/runbook 位置：________
- [ ] 配置文件/代码库/数据位置：________
- [ ] 文档最后更新时间及是否需补：________

**6. 外部依赖与联系人**
- [ ] 上下游对接人及联系方式：________
- [ ] 供应商/外部支持渠道：________
- [ ] 升级路径（出问题找谁、何时升级）：________

**7. 面对面过检与复述**
- [ ] 已面对面/线上逐项过检　日期：________
- [ ] 接方复述关键操作与风险点，交方纠偏　状态：________
- [ ] 遗留问题及补全计划：________

**8. 确认与归档**
- [ ] 确认人已确认（签字/记录链接）：________
- [ ] 清单归档位置：________
- [ ] 交接后过渡期支持方式与截止时间：________
