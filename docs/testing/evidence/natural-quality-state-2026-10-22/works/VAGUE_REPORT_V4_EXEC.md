# 试用反馈改进建议（给负责人）

## 一、导出入口的可发现性
**建议：**
1. 把导出入口放到用户完成主要操作后容易看到的位置（如结果页顶部或操作栏），并配明确文字标签（如“导出”），不要只用图标。
2. 首次进入相关页面时，对导出入口做一次轻量提示或引导。
3. 在帮助/提示文案中说明导出位置，减少用户需要外部提示才能找到的情况。

**依据：** 6名用户中4名反馈找不到导出入口；其中2名经提示后才完成导出，说明入口本身可用，但可发现性不足。另2名未继续，提示成本已影响任务完成。

## 二、手机端表格显示体验
**建议：**
1. 针对手机端表格做适配：优先显示关键列，次要信息折叠或横向滑动查看。
2. 缩小单元格内边距、精简表头文案，避免内容挤压。
3. 改动后在手机端做一次小范围复测，确认拥挤感是否缓解。

**依据：** 2名用户反馈手机端表格显示拥挤，说明小屏下的信息密度和布局需要优化。
