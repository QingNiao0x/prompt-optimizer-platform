# 试用反馈改进建议（呈负责人）

## 一、优先改进方向

**1. 提升导出入口的可发现性（本轮最突出问题）**
- 6人中4人找不到导出入口，占多数，建议列为第一优先。
- 可执行动作：将导出入口前置到表格页显眼位置（如工具栏常驻按钮），避免藏在二级菜单；入口文案明确写“导出”，不用模糊图标；首次进入时增加轻量引导提示。
- 验证方式：改动后复测“用户能否在无提示下自行找到并完成导出”，记录成功人数与所需提示次数。

**2. 优化移动端表格显示**
- 2人反馈手机表格拥挤。建议先确认具体拥挤场景（列过多、字号、横向滚动等），再针对性处理，如移动端精简默认列、支持横向滑动或卡片式展示。
- 验证方式：改动后在手机端复测可读性与操作顺畅度。

## 二、下一步需优先补充的信息（当前资料缺失，暂不作结论）
- **实际导出耗时**：补记从点击到完成的时间，判断是否还有效率问题。
- **设备分布**：记录各用户使用设备，确认移动端问题的影响范围。
- **人群重叠情况**：确认“找不到入口”与“表格拥挤”是否为同一批用户，避免重复归因。
- **改动后效果**：上述改动需安排复测并留存前后对比，暂不预设效果。

## 三、建议节奏
先做导出入口调整并小范围复测，同步补齐耗时、设备、人群重叠记录；移动端表格问题在明确具体场景后再排期优化。
