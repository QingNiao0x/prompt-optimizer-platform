# 研究设计方案：先回答关键问题再增强提示词 vs. 直接增强提示词

> 说明：本方案为**拟议设计**，不代表用户已确认或已实施。文中凡涉及评分尺度、样本量、具体工具版本等未指定参数，均保持未决，不默认取值。以下内容严格区分「已知事实」「用户确认信息」「必要假设」。

---

## 1. 研究问题与假设

### 1.1 研究问题

**主问题（方法收益，同信息条件下）：**
在两组获得逐字相同的原始任务与同一份实际确认信息、并保留各自指定增强流程的前提下，「先回答关键问题再增强提示词」（下称**问答增强组**）与「直接增强提示词」（下称**直接增强组**）在**提示词质量**上是否存在差异？

**次问题（自然使用效果）：**
在自然使用条件下（问答增强组可主动提问获取信息，直接增强组不进行提问环节），两组的提示词质量与任务完成质量是否存在差异？该差异在多大程度上可归因于「提问获取到的信息」而非「增强方法本身」？

**补充问题：**
两组在任务完成质量（次要结局）上是否存在差异？

### 1.2 假设

- **H1（同信息方法收益）**：在获得同一份实际确认信息的条件下，问答增强组与直接增强组在提示词质量上存在差异。方向不预设为必然优于，需由数据判断；若文献或前期证据支持某方向，可在注册时预注册方向性假设。
- **H2（自然使用效果）**：在自然使用条件下，问答增强组与直接增强组在提示词质量上存在差异。
- **H3（次要结局）**：两组在任务完成质量上存在差异。
- **H0**：上述对应比较中无差异。

> 说明：H1 与 H2 的区分是本设计的核心。H2 可能混合了「提问获取信息」与「增强方法」两种来源；H1 在信息一致条件下更接近方法本身的收益。**不得用一组显著、另一组不显著直接推断两组效果不同**，必须做对应组间比较。

## 2. 研究设计类型与主方案说明

### 2.1 推荐主方案

**被试间随机对照实验（between-subjects randomized controlled trial）**，采用**两阶段信息流控制**：

- **阶段 A（自然使用比较）**：按随机分配，问答增强组进行提问环节，直接增强组不进行提问环节；两组各自完成增强并提交提示词。
- **阶段 B（同信息方法收益比较）**：针对同一案例，先取得并封存实际确认信息（关键问题及答案）；两组均获得逐字相同的原始任务与同一份实际确认信息；问答增强组按指定增强流程使用该信息，直接组同样可使用该信息但不进行提问环节；两组各自完成增强并提交提示词。

> 若资源允许，阶段 A 与阶段 B 可作为**两个独立子研究**分别开展；若在同一参与者内开展，需注意顺序效应与污染，建议采用替代方案中的混合设计（见第 11 节）。

### 2.2 选择依据

- **被试间设计**可避免同一参与者学习效应、需求特征与增强流程污染。
- **随机分配**用于平衡可观测与不可观测的个体差异。
- **两阶段信息流**用于分离「自然使用效果」与「同信息方法收益」，回应公平比较要求。
- **评价对象为提示词质量**，任务完成质量作为次要指标，避免把「答案好坏」与「提示词好坏」混为一谈。

### 2.3 适用条件

- 参与者需具备基本提示词撰写或使用经验（具体门槛见第 3 节）。
- 任务材料需可标准化、可评分，且不依赖不可复现的外部数据。
- 增强工具版本需固定并可记录。
- 评分者需接受统一培训并盲评。

### 2.4 可调整处

- 若样本量受限，可改为**混合设计**（见第 11 节）。
- 若任务类型单一，可增加任务类型作为区组因素。
- 若无法实现完全盲评，需在分析中纳入评分者固定效应并报告盲法破坏情况。
- 评分尺度、样本量、任务数量等未决参数由用户在实施前确认。

## 3. 参与者与招募

### 3.1 目标人群

拟议为**具备提示词撰写经验的成年人**（如高校学生、研究人员、产品/运营/设计从业者等）。具体人群由用户确认。

### 3.2 纳入标准（拟议，待确认）

- 年龄与法定同意能力符合所在机构伦理要求。
- 自报有提示词撰写或大语言模型使用经验（具体门槛未决，例如使用频率、时长、作品数量等）。
- 能阅读并理解任务语言。
- 自愿参与并签署知情同意。

### 3.3 排除标准（拟议，待确认）

- 参与过同案例或同工具的前期试点。
- 与研究者存在直接隶属或评价关系（若无法避免，需在分析中控制）。
- 无法完成全部任务或无法提交可评分提示词。
- 自报使用自动化工具代写提示词且无法记录流程（若研究要求记录流程）。

### 3.4 招募方式

拟议通过**公开招募广告、课程招募、研究参与者池、专业社群**等方式。具体渠道、报酬与伦理审批由用户确认。**不得编造招募数据或参与人数。**

## 4. 随机分配与盲法

### 4.1 随机分配流程

1. 在参与者完成基线问卷后、接触任务材料前进行随机分配。
2. 采用**区组随机化**或**分层随机化**，分层因素可包括：提示词经验水平、任务类型、性别（若伦理与统计需要）。
3. 分配序列由不参与评分的人员生成并保管；使用密封信封或等效的中央随机系统。
4. 记录分配时间、分配结果与任何偏离方案的情况。

### 4.2 盲法安排

- **参与者**：无法对自身是否提问完全盲，但可对研究假设盲（告知为「提示词增强方式比较」）。
- **评分者**：对分组、案例来源、参与者身份**盲评**；提示词文本需去除可识别分组线索（如提问记录、工具界面截图等）。
- **研究者/分析者**：统计分析与评分尽量盲法；若无法盲，需在报告中说明。

### 4.3 盲法破坏处理

记录任何盲法破坏事件，并在分析中做敏感性分析。

## 5. 任务材料与增强工具操作定义

### 5.1 任务材料

- **任务类型**：拟议选择可标准化、可评分的提示词撰写任务，例如「为某类写作/分析/设计任务撰写提示词」。具体任务类型与难度由用户确认。
- **任务数量**：未决。若每人多任务，需考虑顺序与疲劳。
- **任务呈现**：统一格式、统一字数上限或下限（若设限，两组一致）、统一提交模板。
- **案例**：每个案例包含原始任务描述与（阶段 B）实际确认信息。实际确认信息需**先取得并封存**，不得由模型自行生成执行计划替代。

### 5.2 增强工具与操作定义

- **问答增强组**：按指定增强流程，先由增强器提出关键问题，用户回答，再将有效回答融入优化提示词。提问轮次、问题数量、是否允许追问等由用户确认。
- **直接增强组**：不主动发起问答轮次，但仍正常使用已经提供的需求与确认信息；在阶段 B 中同样可使用同一份实际确认信息。
- **工具版本**：固定模型名称、版本、参数（温度、top-p 等）、界面与提示模板；记录调用日志。
- **禁止事项**：不得改写某组回答、另换任务、只增加某组修订轮次；不得以相同字数替代信息一致。

## 6. 公平比较的信息流控制流程

### 6.1 阶段 A（自然使用比较）

1. 两组获得**逐字相同的原始任务**。
2. 问答增强组进行提问环节，获取信息；直接增强组不进行提问环节。
3. 两组各自按指定增强流程完成提示词。
4. 记录问答增强组实际获取的信息内容与轮次。

### 6.2 阶段 B（同信息方法收益比较）

1. **先取得并封存同一案例的实际确认信息**（关键问题及答案）。封存方式：由不参与评分的人员保管，记录封存时间与内容哈希。
2. 两组获得**逐字相同的原始任务**与**同一份实际确认信息**。
3. 问答增强组按指定增强流程使用该信息；直接组同样可使用该信息但不进行提问环节。
4. 两组各自完成增强并提交提示词。
5. **不得**改写某组回答、另换任务或只增加某组修订轮次。

### 6.3 方法收益判断

- 方法收益由**阶段 B 的对应组间比较**判断。
- 自然使用效果由**阶段 A 的对应组间比较**判断。
- **不得**以一组显著、另一组不显著直接证明两组效果不同；需做交互或对应比较。

## 7. 结局指标与测量工具

### 7.1 主要结局：提示词质量

- **定义**：提示词在清晰度、完整性、可执行性、约束明确性、上下文充分性、输出格式规范性等维度的质量。具体维度与权重由用户确认。
- **测量工具**：优先采用已有量表；若无可核实来源，则自编量表并报告编制依据、专家评审与预试结果。**不得编造文献或引用。**
- **评分尺度**：未决。用户未指定前，不默认取值（如不默认 1–5 或 1–7）。

### 7.2 次要结局：任务完成质量

- **定义**：使用该提示词后，任务输出在正确性、完整性、相关性、格式符合度等维度的质量。
- **测量工具**：可采用与主要结局同源或独立的评分量表；具体由用户确认。
- **注意**：评价对象仍以提示词质量为主，任务完成质量仅作补充。

### 7.3 其他指标

- 问答增强组的提问数量、问题类型、信息获取量。
- 增强耗时、修订轮次（需两组一致或作为协变量）。
- 参与者自报满意度、认知负荷（可选）。

## 8. 评分流程与评分者间一致性检验

### 8.1 评分者人数与培训

- 拟议至少 **2 名评分者**独立评分；具体人数未决。
- 培训内容包括：量表维度、评分标准、示例、边界案例、盲评要求。
- 培训后需进行**校准练习**，达到预设一致性门槛后方可正式评分。门槛未决。

### 8.2 盲评安排

- 评分材料去除分组、身份、时间、工具版本等可识别信息。
- 随机化评分顺序。
- 评分者不得参与随机分配与信息封存。

### 8.3 评分者间一致性检验

- 连续变量：ICC（具体模型未决，如 ICC(2,k) 或 ICC(3,k)）。
- 分类变量：Cohen's κ 或 Fleiss' κ。
- 报告点估计与置信区间；若一致性不足，需讨论原因并做敏感性分析。

## 9. 统计分析计划

### 9.1 主要分析

- **阶段 B 主要比较**：以提示词质量为因变量，组别为自变量，纳入预设协变量（如基线经验、任务类型、评分者）。若评分者嵌套，使用混合效应模型。
- **阶段 A 自然使用比较**：同模型，但需注意信息获取量差异。
- **交互检验**：若阶段 A 与 B 在同一参与者内，需检验阶段×组别交互。

### 9.2 次要分析

- 任务完成质量同模型。
- 提问数量、信息获取量作为中介或调节变量（探索性）。
- 亚组分析：按经验水平、任务类型分层。

### 9.3 缺失数据

- 报告缺失比例与模式。
- 预设主要分析采用**完整案例**或**多重插补**；具体由用户确认。
- 做敏感性分析（如 worst-case、tipping point）。

### 9.4 多重比较

- 明确主要与次要结局；次要结局需校正或标注为探索性。
- 报告效应量与置信区间，不只报 p 值。

### 9.5 统计口径

- 明确分析单位（参与者、提示词、评分者）。
- 明确纳入分析的数据范围与排除规则。
- 预注册分析计划，报告任何偏离。

## 10. 潜在混淆变量与控制

| 混淆变量 | 控制方法 |
|---|---|
| 提示词经验 | 分层随机化、基线测量、协变量 |
| 任务类型与难度 | 区组、固定任务集、随机顺序 |
| 工具版本与参数 | 固定版本、记录日志、同环境 |
| 评分者偏差 | 盲评、培训、ICC、多评分者 |
| 顺序与疲劳 | 随机顺序、休息、任务数量控制 |
| 需求特征 | 统一指导语、不透露假设 |
| 信息量差异 | 阶段 B 逐字相同信息；阶段 A 记录信息量 |
| 修订轮次 | 两组一致或作为协变量 |
| 参与者动机 | 统一报酬、统一截止时间 |

## 11. 替代方案及适用条件

### 11.1 被试内设计

- **适用条件**：样本量受限、任务可等价替换、无严重顺序效应。
- **风险**：学习效应、污染、需求特征。
- **控制**：拉丁方平衡、洗脱期、任务等价性检验。

### 11.2 混合设计

- **适用条件**：既想比较组间差异，又想比较阶段差异。
- **结构**：组别为被试间因素，阶段为被试内因素。
- **风险**：阶段顺序效应；需平衡阶段顺序或做交叉设计。

### 11.3 单组前后测

- **适用条件**：仅探索性、无法随机分配。
- **局限**：无法排除时间与练习效应，因果推断弱。

### 12.1 已知事实

### 12.3 必要假设
