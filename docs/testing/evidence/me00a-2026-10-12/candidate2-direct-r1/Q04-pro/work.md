# 研究设计方案（拟议稿，尚未实施）

> 状态说明：本文件为**拟议研究设计**，不是已完成研究的报告。文中所有“建议”“拟”“计划”均表示尚未执行；所有参数凡未确定者均列为“未决参数”，不默认取值；不包含任何实际数据、结果或文献引用。


## 1. 研究问题与假设

### 1.1 研究问题

**主问题**：在相同的原始任务信息与相同的用户确认信息条件下，两种提示词增强流程——
- **A 流程（问答式增强）**：增强器先向用户提出若干关键问题，用户回答后，将有效回答融入原始提示词形成增强提示词；
- **B 流程（直接增强）**：增强器不主动发起问答轮次，直接基于用户已提供的原始任务与确认信息形成增强提示词；

——在**提示词质量**上是否存在可检测的差异？

**次级问题**：
1. 在“同等信息”条件下（即两组获得逐字相同的原始任务与确认信息），A 流程相对 B 流程是否仍有额外收益？
2. 在“自然使用”条件下（即 A 组允许问答、B 组不追问），两组提示词质量差异有多大？该差异在多大程度上可归因于“信息量不同”而非“方法本身”？
3. 提示词质量评价与下游作品质量评价之间的关系如何（仅作补充，不替代主评价）？

### 1.2 假设

- **H1（方法收益假设）**：在同等信息条件下，A 流程产生的提示词质量与 B 流程产生的提示词质量存在差异。
- **H2（自然使用差异假设）**：在自然使用条件下，A 流程产生的提示词质量与 B 流程产生的提示词质量存在差异。
- **H3（信息量解释假设，探索性）**：自然使用条件下的组间差异，大于同等信息条件下的组间差异，即问答带来的额外信息对提示词质量有贡献。
- **H4（下游关联假设，探索性）**：提示词质量评分与下游作品质量评分呈正相关。

> 说明：H1、H2 为双侧检验，不预设方向；H3、H4 为探索性分析。


## 2. 研究对象与招募建议

### 2.1 研究对象

**评价对象**：提示词增强流程产出的**增强提示词文本**。这是本研究的主评价对象，不改为只评下游答案质量。

**任务对象**：一组真实或模拟的“原始任务描述 + 用户确认信息”。任务类型建议选择对提示词质量敏感、且用户有真实需求的任务，例如：
- 写作类任务（如“帮我写一份面向非技术读者的产品说明”）；
- 分析类任务（如“根据给定数据写一份经营分析要点”）；
- 生成类任务（如“设计一个活动方案框架”）。

**未决参数**：任务类型、任务数量、任务难度分布，需在正式实施前确定并预注册。

### 2.2 招募建议（实际招募另标为建议）

- **用户/任务提供者**：建议招募 20–40 名有真实任务需求的用户，每人提供 1–2 个原始任务及必要的确认信息。样本量需根据效应量预期与统计功效计算确定（未决参数）。
- **提示词质量评分者**：建议招募 3–5 名具备提示词工程或任务领域经验的评分者，独立盲评。
- **下游作品执行者**（如设置下游评价）：建议使用固定模型（如某一大语言模型）执行增强提示词，生成下游作品；模型版本与参数需固定并记录。

**纳入标准（建议）**：
- 用户提供的任务为真实需求，非为研究临时编造；
- 任务在增强前具有可识别的不完整或可追问空间（以保证 A 流程有实际问答内容）；
- 用户愿意在流程中提供真实回答。

**排除标准（建议）**：
- 任务涉及违法、高风险或无法由通用模型安全处理的内容；
- 用户无法完成问答或确认环节。


## 3. 实验设计与分组流程

### 3.1 总体设计

采用 **2×2 混合设计**：

| 条件 | 信息条件 | 增强流程 |
|---|---|---|
| A-自然 | 自然使用（允许问答） | 问答式增强 |
| B-自然 | 自然使用（不追问） | 直接增强 |
| A-同等 | 同等信息（封存答案） | 问答式增强 |
| B-同等 | 同等信息（封存答案） | 直接增强 |

其中：
- **自然使用条件**：A 组增强器可向用户提问并获取回答；B 组增强器不提问，仅使用用户已提供信息。
- **同等信息条件**：先将 A 组在自然使用中产生的“用户问答记录”封存；随后将**同一原始任务 + 同一份用户确认信息 + 同一份问答记录（逐字相同）**提供给 A-同等组与 B-同等组。两组均可使用这些信息，但 B-同等组不额外追问。

**关键公平性控制**：
- 同等信息条件下，两组接收并可使用**同一原始任务**和**同一份实际确认信息**；
- 不修改任何一组的回答内容；
- 不更换任务；
- 不额外增加某一组的修订轮次；
- 问答环节由增强器向用户提问、用户回答，**不得由模型自行生成计划或自行拟造回答**。

### 3.2 分组流程

**第一阶段：自然使用条件**

1. 用户提交原始任务 T 与基础确认信息 C0。
2. 将用户随机分配至 A 组或 B 组（或采用被试内设计，同一用户的两个任务分别进入两组；未决参数）。
3. **A 组**：增强器基于 T 与 C0 提出关键问题 Q1…Qk；用户回答 A1…Ak；增强器将有效回答融入，产出增强提示词 P_A_nat。
4. **B 组**：增强器不提问，直接基于 T 与 C0 产出增强提示词 P_B_nat。
5. 封存 A 组的问答记录 R = {Q1…Qk, A1…Ak}。

**第二阶段：同等信息条件**

6. 对每个任务，将封存的 R 与 T、C0 打包为“同等信息包”。
7. **A-同等组**：增强器接收同等信息包，按问答式增强流程产出 P_A_eq。此阶段增强器**不再向用户提出新问题**，仅使用信息包内已有问答记录（即“谁提问、谁回答”已发生在第一阶段；第二阶段不新增提问）。
8. **B-同等组**：增强器接收同等信息包，按直接增强流程产出 P_B_eq。B-同等组不追问，但**可以使用信息包内的全部信息**，包括问答记录 R。

> 说明：第二阶段 A-同等组“不再提问”是为了保证同等信息条件成立。若 A-同等组再提问并获得新回答，则信息量又多于 B-同等组，公平性被破坏。因此，同等信息条件下的“问答式增强”指的是：增强器使用已有的问答记录进行增强，而非新增问答。

### 3.3 流程示意

```
用户任务 T + 确认信息 C0
        │
        ├── A组（自然）：提问 → 用户回答 R → 增强 → P_A_nat
        │
        └── B组（自然）：不提问 → 增强 → P_B_nat
                    │
                    ▼
        封存 R，构建同等信息包 {T, C0, R}
                    │
        ├── A-同等：使用 {T, C0, R} → 增强 → P_A_eq
        │
        └── B-同等：使用 {T, C0, R} → 增强 → P_B_eq
```

### 3.4 随机化与分配

- **随机化层级**：任务级随机化。每个任务在自然使用条件下随机分配至 A 或 B 流程。
- **分配隐藏**：用户提交任务前不知晓分组。
- **盲法**：提示词质量评分者不知道每条提示词来自哪个流程、哪个信息条件。
- **未决参数**：采用被试间还是被试内设计；若被试内，任务顺序的平衡方式（如拉丁方）。


## 4. 变量定义与测量指标

### 4.1 自变量

| 变量 | 水平 | 定义 |
|---|---|---|
| 增强流程 | A 问答式 / B 直接式 | 增强器是否在增强前主动发起用户问答轮次 |
| 信息条件 | 自然使用 / 同等信息 | 两组是否获得逐字相同的问答记录 |

### 4.2 主因变量：提示词质量

**定义**：增强提示词在多大程度上完整、准确、可执行地表达了用户任务需求与约束。

**测量方式（建议采用多维评分量表）**，每个维度 1–7 分：

| 维度 | 操作定义 |
|---|---|
| 完整性 | 提示词是否覆盖任务目标、背景、约束、输出要求等必要要素 |
| 准确性 | 提示词是否忠实于用户原始需求与确认信息，无曲解、无遗漏关键约束 |
| 可执行性 | 提示词是否可直接交由模型执行，无需执行者再猜测或补充关键信息 |
| 结构清晰度 | 提示词组织是否层次分明、易于理解 |
| 信息冗余度（反向） | 是否包含无关或重复信息，干扰执行 |

**主指标**：上述维度的总分或均值（未决参数：是否加权、权重如何确定）。

**评分流程**：
- 评分者独立盲评；
- 每条提示词由至少 2–3 名评分者评分；
- 报告评分者间信度（如 ICC 或 Krippendorff’s α）。

### 4.3 次要因变量：下游作品质量（补充，不替代主评价）

**定义**：将增强提示词交由固定模型执行后，产出作品在任务相关维度上的质量。

**测量方式**：
- 由评分者按任务特定标准盲评（如写作类：清晰度、受众适配度、信息准确性；分析类：逻辑性、数据使用正确性等）；
- 维度与量表需在正式实施前按任务类型确定（未决参数）。

### 4.4 控制变量与协变量

- 原始任务复杂度（评分者评定或字数/要素数）；
- 原始任务类型；
- 用户确认信息的详细程度；
- 问答轮次数量（A 组自然使用）；
- 增强提示词长度（作为协变量或进行敏感性分析）；
- 执行模型版本与参数（固定）。

### 4.5 指标口径

- **提示词质量分**：多名评分者评分的均值；若信度不足（如 ICC < 0.6），需增加评分者或修订评分标准后重评。
- **方法收益**：由**同等信息条件下的组间比较**（P_A_eq vs P_B_eq）判断。
- **自然使用差异**：由自然使用条件下的组间比较（P_A_nat vs P_B_nat）判断。
- **信息量贡献**：由自然使用差异与方法收益的对比（交互效应或差值比较）探索性判断。


## 5. 数据收集与记录流程

### 5.1 数据收集步骤

1. **任务收集**：用户提交原始任务 T 与基础确认信息 C0；记录提交时间、用户编号。
2. **自然使用阶段**：
   - A 组：记录增强器提出的每个问题、用户的逐字回答、问答轮次、时间戳；
   - B 组：记录增强器未提问的事实；
   - 两组均记录产出的增强提示词全文。
3. **同等信息阶段**：
   - 记录同等信息包内容（T、C0、R 的逐字文本）；
   - 记录两组产出的增强提示词全文；
   - 记录两组是否遵守“不新增提问”的约束（通过流程日志核查）。
4. **评分阶段**：
   - 对提示词去标识化、随机排序；
   - 评分者独立评分并提交评分表；
   - 记录评分者编号、评分时间。
5. **下游执行阶段（如设置）**：
   - 固定模型与参数；
   - 逐条执行增强提示词，保存输出全文；
   - 对下游作品去标识化、随机排序后盲评。

### 5.2 数据记录清单

| 数据项 | 内容 | 格式 |
|---|---|---|
| 任务元数据 | 任务编号、类型、复杂度 | 结构化表格 |
| 原始任务 | T 全文 | 文本 |
| 确认信息 | C0 全文 | 文本 |
| 问答记录 | Q1…Qk, A1…Ak 逐字文本 | 文本 |
| 增强提示词 | P_A_nat, P_B_nat, P_A_eq, P_B_eq 全文 | 文本 |
| 提示词评分 | 各维度分、总分、评分者编号 | 数值 |
| 下游作品 | 模型输出全文 | 文本 |
| 下游评分 | 各维度分、总分、评分者编号 | 数值 |
| 流程日志 | 是否提问、轮次、时间戳、违规记录 | 结构化表格 |

### 5.3 数据完整性

- 所有文本数据保留原始版本，不做事后修改；
- 若某任务在任一阶段缺失数据（如用户未完成问答、增强失败），该任务在对应分析中标记为缺失，并报告缺失原因；
- 缺失数据处理方案：主分析采用可用数据；敏感性分析采用多重插补或完整案例分析（未决参数）。


## 6. 统计分析方法

### 6.1 主分析：提示词质量

**模型**：线性混合效应模型（LMM）

```
提示词质量分 ~ 增强流程 × 信息条件 + (1 | 任务) + (1 | 评分者)
```

- 固定效应：增强流程（A/B）、信息条件（自然/同等）、二者交互项；
- 随机效应：任务（截距）、评分者（截距）；
- 若任务数量较少，可考虑将任务作为固定效应或使用稳健标准误（未决参数）。

**关键比较**：
- **方法收益**：同等信息条件下 A vs B 的简单效应（P_A_eq vs P_B_eq）；
- **自然使用差异**：自然使用条件下 A vs B 的简单效应（P_A_nat vs P_B_nat）；
- **信息量贡献（探索性）**：交互项是否显著，或比较 (P_A_nat − P_B_nat) 与 (P_A_eq − P_B_eq) 的差值。

### 6.2 效应量

- 报告标准化均值差（如 Cohen’s d 或 Hedges’ g）及其置信区间；
- 报告模型估计系数与 95% CI。

### 6.3 信度分析

- 评分者间信度：ICC（双向随机、绝对一致）或 Krippendorff’s α；
- 若信度不足，进行评分者培训后重评或增加评分者。

### 6.4 敏感性分析

- 控制提示词长度后重复主分析；
- 排除问答轮次为 0 的 A 组任务后重复分析；
- 按任务类型分层分析；
- 使用非参数方法（如 Wilcoxon 秩和检验）作为稳健性检验。

### 6.5 多重比较

- 若进行多个简单效应检验，采用 Holm 或 Benjamini-Hochberg 校正（未决参数）。

### 6.6 样本量

- **未决参数**：需基于预试验或文献估计效应量，设定 α = 0.05、功效 ≥ 0.80，计算所需任务数量与评分者数量。本方案不默认任何具体数值。


## 7. 适用条件与局限性

### 7.1 适用条件

本设计适用于以下情形：
1. 用户能提供真实任务，且任务存在可追问空间；
2. 增强器可被标准化为固定流程（如固定提示词模板、固定模型），以保证组内一致性；
3. 评分者能理解任务领域并接受统一评分培训；
4. 问答环节能真实发生，且用户回答可被逐字记录；
5. 同等信息阶段能严格封存并使用同一份问答记录。

### 7.2 局限性

1. **外部效度有限**：研究中的增强器行为受标准化约束，与真实使用中的灵活增强可能有差异。
2. **任务异质性**：不同任务类型对提示词质量的敏感度不同，汇总分析可能掩盖类型特异性效应。
3. **评分主观性**：提示词质量评分虽有量表，仍受评分者经验与偏好影响；通过盲评与信度报告缓解，但无法完全消除。
4. **同等信息条件的构造性**：同等信息条件下 A 组“不再提问”是对自然流程的约束，可能低估 A 流程在真实场景中的完整收益；但这是公平比较所必需。
5. **问答质量依赖用户**：用户回答质量影响 A 流程效果；若用户回答敷衍，A 流程优势可能无法体现。
6. **不能由单组显著性推断组间差异**：本方案明确以组间比较判断方法收益与自然使用差异，不采用“A 组显著、B 组不显著即证明两组不同”的推断逻辑。
7. **未控制增强器模型差异**：若 A、B 流程使用不同底层模型或不同增强模板，混杂风险增加；需固定模型与模板（未决参数）。
8. **缺失数据**：用户中途退出或问答不完整可能导致缺失；需报告缺失机制并做敏感性分析。


## 8. 拟议主方案与替代方案

### 8.1 拟议主方案（推荐直接开展）

**方案名称**：封存问答的同等信息对照设计

**要点**：
- 第一阶段：自然使用条件下，A 组问答式增强、B 组直接增强，产出 P_A_nat 与 P_B_nat，并封存 A 组问答记录 R；
- 第二阶段：同等信息条件下，将 {T, C0, R} 提供给 A-同等组与 B-同等组，分别产出 P_A_eq 与 P_B_eq；
- 主评价对象为增强提示词质量，多维盲评；
- 方法收益由 P_A_eq vs P_B_eq 判断；自然使用差异由 P_A_nat vs P_B_nat 判断；
- 下游作品质量作为补充评价。

**优点**：
- 直接分离“信息量差异”与“方法本身差异”；
- 公平性控制明确：两组接收并可使用同一原始任务与同一份实际确认信息；
- 保留真实用户问答，不改为模型自行生成计划。

**适用条件**：
- 能招募到真实用户并完成问答；
- 能对增强器流程做标准化约束；
- 能组织盲评并保证评分者信度。

### 8.2 替代方案一：仅同等信息对照（简化版）

**要点**：
- 不设自然使用阶段；
- 预先收集一批任务的原始描述、确认信息与问答记录（问答记录可来自真实用户或历史数据，但必须为真实问答，不得由模型生成）；
- 将同一信息包分别交给 A、B 两种增强流程，比较 P_A_eq 与 P_B_eq。

**优点**：
- 流程更简单，样本量需求较小；
- 直接回答“方法收益”问题。

**缺点**：
- 无法估计自然使用条件下的总差异；
- 无法分离信息量贡献。

**适用条件**：
- 研究资源有限，或主要关心方法本身收益；
- 已有可用的真实问答记录。

### 8.3 替代方案二：被试内交叉设计

**要点**：
- 同一用户提供两个任务，一个任务分配至 A 流程，另一个分配至 B 流程；
- 同等信息阶段按任务分别构建信息包；
- 比较同一用户内两流程的提示词质量差异。

**优点**：
- 控制用户层面的个体差异；
- 统计功效可能更高。

**缺点**：
- 用户可能因先经历某一流程而产生学习效应或期望效应；
- 任务间差异仍存在，需随机化与平衡。

**适用条件**：
- 用户能提供多个同质任务；
- 能有效平衡顺序效应。

### 8.4 替代方案三：下游作品为中介的扩展设计

**要点**：
- 在主方案基础上，增加下游作品质量评价，并分析提示词质量是否中介了流程对下游作品质量的影响。

**优点**：
- 提供从提示词到作品的作用链条证据。

**缺点**：
- 增加执行与评分成本；
- 下游作品质量受模型能力影响，可能稀释提示词质量差异。

**适用条件**：
- 研究问题同时关心提示词质量与下游效果；
- 能固定执行模型并控制生成随机性（如设置温度参数、多次采样取均值）。

## 11. 结论

本方案为一项拟议研究设计，旨在公平比较“问答式增强”与“直接增强”两种提示词增强流程。核心设计为**封存问答的同等信息对照**：先在自然使用条件下收集真实问答并封存，再在同等信息条件下比较两种流程的提示词质量。方法收益由同等信息条件下的组间比较判断，自然使用差异由自然使用条件下的组间比较判断，二者不可混淆。所有已定与未决参数分开列示，未决参数需在实施前确定并预注册。本方案不包含任何实际数据、结果或已完成研究状态的陈述。
