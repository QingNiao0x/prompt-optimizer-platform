# 分数大小比较课时设计（合成学校·初一·45分钟）

以下为三份交付物：教师教案、学生练习页、单独答案页，最后附依据核对。全部例题与练习只用正真分数，不涉及负数、假分数与代数分式。

---

## 交付一：教师教案

**课题**：异分母分数的大小比较——用数轴与通分说理由
**对象**：初一某班，30人，10组×3人
**课时**：45分钟（导入5 + 示范10 + 合作活动15 + 练习10 + 总结5）
**已有基础**：会同分母比较，会基本通分
**本节重点**：用数轴与通分两种方式**解释**异分母正真分数的大小关系，不只教算法口诀

### 教学目标（可观察行为）

1. 能在同一条0到1的数轴上标出两个异分母正真分数，并依据“右边的数大”判断大小；
2. 能用分数基本性质说明“通分后分数值不变”，再按同分母法则比较分子；
3. 能用“因为……所以……”完整说出比较理由，并指出“只比分子”“只比分母”“整体不同”三类说法错在哪里。

### 课前材料准备（不占45分钟课时）

| 材料 | 数量 | 用途 |
|---|---|---|
| 黑板0到1数轴 | 1条（课前画好，留出再画空间） | 示范与汇报验证 |
| 等长纸条（如20厘米） | 每组4条共40条，另备教师演示2条 | 合作活动折出分数 |
| 任务卡（教师预写） | 每组1张 | 写明活动两个任务 |
| 记录纸 | 每组1张 | 记录结论与理由 |
| 学生练习页 | 30份 | 练习环节才发放 |
| 答案页 | 教师自留 | 核对 |

**注意**：学生用纸条必须全部等长（代表同一个整体）；教师另备的两条**不等长**纸条只在示范环节做反例展示，不发给学生。本节不使用任何电子设备。

### 教学过程

**一、导入（5分钟）**
1. （约2分钟）口头复习：3/7和5/7哪个大？为什么？（预设：分母相同，每份一样大，分子大的份数多。）
2. （约2分钟）提出新问题：3/4和5/6哪个大？分母不同、分子也不同，还能直接比吗？请学生口头猜。
3. （约1分钟）若有学生提“交叉相乘”，回应：结果可以验证，但今天要求每个人能**讲出道理**，学两种能解释的方法——数轴与通分。板书课题。

**二、示范（10分钟）——例题：比较3/4和5/6**

1. 数轴解释（约4分钟）
   - 黑板画同一条0到1数轴，说明"1"代表同一个整体。
   - 把0到1平均分成4份，标出3/4；再在**同一个整体**上平均分成6份，标出5/6。
   - 观察：5/6在3/4右边——数轴上右边的数大。
   - 追问：“两点很近，只靠眼睛看可靠吗？”→ 把0到1平均分成12份：3/4=9/12，5/6=10/12，10/12恰在9/12右边一格，精确确认。
2. 通分解释（约4分钟）
   - 3/4 = (3×3)/(4×3) = 9/12；5/6 = (5×2)/(6×2) = 10/12。
   - **必须讲清理由**：分子分母同乘不为0的同一个数，分数值不变——相当于每份切得更细、份数变多，但取的部分一样多。
   - 分母相同→每份一样大→比分子：10>9，所以5/6>3/4。与数轴结论一致。
3. 误解追问（约2分钟）
   - 追问1：“5>3，所以5/6>3/4，行吗？”反例：1/2和3/8，分子3>1，但3/8<1/2。
   - 追问2：“分母4<6，所以3/4>5/6，行吗？”反例：1/3和1/5，分母5>3，但1/5<1/3。
   - 追问3（出示两条不等长纸条）：“这两条纸条上的3/4能直接比吗？”——不能，整体不同；要比较必须回到同一个整体。
   - 追问只针对理由本身，不评价学生。

**三、合作活动（15分钟）——十组三人，纸条＋口头解释**

1. 分工与领材料（约1分钟）：每组三人，角色为**定位员**（把纸条折出等份、标出分数）、**记录员**（写下比较结果和理由）、**说明员**（用“因为……所以……”解释）。两个任务之间至少轮换一次角色。
2. 任务一（约6分钟）：比较 **2/3 和 3/8**。
   - 定位员把两条等长纸条分别折出三等份、八等份；
   - 全组通分：2/3=16/24，3/8=9/24，所以2/3>3/8；
   - 记录员写下结论与理由，说明员准备口头解释。
   - 预设陷阱：只比分子会误判为3/8大（3>2），巡视时追问。
3. 任务二（约5分钟，轮换角色）：比较 **5/8 和 3/4**。
   - 通分：3/4=6/8，5/8<6/8，所以5/8<3/4。
   - 预设陷阱：只比分母会误判为5/8大（8>4）。
4. 汇报与验证（约3分钟）：抽2—3组的说明员到黑板前，在数轴上指出位置并说理由；教师在黑板数轴上标出通分结果核对。可随机请记录员补充，保证“会解释”不是一个人的事。

巡视追问语（教师用）：
- “你的两条纸条一样长吗？为什么必须一样长？”
- “通分以后，为什么分数的大小没有变？”
- “数轴上谁在右边？和通分的结果一致吗？”

**四、练习（10分钟）**
- 发放学生练习页（基础层3题＋应用层3题），独立完成。
- 时间分配：基础层约4分钟，应用层约6分钟。
- 教师巡视，优先查看应用层是否写出理由；对只写结果的学生追问“为什么”。
- 未完成部分在总结环节口头核对，**不布置任何课后作业**。

**五、总结（5分钟）**
1. 请1—2名学生口头总结两种方法。
2. 教师板书要点：
   - 数轴法：同一个整体、同一条0到1数轴，右边的数大；
   - 通分法：分数基本性质保证分数值不变→化成同分母→分子大的分数大；
   - 前提：比较必须在同一个整体（单位"1"相同）下进行。
3. 收尾语：比较分数大小，要么“看位置”，要么“变同分母”，都要能说出理由。

### 板书设计

- 左：0到1数轴，标出3/4、5/6、9/12、10/12的位置
- 中：通分过程 3/4=9/12，5/6=10/12，5/6>3/4
- 右：方法两条＋误区提醒：只比分子✗ 只比分母✗ 整体不同✗

### 评价方式

以“能否解释比较理由”为主：活动中听说明员表达，练习中看应用层书面理由。不排名、不公开个人成绩；对错误回答用追问引导，不归因于学生能力或态度。

## 交付三：参考答案与讲解（教师用，单独成页）

**基础层**

1. 4/9 **<** 7/9。分母相同，每份一样大；7份比4份多，所以7/9大。
2. 1/3 **>** 1/5。数轴上1/3的点在1/5右边（可把0到1分成15份核对：1/3=5/15，1/5=3/15）。同一个整体，分的份数越多，每份越小。
3. 2/5 = 4/10 **>** 3/10。分子分母同乘2，分数值不变；化成同分母后比分子，4>3。

**应用层**

4. 4/5 = (4×7)/(5×7) = 28/35；5/7 = (5×5)/(7×5) = 25/35。因为28>25，所以4/5>5/7。
   分数值不变的理由：分子分母同乘不为0的同一个数，相当于每份切得更细、份数按同比例变多，取的部分没有变（分数基本性质）。
5. 把0到1平均分成6份：2/3=4/6标在第4个分点，5/6标在第5个分点。5/6在右边，所以5/6>2/3。理由：同一条0到1数轴上，右边的数大。
6. 小明不对。两个分数分母不同，每份大小不同，只比分子没有依据。通分：7/10=14/20，3/4=15/20，15>14，所以3/4>7/10。（数轴验证：把0到1分成20份，15/20在14/20右边。）建议示例：“分母不同时，先通分或在数轴上比位置，不能只看分子。”

**讲解要点**
- 数轴法直观定位，通分法精确计算；两者结论一致，可互相验证。答案展示两种思路供讲评选用，不要求学生对每题两种方法各做一遍。
- 全部题目只使用正真分数，未引入负数、假分数或代数分式。
