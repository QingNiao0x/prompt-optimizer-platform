# 甲地区2015—2025年心脑血管死亡登记研究：开题讨论版方法方案

**文档状态**：开题讨论稿，非已完成分析。所有数值、置信区间、显著性均未计算；图表标题仅为模板。

**读者**：医学研究生论文开题评审组、方法学审查人员。

**资料边界**：本方案基于合成资料，不涉及真实个体数据。研究工具为R，计划数据格式为CSV，但当前尚未获得完整死亡记录和人口分母。


## 1. 研究设计

**设计类型**：基于死亡登记资料的回顾性描述性研究，拟覆盖甲地区2015—2025年心脑血管死亡记录。

**研究问题**：描述甲地区心脑血管死亡的长期趋势、季节性特征及人群分布差异，并在前提满足时估计减寿负担。

**当前可执行与暂不可执行的区分**：

| 分析模块 | 当前状态 | 前置缺口 |
|---|---|---|
| 死亡记录字段与字典核对 | 可执行 | 需完整CSV记录 |
| 粗死亡率趋势 | 待人口分母 | 各年度人口分母未提供 |
| 年龄特异率趋势 | 待人口分母与年龄组口径 | 5岁组/10岁组聚合映射未确认 |
| 标准化率趋势 | 暂不可执行 | 无标准人口权重 |
| 季节性分析 | 暂不可执行 | 需按月登记完整性核查；年度汇总不能自动补成月度序列 |
| 性别/地区/亚类比较 | 部分待定 | U记录分母口径、地区归属口径、A/B/C映射均未确认 |
| YLL与YLL率 | 暂不可执行 | 参考寿命表、死亡年龄、人口分母均未确定 |
| Arriaga分解 | 暂不可执行 | 比较对象与差异指标未确定 |


## 2. 数据来源与字段

**计划数据源**：合成死亡登记CSV，字段字典如下（来源：materials/medical_research/current-brief.md）。

| 字段 | 格式/值域 | 说明 |
|---|---|---|
| 死亡日期 | YYYY-MM-DD | 用于年度、月度、年龄计算 |
| 性别 | F / M / U | U为未知，不并入F或M |
| 年龄组 | 5岁组（登记字典口径） | 分析草稿使用10岁组，聚合映射未确认 |

**数据质量核查项（开题阶段安排，不视为已完成）**：
- 死亡日期完整性、重复记录、跨年度记录归属。
- 性别U的记录数及分布。
- 年龄组最高开放组边界。
- 地区字段的登记口径说明。
- 各年度记录制度变化核查清单（材料未给出改革日期，不预设某年调整）。


## 3. 分析思路

### 3.1 长期趋势

**指标分层**：
- **粗死亡率**：死亡数 ÷ 同期人口总数。需人口分母。
- **年龄特异率**：某年龄组死亡数 ÷ 该年龄组人口数。需年龄组人口分母；5岁组与10岁组口径须先统一。
- **标准化率**：需标准人口权重。当前字典含年龄字段但无标准人口权重，**不得声称已可完成标准化**。

**趋势描述**：拟用R进行描述性统计与绘图。模型选择（如Joinpoint、Poisson回归等）仅作为候选建议，需在获得完整数据后评估样本量与零死亡单元情况，不保证模型收敛。

### 3.2 季节性分析

**前提**：需按月登记完整性核查及报告延迟评估。若仅有年度汇总表，**季节性分析暂无法执行**，不得将年度数据自动拆分为月度序列。

### 3.3 性别比较

- 性别F、M、U分别呈现。
- U作为数据质量项单独报告。
- U是否进入总量与分层分母：**待团队确认**，不按姓名或其他个人特征推断。

### 3.4 地区比较

- 使用登记归属地区字段。
- 解释时保留“登记归属地区”口径，**不得称为居住地区死亡风险**，除非另有居住地核对资料。

### 3.5 疾病亚类比较

- A、B、C为占位代码，实际映射须由专业人员确认。
- 在映射批准前，亚类比较仅作为方法框架，不产出分类结论。

### 3.6 YLL与YLL率

- **YLL**：取决于参考寿命表与死亡年龄。参考寿命表及适用年份**尚未决定**，不自动选某机构寿命表。
- **YLL率**：YLL ÷ 对应人口分母。需各年度与分层人口分母。
- **禁止把标准化死亡率当作YLL率**。两者是不同指标，不能相互替换。

### 3.7 Arriaga分解

- Arriaga方法涉及比较对象和分解指标。
- 当前**比较哪些人群、分解哪个差异对象尚未确定**。
- 在比较对象未知时，不写出看似完整但可能不适用的计算流程。
- 需先确认：比较的是死亡率差异还是预期寿命差异，以及分解到年龄组的指标定义。
