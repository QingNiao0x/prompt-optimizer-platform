## 2. 缺失处理决策表

> 缺失答卷状态未知（F2/F10），以下为**可能呈现方式及其影响**，均**不默认执行**。用户已确认（U2/U3）：保留独立缺失状态，不默认剔除、补零或计为未完成。

| 场景 | 可能呈现方式 | 对完成率的影响 | 对分部门表的影响 | 是否默认 | 依据/备注 |
|---|---|---|---|---|---|
| 完成率 | 保留为独立“缺失”状态，不计入分子也不计入分母 | 完成率仅在“已明确状态”的子集上计算，需注明覆盖 | — | 否（待 P2） | U2；F2 |

| 完成率 | 补零 | 等同于计为未完成 | — | 否（待 P2） | 不得补零（U2） |

### 4.1 工具无关流程（主流程）

```
输入：登记表（含月份、registered_count 等）、答卷汇总表（含 valid_response_count、missing_response_count、完成状态字段）
输出：空白分部门汇总表结构 + 口径标注（不计算比例）

步骤：
1. 校验输入
   1.1 检查必需字段是否存在：registered_count, valid_response_count, missing_response_count, 完成状态字段, 部门字段

   1.3 检查边界：分母为 0 时，不计算比例，返回“分母为零，无法计算”
   1.4 检查非法值：负数、非数值文本 → 返回清晰错误信息，不吞掉错误

   2.1 标注完成率分母口径：待用户确认（全部登记人数 / 有效答卷人数）

3. 构建空白分部门汇总表
   3.1 列：部门、已登记数、有效答卷数、已完成数、缺失答卷数、口径标注、备注

5. 输出
   5.1 返回空白模板与口径说明
```

```r
validate_input <- function(df) {
  required <- c("registered_count", "valid_response_count",
                "missing_response_count", "completion_status", "department")
  missing_cols <- setdiff(required, names(df))
  if (length(missing_cols) > 0) {
    stop(paste("缺少必需字段:", paste(missing_cols, collapse = ", ")))
  }
  num_cols <- c("registered_count", "valid_response_count", "missing_response_count")
  for (col in num_cols) {
    if (any(df[[col]] < 0, na.rm = TRUE)) {
      stop(paste(col, "存在负值，非法"))
    }
  }
  # 空值视为未登记，不视为 0
  invisible(TRUE)
}

build_blank_summary <- function(departments) {
  data.frame(
    department = departments,
    registered_count = NA_integer_,
    valid_response_count = NA_integer_,
    completed_count = NA_integer_,
    missing_count = NA_integer_,
    completion_status_scope = "待确认（COMPLETE/DONE）",
    missing_handling_scope = "待确认",
    note = "",
    stringsAsFactors = FALSE
  )
}
```

### 4.3 Python 等价表达（参考，非已选工具）

```python
# 仅结构校验与空白模板构建，不计算比例
def validate_input(df):
    required = ["registered_count", "valid_response_count",
                "missing_response_count", "completion_status", "department"]
    missing_cols = [c for c in required if c not in df.columns]
    if missing_cols:
        raise ValueError(f"缺少必需字段: {missing_cols}")
    for col in ["registered_count", "valid_response_count", "missing_response_count"]:
        if (df[col].dropna() < 0).any():
            raise ValueError(f"{col} 存在负值，非法")
    # 空值视为未登记，不视为 0
    return True

def build_blank_summary(departments):
    return [
        {
            "department": d,
            "registered_count": None,
            "valid_response_count": None,
            "completed_count": None,
            "missing_count": None,
            "completion_status_scope": "待确认（COMPLETE/DONE）",
            "missing_handling_scope": "待确认",
            "note": "",
        }
        for d in departments
    ]
```

## 5. 分子是否要求同时满足完成与有效

| 候选分子定义 | 含义 | 适用条件 | 当前状态 |
|---|---|---|---|
| 候选 1：仅“已完成” | 分子 = 完成状态为 `COMPLETE`（或 `DONE`，待映射）的答卷数 | 关注完成动作本身，不要求通过质检 | **待用户确认（P4）** |
| 候选 2：同时满足“完成”与“有效” | 分子 = 既完成又通过质检的答卷数 | 关注“完成且可用”的答卷 | **待用户确认（P4）** |

> **说明**：完成状态与有效状态不是同一维度（F3），一份完成的答卷仍可能被质检排除。因此分子定义必须由用户明确选择，**不得默认**。用户选择与数据来源须同时标注（F14）。

## 6. 跨部门比较的呈现要求

1. **呈现登记覆盖与缺失情况**，而非只排高低名次（F14）。
2. 缺失程度不均可能影响解释，但**无证据时不声称存在选择偏倚**（F14）。
3. 报告解释只说明**可观察差异与数据限制**，不推断部门管理效果、员工态度或个人绩效。
4. 不将合成示例当作单位真实表现。
5. 若分母后来改为有效答卷人数，**登记口径不能直接消失**，应保留覆盖差异（F14）。
