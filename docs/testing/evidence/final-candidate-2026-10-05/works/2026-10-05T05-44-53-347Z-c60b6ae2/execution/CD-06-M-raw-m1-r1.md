## 1. 指标定义与两种分母口径对照

### 1.1 基础字段（来自数据字典）

- `registered_count`：登记数，纳入名单的事件总数。
- `valid_response_count`：有效答卷数，经过现有质检的问卷数量。
- `missing_response_count`：缺失答卷数，状态未知。
- 百分号字段：人工登记的文本标签，**不保证与分子分母一致，不得直接作为计算结果**。

### 1.2 指标定义

| 指标 | 定义 | 分子 | 分母 | 当前可否计算 |
|---|---|---|---|---|
| 登记覆盖 | 有效答卷占登记数的比例 | `valid_response_count` | `registered_count` | 分母未定，暂不计算 |
| 有效完成率 | 有效答卷占登记数的比例 | `valid_response_count` | `registered_count` | 同上 |
| 缺失占比 | 缺失答卷占登记数的比例 | `missing_response_count` | `registered_count` | 同上 |
| 完成状态占比 | 完成状态为 COMPLETE 的记录占比 | 待确认状态码 | 待确认 | 状态码映射未定，暂不计算 |

### 1.3 两种分母口径对照

| 维度 | 口径 A：分母 = 全部登记人数 | 口径 B：分母 = 有效答卷人数 |
|---|---|---|
| 分子 | 有效答卷数 | 有效答卷数 |
| 分母 | `registered_count` | `valid_response_count` |
| 含义 | 反映登记名单中最终有效的覆盖程度 | 反映有效答卷内部的构成 |
| 缺失答卷位置 | 在分母中，作为未覆盖部分 | 不在分母中，需单独列示 |
| 登记口径是否保留 | 是 | 是，必须同时保留覆盖差异 |
| 当前状态 | 未决定，不得默认补全 | 未决定，不得默认补全 |

**说明**：两种口径不是“哪个更好看”的选择，而是回答不同问题。最终方案须同时标注**用户选择**与**数据来源**。若分母改为有效答卷人数，登记口径不能消失，应保留覆盖差异列。

## 2. 缺失处理决策表

缺失答卷状态未知，**不能自动剔除、补零或当作未完成**。以下为待确认的处理选择，每项均需研究者明确决定后方可执行。

| 编号 | 决策项 | 可选处理 | 当前状态 | 影响 |
|---|---|---|---|---|
| M1 | 缺失答卷是否进入完成率分母 | 进入 / 不进入 / 单独列示 | 未决定 | 改变完成率数值与解释 |
| M2 | 缺失答卷在分部门表中的呈现 | 单列 / 合并 / 省略 | 未决定 | 影响部门间可比性 |
| M3 | 缺失原因是否区分 | 区分未作答/同步失败/未完成登记 | 字典未区分 | 无法归因 |
| M4 | 缺失是否等同未完成 | 是 / 否 | 未决定，不得默认 | 影响完成状态统计 |
| M5 | 空白与零的区分 | 零为有效观测，空白为未登记 | 已明确 | 不得用零填充空白 |
| M6 | 分母为零时的呈现 | 留空 / 标注“不适用” | 未决定 | 避免除零与误导 |

**注意**：M1–M4、M6 为真正影响任务目标的业务决定，保留为待确认项；M5 已由资料明确，不需再确认。

| 数据字典 | COMPLETE | 未提供与其他码的映射 |

## 5. 可复核伪代码（工具无关流程）

以下为工具无关流程，不假定研究者已选择 R 或 Python。若需具体语言实现，可分别映射。

```
# 输入：登记表（含 registered_count、月份）、答卷汇总表（含 valid_response_count、missing_response_count、完成状态）
# 注意：两表无关联键时，不得编造各月有效答卷数量

流程 描述性汇总:
    1. 读取登记表与答卷汇总表
    2. 检查字段:
        - registered_count 是否存在
        - valid_response_count 是否存在
        - missing_response_count 是否存在
        - 完成状态码取值集合（COMPLETE / DONE / 其他）
    3. 若完成状态码映射未确认:
        标记完成状态统计为“待确认”，不计算
    4. 若完成率分母未确认:
        标记完成率为“待确认”，不计算
    5. 按部门分组:
        对每个部门:
            registered = 该部门 registered_count
            valid = 该部门 valid_response_count
            missing = 该部门 missing_response_count
            completed = 待确认
            输出: 部门, registered, valid, completed, missing
            若 registered == 0:
                按 M6 决定完成率呈现（留空或“不适用”）
            否则:
                完成率 = 待确认（分母未定）
    6. 区分零与空白:
        零 -> 有效观测值，参与统计
        空白 -> 未登记，不填充，不参与均值计算
    7. 输出空白结果表，不生成数据行
```

**语言映射提示**：
- R：可用 `dplyr::group_by` + `summarise`，但不得在分母未定时计算比例。
- Python：可用 `pandas.groupby` + `agg`，同样不得在分母未定时计算比例。
- 工具选择不影响完成率定义。

## 6. 限制与待确认项

### 6.1 已明确的限制

- 无完整数据文件，仅有数据字典与抽样示意。
- 百分号字段为人工文本标签，不得直接作为计算结果。
- 月份仅在登记表中存在，无关联键时不能编造各月有效答卷数量或时间序列。
- 旧报表百分比为演示排版，不得继承。
- 不声称有完整数据，不生成假统计结果，不写因果结论。
- 不推断部门管理效果、员工态度或个人绩效。

| Q4 | 分母为零时的呈现规则 | 决定除零处理 |
| Q5 | 缺失原因是否可区分 | 决定能否归因 |

### 6.3 不需再确认的项
