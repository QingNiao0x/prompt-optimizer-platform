# 初一数学《异分母分数的大小比较》教案

**课题**：用数轴与通分比较异分母分数的大小  
**年级**：初一  
**班级规模**：30人，每组3人，共10组  
**课时**：45分钟  
**教学条件**：黑板、纸条、教师口头提问；无投影、无个人电子设备  
**教学内容边界**：只使用正真分数；不涉及负数、假分数、代数分式；不把交叉相乘作为唯一方法

**材料准备（课前完成，不占用45分钟）**：
- 黑板划分区域：左侧画一条0到1的数轴，中间留通分演算区，右侧写活动要求。
- 每组准备若干等长纸条（代表同一个整体“1”），可预先折出二等分、三等分、四等分、六等分刻度。
- 教师可预写几组分数卡片：如 \(\frac12\) 与 \(\frac13\)、\(\frac23\) 与 \(\frac34\)、\(\frac34\) 与 \(\frac56\) 等，供示范和活动使用。
- 学生练习页与答案页分开印制；答案页不发给学生。

**学习目标（可观察行为）**：
1. 学生能在同一条0到1的数轴上指出两个异分母分数的位置，并依据位置说明大小。
2. 学生能通过通分把两个异分母分数化为同分母分数，说明变换后分数值不变，再比较分子。
3. 学生能用“因为……所以……”的口头或书面句式表达比较理由，不只说结论。

**评价重点**：能否解释比较理由；不排名、不公开个人成绩。


## 一、导入：5分钟

**教师活动**：
1. 黑板写出同分母比较题：\(\frac35\) 与 \(\frac45\)。  
   提问：“哪个大？为什么？”  
   预设回答：分母相同，分子大的分数大。
2. 写出新问题：\(\frac12\) 与 \(\frac13\)。  
   提问：“分母不同，还能直接比分子吗？能不能直接比分母？”  
   引导学生说出：分母不同时，不能只看分子或只看分母，需要找到共同的比较依据。
3. 板书课题：异分母分数的大小比较。

**学生活动**：口头回答，倾听并进入新问题。

**设计意图**：用已学同分母比较复习引入，暴露“分母不同不能直接比”的冲突，引出数轴与通分两种依据。


## 二、示范：10分钟

**示范题**：比较 \(\frac12\) 与 \(\frac13\)。

### 方法一：数轴解释（约4分钟）

1. 黑板画一条0到1的数轴，标明0和1。
2. 提问：“\(\frac12\) 表示把0到1平均分成几份，取几份？”  
   学生答：平均分成2份，取1份。
3. 在数轴上标出 \(\frac12\) 的位置：0到1的中点。
4. 提问：“\(\frac13\) 表示把同一个0到1平均分成几份，取几份？”  
   学生答：平均分成3份，取1份。
5. 在数轴上标出 \(\frac13\) 的位置：0到1的三等分点中靠近0的那个点。
6. 引导观察：在同一条0到1的数轴上，\(\frac13\) 在 \(\frac12\) 的左边。  
   结论：\(\frac13 < \frac12\)，即 \(\frac12 > \frac13\)。

**关键强调**：两个分数必须在同一条0到1的数轴上比较，也就是对应同一个整体“1”；不能用长度不同的纸条分别表示两个分数来比较。

### 方法二：通分解释（约4分钟）

1. 提问：“能不能把 \(\frac12\) 和 \(\frac13\) 变成分母相同的分数？”  
2. 引导找2和3的公分母：6。
3. 板书：
   \[
   \frac12=\frac{1\times3}{2\times3}=\frac36
   \]
   \[
   \frac13=\frac{1\times2}{3\times2}=\frac26
   \]
4. 强调：分子分母同时乘同一个不为0的数，分数值不变。所以 \(\frac12\) 和 \(\frac36\) 相等，\(\frac13\) 和 \(\frac26\) 相等。
5. 比较同分母分数：\(\frac36\) 与 \(\frac26\)，分母相同，分子3大于2，所以 \(\frac36>\frac26\)。
6. 回到原分数：\(\frac12>\frac13\)。

### 两种方法对照（约2分钟）

- 数轴方法：看位置，谁在右边谁大。
- 通分方法：化成同分母，看分子，分子大的分数大。
- 两种方法得到同一个结论，互相验证。
- 不要求所有题两种方法都做；本节课重点是理解两种依据。


## 三、合作活动：15分钟

**分组**：全班30人，每组3人，共10组。  
**材料**：每组一张等长纸条（代表同一个整体“1”），可折出等分刻度；黑板供部分小组展示。

**活动任务**：每组从教师给出的分数对中选一组，用纸条和口头解释比较大小。  
**建议分数对**（教师可写在黑板上）：
- \(\frac12\) 与 \(\frac14\)
- \(\frac23\) 与 \(\frac12\)
- \(\frac34\) 与 \(\frac23\)
- \(\frac56\) 与 \(\frac34\)
- \(\frac25\) 与 \(\frac13\)

**组内角色轮换**（每人都要参与）：
1. **定位员**：在纸条或数轴草图上指出两个分数的位置。
2. **记录员**：写下比较过程和结论。
3. **说明员**：向全班或邻组口头解释“为什么这样比”。

**活动步骤**：
1. 教师说明任务和要求（1分钟）。
2. 各组选择分数对，组内轮换角色，用纸条折出或画出同一整体的等分，比较两个分数（8分钟）。
3. 教师巡视，针对常见误解提问：
   - “你比较的是同一个整体吗？”
   - “分母不同时，你找到了什么共同依据？”
   - “通分后分数值变了吗？为什么？”
4. 选取2—3组展示，说明员口头解释，其他组可补充（5分钟）。
5. 教师归纳：数轴看位置，通分看同分母分子；两种方法都要说明理由（1分钟）。

**常见误解与追问**：
- 只比较分子：追问“分母不同时，分子能直接说明大小吗？举例试试。”
- 只比较分母：追问“分母大的分数一定小吗？用 \(\frac12\) 和 \(\frac13\) 检验。”
- 使用不同整体：追问“你这两条纸条一样长吗？表示的是同一个‘1’吗？”
- 纠正时针对方法，不评价学生能力或态度。


## 四、练习：10分钟

**安排**：
- 学生独立完成练习页。
- 基础层三题、应用层三题。
- 教师巡视，个别口头提示；不公开排名，不集体报分。
- 练习页不附答案；答案页单独成页，由教师掌握。

**练习页见下。**


## 五、总结：5分钟

**教师提问**：
1. “比较异分母分数，今天学了哪两种依据？”
2. “数轴方法看什么？”
3. “通分方法先做什么，再做什么？”
4. “通分时分数值变了吗？为什么？”

**学生回答后教师归纳**：
- 数轴方法：在同一条0到1的数轴上定位，右边的分数大。
- 通分方法：化成同分母分数，分子大的分数大；通分时分子分母同时乘同一个不为0的数，分数值不变。
- 比较时要说明理由，不只看结论。
- 交叉相乘可以作为计算辅助，但不能代替对大小依据的解释。

**结束**：收练习页，答案页不发给学生。

# 答案与简短讲解（单独成页，不发给学生）

## 基础层

**1.** \(\frac25\) 和 \(\frac45\)  
同分母分数，分母相同，分子4大于2，所以  
\[
\frac25<\frac45
\]

**2.** \(\frac12\) 和 \(\frac14\)  
方法一：数轴。在同一条0到1数轴上，\(\frac12\) 在中点，\(\frac14\) 在左起第一个四等分点，\(\frac14\) 在 \(\frac12\) 左边，所以 \(\frac14<\frac12\)。  
方法二：通分。  
\[
\frac12=\frac24,\quad \frac14=\frac14
\]
同分母比较，\(\frac24>\frac14\)，所以  
\[
\frac12>\frac14
\]

**3.** \(\frac23\) 和 \(\frac12\)  
通分：  
\[
\frac23=\frac46,\quad \frac12=\frac36
\]
因为 \(\frac46>\frac36\)，所以  
\[
\frac23>\frac12
\]

## 应用层

**4.** \(\frac34\) 和 \(\frac56\)  
通分：  
\[
\frac34=\frac{3\times3}{4\times3}=\frac9{12}
\]
\[
\frac56=\frac{5\times2}{6\times2}=\frac{10}{12}
\]
通分时分子分母同时乘同一个不为0的数，分数值不变。  
因为 \(\frac9{12}<\frac{10}{12}\)，所以  
\[
\frac34<\frac56
\]
理由：化成同分母后，分子10大于9，所以 \(\frac56\) 大。

**5.** \(\frac23\) 和 \(\frac35\)  
通分：  
\[
\frac23=\frac{2\times5}{3\times5}=\frac{10}{15}
\]
\[
\frac35=\frac{3\times3}{5\times3}=\frac9{15}
\]
分子分母同时乘同一个不为0的数，分数值不变。  
因为 \(\frac{10}{15}>\frac9{15}\)，所以  
\[
\frac23>\frac35
\]

**6.** \(\frac38\) 和 \(\frac25\)  
方法一：通分。  
\[
\frac38=\frac{3\times5}{8\times5}=\frac{15}{40}
\]
\[
\frac25=\frac{2\times8}{5\times8}=\frac{16}{40}
\]
因为 \(\frac{15}{40}<\frac{16}{40}\)，所以  
\[
\frac38<\frac25
\]
方法二：数轴。在同一条0到1数轴上，\(\frac38\) 在0.375处，\(\frac25\) 在0.4处，\(\frac38\) 在 \(\frac25\) 左边，所以 \(\frac38<\frac25\)。  
两种方法结论一致。
