## 1. 系统概览

- 形态：前后端分离的**模块化单体**（来源：`materials/project_docs/current-brief.md`）。
- 前端：Vue 3 + TypeScript（同上）。
- 后端：Java 21 + Spring Boot 3（同上）。
- 数据库：PostgreSQL（同上）。
- 模型调用：服务端通过**统一模型网关**调用**已发布模型**；用户不能输入模型密钥（同上）。
- 工作台三区域：**原始提示词、上下文、优化结果**（同上）。
- 分层边界：`api/controller` 只描述协议入口，业务编排由 `service` 层负责（同上）。

## 5. 权限边界

- **平台角色 vs 工作区角色**：两者是两个边界（current-brief.md）。`workspace` 管理员**不是**全平台模型配置管理员。
- **模型密钥**：用户不能输入模型密钥；交接材料**不能建议浏览器存放 API Key**（current-brief.md）。
- **模型列表**：由后台发布，普通用户只选择已发布条目；**显示版本与实际调用标识分开记录**（current-brief.md）。
- **前端路由守卫**：管理员界面可见性**不是**后端授权的替代；路由守卫与服务端权限校验须区分（current-brief.md）。
- **历史记录**：不得解释为账单或支付凭证（current-brief.md）。
