# 合成问卷汇总数据：描述性分析方案与空白结果表模板

## 0. 交付边界

本文件交付的是**分析方案、口径说明、缺失处理决策表和空白结果表模板**，不是分析报告，不包含任何已计算的比例、均值或部门统计结果。所有表格中的数值位置均为空白占位，待研究者确认口径并取得完整数据后填写。

本方案不声称拥有完整数据文件；仅依据数据字典与抽样示意编写。不生成假统计结果，不写因果结论。

## 2. 指标定义

### 2.1 基础计数指标

| 指标 | 字段/定义 | 说明 |
|---|---|---|
| 登记数 | `registered_count` | 纳入名单的事件总数；资料未提供人员去重规则。若同一合成编号重复出现，不能仅凭姓名相同自动合并 |
| 有效答卷数 | `valid_response_count` | 经过现有质检的问卷数量；质检说明未给出具体阈值，方案可要求补充规则，不自行设定答题时长门槛 |
| 缺失答卷数 | `missing_response_count` | 缺失记录可能源于未作答、同步失败或未完成登记；字典未区分原因，缺失不能等同某一种业务状态 |
| 已完成数 | 待确认 | 完成状态与有效状态不是同一维度；一份完成的答卷仍可能被质检排除。分子是否要求同时完成与有效，尚待确认 |

### 2.2 完成状态与有效状态的关系

完成状态与有效状态是**两个不同维度**，不能互相替代：

- 一份答卷可以"完成"但被质检排除（不计入有效）。
- 一份答卷可以"有效"但完成状态字段的取值口径尚未确认（COMPLETE / DONE 映射未定）。
- 因此，完成率的分子定义需要明确：是仅要求完成状态，还是要求同时满足完成与有效。**当前尚未决定，不得默认补全。**

### 2.3 百分号字段的处理

字典中的百分号字段是**人工登记的文本标签**，不保证与分子分母一致。本方案：

- 不直接将该字段作为计算结果。
- 不将其与 `valid_response_count / registered_count` 等自动对齐。
- 如需使用，应作为独立来源标注，并与重新计算的口径并列展示差异。

## 3. 完成率两种分母口径对照

分母未确定时**不计算完成率**，不能选择让结果更好看的分母。以下两种口径并列呈现，供研究者决策。

| 对照项 | 口径 A：分母 = 全部登记人数 | 口径 B：分母 = 有效答卷人数 |
|---|---|---|
| 分母定义 | `registered_count` | `valid_response_count` |
| 分子候选 | 待确认（完成状态？完成且有效？） | 待确认（完成状态？完成且有效？） |
| 覆盖范围 | 覆盖全部登记事件，包括缺失和无效 | 仅覆盖通过质检的答卷 |
| 缺失答卷的位置 | 在分母中，但状态未知 | 不在分母中，需单独呈现 |
| 登记口径是否保留 | 是，本身即登记口径 | 是，需保留登记口径作为覆盖差异说明 |
| 主要局限 | 缺失原因未区分，可能低估完成水平 | 排除了缺失和无效，可能高估完成水平 |
| 适用场景 | 关注登记名单整体覆盖 | 关注有效答卷内部的完成情况 |
| 当前状态 | **待研究者确认** | **待研究者确认** |

**决策规则：**

- 在研究者明确选择之前，结果表中完成率列保持空白，并标注"分母口径待确认"。
- 若最终选择口径 B，登记口径不能直接消失，应保留覆盖差异（登记数、有效数、缺失数并列）。
- 最终方案应把**用户选择**与**数据来源**同时标注。

## 4. 缺失处理决策表

缺失答卷不能自动剔除、补零或当作未完成。以下为待确认的处理选择：

| 决策项 | 可选处理 | 当前状态 | 禁止的默认操作 |
|---|---|---|---|
| 缺失答卷是否纳入完成率分母 | 纳入 / 不纳入 / 单独呈现 | 待确认 | 不得默认剔除或默认纳入 |
| 缺失答卷在完成率中如何呈现 | 独立缺失状态 / 单独行 / 脚注 | 待确认 | 不得计为未完成 |
| 缺失答卷在分部门表中如何呈现 | 独立缺失列 / 单独行 / 脚注 | 待确认 | 不得剔除、补零或计为未完成 |
| 缺失原因是否区分 | 未作答 / 同步失败 / 未完成登记 | 字典未区分，待补充 | 不得自行归因 |
| 缺失是否影响部门比较 | 需展示缺失程度 | 待确认 | 无证据时不声称存在选择偏倚 |
| 零值与空值的区分 | 零 = 真实零件数；空 = 未登记 | 已明确 | 不得用零填充空白后计算均值 |

**零值与空值处理规则（已明确）：**

- 零是有效观测值，空白是未登记。
- 统计伪代码应分别显示二者。
- 检查分母为零时的呈现规则（例如：分母为零时比例未定义，应显示为空白或"不适用"，而非 0%）。

## 6. 可复核的伪代码（工具无关）

以下伪代码不假定研究者已选择 R 或 Python，使用工具无关的流程描述。研究者可根据偏好选择实现语言。

### 6.1 数据读取与字段检查

```
读取登记表，字段包括：合成编号、部门、月份、registered_count
读取答卷汇总表，字段包括：合成编号、部门、valid_response_count、missing_response_count、完成状态
检查两份表的关联键是否存在
若月份仅在登记表中存在，且无关联键：
    不编造各月有效答卷数量
    不画时间序列
```

### 6.2 零值与空值区分

```
对每个数值字段：
    若值为 0：
        标记为"真实零值"
    若值为空：
        标记为"未登记"
    不得用 0 填充空白
    不得对含空白的字段直接计算均值
```

### 6.3 完成率计算（分母未定时不执行）

```
若研究者已确认分母口径：
    若口径 A：
        分母 = registered_count
    若口径 B：
        分母 = valid_response_count
    分子 = 待确认（完成状态？完成且有效？）
    若分母为 0：
        完成率 = 空白或"不适用"
    否则：
        完成率 = 分子 / 分母
否则：
    完成率 = 空白
    标注"分母口径待确认"
```

### 6.4 缺失处理（不默认剔除、补零或计为未完成）

```
对每条缺失记录：
    保留独立缺失状态
    不剔除
    不补零
    不计为未完成
    若研究者已确认处理方式：
        按确认方式执行
    否则：
        在结果表中单独呈现
```

### 6.5 分部门汇总

```
按部门分组：
    计算 registered_count 合计
    计算 valid_response_count 合计
    计算 missing_response_count 合计
    已完成数 = 待确认（状态来源待确认）
    不为了让各列相加相等而制造"其他"类别
    不输出个体编号
```

### 6.6 完成状态来源差异

```
若数据字典写 COMPLETE，旧报表示例写 DONE：
    并列列出两种写法
    不直接视为同义
    不自行选择其中之一
    在结果表中标注状态来源
```

## 7. 限制与待确认项

### 7.1 已明确的限制

- 本方案不包含完整数据文件，不生成假统计结果。
- 缺失答卷不能自动剔除、补零或当作未完成。
- 字典中的百分号字段不能直接作为计算结果。
- 部门名称为合成分组，个体编号不得出现在结果表中。
- 零是有效观测值，空白是未登记，不得用零填充空白后计算均值。
- 月份只在登记表中存在，无关联键时不能编造各月有效答卷数量。
- 旧报表的百分比是排版演示，不是本次数据，结果模板不得继承。
- 跨部门比较需展示登记覆盖与缺失情况，不是只排高低名次。
- 无证据时不声称存在选择偏倚。
- 不推断部门管理效果、员工态度或个人绩效。
- 不将合成示例当作单位真实表现。

### 7.2 待确认项（仅保留真正影响任务目标的业务决定）

| 编号 | 待确认项 | 影响 | 当前处理 |
|---|---|---|---|
| Q1 | 完成率分母采用全部登记人数还是有效答卷人数 | 决定完成率计算方式 | 两种口径并列，不计算比例 |
| Q2 | 缺失答卷在完成率中如何呈现 | 决定分子分母构成 | 保留独立缺失状态，不默认处理 |
| Q3 | 缺失答卷在分部门表中如何呈现 | 决定表格结构 | 保留独立缺失状态，不默认处理 |
| Q4 | COMPLETE 与 DONE 的映射关系 | 决定完成状态字段的使用 | 并列列出，不自行选择 |
| Q5 | 完成率的分子是否要求同时满足完成与有效 | 决定分子定义 | 待确认 |
| Q6 | 质检的具体阈值规则 | 决定有效答卷的判定 | 要求补充规则，不自行设定 |
| Q7 | 缺失原因是否可区分 | 决定缺失分类 | 字典未区分，待补充 |
| Q8 | 人员去重规则 | 决定登记数口径 | 资料未提供，不自动合并 |

### 7.3 工具偏好说明

分析工具偏好影响代码语言而不影响完成率定义。本方案提供工具无关的流程，不假定研究者已选择 R 或 Python，不借机改为特定商业软件操作手册。测试示例中的"分析工具 Python"仅为排版演示，不是工具偏好。
