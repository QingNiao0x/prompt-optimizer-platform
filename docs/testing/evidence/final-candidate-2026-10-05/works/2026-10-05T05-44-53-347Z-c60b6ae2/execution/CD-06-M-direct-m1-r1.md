## 1. 指标定义及两种分母口径对照表

### 1.1 基础指标定义（口径中立，不预设分母）

| 指标 | 定义 | 备注 |
|---|---|---|
| 登记数 `registered_count` | 纳入名单的事件总数 | 资料未给人员去重规则；合成编号重复出现时不能仅凭姓名相同自动合并 |
| 有效答卷数 `valid_response_count` | 经现有质检的问卷数量 | 质检阈值未给出，方案可要求补充规则，不得自行设定答题时长门槛 |
| 缺失答卷数 `missing_response_count` | 缺失答卷记录数 | 可能源于未作答、同步失败或未完成登记，字典未区分原因 |
| 已完成数 | 完成状态为“完成”的答卷数 | 完成状态取值口径未统一（`COMPLETE` vs `DONE`），见第 6 节 |
| 完成率 | 分子 ÷ 分母 | **分母未确定前不计算**；字典百分号字段不得直接作为结果 |

### 1.2 两种分母口径对照表

| 对照项 | 口径 A：分母 = 全部登记人数 | 口径 B：分母 = 有效答卷人数 |
|---|---|---|
| 分子（候选，待用户确认） | 需明确是否要求“同时满足完成与有效”；候选：已完成数 / 已完成且有效数 | 同左，需与口径 A 使用同一分子定义以便对照 |
| 分母 | `registered_count`（登记数） | `valid_response_count`（有效答卷数） |
| 适用条件 | 关注“登记名单中最终完成的比例”，保留登记覆盖视角 | 关注“进入有效质检样本中完成的比例”，聚焦有效样本内部 |
| 覆盖差异 | 分母包含未作答、同步失败、未完成登记等全部登记事件；缺失与无效均留在分母 | 分母已排除无效与部分缺失；登记口径的覆盖信息**不能因此消失**，须在结果中保留登记覆盖与缺失情况 |
| 解释边界 | 反映登记到完成的整体覆盖，但受缺失原因不明影响 | 反映有效样本内完成情况，但受质检规则与缺失程度影响 |
| 何时可用 | 用户确认采用登记口径，且完成状态口径已统一 | 用户确认采用有效口径，且完成状态口径已统一 |
| 当前状态 | **未确定，不计算** | **未确定，不计算** |

> 说明：若最终采用口径 B，登记口径不能直接消失，应在结果中并列保留登记覆盖与缺失情况，供跨部门比较时判断缺失是否均匀。

## 2. 缺失处理决策表

缺失答卷在**完成率**与**分部门表**两种场景下的可能呈现方式及其影响。以下均为**待确认的处理选择**，不默认补全、不自动剔除、不补零、不当作未完成。

| 场景 | 呈现方式 | 对分子/分母的影响 | 对解释的影响 | 状态 |
|---|---|---|---|---|
| 完成率 | 缺失保留在分母，分子不含缺失 | 分母不变，完成率被压低（若缺失本可完成） | 需说明缺失原因未知，不能推断缺失者态度 | 待确认 |
| 完成率 | 缺失从分母剔除 | 分母缩小，完成率可能升高 | 需说明剔除规则与依据，否则不可比 | 待确认 |
| 完成率 | 缺失单独报告，不进入完成率 | 完成率仅覆盖已明确状态者 | 需并列展示缺失规模，避免只报比例 | 待确认 |
| 完成率 | 缺失补零 | 相当于把缺失当作未完成 | **禁止默认采用**；如采用须用户明确确认并标注 | 待确认（默认禁止） |
| 完成率 | 缺失补全为完成 | 人为抬高完成率 | **禁止默认采用**；无依据不得补全 | 待确认（默认禁止） |
| 分部门表 | 缺失单列展示，未知保持未知 | 不影响其他列 | 便于观察缺失是否部门间不均 | 待确认 |
| 分部门表 | 缺失并入“已完成”或“有效” | 混淆维度 | 会掩盖缺失，不建议 | 待确认 |
| 分部门表 | 缺失并入“其他”类别凑数 | 制造不存在的类别 | **禁止**；不得为使各列相加相等而造“其他” | 禁止 |
| 分部门表 | 缺失行留空 | 未知保持未知 | 需在表注说明空白=未登记/未知 | 待确认 |
| 分部门表 | 缺失按零填充 | 把未知当零 | **禁止**；零是有效观测值，空白是未登记 | 禁止 |

> 关键约束：缺失原因未区分（未作答 / 同步失败 / 未完成登记），因此任何“缺失=未完成”的推断都缺乏依据。

## 4. 可复核的伪代码与限制说明

> 工具中立：以下用**流程描述 + 可选 R / Python 片段**表达，**不假定研究者已选择其中一种**。无用户偏好时以工具无关流程为准。

### 4.1 工具无关流程（主流程）

```
输入：分部门汇总记录（每部门含 registered_count, valid_response_count,
      missing_response_count, 完成状态字段）
前置检查：
  1. 确认完成状态口径（COMPLETE / DONE / 映射规则）——未确认则停止计算完成率
  2. 确认完成率分母（登记口径 / 有效口径）——未确认则停止计算完成率
  3. 确认分子是否要求同时满足完成与有效——未确认则停止计算完成率
  4. 确认缺失呈现方式——未确认则缺失仅单列展示，未知保持未知

对每个部门：
  - 校验 registered_count、valid_response_count、missing_response_count
    为非负整数；空值/非法值报错，不静默替换
  - 区分“0”与“空白”：0 保留为有效观测值；空白标记为未知
  - 若分母为 0：不计算比例，输出“分母为零，未定义”，不返回 0 或 NaN 冒充结果
  - 缺失列单独保留，不并入其他列，不补零，不标为未完成

输出：
  - 分部门空白/汇总表（四列，未知保持未知）
  - 完成率仅在上述前置条件全部确认后计算；否则输出“口径未确定，未计算”
```

```python
# 仅示意校验与边界处理，不含真实数据
def summarize_dept(records, denominator=None, complete_status=None):
    if denominator is None:
        raise ValueError("分母口径未确定，不计算完成率")
    if complete_status is None:
        raise ValueError("完成状态口径未确定，不计算完成率")
    for r in records:
        for col in ("registered_count", "valid_response_count", "missing_response_count"):
            v = r.get(col)
            if v is None or not isinstance(v, int) or v < 0:
                raise ValueError(f"{col} 存在空值或非法值")
        # 分母为零时不计算比例，返回“未定义”
    return records
```

### 4.3 限制说明

1. 无完整数据文件，伪代码**不产生真实结果**，仅用于复核流程与边界处理。
2. 完成状态口径（`COMPLETE` / `DONE`）未统一前，完成率不可计算。
3. 分母未确定前，不计算完成率，不选择让结果更好看的分母。
4. 缺失不自动剔除、不补零、不当作未完成；缺失原因未区分。
5. 零是有效观测值，空白是未登记；不得用零填充空白后计算均值。
6. 字典百分号字段不得直接作为计算结果。
7. 月份仅在登记表，答卷汇总无月份且无关联键，**不编造各月有效答卷数量，不画假时间序列**。
8. 部门为合成分组，个体编号不得出现在结果表。
9. 跨部门比较须呈现登记覆盖与缺失情况，不只排高低名次；缺失程度不均可能影响解释，但**无证据时不声称存在选择偏倚**。
10. 报告只说明可观察差异与数据限制，不推断部门管理效果、员工态度或个人绩效，不将合成示例当作单位真实表现。
