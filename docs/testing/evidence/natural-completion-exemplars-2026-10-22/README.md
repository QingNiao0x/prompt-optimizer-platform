# 实质补全指导与少量内部示范对照

本批次从删除示例参考功能后的 `73fb3541` 出发，只改变自然正文写作指导。第四版保留原件；第七版仅替换补全指导，第八版在第七版上增加三份固定、短小的内部改写示范。候选的 Plan 提问指导与第四版相同，全部来源、实际题答、覆盖、安全及历史机制继续复用。默认版本在取得采用证据前保持第四版。

示范不是当前任务事实，不进入 `taskSources`，不要求下游回答包含示例，不恢复用户开关，不按职业或主题选择模板。题集是新编合成任务，未使用示范中的任务和原文；同一开发代理编写，不能声称外部独立留出集。

`protocol.json` 在首次调用前冻结模型、参数、任务、判据、作业及阶段上限。本次用户授权新增最多 1024 次实际调用，首阶段最多 64 次；计划 54 次，其余仅供既有有界协议修复。失败和评审均计数，不做质量重试。旧闭批余额不转移。

每题比较原始、第四版、第七版、第八版的实际作品，材料及实际回答相同。确认后生成使用真实第四版 Plan 作为共同问题锚点，第七、八版 Plan 另作提问回归，不能声称三条各自的完整 Plan 闭环都已验收。辅助评审只接收随机重排的匿名作品，仍使用相同模型，不是独立专家评测；开发代理另外核对提示词与原作品。

临时 Java 入口仅启动于回环端口 9003，通过当前认证、CSRF、固定合成账号和正常服务保存优化历史，不执行 Flyway，不创建账号。模型密钥及登录凭据只存在于进程环境和内存，不进入证据或命令参数。实际传输在出网前预留额度并校验冻结源码；运行副本、日志及验证码在被忽略的 `tmp/natural-completion-exemplars-20261022`。
