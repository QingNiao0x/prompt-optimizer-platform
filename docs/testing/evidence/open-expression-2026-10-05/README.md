- `generation/candidate-01`至`candidate-04`：分别保存冻结资料、公开模型目录、代码哈希、实际Plan与最终返回，以及逐题审核答案。03只有Plan，不能算完整流程；01不是未修改基线。

- `review/`：预先冻结的600–800正文、标题另计标准；中间48份和最终24份的正文计数、排除标题与关键词线索。最终结果仍有不足、超长及当前阶段遗漏，不改标准掩盖失败。

- `verification-summary.json`：最终后端、工具检查、跳过项目及本轮未验证范围。
- `manifest.json`：收录文件的相对来源、SHA-256、数据授权与版本边界；不含自身循环哈希。

`.gitattributes`禁止证据的换行转换，并仅在本证据目录关闭空白格式检查，以保留原始CRLF和模型有意生成的Markdown行末空格及字节哈希。生产代码和开发文档仍执行空白检查。不要格式化历史返回；新的候选和重跑应另存。原始服务日志和测试账号只留本机tmp，不进入此目录。
