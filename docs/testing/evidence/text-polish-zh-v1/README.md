# 中文文章编辑策略及作品验收

`text-polish-zh-v1` 针对中文报告、通知、服务说明和叙事，要求改写最妨碍阅读的句段。报告中展开原文支持的对象、动作和关系。通知及服务说明把条件放在所限定的动作旁。叙事保留作者视角、态度、顺序和已有细节。轻度允许段内完整改句，大幅重构允许调整独立信息位置和拆合段落，用户明确范围优先。

[中文指令](../../../../services/api/src/main/resources/textpolish/skills/text-polish-zh-v1/SKILL.md)和[服务示范](../../../../services/api/src/main/resources/textpolish/skills/text-polish-zh-v1-service/SKILL.md)作为独立资源。示范保留两个目的、持续改进承诺、提交后的补齐期限、两项进入分配的前提和线下例外。候选可在测试实例显式选择 `app.text-polish.strategy-version=text-polish-zh-v1`。识别为英文、中英混合或未知语种时回到 v3，实际版本与资源哈希随请求快照记录。

260 项后端检查通过，涵盖中文三文体与两幅度的真实请求装配、用户要求传递、非中文回退、协议修复冻结、普通工作台接口与历史。本轮使用既有本机合成账号。

## 回归阶段

[回归题集与冻结条件](pilot/samples.json)使用五篇已见中文原稿，其中自然叙事在两档各测一次。模型为 DeepSeek Flash，固定温度 0.2、最多 8000 输出 Token、JSON 模式和关闭思考。两臂正文及用户要求一致，仅切换编辑策略。12 次真实生成均首次成功。评阅先看匿名 A/B，落盘后才揭晓。[匿名初评](pilot/blind-review.md)

- 数字化报告两版都保留三段和抽象协同表达，尚未让非专业读者看懂关键关系。
- 服务说明两版保住两个目的、处理期限及其触发条件，可读性接近。
- 图书通知候选通过分段让取书条件更好找。“资料更顺手”相较“提高资料利用效率”存在精度争议。
- 资源申请稿的行政开场仍在。自然叙事两档均保住主要细节和视角。

环境恢复记录保留在 [回归阶段](pilot/environment-blocked/reconciliation.json)。首次 JVM 启动因系统内存不足退出。随后 Redis 限流在发送前拦截一项回归请求，保存失败原件与预扣账本后，根据零上游事件重新结算。续跑仅在隔离进程使用内存限流。

## 中文新稿

[新稿与评阅卡](holdout/samples.json)在调用前冻结。轻度与大幅重构各 6 篇，其中各有 4 篇需要实质编辑、1 篇自然叙事及 1 篇含锁定引文的条款。覆盖报告、业务邮件、通知、办事指南和叙事。24 次真实生成均首次成功。与回归阶段相同，每组逐项比对输入、温度、路由、思考状态、策略及资源哈希。评阅由一位开发助手完成，[匿名初评](holdout/blind-review.md)先于标签揭晓落盘。

| 范围 | 需要编辑的稿件中达标 | 相对 v3 | 采用判断 |
| --- | ---: | --- | --- |
| 轻度 | 1/4 | 1 胜、4 平、1 负 | 未达标。抽查报告把发现写得更直接，邮件和通知仍有行政铺垫，毕业照叙事的开场落后于 v3。 |
| 大幅重构 | 3/4 | 2 胜、3 平、1 负 | 阅读初评达线。储物柜指南及设备借用邮件更容易找到动作和期限，复盘报告两组皆有收益，旧台灯叙事落后于 v3。 |

大幅重构未确认重大语义错误。储物柜指南将原文“前台会把未归还钥匙记入交接单，方便第二天值班人员跟进，并提醒……”写为前台“也会提醒”。原文的提醒责任归属可有两种理解，独立复核需检查候选是否把目的或后续工作强化为前台承诺。中文大幅重构的[匿名作品](holdout/blind-packet.json)可按“wide”题号复核。英文大幅重构沿用自己的[匿名材料](../text-polish-paragraph-v2/en-restructure/blind-packet.json)。

## 试用范围

中文大幅重构已接入 `app.text-polish.zh-v1-restructure-enabled`，默认关闭。显式开关开启且当前策略为 v3 时，中文大幅重构在实测 DeepSeek Flash 路由和参数下使用中文候选。中文轻度及其他未匹配请求仍使用原策略。英文开关独立选择，不共享语言通过结论。部署默认的启用有待第二位评阅者对相应语言独立复核。

新增的工作台接口验证使用既有合成账号范围提交全新中文，核对受控上游的正文与实际策略，再从历史详情读取同一正文和执行快照。PostgreSQL 写入随测试回滚。中英文范围切换、请求装配、v3 等价及数据库共 235 项相关检查在加开关后重跑通过。
