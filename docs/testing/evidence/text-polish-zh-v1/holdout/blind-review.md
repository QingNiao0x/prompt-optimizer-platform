# 中文新稿匿名初评

一位开发助手按冻结题卡评阅。下表在读取策略映射前落盘。阅读分与保真分别判断。

| 稿件 | A / B 阅读分 | 判断依据 |
| --- | --- | --- |
| 轻度·宣传交付邮件 | 1 / 1 | 两稿都保留宣布沟通的第一句，两个回复分支虽完整，位置与原文基本一致。周二 17 点、周五交付、延期免解释、排期更新和两个目的均在。 |
| 轻度·维修通知 | 1 / 1 | 标题和两段保留，时间、南门通行、车辆例外、雨天顺延和协助方式准确。两稿均保留“现将……告知如下”，A 把它和真实安排放在同一句，读者仍先读铺垫。 |
| 轻度·编号抽查报告 | 1 / 2 | B 直接写“本月抽查了……”，比 A 的“围绕……进行了抽查”更容易读。两稿都保留 20 份、5 份、仅核对编号、双目的和建议语气。 |
| 轻度·毕业照叙事 | 1 / 2 | B 将“就那次……的体验而言”改为“那次回中学拿毕业照”，保留所见和安静结尾。A 的开场仍拗口。 |
| 轻度·钥匙和荔枝 | 通过 / 通过 | 两稿保留空间、动作顺序和两颗荔枝，只在“退回去拿”处做小改。 |
| 轻度·续借说明 | 通过 / 通过 | 两稿保留到期前且无人预约的前提、续借 7 天、重新申请及无现存承诺，引文原样。 |
| 大幅·归还登记报告 | 2 / 2 | 两稿都将前后流程写成相邻对照，并分开再试的两个目的。B 首句更快交代试点。都保留两个区域、晚班观察、未测高峰、因果未定和再试范围。相对 B 略顺。 |
| 大幅·共享储物柜指南 | 3 / 1 | A 将清空、过夜、生鲜例外分开，比 B 的一整段更易查找。次日 12 点及生鲜当天仍在。A 的“也会提醒”可能把交接目的写成前台的额外承诺，原文“方便……跟进，并提醒……”的责任归属需复核。 |
| 大幅·设备借用邮件 | 1 / 2 | 两稿开场仍宣布要同步事项。B 用独立段摆放周四和周五要求，且用“到时”把暂定回复绑回周四中午。A 只写“先回复”，周四是靠前句推断。两组均保留用途及备用设备不确定性。 |
| 大幅·旧台灯叙事 | 2 / 1 | A 将冗长陈述缩成“有一件事让我记了很久”，虽仍保留回想式起笔，句子负担明显降低。B 的“给我的感受比预想中长久”较生硬。两稿均保存叙事转折和结尾。 |
| 大幅·雨后收衣 | 通过 / 通过 | 两稿相同，保留半步、位置和暖夹子与湿衣的对照。 |
| 大幅·改签说明 | 通过 / 通过 | A 顺句处理，B 显式并列双条件。两稿均保留客服确认前原票有效、关闭通知没有时点承诺及锁定引文。 |
