# 回归稿匿名初评

按冻结评阅卡核对原文和 A/B。排序随机，提交以下判断前不读取标签映射。评阅由一位开发助手完成。

| 样本 | A / B 阅读分 | 语义、要求与差异 |
| --- | --- | --- |
| 中文数字化 | 1 / 1 | 标题、三段、总体顺序和三类优势均保留。两稿都留下“多维度、全链条、深层次”和“三种导向”，读者仍要自行拆解。B 将“完善长效机制”写成“建立长效机制”，暗示所处阶段可能不同。无明确阅读胜方。 |
| 中文服务说明 | 1 / 1 | A 的“为保障用户权益……提升服务体验”更简洁。两稿均保留保障权益与改善体验、持续优化承诺、7 日期限、3 工作日确认义务、材料齐全才开始 5 工作日处理期、退款例外及其他限制。A 有措辞小优，流程组织相近。 |
| 中文自然叙事 | 自然稿通过 / 自然稿通过 | 两稿保留半壶温水、倒一杯、听车和暂时不开灯，第一人称及动作顺序均在。 |
| 英文团队邮件 | 1 / 1 | 两稿都保留“effective alignment”开场。周五评论、周二发布的法务条件、延后安排、两项目的和无需全体一致均在。B 给评论要求加的“When commenting”是重复。两稿均未解决主要问题。 |
| 英文课程说明 | 3 / 2 | A 首句直接交代 9 月拟发布下载版，报名确认和不含录音分句，两个目的和在线版本单列，较 B 更易定位信息。两稿均保留条件与两个具体目的。A 略去较宽泛的无障碍学习开场，邮件申请的资格称呼从“参与者”变为“you”，应按面向实际课程读者理解，后续仍明确报名确认才受理。 |
| 英文自然叙事 | 自然稿通过 / 自然稿通过 | 两稿与原文一致，保留第一人称、位置细节和动作顺序。 |
