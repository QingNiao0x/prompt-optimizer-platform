# 英文大幅重构新稿匿名初评

一位开发助手按冻结评阅卡先对原文和匿名 A/B 评阅，以下结果在读取标签映射前记录。阅读分独立于事实和条件检查。

| 样本 | A / B 阅读分 | 盲评结果 |
| --- | --- | --- |
| 园艺排班邮件 | 2 / 2 | 平。两稿都缩短开场，把可参加和不可参加的回复方式、周一 6 点期限放在一个独立段落，读者更容易快速找到。协调开场仍先出现。志愿者时间、共同工作的目的、周四计划、看门人确认及不能保证搭档均保留。 |
| 用电监测报告 | 1 / 3 | B 胜。B 开头先交代上月试点发现的问题，再按测量方法、局限和后续提议分段；A 保持原来冗长的背景起笔，仅将测量方式合成一句。两稿均保留三次差异、两种可能原因、再留一个月的两个目的和仅限车间。B 将“indicated”变为“found”，但结论限定为该试点中读数并不总一致，三次实测不一致支持这一表述，且原因仍保留不确定。 |
| 印刷工作室托盘指南 | 2 / 3 | B 胜。两稿都缩短程序铺垫，B 更进一步，将清洗与核验、无人值守及破损例外分开，读者更容易对应到搁架、沥水架和标记桶。目的与防止错怪下一位用户均保留。两稿把“can put”写为操作句“put”，在归还指南中可理解为经核验可采用的归还步骤，仍建议复核是否需保留明示的许可语气。 |
| 明信片随笔 | 2 / 2 | 平。A 简化回想句，B 直接进入搬家当日并把最后一幕单列，两种写法都减少原稿的抽象铺垫。两稿都保留原本想留卡片、走到门边后改变主意、自寄和两天后安静的结果。差别主要是起笔和节奏。 |
| 市集自然叙事 | 自然稿通过 / 自然稿通过 | 平。两稿均原样保留动作顺序、人物位置及叙述口吻。 |
| 场地预订说明 | 保真对照 / 保真对照 | 平。默认、截止和续时三个时间点仍各有所指，晚到条款、无障碍说明及原样引文均保留。A 先说默认时点，下一句立即给出批准例外。原稿已清楚，两稿均可读。 |
