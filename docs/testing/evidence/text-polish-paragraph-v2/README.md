# 文章编辑评分校准与第二版候选

## 评分规则

先读原文和用户要求，写下最影响阅读的一到两处问题。分别为两组作品评分，并记录具体的原句和改句。完成单稿评分后再比较两组。达到阅读目的的不同写法均可通过。评阅者喜欢的开头、句型或段落安排只作参考，用户明确提出的要求另行检查。

| 分数 | 相对原文的阅读效果 |
| --- | --- |
| 0 | 改坏表达，使文章更难读，或明显破坏作者口吻。 |
| 1 | 没有解决主要阅读问题。允许记录措辞或排版上的局部改善。 |
| 2 | 至少解决一处事先标出的主要阅读问题，其他地方没有明显阅读退步。 |
| 3 | 解决多处主要问题，或对整篇文章的组织、节奏或文体带来清楚可见的改善。 |

原本自然的稿件允许少改或原样通过。待改稿的绝对通过需要达到 2 分，并遵守用户明确要求，保持重要含义。分别核对事实、数值、限定条件、独立目的、承诺强度和锁定原文。仅凭原文难以判定的语义争议单独标记，留待复核。相对结果用胜、平、负表示，写清优势来自阅读还是保真。两组同分时仍可根据具体句子判定谁更易懂。

后续在调用前冻结题目、主要问题与语义清单。两位熟悉原文语言的评阅者独立评阅，隐藏策略身份并打散左右顺序。沿用原方案的试用门槛，每个语言与幅度组合的四篇待改新稿至少三篇绝对通过，至少两个不同用途的新稿明确优于 v3，胜数大于负数，受测作品的重要语义错误为零。

## 第二版编辑策略

`text-polish-paragraph-v2` 要求根据读者、用途和明确要求找到主要阅读问题，并实际改写造成问题的段落。锁定文字、引文与出处按原样保护。事实、观点、独立目的、承诺和限定按含义保护，允许重写普通措辞和组织方式。用户明确提出的呈现要求优先于文体和幅度默认值，并遵守事实和锁定边界。

六份中英文示范分别包含原稿、改写稿和含义核对，覆盖正式报告、工作邮件、个人叙事及含多个前置条件的说明。每次按正文语言和所选文体装入一份示范。混合或识别不确定时使用通用指导。示范使用与评测样本不同的素材。

测试实例可通过 `--app.text-polish.strategy-version=text-polish-paragraph-v2` 启用。第二版的阅读效果待配对作品验收。

离线验证通过 191 项文章模块测试，覆盖中英文、混合和未知语种，三种文体、两种幅度及完整用户要求的发送。另复现第一版 12 份已归档候选请求的完整系统指令和资源哈希。此次复评使用既有输出，真实模型调用数为零。

## 第 5 步 工作台链路

209 项后端检查通过。新增候选的协议修复用例核实第一次与修复请求的用户消息、模型参数和基础指令一致，即使期间配置变化也继续使用首次快照。检查涵盖了接口授权、PostgreSQL 历史、数据隔离和继续润色来源。8 项桌面与移动端浏览器用例通过，使用受控接口确认新版快照显示、幅度传递、历史恢复、用当前稿继续润色和复制纯正文。

## 第 6 步 已有作品真实对照

[冻结协议](pilot/protocol.json)沿用六篇文章原件及全部要求。两臂分别用 v3 和段落编辑第二版生成一次，DeepSeek Flash、温度 0.2、最多 8000 输出 Token、思考关闭、JSON 输出。每组的输入、参数、路由、完整系统指令和资源哈希均已核实。12 次均首次成功。[匿名评分](pilot/blind-review.md)在揭晓策略标签前落盘，由一位开发助手完成。

| 样本 | 第二版相对 v3 的结果 |
| --- | --- |
| 数字化文章 | 标题和三段正文完整，协同和“三种导向”仍需读者自行理解。两稿均未解决主要问题。 |
| 服务说明 | 末句更短，权益与体验目的、义务及时限均在。整体组织与 v3 接近，阅读分均为 1。 |
| 英文团队邮件 | 两稿都保留协调团队的开场，审阅时间和条件仍在后面。 |
| 英文课程说明 | 首句交代 9 月拟发布下载版，报名门槛和不含录音分别表述，两个目的与在线版保留。按评阅卡分别得 3 分和 2 分。较宽泛的无障碍背景略去，“参与者”改为面向读者的“you”，作为范围释义记录。 |
| 中英文自然叙事 | 两稿均保住主要细节、顺序和叙事视角，允许保留或少改。 |

英文大幅重构进入新稿阶段。中文两档及英文轻度的回归结果没有显示足够的相对阅读收益。混合文章本轮覆盖工程装配。

## 第 7 步 定点修订判断

取得明确收益的课程说明已经解决目标阅读问题。数字化文章和英文轻度润色邮件的问题仍在首稿。新稿的园艺邮件把请求和期限整理到了独立段落，两组仍用背景起笔。当前只有一份英文大幅重构成品在已取得明显收益后留下这一问题，尚无同一范围内的重复证据。此次未触发额外生成，保留原稿供后续对照。

## 第 9 步 范围开关

已实现英文大幅重构的试用开关 `app.text-polish.paragraph-v2-english-restructure-enabled`。显式开启后，仅当原策略是默认 v3、正文识别为英文、幅度为大幅重构，且模型路由、温度、思考设置、JSON 模式与输出上限符合本次实验条件时使用第二版。其他配置或输入仍按原策略处理。策略和参数在初次调用前读取，协议修复继续使用冻结的内容。

已通过新增的上游请求和执行快照测试。另从工作台使用的生成接口提交一篇全新英文，使用受控上游响应和本机 PostgreSQL，从历史详情读取已保存正文和策略快照，验证二者与生成结果一致。测试使用既有合成账号范围，数据库写入随测试事务回滚。

工作台的默认开关为关闭。初评的数值结果支持该范围继续复核，独立语义复核是正式启用前尚缺的验收项。复核可直接使用匿名作品文件。
