# 中文轻度段内改句匿名初评

先按归档题卡记录匿名 A/B 判断，再揭晓版本。评阅者为一位开发助手。

| 样本 | A / B 阅读分 | 对照依据 |
| --- | --- | --- |
| 宣传材料邮件 | 2 / 1 | A 直接交代周二 17 点前的回复，保留按期和延期两个回复分支及两项目的。B 仍先宣布要沟通。 |
| 西门维修通知 | 1 / 2 | B 首句即给出维修时段，保留原来的标题和两段。A 仍有行政开场。B 将“行人可从南门进出”写成“行人请从南门进出”，可能将许可写成指引或要求，列为语义风险。 |
| 交接单抽查 | 1 / 1 | A 的“抽查了”比 B 的“开展了抽查”短，两稿仍留下管理背景起笔，主要收益有限。数字、只核编号和两项目的保留。 |
| 毕业照叙事 | 2 / 2 | 两稿都将“就那次……的体验而言”换为直接回忆，同时保留老师、旧饼干盒和结尾，无明显相对优势。 |
| 外婆与荔枝 | 通过 / 通过 | 自然稿少改，空间、数量和动作顺序相同。 |
| 借阅规则 | 通过 / 通过 | 7 天、两个前置条件和锁定原文均保留。复借和不承诺可借的表述仍在。 |
