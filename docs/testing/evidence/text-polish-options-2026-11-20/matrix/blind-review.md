# 新稿文体与幅度匿名评阅

文体 A/B/C 与幅度 A/B 各自随机分配。以下判断在读取标签映射前保存，评阅者为一位开发助手。

| 稿件 | 文体对照 | 幅度对照及语义 |
| --- | --- | --- |
| 中文照明报告 | B 的“于上月、均可”偏书面。A/C 基本只换句式，未让试点发现前置。 | A/B 持平，均保留三晚、天气和车玻璃未测、因果不明及东区保留亮度建议。 |
| 中文排班邮件 | A 最书面，B 用“麻烦你、要是”明显较口语，C 介于两者。三稿都先说同步消息。 | A/B 持平，周三期限、两种备选、入口前提、暂定排期和范围保留。 |
| 中文资料归还 | A 用“要是……就”讲分支，B/C 同文。三稿均保留繁琐开场。 | 两稿改动很小，B 将周六例外独立成句。柜门引文、许可和登记边界均在。 |
| 中文长凳叙事 | A 仍写“描述起来很小”，B/C 虽缩短但文体差异微弱。叙事细节都保留。 | A 小幅简化开头，B 仍较累赘，两稿保持单段及真实时序。 |
| 中文雨中送报 | B“随后”偏书面，C“的时候、一直等”更口语，A 较平实。自然稿均可少改。 | A/B 均保住时间、位置和细节，修改有限。 |
| 中文撤回规则 | A 用“就得……才能”解释条件，B/C 近同。三组义务、许可、档案员确认及未指定的确认时限均在。 | A/B 持平，重组语序不改变条款。 |
| 英文装载报告 | B 较书面，A 平实，C 用缩约和较直接的背景解释，区分较明显。 | A 更早交代试点，但实测结果和建议仍在后面。原有样本范围及未记录时间均在。 |
| 英文设备邮件 | B/C 逐字相同，A 缩约较多。三稿都保留“getting in touch”铺垫。 | 两稿未提前请求。A 用“Please send”，B 保留“Could you send”；期限、临时清单、审批前提和适用范围均在。 |
| 英文归还刷具 | A 较书面，B 更像面对访客解释，C 介于两者。各稿均保留许可和破损分支。 | 两稿仍是一段，A 段首较空泛，操作归属与 B 基本相同。 |
| 英文旧地图 | C 较书面，A/B 大部分相同。三稿留有拗口回想开头，叙事细节均在。 | A 把回想式开场改为直接叙述，明显更易读，保留叔叔、铅笔、眼镜和结尾。 |
| 英文茶罐对照 | 两稿相同，另一个仅改“put”为“placed”，原稿自然。 | A/B 变化有限，均保留数量与顺序。 |
| 英文替换通行证 | B 更口语且保留“can/only if”，A/C 接近。锁定引文、不承诺发证时间均在。 | A 的被动句弱化显式“访客”主体，范围仍可从同段理解，记为轻微清晰度退步。许可与限定均在。 |
