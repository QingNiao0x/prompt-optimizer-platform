# 润色文体与改写幅度对照

## 四项交付

1. [中文三文体示范](../../../../services/api/src/main/resources/textpolish/skills/text-polish-style-contract-v1-zh/SKILL.md)及[英文三文体示范](../../../../services/api/src/main/resources/textpolish/skills/text-polish-style-contract-v1-en/SKILL.md)各用同一种素材写三个版本。正式清晰看结论、责任方、条件是否好找。自然流畅看作者口吻和叙述是否连贯。轻松交流看能否用读者易懂的话解释关系与术语。对应的离线请求覆盖中英文、三种文体和两种幅度。
2. [中文轻度指导与对照](light/README.md)完成 12 次真实调用。新增指令让宣传邮件和维修通知更早给出要点，但将“可从南门进出”改成“请从南门进出”，许可变化需要复核。
3. [大幅重构保真对照](fidelity/README.md)完成 12 次真实调用。托盘指南恢复许可措辞，用电报告保留有限证据的表述。中文告知责任和复查时间边界仍有偏差，既有开关尚缺独立复核及采用核对。
4. [文体与幅度矩阵](matrix/samples.json)完成 48 次真实调用，覆盖 6 篇中文和 6 篇英文新稿。每种语言有 4 篇需要编辑的稿件、1 篇自然对照和 1 篇规则对照。

## 文体与幅度结果

固定 `text-polish-style-contract-v1`、DeepSeek Flash、温度 0.2、思考关闭、8000 输出 Token 及 JSON 格式。固定轻度观察三种文体，再固定正式清晰观察两种幅度。两组复用正式轻度输出。逐份验明实际模型、参数、原文、策略版本和资源哈希。只有相应选项值及系统指令尾部对应文体或幅度发生变化。采用范围开关不参与选择。

| 对照 | 观察 |
| --- | --- |
| 三种文体 | 中文排班邮件、英文装载报告和刷具说明可看出三种语气的差别。其余稿件常只变用词或缩约。中文归还说明及英文设备邮件的正式和自然稿完全相同。三档整体区分度仍不足。 |
| 轻度与大幅重构 | 12 份正式轻度稿保持原段落数。切到大幅后，12 组稿件均未改变段落数，英文旧地图叙事的回想式开场明显变简洁，英文装载报告稍早交代试点。中文邮件和报告仍有主要铺垫，未证明大幅能稳定改善组织。 |
| 保真 | 两种幅度正常保住对照稿的日期、例外和锁定引文。个别措辞仍有清晰度或语气变化，因此以逐稿结果为准。工程断言覆盖请求和锁定内容，语义差异依赖评阅。 |

[匿名评阅](matrix/blind-review.md)在身份揭晓前落盘，由一位开发助手完成。矩阵回答选项本身能否产生明显差异。正式采用所需的独立评阅及同题候选对 v3 的比较，尚未由这个矩阵满足。另有已见稿上发现的语义风险，因此没有切换默认策略。

本次合计 **72/200 次真实调用**，均首次成功，失败、协议修复及付费评阅均为零。阶段账本均已关闭。本轮源码的相关 535 项后端工程检查通过。可用以下命令离线复核保存的结果，无模型费用。

```powershell
node scripts/evaluation/text-polish-options/verify.cjs docs/testing/evidence/text-polish-options-2026-11-20/matrix matrix --validate-only
```
