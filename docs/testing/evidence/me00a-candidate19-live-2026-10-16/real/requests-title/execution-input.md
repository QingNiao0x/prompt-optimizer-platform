## 背景
本次交付为一个小型 Python 功能实现：使用 requests 库爬取网页标题。原始需求未指定输入来源、输出形式、解析方式与异常处理口径，以下按可直接运行的最小实现组织，并在相应位置标明拟议做法。

## 任务
实现一个使用 requests 库获取网页标题的功能：
- 以函数入参接收一个或多个 URL，返回 URL 到标题的映射；同时提供命令行入口，接收一个或多个 URL 并打印结果。
- 对每个 URL 使用 requests.get 发起请求并设置超时；按响应声明的编码或 apparent_encoding 解码后提取 <title> 标签文本，去除首尾空白。
- 解析方式拟议优先使用标准库 html.parser；若目标页面结构复杂或需处理畸形 HTML，可改用 BeautifulSoup+lxml，并说明该选择会新增依赖。
- 对每个 URL 独立处理：请求失败、超时、非 200 状态、无 <title> 标签、空标题、非 HTML 内容、非法 URL 均需给出明确结果或错误标识，不中断其余 URL 的处理。
- 为核心逻辑补充测试，覆盖正常、异常与边界场景；测试使用本地构造的 HTML 或打桩的响应对象，不依赖真实外网。

## 输出

- 完整可运行代码。
- 核心行为的可执行测试代码。
- 接口契约随代码说明，包括函数入参、返回值、错误标识的含义。
