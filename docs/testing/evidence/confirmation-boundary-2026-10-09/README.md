## 文件说明

- `*-generation.json`：实际 Plan、提交答案、已知／未决决定、运行时选项、平台结果与耗时；`*-generation.md`：最终优化正文。
- `*-trace-*.json`：合成请求业务正文、上游原始 content、公开模型名、用量、停止原因和计时。不包含请求头、密钥或 reasoning_content。
- `*-raw-work` 是原始需求＋同材料同答案；`*-direct-work` 是执行优化提示词。本轮报告题为 Plan 增强，文件中的 arm 名不表示关闭 Plan。
- `final03-audit.json`：派生计数／时长／散列；`final03-review.md`：模型段落与平台新增行对照，逐行不相同不自动等于语义错误，仍需结合对象、状态及完整句核对。
- `ui-*`：普通工作台业务请求和响应；成功轮次为 `ui-direct-v2`、`ui-plan-v3`，实际示例开关可从请求正文核对。早期工具失败保留，不能混算为产品拒绝。
- `copy-diagnostic.json`：无头浏览器剪贴板读回权限限制；真实写入观察未替换原生调用。`mobile-result-v2` 验证实际移动端结果页，截图不等同全部响应式矩阵。
- `unit-final-summary.json`：最终 116 类／1572 项／6 跳过和逐例结果；未归档完整 Surefire XML 的运行环境属性。
- `sha256-index.json`：归档文件 SHA-256 与字节数；索引本身不递归加入自身。

本目录使用路径限定的 `-text -whitespace` 属性，保留 Windows 换行及模型原文空白，不为通过格式检查修改原件。应用源码和普通文档继续执行正常空白检查，证据用散列与 JSON 解析验证完整性。

## 复现工具

保留 `ConfirmationBoundaryRealEvaluation.java`、`run.ps1`、隔离 `pom.xml` 和 `audit-evidence.mjs`。工具按本仓库原临时目录组织；复现时复制到独立工作目录并核对脚本路径，生成全新的结果目录，不在本证据目录运行 Collect／Execute，不覆盖历史记录。密钥只从 Windows 用户环境读取，不填入源码或聊天。

脚本的 Validate 只校验合成输入、固定调用预算及工具编译；不代替业务验收。组件身份和存储为隔离夹具，不代表正常 HTTP／数据库／历史链路；普通登录工作台证据另列。所有专业内容审阅均为 AI 辅助定向检查，不是独立专业认证。
