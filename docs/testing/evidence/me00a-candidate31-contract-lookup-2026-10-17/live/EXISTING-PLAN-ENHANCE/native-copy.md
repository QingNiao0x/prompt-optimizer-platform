## 背景
本次交付为在现有订单项目的用户模块中实现登录接口。前端为 Vue3 + TypeScript，后端为 Spring Boot 3，数据库为 PostgreSQL，缓存为 Redis。项目已有用户表、密码校验逻辑和 JWT 认证契约，登录接口需与之一致。

## 任务
1. 先熟悉项目：检索并阅读用户模块、用户表实体与相关迁移脚本、密码校验实现、JWT 签发与校验配置、安全过滤器与权限规则、现有登录入口及对应测试，列出实际契约（接口路径、请求/响应字段、Token 结构与有效期、错误码与提示、权限规则）。
2. 基于核查到的契约实现登录接口，沿用现有用户表、密码校验和 JWT 认证方式；不新增用户表、不迁移数据、不改变其他登录入口。
3. 若源码中某项契约无法确认，明确标注未核实并说明所需证据，不按惯例假设字段名、路径或 Token 结构。
4. 识别并运行受影响的现有测试，补充登录接口的正常、异常与边界场景测试。
5. 给出实现方案、需新增或修改的模块、关键代码、接口契约说明和测试方案。

## 输出
- 现有契约核查结果：相关文件路径与符号、接口路径、请求/响应字段、Token 结构、错误码、权限规则。
- 实现方案：分层与模块划分，新增或修改的文件清单及理由。
- 关键代码：登录接口实现、必要的 DTO 与异常映射，风格与现有项目一致。
- 接口契约：请求方法、路径、入参、成功与失败响应示例（示例须标注为示意，字段以实际契约为准）。
- 测试方案与受影响测试：测试文件、覆盖场景、运行方式与结果说明。
