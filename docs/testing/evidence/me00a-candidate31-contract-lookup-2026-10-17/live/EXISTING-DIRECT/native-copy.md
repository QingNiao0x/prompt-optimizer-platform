## 背景
订单项目为前后端分离结构：前端 Vue3 + TypeScript，后端 Spring Boot 3，数据库 PostgreSQL，缓存 Redis。本次任务是在现有用户模块上实现登录接口，需沿用现有用户表、密码校验与 JWT 认证契约，不新增用户表、不迁移数据、不改变其他登录入口。

## 任务
1. 先熟悉订单项目：检索并阅读用户模块相关源码与配置，包括用户实体与数据访问层、密码编码器、JWT 签发与校验工具、安全/权限配置、现有登录入口及其控制器，确认现有接口路径、请求与响应字段、权限规则和错误返回约定。
2. 基于检索到的现有契约实现登录接口，复用现有用户表、密码校验逻辑与 JWT 认证机制；不新增用户表、不迁移数据、不修改其他登录入口。
3. 若源码中某项契约无法确认，明确标注“未核实”，给出拟议方案及适用条件，不把猜测写成既有事实。
4. 补充或调整受影响测试，覆盖正常登录、异常与边界场景，并验证现有功能与其他登录入口保持兼容。
