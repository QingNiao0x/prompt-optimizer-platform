真实登录复用 tmp/local-acceptance/account.json 指向的既有合成账号，DPAPI凭据和会话Cookie不导出。额外评测入口只在独立回环9002进程注册，不进入产品构建。PostgreSQL使用本机实例，Flyway关闭；本机当时仅有Redis 3.2.100可执行程序，启动了只绑定回环、不持久化的专用实例，不能据此宣称Redis 7验收完成。
