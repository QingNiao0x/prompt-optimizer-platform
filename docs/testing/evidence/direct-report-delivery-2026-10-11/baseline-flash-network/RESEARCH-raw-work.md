## 一、研究总体设计

### 1.1 研究目的
描述2015—2025年某地区心脑血管疾病（CVD）死亡率的长期趋势、季节性特征、人群与亚类差异，量化早死负担（YLL/YLL率），并采用Arriaga分解法解析死亡率变化的年龄/死因贡献。

### 1.2 数据来源与质量控制（撰写时按实际填写）
- 死亡数据：某地区全人群死因监测系统/户籍死亡登记，ICD-10编码 I00–I99（心脑血管疾病），亚类建议细分：
  - 缺血性心脏病（I20–I25）
  - 脑血管病（I60–I69）
  - 高血压性心脏病（I10–I15）
  - 其他心脏病/循环系统疾病
- 人口数据：公安/统计年鉴分年龄、性别、地区年末人口数
- 标准人口：建议采用**2010年全国人口普查年龄结构**或**WHO世界标准人口**，用于标化率计算
- 质量控制：漏报率调查、ICD编码一致性核查、逻辑校验（如年龄≥0、死因与性别一致性）

### 1.3 统计指标
| 指标 | 公式/说明 |
|---|---|
| 粗死亡率（CDR） | 某年CVD死亡数 / 同年平均人口 × 100,000 |
| 年龄标化死亡率（ASMR） | 直接法：Σ(年龄组死亡率×标准人口构成) |
| 年度变化百分比（APC） | 对数线性回归：ln(率)=α+β·年，APC=(e^β−1)×100% |
| 平均年度变化百分比（AAPC） | 分段回归加权平均，Joinpoint软件 |
| 季节指数 | 各月死亡数/月均死亡数×100% |
| YLL | Σ(各年龄组死亡数×该组期望寿命) |
| YLL率 | YLL / 人口数 × 1,000（或100,000） |
| Arriaga分解 | 见第四部分 |

## 四、减寿分析（YLL与YLL率）

### 4.1 计算方法
- **YLL** = Σ(各年龄组死亡数 × 该年龄组期望寿命)
  - 期望寿命可取自当地简略寿命表，或采用WHO标准期望寿命表
  - 建议报告：全人群、分性别、分年度、分亚类
- **YLL率** = YLL / 平均人口数 × 1,000（或100,000）
- **标化YLL率**：按标准人口年龄结构标化
- **平均减寿年数（AYLL）** = YLL / 死亡数

## 五、Arriaga分解方法

### 5.1 方法原理
Arriaga分解用于将两个时点（或两个人群）之间**期望寿命差**分解为：
- **直接效应**：某年龄组死亡率变化对期望寿命的贡献
- **间接效应**：某年龄组死亡率变化通过存活人数影响后续年龄组的贡献
- **交互效应**：年龄组间死亡率变化的联合作用

若研究的是**死亡率差**而非期望寿命差，也可采用Arriaga分解的扩展形式，将CVD死亡率变化分解为：
- 年龄结构变化贡献
- 年龄别死亡率变化贡献
- 死因构成变化贡献

### 5.2 分析步骤（以期望寿命差分解为例）
1. 构建2015年与2025年简略寿命表（分性别）
2. 计算两时点期望寿命差：e₀²⁰²⁵ − e₀²⁰¹⁵
3. 按年龄组分解：
   - 直接效应：Δᵢ = (nqₓ¹ − nqₓ²) × (lₓ¹/l₀) × (eₓ² + n/2) 等（按Arriaga公式）
   - 间接效应：由存活人数变化引起
   - 交互效应：直接×间接
4. 汇总各年龄组贡献，识别关键年龄组
5. 若需分死因，可结合**去死因寿命表**或**多死因分解**
