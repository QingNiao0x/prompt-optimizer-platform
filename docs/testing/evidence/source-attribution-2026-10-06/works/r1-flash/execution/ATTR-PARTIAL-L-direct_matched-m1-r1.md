# 复核备忘录草稿（合成材料·承租方视角）

**适用地点**：合成项目所在中国大陆甲市。**读者**：承办律师及受托整理人员。**性质**：材料整理与方法草稿，不构成已生效法律意见，不替代执业律师对法律适用和条款效力的判断。

**本次做什么**：将合成商业租赁往来材料整理为供律师复核的事实与问题清单，识别材料矛盾、缺失证据和需律师核实的条款范围。**依据什么**：仅依据下列已列明来源的合成材料。**交付什么**：事实与证据来源表、两版条款差异表、分优先级律师复核问题、本限制性备忘录草稿。**不能做什么**：不评价某方一定胜诉或一定违法，不输出具体条文编号、现行效力、赔偿数额或胜诉概率，不发送律师函、不公开争议、不执行催告，不加入真实当事人信息、联系地址或身份证件内容。

**两项执行前未决条件（不得默认补全）**：
1. 两版租赁草稿中哪一份是本次律师复核的主文本——**暂不确定**。影响：主文本未定时只能制作并列差异清单，不能写最终合同摘要。
2. 复核优先侧重持续履约还是可能提前退出——**暂不确定**。影响：该选择决定律师复核问题的优先级排序和条款核对重点。

## 四、明确限制的备忘录草稿

**本次做什么**：将合成商业租赁往来材料整理为供律师复核的事实和问题清单，识别材料矛盾、缺失证据和需律师核实的条款范围。

**依据什么**：materials/legal_memo/current-brief.md、materials/legal_memo/legacy-note.md、materials/legal_memo/maintenance-confirmation.md。materials/legal_memo/tests/layout-example.txt 仅为排版和来源识别的测试例子，不是本题事实，已排除。

**交付什么**：事实与证据来源表、两版条款差异表、分优先级律师复核问题、本限制性备忘录草稿。

**不能做什么**：
- 不评价某方一定胜诉或一定违法。
- 不输出具体条文编号、现行效力、确定法律结论、赔偿数额或胜诉概率。
- 不发送律师函、不公开争议、不执行催告。
- 不加入真实当事人信息、联系地址或身份证件内容。
- 不把草稿当作双方已生效的协议，不把协商邮件自动解释为承诺或违约。
- 不根据签名占位图认定已经签署。
- 不把“文件未提供”写成“项目中不存在”，不把“草稿建议”写成“已批准制度”，不把“测试通过”写成“真实业务准确”。
- 不把两个版本拼接成对承租方更不利的统一条款。
- 不按字数、写作风格或较新的文件日期决定哪个值正确。
- 不先判定出租方无权出租。
- 不声称已经完成实际法律与律师文书业务验收。

**结论——材料充分程度**：
- 可直接使用：承租方视角与目标、草稿未签署状态、合成示例性质、条款逐条核对要求、文档日期含义、押金差异两值、草稿A“承租方承担日常维护”、维修条款拼接禁止、协商邮件性质、风险级别含义、主文本未定时处理方式、解除条款结构、敏感信息边界、备忘录结论边界、文书送达限制。
- 候选待选：无（本次未给出候选方案）。
- 暂不能执行：主文本选定、复核优先侧重选定、“全部设施故障费用”版本归属、提前解约具体值、租金具体值、房屋权属和授权链、示例判决标题可核验出处。

**后续核验事项**：
1. 由委托人业务决定明确两版草稿的主文本，或确认继续并列差异清单。
2. 由委托人业务决定复核优先侧重持续履约还是可能提前退出。
3. 补充“全部设施故障费用”条款的版本归属证据。
4. 补充提前解约条款的通知形式、提前量和费用原文及条件关系。
5. 补充租金条款原文。
6. 核验房屋权属和授权链证据。
7. 核验示例判决标题出处。
8. 由执业律师按真实事实与现行依据处理法律适用和条款效力。

**未解决的关键条件（可复制正文）**：
