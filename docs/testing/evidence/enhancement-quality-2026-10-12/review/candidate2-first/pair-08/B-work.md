# 研究设计方案：用户先回答关键问题再增强提示词 vs. 直接增强提示词

> **信息分类声明**：本方案中，所有已明确标注“待定”的参数均为尚未确定的研究设计参数，不代表任何实际数据或预判结果。方案不包含任何编造的数据、统计结果或文献引用。所有研究程序均为设计建议，需在实际实施前通过伦理审查和预注册。


## 一、研究问题与假设

### 1.1 研究问题

**主研究问题**：在用户使用大语言模型完成开放式任务的场景中，“用户先回答关键问题再增强提示词”（以下简称“问答增强条件”）与“直接增强提示词”（以下简称“直接增强条件”）相比，是否在生成回答的质量和用户满意度上存在差异？

**子研究问题**：
- **RQ1**：两种条件在生成回答的客观质量评分上是否存在差异？
- **RQ2**：两种条件在用户主观满意度（含感知相关性、感知有用性、感知控制感）上是否存在差异？
- **RQ3**：用户先回答关键问题所引入的额外信息量，是否中介或调节了条件对回答质量的影响？（即：问答增强的效果是否可归因于信息量增加本身，而非“问答”这一交互形式）
- **RQ4**：问答增强条件中，用户回答关键问题的质量（如详细程度、具体性）与最终回答质量之间是否存在关联？

### 1.2 假设

> 以下假设为研究设计的理论预期，**并非事实陈述或已有结论**，需通过数据检验。

- **H1（回答质量假设）** ：问答增强条件下的生成回答质量评分高于直接增强条件。
- **H2（满意度假设）** ：问答增强条件下的用户主观满意度高于直接增强条件。
- **H3（信息量中介假设）** ：问答增强条件对回答质量的正向效应（若存在）至少部分由用户提供的额外信息量所中介。
- **H4（信息量控制假设）** ：当直接增强条件获得与问答增强条件等量的用户背景信息时（通过独立的信息收集步骤），两种条件在回答质量上的差异缩小或消失。若此假设成立，则说明“问答是否有用”主要取决于信息增量而非交互形式本身。

### 1.3 假设的检验逻辑

H1和H2检验两种条件的总体效应差异；H3和H4共同回答“问答是否有用”的机制问题——即效果是来自“问答交互过程”本身（如帮助用户澄清需求），还是仅仅来自“用户提供了更多信息”。这一区分对实践有直接指导意义：如果H4成立，则产品设计者可选择任何高效的信息收集方式；如果H4不成立而H1成立，则说明问答交互过程本身具有独特价值。


## 二、方法

### 2.1 研究设计概览

采用 **2（条件：问答增强 vs. 直接增强）× 2（信息量控制：无额外信息 vs. 等量信息）混合设计**，其中条件为受试者内因素（within-subjects），信息量控制为受试者间因素（between-subjects）。

具体而言，将参与者随机分为两组：

| 组别 | 问答增强条件 | 直接增强条件 |
|------|-------------|-------------|
| **A组（无信息控制）** | 用户回答关键问题 → 基于回答增强提示词 | 直接增强提示词（无额外用户信息） |
| **B组（信息量控制）** | 用户回答关键问题 → 基于回答增强提示词 | 用户先独立填写背景信息表（与关键问题等量信息）→ 基于该信息增强提示词 |

**设计逻辑**：
- A组模拟两种策略的“现实对比”：问答增强有额外信息，直接增强没有。
- B组模拟“信息量匹配对比”：两种条件都获得等量用户信息，差异仅在于信息获取方式（交互式问答 vs. 独立填表）。
- 通过A组与B组的对比，可以分离“信息量效应”与“交互形式效应”。

### 2.2 参与者

- **招募来源**：待定（建议通过大学参与者库、在线众包平台或产品用户群招募，具体渠道需根据伦理审查和可行性确定）。
- **纳入标准**：待定（建议包括：年满18岁；具有使用大语言模型的基本经验；能够完成指定类型的任务；语言能力满足任务要求）。
- **排除标准**：待定（建议包括：无法完成预测试任务者；对研究目的有先验了解可能影响表现者；数据不完整者）。
- **样本量**：待定。需基于预实验（pilot study）的效应量估计，通过功效分析（power analysis）确定。建议预实验样本量不少于每组15–20人，正式实验的目标功效不低于0.80，显著性水平α=0.05（双侧）。
- **激励方式**：待定（需根据招募渠道和任务时长确定，应确保两组激励一致）。

### 2.3 任务类型

- **任务领域**：待定。建议选择2–4个开放式、有明确质量评判标准的任务类型，例如：
  - 写作类任务（如撰写一封投诉邮件、一份简短报告）
  - 规划类任务（如制定旅行计划、活动方案）
  - 问题解决类任务（如分析一个具体问题并提出解决方案）
  - 信息整合类任务（如根据给定材料撰写摘要或对比分析）
- **任务数量**：每位参与者完成 **2个任务**（一个在问答增强条件下，一个在直接增强条件下），以支持受试者内比较。任务数量可根据预实验调整。
- **任务分配**：任务与条件的配对需通过拉丁方设计（Latin square）平衡，确保每个任务在两种条件下出现的次数相等。
- **任务难度**：待定。建议在预实验中校准，使任务具有足够的开放性和复杂度，使得提示词增强有实际意义（即任务不能过于简单以至于原始提示词已足够）。

### 2.4 提示词增强的具体操作

#### 2.4.1 基础提示词（用户原始输入）

参与者在看到任务描述后，先自行撰写一个初始提示词（即他们原本会输入给大语言模型的内容）。该初始提示词在两种条件下保持一致，作为增强的起点。

#### 2.4.2 问答增强条件

1. 参与者撰写初始提示词。
2. 系统/研究者向参与者呈现 **3–5个关键问题**（具体数量待定，需在预实验中确定），这些问题旨在澄清任务的核心要素，例如：
   - 目标受众是谁？
   - 期望的语气/风格是什么？
   - 有哪些必须包含或避免的内容？
   - 输出的格式或长度要求是什么？
   - 有什么背景信息是模型需要知道的？
3. 参与者以自由文本形式回答这些问题。
4. 研究者（或预设的增强模板）将初始提示词与参与者的回答整合，生成增强后的提示词。整合方式需标准化（见2.4.4）。

#### 2.4.3 直接增强条件

- **A组（无信息控制）** ：研究者直接基于初始提示词进行增强，不向参与者询问任何额外问题。增强操作遵循相同的标准化增强模板，但仅使用初始提示词中已有的信息。
- **B组（信息量控制）** ：参与者在撰写初始提示词后，独立填写一份 **背景信息表**。该表格包含与问答增强条件中关键问题相同的信息维度（如目标受众、语气风格、必须包含的内容等），但以一次性表格形式呈现，而非交互式问答。研究者基于初始提示词和该表格内容进行增强。

#### 2.4.4 增强操作的标准化

为确保两种条件下的增强质量一致且可复现，增强操作需遵循以下原则：

- **增强模板**：预先制定标准化的提示词增强模板（如“角色设定 + 任务描述 + 具体要求 + 输出格式”的结构），两种条件均使用同一模板。
- **增强执行者**：待定。可选择以下方案之一：
  - 方案一：由研究者人工执行增强，使用详细的增强操作手册，并通过双人独立增强和一致性检验来保证可靠性。
  - 方案二：使用预设的规则化增强脚本（如基于模板的自动拼接），完全消除人为差异。
  - 方案三：使用另一个大语言模型执行增强（如“请根据以下用户原始提示词和补充信息，生成一个增强版提示词”），需固定模型版本和参数。
- **增强质量检查**：无论采用哪种方案，需对增强后的提示词进行质量检查（如完整性、忠实于用户原始意图、未添加用户未提供的信息），确保两种条件下的增强提示词在格式和结构上可比。

### 2.5 大语言模型调用

- **模型选择**：待定。需在研究开始时固定所使用的模型（如某个特定版本的商用或开源大语言模型），并在整个研究期间保持不变。
- **参数设置**：温度、最大生成长度等参数需固定并在方案中预先声明。
- **输出记录**：完整记录每次模型调用的输入（增强后提示词）和输出（生成回答），确保可复现。

### 2.6 实验程序

#### 2.6.1 预实验阶段

1. 招募小样本参与者（待定，建议15–20人/组）。
2. 测试任务难度、关键问题的清晰度和有效性、增强模板的适用性。
3. 估计效应量，确定正式实验的样本量。
4. 检验评分量表的信度和效度。
5. 根据预实验结果修订实验材料和程序。

#### 2.6.2 正式实验阶段

每位参与者的实验流程如下：

1. **知情同意与说明**：参与者阅读并签署知情同意书，了解实验流程（但不被告知具体研究假设，以避免需求特征）。
2. **人口学信息收集**：收集基本人口学信息（如年龄、性别、教育水平、大语言模型使用经验等，具体项目待定）。
3. **任务1**：
   - 阅读任务描述。
   - 撰写初始提示词。
   - 根据分配的条件（问答增强或直接增强），完成相应步骤（回答关键问题 / 填写背景信息表 / 无额外步骤）。
   - 系统生成增强后提示词并调用大语言模型。
   - 参与者阅读生成回答。
   - 填写满意度量表。
4. **任务2**：重复步骤3，但条件与任务1互换（受试者内交叉）。
5. **后续问卷**：填写关于整体体验的问卷，包括对两种条件的主观偏好（若有）。
6. **简报与致谢**：向参与者说明研究目的，回答疑问。

#### 2.6.3 时间安排

- 每位参与者的总时长：待定（预计30–60分钟，需根据任务复杂度确定）。
- 两个任务之间建议设置短暂的休息或干扰任务（如2–3分钟的无关填充任务），以减少任务间的直接对比效应和疲劳效应。

### 2.7 顺序效应与个体差异的控制

| 偏倚来源 | 控制方法 |
|---------|---------|
| **顺序效应**（任务1影响任务2） | 使用拉丁方设计平衡条件顺序和任务顺序；在任务间设置填充任务；在分析中将顺序作为协变量或检验顺序×条件的交互效应 |
| **个体差异**（参与者能力、经验不同） | 受试者内设计使每位参与者作为自身对照；随机分配至A组或B组；收集大语言模型使用经验等变量作为协变量 |
| **任务差异**（不同任务难度不同） | 拉丁方设计确保每个任务在两种条件下出现次数相等；在分析中将任务作为随机效应或固定效应 |
| **信息量差异**（问答条件获得更多信息） | 通过A/B组设计分离信息量效应：A组反映现实差异，B组匹配信息量 |
| **需求特征**（参与者猜测研究目的） | 不告知具体假设；使用中性指导语；事后问卷中检测参与者对研究目的的猜测 |
| **实验者效应** | 标准化指导语；增强操作使用统一模板和手册；若人工增强，采用双人独立操作和盲法评分 |


## 三、结果指标与测量

### 3.1 主要结果指标

#### 3.1.1 回答质量评分（客观指标）

- **评分维度**：待定。建议包括但不限于：
  - **相关性**：回答是否直接回应了用户提示词中的核心需求
  - **完整性**：回答是否覆盖了任务要求的所有关键方面
  - **准确性**：回答中的事实性内容是否准确（如适用）
  - **有用性**：回答对用户完成任务的实用价值
  - **格式符合度**：回答是否符合用户指定的格式要求（如适用）
- **评分方式**：由经过培训的独立评分者使用标准化评分细则（rubric）进行评分。每个维度使用 **待定** 点量表（如1–5或1–7，需在预实验中确定信度）。
- **评分者数量**：待定（建议至少2–3名独立评分者）。
- **盲法**：评分者不知道每个回答来自哪种条件（对条件盲法）。
- **信度检验**：计算评分者间信度（如组内相关系数ICC或Krippendorff's α），需达到预设阈值（待定，如ICC ≥ 0.70）方可认为评分可靠。

#### 3.1.2 用户满意度（主观指标）

- **测量工具**：自编满意度问卷，包含以下维度（各维度使用待定点Likert量表，如1–7）：
  - **感知相关性**：生成回答与我的需求相关
  - **感知有用性**：生成回答对我完成任务有帮助
  - **感知控制感**：我觉得自己能够影响生成结果的方向
  - **整体满意度**：我对最终回答的整体满意程度
  - **过程满意度**：我对提示词增强过程的满意程度
- **量表信效度**：需在预实验中检验内部一致性（如Cronbach's α）和结构效度。

#### 3.1.3 信息量指标（用于中介/调节分析）

- **信息量测量**：对参与者在问答增强条件中的回答（或B组直接增强条件中的背景信息表）进行信息量编码。编码维度待定，可包括：
  - 总字数
  - 信息单元数量（独立的信息点数量）
  - 信息维度覆盖率（覆盖了多少个预设的关键信息维度）
- **编码方式**：由独立编码者使用标准化编码手册进行，需报告编码者间信度。

### 3.2 次要结果指标

- **增强后提示词质量**：对增强后的提示词本身进行质量评分（如清晰度、具体性、结构完整性），以检验增强操作是否在两种条件下达到了可比的增强水平。
- **任务完成时间**：参与者在两种条件下完成任务所需的时间（可作为效率指标）。
- **条件偏好**：实验结束后询问参与者更偏好哪种条件（可作为探索性指标）。


## 四、数据分析计划

### 4.1 数据预处理

1. 检查数据完整性，记录缺失数据模式和比例。
2. 对缺失数据的处理策略需预先声明（如多重插补、完全案例分析或混合模型处理），不得事后选择。
3. 检验异常值，使用预先声明的标准（如超出均值±3SD）识别，并报告敏感性分析（含/不含异常值的结果对比）。

### 4.2 主要分析

#### 4.2.1 回答质量与满意度（H1、H2）

- **分析模型**：线性混合效应模型（Linear Mixed-Effects Model, LMM）或广义线性混合模型（视因变量分布而定）。
- **固定效应**：条件（问答增强 vs. 直接增强）、组别（A组 vs. B组）、条件×组别交互项、任务、顺序。
- **随机效应**：参与者（随机截距）、任务（随机截距，如适用）。
- **协变量**：大语言模型使用经验、任务完成时间等（如适用）。
- **模型设定示例**（以回答质量评分为因变量）：
  ```
  质量评分 ~ 条件 × 组别 + 任务 + 顺序 + (1|参与者) + (1|任务)
  ```
- **假设检验**：
  - H1检验：条件的主效应是否显著（问答增强 > 直接增强）。
  - H2检验：满意度各维度的条件主效应。
  - 条件×组别交互效应：检验信息量控制是否改变了条件效应的大小。

#### 4.2.2 信息量的中介分析（H3）

- **分析框架**：使用中介分析（如Baron & Kenny方法或基于bootstrap的间接效应检验）。
- **路径**：条件 → 信息量 → 回答质量。
- **适用条件**：仅当条件对回答质量的总效应显著时进行中介分析。
- **注意**：由于条件为受试者内因素，中介分析需使用适用于重复测量数据的多水平中介模型。

#### 4.2.3 信息量控制下的条件对比（H4）

- **分析策略**：在B组数据中单独检验条件效应（此时两种条件的信息量已匹配）。
- **预期模式**：
  - 若B组中条件效应不显著而A组中显著，则支持H4（效果主要由信息量驱动）。
  - 若B组中条件效应仍显著，则说明交互形式本身有独立贡献。

### 4.3 补充分析

- **评分者信度分析**：报告ICC或α系数及置信区间。
- **量表信度分析**：报告Cronbach's α。
- **敏感性分析**：排除异常值、排除猜测研究目的的参与者、使用非参数方法等。
- **探索性分析**：问答质量（RQ4）与回答质量的相关分析；条件偏好与满意度的一致性。

### 4.4 统计软件与可复现性

- **软件**：待定（如R或Python，需在研究方案中预先声明）。
- **可复现性**：分析代码、数据清洗脚本、模型设定需在研究报告中完整提供（在数据匿名化前提下）。


## 五、偏倚控制与局限性

### 5.1 偏倚控制措施汇总

| 偏倚类型 | 控制措施 |
|---------|---------|
| **选择偏倚** | 随机分配至A/B组；明确的纳入/排除标准 |
| **顺序效应** | 拉丁方设计；填充任务；顺序作为协变量 |
| **评分者偏倚** | 盲法评分；多评分者；标准化评分细则；信度检验 |
| **实验者偏倚** | 标准化指导语和操作手册；增强操作标准化 |
| **需求特征** | 不告知具体假设；事后检测 |
| **测量偏倚** | 量表预实验验证；多维度测量 |
| **报告偏倚** | 预注册研究方案；报告所有预设分析的结果 |
| **缺失数据偏倚** | 预先声明缺失数据处理策略；报告缺失模式 |

### 5.2 局限性

1. **生态效度有限**：实验环境中的任务可能与真实使用场景存在差异。参与者在实验中的动机和投入程度可能不同于实际使用情境。
2. **增强操作的标准化与真实性的张力**：为公平比较而标准化的增强操作可能不完全代表实际产品中提示词增强的多样性和灵活性。
3. **关键问题的选择**：关键问题的设计（数量、内容、措辞）可能影响问答增强条件的效果。本研究只能检验特定关键问题集的效果，不能推广到所有可能的问答设计。
4. **任务类型的有限性**：结果可能依赖于所选任务类型，不同任务领域（如创意写作 vs. 技术问题解决）可能有不同的模式。
5. **单次交互限制**：本研究仅考察单轮问答增强，不涉及多轮迭代式增强，后者在实际应用中可能更常见。
6. **大语言模型的版本依赖性**：结果可能依赖于所使用的具体模型版本，不同模型对提示词增强的敏感度可能不同。
7. **信息量匹配的近似性**：B组中通过背景信息表收集的信息量与问答条件中的信息量可能无法完全匹配（如问答可能激发参与者提供表格中不会主动填写的信息），信息量编码仅能近似控制这一差异。
8. **参与者群体的代表性**：结果可能不适用于所有用户群体（如不同语言背景、不同技术熟练度的用户）。
9. **评分的主观性**：尽管采用标准化评分细则和盲法评分，回答质量评分仍不可避免地包含主观成分。
10. **无法完全排除的混淆因素**：问答增强条件中参与者投入了更多时间和认知努力，这可能通过“努力正当化”等心理机制影响满意度评分，而不仅仅是信息量差异所致。


## 六、适用条件

### 6.1 本方案适用的条件

- **任务特征**：开放式、有明确质量评判标准、复杂度足以使提示词增强产生实际差异的任务。
- **用户特征**：具有基本大语言模型使用经验的成年用户。
- **技术条件**：可固定使用同一版本的大语言模型，且模型对提示词变化有可检测的响应。
- **资源条件**：有足够资源进行预实验、招募参与者、培训评分者和执行标准化增强操作。

### 6.2 本方案不适用的条件

- 封闭式或简单任务（提示词增强可能无实际意义）。
- 多轮对话场景（本方案仅覆盖单轮增强）。
- 需要高度个性化或领域专业知识的增强场景（标准化增强操作可能不适用）。
- 无法固定模型版本或参数的环境。

### 6.3 结果推广的边界

本研究的结果仅能在以下范围内进行推广：
- 与实验中所用任务类型相似的任务。
- 与实验中所用关键问题设计相似的问答增强策略。
- 与实验中所用模型能力相近的大语言模型。
- 单轮提示词增强场景（不涉及多轮迭代）。


## 七、伦理考量

- **知情同意**：参与者需在充分了解实验流程、数据用途和权利后签署知情同意书。
- **数据隐私**：所有参与者数据需匿名化处理，个人可识别信息不得出现在分析数据集中。
- **数据存储**：数据存储方式和期限需符合所在机构的伦理要求。
- **伦理审查**：本方案需提交伦理审查委员会（IRB）审批后方可实施。
- **预注册**：建议在数据收集开始前对研究方案进行预注册（如OSF），以减少报告偏倚。
