# 中文轻度示范匿名初评

一位开发助手按冻结题卡评阅，记录落盘后才读取标签。

| 样本 | A / B 阅读分 | 判断 |
| --- | --- | --- |
| 交付邮件 | 1 / 1 | 两稿都保留宣布要沟通的开场。周二截止、周五计划、延期回复、两个目的均保留。A 的首句稍短，读者仍须读第二句才知道要做什么。 |
| 维修通知 | 2 / 2 | 两稿都拿掉行政开场，直接交代维修时段、南门通行和车辆例外，标题、两段及雨天条件均在。 |
| 毕业照叙事 | 2 / 2 | 两稿相同，简化回忆开场并保留旧饼干盒、卷边照片和含蓄结尾。 |
| 钥匙和荔枝 | 通过 / 通过 | 自然稿可少改。两稿均保留空间、动作、两颗荔枝及原口吻。 |
