# 中文示范对照及采用检查

以 `text-polish-zh-v1` 为基础，注册两种显式实验配置。轻度候选换用邮件和通知的段内重写示范，大幅重构候选换用复杂报告示范。模型、温度、思考、响应格式、原文、用户要求、基础指令和文体幅度规则一致。资源清单逐项记录实际基础指导与示范的哈希。

- [轻度示范](../../../../services/api/src/main/resources/textpolish/skills/text-polish-zh-light-example-v1/SKILL.md)把请求或安排及其时限放到原段开头，保留等候分支、条件、责任与承诺。
- [报告示范](../../../../services/api/src/main/resources/textpolish/skills/text-polish-zh-report-example-v1/SKILL.md)展开参与方与工作关系，组织已有观察、未验证事实及下一项建议。

## 现有中英文大幅重构复核

核对现有材料后，仍需第二位评阅者独立复核。中文储物柜说明的“也会提醒”可能把提醒目的或后续责任表述成前台承诺。英文用电报告的 “indicated” 与 “found” 需要结合只在三次观察中发现不一致的范围核对。英文托盘指南两组均将 “can put” 写成 “put”，需要判定该场景下操作指引是否改变许可强度。

可将各组完整匿名材料直接交给独立评阅者。先核对原文与匿名作品的阅读收益和语义偏差，再揭晓标签。两组试用开关保持默认关闭。[中文匿名材料](../text-polish-zh-v1/holdout/blind-packet.json) · [英文匿名材料](../text-polish-paragraph-v2/en-restructure/blind-packet.json)
