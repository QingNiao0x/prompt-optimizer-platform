# 2015—2025年青禾地区心脑血管疾病死亡率特征分析

## 一、研究背景

心脑血管疾病长期位居我国居民死因前列，其死亡水平的时间变化、人群分布和早死负担是区域公共卫生监测与评价的重要内容。青禾地区为本次验收的虚构地区，设定年份范围为2015—2025年。本报告拟在该时空范围内，围绕心脑血管疾病死亡率的年度时间趋势及季节性、性别/地区/人群亚类差异、年度分性别YLL及YLL率、Arriaga分解四项内容展开分析，为课题组内部讨论提供报告初稿。需要说明的是，本报告不用于诊疗或公共发布，且现有输入未包含任何实证结果，因此以下正文仅完成不依赖实际数值的部分，涉及缺失数据或未决口径之处均以占位标记标明。

## 二、资料与方法

本报告拟使用的资料类型为青禾地区死亡登记资料与年度人口资料。死亡登记资料用于提取心脑血管疾病死亡个案及其性别、年龄、地区子区、人群亚类等属性；年度人口资料用于计算死亡率、YLL率等相对指标。性别字段拟采用male/female/unknown三类取值，但该字段仅表示记录中的取值类别，不代表各组人数或比率已知。心脑血管疾病的判定口径、死亡个案的纳入与排除规则、重复记录处理方式等，均需在正式分析前明确。

在时间趋势及季节性分析中，拟按年度汇总心脑血管疾病死亡数、粗死亡率及（如标准人口确定后）标化死亡率，并观察月度或季度分布特征。在性别/地区/人群亚类差异分析中，拟按性别、地区子区和人群亚类分别汇总死亡水平并进行组间比较。在年度分性别YLL及YLL率分析中，拟依据寿命表计算各年度分性别的早死寿命损失年（YLL）及YLL率。在Arriaga分解中，拟将两个年度之间死亡率或预期寿命差异分解为年龄别死亡水平变化的贡献与人口年龄结构变化的贡献。

上述分析均依赖若干尚未提供的输入，包括实际死亡数与人口数、标准人口、寿命表、年龄分组、地区子区与人群亚类的映射关系等。在这些输入缺失或口径未决的情况下，本报告不能给出任何实证数值或方向性判断。各分析所需的具体依据将在相应位置以占位标记说明。

## 三、分析结果

### （一）年度时间趋势及季节性

本部分拟呈现2015—2025年青禾地区心脑血管疾病死亡率的年度变化及季节分布。由于实际死亡数、年度人口数、标准人口及年龄分组均未提供，无法计算粗死亡率、标化死亡率或判断趋势方向与季节峰值。相关位置所需依据如下：

- 年度死亡数与对应人口数：用于计算各年度死亡率，需提供死亡登记与年度人口资料。
- 标准人口及年龄分组：用于计算标化死亡率，需明确标准人口来源与年龄组划分。
- 月度或季度死亡汇总：用于判断季节性，需提供死亡发生时间字段及完整月份覆盖。

在以上依据齐备前，本部分不呈现具体数值、趋势方向或季节峰值。

### （二）性别/地区/人群亚类差异

本部分拟呈现不同性别、地区子区和人群亚类之间的心脑血管疾病死亡水平差异。性别字段拟为male/female/unknown，但各组人数与比率均未知；地区子区与人群亚类的映射关系尚未确定。因此，无法判断任何组间优劣或差异大小。相关位置所需依据如下：

- 分性别死亡数与人口数：用于计算分性别死亡率，需明确unknown组的处理方式。
- 地区子区划分方案及对应死亡数与人口数：用于计算地区别死亡率。
- 人群亚类定义及对应死亡数与人口数：用于计算亚类别死亡率。
- 年龄分组与标化方法：用于控制年龄结构影响后再比较。

在以上依据齐备前，本部分不呈现组间比较结果。

### （三）年度分性别YLL及YLL率

本部分拟呈现2015—2025年各年度分性别的YLL及YLL率。YLL计算依赖寿命表、年龄分组、各年龄别死亡数及对应预期寿命，YLL率还需对应分性别、分年度人口数。上述输入均未提供，故无法给出任何YLL数值或YLL率数值。相关位置所需依据如下：

- 寿命表：需明确所用寿命表类型、来源及适用年份。
- 年龄分组：需明确年龄组划分方式及各组死亡数。
- 分性别、分年度死亡数与人口数：用于计算YLL及YLL率。
- 期望寿命取值：需与所选寿命表一致。

在以上依据齐备前，本部分不呈现YLL及YLL率数值。

### （四）Arriaga分解

本部分拟对两个年度之间的心脑血管疾病死亡率或预期寿命差异进行Arriaga分解，区分年龄别死亡水平变化与人口年龄结构变化的贡献。该分析依赖两个年度的年龄别死亡率、年龄结构、寿命表及年龄分组，上述输入均未提供，故无法给出任何分解贡献数值。相关位置所需依据如下：

- 两个对比年度的年龄别死亡数与人口数：用于计算年龄别死亡率。
- 两个对比年度的年龄结构：用于区分结构变化贡献。
- 寿命表及年龄分组：用于计算预期寿命及其变化。
- 分解公式的具体形式与符号约定：需在分析前统一。

在以上依据齐备前，本部分不呈现分解贡献数值。
