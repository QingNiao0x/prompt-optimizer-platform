## 二、时间序列的长期趋势与季节性趋势

### 2.1 长期趋势
**方法：**
1. **年度变化百分比（APC）与平均年度变化百分比（AAPC）**：对率取对数后拟合回归 `ln(率) = α + β·年 + ε`，APC = (e^β − 1)×100%。
2. **Joinpoint回归**：识别趋势转折点，计算各段APC及全程AAPC，用Monte Carlo置换检验确定最优转折点数。
3. **标化率与粗率并行报告**，避免人口老龄化造成的误读。

### 2.2 季节性趋势
**方法：**
1. **月度/季度死亡率描述**：计算各月平均死亡率及变异系数。
2. **季节分解**：STL（Seasonal-Trend decomposition using Loess）或 X-13ARIMA-SEATS，分离趋势项、季节项、残差项。
3. **季节指数**：季节指数 = 各月均值 / 全年均值 × 100%。
4. **循环分布检验**：Watson's U² 或 Rayleigh 检验，判断死亡是否存在季节性聚集。
5. **气温关联（可选）**：分布滞后非线性模型（DLNM）分析气温与CVD死亡的暴露-滞后-反应关系。

## 五、Arriaga 分解方法

### 5.1 方法原理
Arriaga分解用于将**期望寿命变化**或**死亡率变化**分解为：
1. **直接效应**：某年龄组死亡率变化对寿命/率变化的直接贡献
2. **间接效应**：该年龄组存活人数变化导致后续年龄组死亡数变化的贡献
3. **交互效应**：各年龄组变化的共同作用

### 5.2 分析步骤
1. 构建2015年与2025年（或相邻年份）简略寿命表
2. 计算两期期望寿命差 `e₀(2025) − e₀(2015)`
3. 按年龄组分解各年龄组对总变化的贡献（直接+间接+交互）
4. 按死因分解：将CVD各亚类作为分死因，采用**Arriaga死因分解**或**Pollard**方法，量化各亚类对期望寿命变化的贡献
