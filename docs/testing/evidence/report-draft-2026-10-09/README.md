- `input.json`：相同六题原始需求、合成材料、执行参数。R1按截图转录，没有补充答案。
- `manifest.json`、`source-manifest.json`：候选类摘要、来源与源码文件摘要。源文件物理快照仍在本地同名 `tmp/report-draft-real-20261009` 目录，最终修复由本次 Git 提交追溯。

- `technical-summary.json`：完整返回、请求次数、实际用量及同信息核对。`COMPLETE` 不等于业务通过。
- `review-pending.md`：独立 AI 辅助评审快照；名称不代表缺少评审，具体完成状态看正文。candidate03 另有 `review-final.md`，在冻结盲审后核对实际增强输入补充归因，不覆盖先前快照。
