# 通用文章编辑候选的中文作品对照

16 篇封存新稿各调用一次 v3 和通用候选，共 32 次真实生成，全部首次成功，协议修复和付费评阅均为零。沿用已实测的 DeepSeek Flash、温度 0.2、关闭思考、8000 输出 Token、非流式和 JSON。核验完整原文、文体、幅度、受众、要求、模型及实际参数一致。按请求核对策略版本、系统指令哈希与资源哈希。实验的变化是系统编辑指导，评阅卡没有发送给模型。

## 盲评结果

一位开发助手先保存[匿名初评](blind-review.md)，再读取[标签映射](blind-key.json)。阅读改善与语义核对分别记录。相对结果包含每档全部八篇，主要阅读问题改善数仅统计四篇待改稿。

| 幅度 | 候选 / v3 的主要问题改善 | 候选相对胜／平／负 | 主要观察 |
| --- | --- | --- | --- |
| 轻度润色 | 0/4、0/4 | 0／8／0 | 公交报告、工具借用、旧磁带随笔和访谈方法论文都只局部顺句，读者需要绕过的开场仍在。 |
| 大幅重构 | 1/4、1/4 | 0／7／1 | 两稿都按角色拆开了图纸交接，主要问题解决。接收和归档动作都被写入资料员职责，责任归属有待复核。候选的自然稿改弱了短句停顿和时序。 |

混合稿方面，两组大幅重构都让值班室稿的查阅范围更直接，保持现场见闻和引文的来源。陌生题材方面，两组都让试烧记录的两次观察更易比较，保留无法仅凭记录归因于炉温的边界。两项均为共同收益。

严格限定稿的两条锁定引文原样保留，时间、许可、受理与决定的分工及适用范围均通过开发侧核对。主要语义疑点是两组图纸交接稿对原文未明确的责任归属作了具体化。大幅重构另有模拟论文用“因此”强化了依据与研究用途之间的联系，候选自然稿把“没急着关”和“响完一遍”的顺序倒置。阅读通过数不代表这些疑点已经解决。
