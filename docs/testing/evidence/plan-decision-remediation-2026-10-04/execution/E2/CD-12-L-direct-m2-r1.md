# 分数大小比较课教学材料

---

## 一、教师教案

**课题**：分数大小比较（异分母分数）

**授课对象**：初一学生，30人，分为10个三人小组

**课时**：45分钟

**材料准备与课前安排**（不占用教学时间）：

- 黑板、粉笔（含彩色粉笔）
- 每组3张空白纸条（约20cm×5cm，全班共30张），纸条长度必须完全一致
- 教师预写卡片：写有各组合作题目的卡片10张（每组1张，每张含两个异分母真分数）
- 学生练习页30份（基础层与应用层共6题，题目后不附结论）
- 答案页1份（教师用，单独成页，不与学生练习页装订在一起）

**学习目标**：本节课结束时，学生能够——
1. 在同一条0到1的数轴上，用对应相同整体的刻度定位两个异分母真分数，并依据位置判断大小；
2. 用通分方法将两个异分母真分数化为同分母分数，说明变换后分数值不变的理由，再比较分子大小；
3. 用口头或书面语言解释比较两个异分母真分数大小的依据，不依赖交叉相乘口诀。

**评价方式**：以学生能否在数轴上定位并解释位置关系、能否说明通分前后分数值不变并比较大小为主要依据。教师观察记录学生解释理由的情况，不制作排名，不公开个人成绩。


### 一、导入（5分钟）

**教师提问**：

“上节课我们比较过同分母分数。谁能说一说，比较 3/8 和 5/8 时，为什么 5/8 更大？”

**预设学生回答**：分母相同，表示整体被分成同样多的份数，每一份大小相同；3份比5份少，所以 3/8 < 5/8。

**教师追问**：“如果分母不同，比如 2/5 和 3/7，还能直接看分子吗？还能直接看分母吗？”

**教师过渡**：“今天我们要解决的就是这类问题——分母不同时，怎样比较两个分数的大小。我们会用到两个工具：数轴和通分。”


### 二、示范（10分钟）

**示范题**：比较 2/5 和 3/7。

#### 方法一：数轴定位

教师在黑板上画一条长度约1米的线段，左端标0，右端标1。

**教师边画边讲**：

“这条线段表示整体1。要在这条数轴上找到 2/5，我需要把这条线段平均分成5份，每一份是这个整体的1/5。2/5就是从0往右数2份的位置。”

教师用彩色粉笔在数轴上方标出5等分刻度，并在2/5处做标记。

“现在要在同一条数轴上找 3/7。注意，还是这同一个整体，还是这条从0到1的线段。我把这同一条线段平均分成7份，每一份是1/7。3/7就是从0往右数3份的位置。”

教师用另一种颜色在数轴下方标出7等分刻度，并在3/7处做标记。

**关键强调**：“两次分割的是同一条线段、同一个整体。不能因为5份和7份不一样，就画两条长度不同的线段来比较——那样每一份的大小基准就变了，比较就没有意义。”

**教师提问**：“从数轴上看，2/5 和 3/7 哪个更靠近1？哪个更大？”

**预设结论**：3/7 的位置比 2/5 更靠右，所以 2/5 < 3/7。

#### 方法二：通分

**教师板书**：

“数轴能帮我们直观判断，但每次都画数轴不太方便。我们还可以用通分。”

2/5 = (2×7)/(5×7) = 14/35
3/7 = (3×5)/(7×5) = 15/35

**教师解释等值理由**：

“为什么 2/5 可以写成 14/35？因为分子和分母同时乘同一个数7，相当于把每一份再平均分成7小份，整体从5份变成35份，取的份数也从2份变成14份。每一小份变小了，但取的部分占整体的比例没有变，所以分数值不变。同理，3/7 的分子分母同时乘5，分数值也不变。”

**教师继续**：

“现在两个分数都变成了分母是35的分数，每一份大小相同。14份比15份少，所以 14/35 < 15/35，也就是 2/5 < 3/7。”

**教师小结**：“数轴和通分得到同样的结论。数轴帮我们看见位置，通分帮我们把不同分母变成相同分母再比较分子。两种方法都建立在‘同一个整体、每一份大小相同’的基础上。”


### 三、合作活动（15分钟）

**组织形式**：10个三人小组，每组3人。每组发3张长度完全相同的空白纸条和1张任务卡片。

**任务卡片内容**（10组题目，均为正真分数）：

| 组别 | 比较的分数 |
|------|-----------|
| 1 | 1/3 和 2/5 |
| 2 | 3/8 和 2/5 |
| 3 | 1/4 和 2/7 |
| 4 | 3/10 和 2/7 |
| 5 | 2/3 和 3/5 |
| 6 | 5/12 和 3/8 |
| 7 | 4/9 和 3/7 |
| 8 | 5/8 和 3/5 |
| 9 | 2/5 和 3/8 |
| 10 | 5/6 和 7/9 |

**角色与轮换**（每组3人，每人轮换一次角色，共3轮，每轮约5分钟）：

- **定位员**：在纸条上画0到1的数轴，标出两个分数的位置；
- **记录员**：在纸条空白处写出通分过程和比较结果；
- **说明员**：向组内口头解释“为什么这样比较是对的”，重点说明数轴上的位置关系或通分前后分数值不变。

**轮换方式**：第一轮A定位、B记录、C说明；第二轮B定位、C记录、A说明；第三轮C定位、A记录、B说明。教师巡视时确认每组三人都轮换过角色。

**教师巡视要点**：

- 纸条是否长度一致，是否在同一条数轴上标两个分数；
- 定位员是否把整体1等分成对应份数；
- 记录员通分过程是否正确，是否写出等值理由；
- 说明员是否说出“同一个整体”“分数值不变”“每一份大小相同”等关键理由。

**常见误解与追问**（教师巡视时使用）：

| 误解表现 | 教师追问 |
|---------|---------|
| 只比较分子，如“3/8 > 2/5 因为3>2” | “分子大就一定大吗？1/2 和 2/100，分子2比1大，哪个大？分母不同时每一份大小一样吗？” |
| 只比较分母，如“3/8 < 2/5 因为8>5” | “分母大分数就一定小吗？3/8 和 1/8 分母相同，哪个大？分母不同时能直接比分母吗？” |
| 用两条长度不同的纸条分别表示两个分数 | “你的1/3和2/5是在同样长的整体上分的吗？如果整体长度不一样，每一份的大小还能直接比较吗？” |

**追问原则**：追问指向“比较依据是否成立”，不评价学生能力或态度。学生修正后给予肯定。


### 四、练习（10分钟）

**教师发放学生练习页**，学生独立完成。

**教师说明**：“练习页分基础层和应用层，各3题。基础层直接比较大小，应用层要写出你的比较理由。时间10分钟，先做基础层，再做应用层。”

**教师巡视**：观察学生是否使用数轴或通分方法，是否在应用层写出理由。对提前完成的学生，教师可轻声追问：“你的理由里有没有说清楚为什么通分后分数值不变？”

**收卷**：练习页统一收齐，教师课后批阅。答案页由教师保管，不在课堂上发给学生。


### 五、总结（5分钟）

**教师提问**：

“今天我们比较异分母分数的大小，用了哪两种方法？”

**预设回答**：数轴定位和通分。

**教师追问**：

“用数轴比较时，最关键的一条规则是什么？”

**预设回答**：必须在同一条0到1的数轴上标刻度，整体必须相同。

**教师再问**：

“通分的时候，为什么可以把 2/5 写成 14/35？”

**预设回答**：分子分母同时乘同一个数，分数值不变。

**教师收束**：

“比较异分母分数，核心是让每一份的大小变得相同——数轴上是同一个整体，通分后是同一个分母。有了相同的一份大小，才能比较份数的多少。下节课我们会继续用这个思路解决分数加减的问题。”

## 三、单独答案页

**分数大小比较练习·答案与讲解**

（教师用，请勿与学生练习页装订在一起）


### 基础层

**1. 5/9 和 7/9**

**答案**：5/9 < 7/9

**讲解**：分母相同，表示整体被分成同样多的9份，每一份大小相同。5份比7份少，所以5/9小于7/9。


**2. 1/6 和 1/8**

**答案**：1/6 > 1/8

**讲解**：分子相同都是1，表示都取1份。但1/6是把整体分成6份，每份较大；1/8是把同一个整体分成8份，每份较小。所以1/6大于1/8。

**数轴思路**：在同一条0到1的数轴上，1/6的位置比1/8更靠右。

**通分思路**：1/6 = 4/24，1/8 = 3/24，分母相同，4份大于3份，所以1/6 > 1/8。


**3. 2/5 和 3/7**

**答案**：2/5 < 3/7

**讲解**：

**通分方法**：2/5 = (2×7)/(5×7) = 14/35；3/7 = (3×5)/(7×5) = 15/35。分子分母同时乘同一个数，分数值不变。分母相同后，14份小于15份，所以2/5 < 3/7。

**数轴方法**：在同一条0到1的数轴上，把整体平均分成5份，2/5在第2份末尾；把同一个整体平均分成7份，3/7在第3份末尾。3/7的位置比2/5更靠右，所以2/5 < 3/7。


### 应用层

**4. 比较 3/10 和 2/7 的大小，并解释理由。**

**答案**：3/10 > 2/7

**讲解**：

**通分方法**：3/10 = (3×7)/(10×7) = 21/70；2/7 = (2×10)/(7×10) = 20/70。分子分母同时乘同一个数，分数值不变。分母相同后，21份大于20份，所以3/10 > 2/7。

**数轴方法**：在同一条0到1的数轴上，把整体平均分成10份取3份，位置在0.3处；把同一个整体平均分成7份取2份，位置约在0.286处。3/10的位置更靠右，所以3/10 > 2/7。


**5. 比较 5/8 和 3/5 的大小，并解释理由。**

**答案**：5/8 > 3/5

**讲解**：

**通分方法**：5/8 = (5×5)/(8×5) = 25/40；3/5 = (3×8)/(5×8) = 24/40。分子分母同时乘同一个数，分数值不变。分母相同后，25份大于24份，所以5/8 > 3/5。

**数轴方法**：在同一条0到1的数轴上，5/8的位置是把整体8等分后取5份，在0.625处；3/5的位置是把同一个整体5等分后取3份，在0.6处。5/8更靠右，所以5/8 > 3/5。


**6. 小明说：“3/8 比 2/5 大，因为分子3比2大。”你同意吗？请写出你的判断和理由。**

**答案**：不同意。3/8 < 2/5。

**讲解**：只比较分子是不对的，因为分母不同时，每一份的大小不同。3/8表示把整体分成8份取3份，每份是1/8；2/5表示把同一个整体分成5份取2份，每份是1/5。1/5比1/8大，所以不能只看分子。

**通分方法**：3/8 = (3×5)/(8×5) = 15/40；2/5 = (2×8)/(5×8) = 16/40。分子分母同时乘同一个数，分数值不变。分母相同后，15份小于16份，所以3/8 < 2/5。

**数轴方法**：在同一条0到1的数轴上，3/8的位置在0.375处，2/5的位置在0.4处。2/5更靠右，所以3/8 < 2/5。
