# 分数大小比较课（初一，45分钟）

## 一、课前准备（不占用教学时间）

**教师准备：**
- 黑板左侧预留画数轴区域，右侧预留通分板书区域。
- 纸条每组3条，长度相同（约30厘米），分别标注“0”和“1”两端，供合作活动使用。
- 预写卡片若干，内容为两组异分母真分数（如 2/3 与 3/4、3/5 与 5/8），供合作活动各组抽取。
- 学生练习页每人1份，答案页教师留存。

**分组：** 全班30人，按3人一组分为10组，每组确定轮换角色：定位员、记录员、说明员。

**本节边界：** 只使用正真分数；不涉及负数、假分数、代数分式；不要求所有题都用两种方法。

---

## 二、教师教案

### 学习目标（可观察行为）

完成本节后，学生能够：
1. 在同一0到1数轴上标出两个异分母真分数，并依据位置说明大小。
2. 用通分把两个异分母分数化为同分母分数，说明“值不变”的理由，再比较分子。
3. 用口头语言说出比较依据，而不是只报结论。

### 环节一：导入（5分钟）

**教师问法：**
- 板书 3/7 与 5/7，问：“哪个大？为什么？”
- 学生回答后追问：“分母相同，我们比的是什么？”
- 再板书 2/3 与 3/4，问：“这两个分母不同，还能直接比分子吗？还能直接比分母吗？”

**引出新问题：** 分母不同时，不能只比分子或只比分母，需要找到共同的比较依据。今天用两种依据：数轴上的位置和通分后的同分母。

**常见误解追问：**
- 若学生说“3/4大因为4比3大”，追问：“分母大就表示分数大吗？1/4和1/3哪个大？”
- 若学生说“2/3大因为2比3大”，追问：“分子大就表示分数大吗？1/5和2/5哪个大？”

### 环节二：示范（10分钟）

**示范题：比较 2/3 与 3/4。**

**方法一：数轴定位**
1. 黑板画一条0到1的数轴，标明0和1。
2. 说明：两个分数必须在同一条数轴上、同一个0到1整体中比较。
3. 在数轴上把0到1三等分，标出2/3的位置。
4. 在同一条数轴上把0到1四等分，标出3/4的位置。
5. 观察：3/4在2/3的右侧，所以3/4 > 2/3。

**方法二：通分**
1. 板书：2/3 = 8/12，3/4 = 9/12。
2. 说明等值理由：把每一份再细分，总份数和取的份数同时变化，但表示的多少不变。
3. 比较：8/12 < 9/12，所以2/3 < 3/4。

**示范后小结：** 数轴看位置，通分看同分母后的分子；两种方法得到同一结论。

### 环节三：合作活动（15分钟）

**活动形式：** 10个三人组，每组抽一张预写卡片（含两个异分母真分数），用纸条和口头解释完成比较。

**角色轮换：**
- 定位员：在纸条或黑板上标出两个分数的位置。
- 记录员：写下比较过程和结论。
- 说明员：向组内说明“为什么这样比”。

**教师巡视要点：**
- 检查是否使用相同整体（同一条纸条或同一条数轴）。
- 听学生是否说出比较依据，而不只是报答案。
- 对只比分子或只比分母的回答，用追问引导回到数轴或通分。

**活动后简短反馈：** 请1至2组说明员口头汇报，教师不排名、不公开个人成绩。

### 环节四：练习（10分钟）

学生独立完成练习页基础层三题和应用层三题。教师巡视，不直接给结论，必要时提示“先想数轴位置或通分”。

### 环节五：总结（5分钟）

**教师引导回顾：**
- 异分母分数比较，可以用数轴看位置，也可以用通分变成同分母再比分子。
- 通分时分数值不变，变的是写法。
- 比较时要说明理由，不只说哪个大。

**结束语：** 今天重点不是记口诀，而是找到共同的比较依据。

## 四、答案与简短讲解（单独成页，教师留存）

### 基础层

**第1题：** 3/8 < 5/8。
- 讲解：同分母分数，分母相同表示每一份大小相同，直接比较分子，3 < 5。

**第2题：** 1/4 > 1/6。
- 讲解：分子相同都是1，分母越大，每一份越小，所以1/4 > 1/6。也可在数轴上看出1/4在1/6右侧。

**第3题：** 2/5 < 3/7。
- 讲解：通分，2/5 = 14/35，3/7 = 15/35，14/35 < 15/35，所以2/5 < 3/7。通分后分数值不变，只是把两份都细分成了35份中的若干份。

### 应用层

**第4题：** 3/4 > 5/7。
- 讲解一（数轴）：在同一条0到1数轴上，3/4在5/7右侧。
- 讲解二（通分）：3/4 = 21/28，5/7 = 20/28，21/28 > 20/28，所以3/4 > 5/7。

**第5题：** 4/9 < 2/5。
- 讲解：通分，4/9 = 20/45，2/5 = 18/45，20/45 > 18/45，所以4/9 > 2/5。
- 说明：本题也可用数轴定位。选择哪种依据都可以，关键是说明理由。注意：若学生先通分再比较，应确认其等值变换正确。

**第6题：** 小明的说法不正确。
- 讲解：5/8 与 3/5 比较，通分得 5/8 = 25/40，3/5 = 24/40，25/40 > 24/40，所以5/8 > 3/5。虽然本题结论碰巧是5/8大，但小明给出的理由“8比5大”是错误的，因为分母大不代表分数大。比较异分母分数要看数轴位置或通分后的同分母分子。

## 五、板书与材料使用提示

- 黑板左侧：0到1数轴，示范题2/3与3/4的定位。
- 黑板右侧：通分过程2/3 = 8/12，3/4 = 9/12。
- 纸条：每组3条等长纸条，用于合作活动定位，不得使用长度不同的纸条。
- 卡片：预写异分母真分数对，供各组抽取。
- 不安排手机扫码、不安排多媒体设备、不排名、不公开个人成绩。
