# 分数大小比较课教学材料（初一，45分钟）

> 适用说明：本材料依据 `materials/education/current-brief.md` 编写，该文件直接说明本课时设计的业务条件。`materials/education/tests/layout-example.txt` 仅为排版与来源识别测试例子，其中“CSV、Python、收入100万元、准确率99%”等内容与本题无关，未采用。本材料为合成教学设计，不含真实学情数据，不宣称已取得任何成绩提升比例。


## 一、教师教案

### 材料准备与课前安排（不占用45分钟教学时间）

**教师准备：**
- 黑板提前画好一条0到1的数轴（留出可标注刻度的空间），旁边留出通分演算区。
- 准备若干张等长纸条（每张长度相同，代表同一个“1”），每组至少2张。
- 预写卡片若干，每张写一个正真分数（如 1/2、1/3、2/3、3/4、2/5、3/5 等），用于合作活动抽取。
- 将全班30人分为10个三人组，每组确定A、B、C三个角色。

**学生准备：**
- 每组领取等长纸条2张、直尺1把、记录纸1张。
- 课前无需预习新内容，只需回忆同分母分数比较方法。

**分组与角色轮换说明：**
- 每组三人，角色为：定位员（在纸条或数轴上标出分数位置）、记录员（写下比较过程与结论）、说明员（向组内或全班口头解释理由）。
- 每完成一题轮换一次角色，确保每位成员都经历三种角色。

**板书分区：**
- 左侧：数轴区（0到1，可标刻度）。
- 中间：通分演算区。
- 右侧：追问与纠错区（记录典型误解与纠正思路）。


### 环节一：导入（5分钟）

**目标：** 由同分母分数比较复习，引出异分母分数如何比较的新问题。

**教师提问（可直接使用）：**
1. “比较 3/7 和 5/7，哪个大？为什么？”
   - 预期回答：5/7大，因为分母相同，分子大的分数大。
2. “比较 2/9 和 5/9，哪个大？理由一样吗？”
   - 预期回答：5/9大，分母相同，看分子。
3. “如果分母不同，比如 1/2 和 1/3，还能直接看分子吗？”
   - 引导学生发现：分母不同时，分子不能直接比较，因为每一份的大小不同。

**引出课题：** 今天我们用两种方法来解释异分母分数的大小——数轴定位和通分。两种方法都是为了建立同一个比较依据。

**时间分配：** 提问与回答3分钟，引出课题与板书2分钟。


### 环节二：示范（10分钟）

**示范题：比较 2/3 和 3/4。**

**方法一：数轴定位（约5分钟）**

1. 在黑板上使用同一条0到1的数轴。
2. 说明：这条数轴上的“1”是同一个整体，所有分数都在同一个整体上定位。
3. 标出2/3：将0到1之间分成3等份，从0出发取2份，标出位置。
4. 标出3/4：将0到1之间分成4等份，从0出发取3份，标出位置。
5. 观察：3/4 的位置在 2/3 的右侧，所以 3/4 > 2/3。
6. 强调：两个分数标在同一条数轴上，分母刻度对应的是同一个整体，不能换成两条长度不同的纸条来比较。

**方法二：通分（约5分钟）**

1. 提问：“2/3 和 3/4 的分母不同，能不能变成分母相同的分数来比较？”
2. 找公分母：3和4的最小公倍数是12。
3. 通分过程：
   - 2/3 = (2×4)/(3×4) = 8/12
   - 3/4 = (3×3)/(4×3) = 9/12
4. 说明等值理由：2/3 的分子分母同时乘4，相当于把每一份再分成4小份，总份数和取的份数按相同倍数变化，分数表示的大小不变；3/4 同理。
5. 比较：8/12 和 9/12 分母相同，分子8 < 9，所以 8/12 < 9/12，即 2/3 < 3/4。
6. 与数轴结论对照：两种方法结论一致，都说明 3/4 更大。

**板书要点：**
- 数轴：同一条0到1，同一整体。
- 通分：分子分母同乘一个数，分数值不变，再比分子。


### 环节三：合作活动（15分钟）

**组织形式：** 10个三人组，每组使用纸条与口头解释，角色轮换。

**活动材料：** 黑板（教师画数轴或预写卡片）、等长纸条、记录纸。不需要手机或扫码。

**活动流程：**

1. **教师发放任务（2分钟）：**
   - 每组从预写卡片中抽取一对正真分数（如 1/2 和 2/5、3/5 和 2/3、1/3 和 3/8 等）。
   - 任务：用纸条折出或标出两个分数，比较大小，并准备口头解释。

2. **小组操作（8分钟）：**
   - 第一轮：定位员用等长纸条折出两个分数并标出位置，记录员写下比较过程，说明员准备口头解释。
   - 第二轮：轮换角色，换一组分数再操作一次。
   - 教师巡视，关注是否使用同一整体（同一张纸条或同一条数轴），及时追问。

3. **组间交流（5分钟）：**
   - 请2—3组说明员向全班口头解释比较理由。
   - 教师追问：“你们是怎么知道这个分数更大的？”“如果换成另一张长度不同的纸条，结论还可靠吗？”
   - 引导全班确认：纸条必须等长，数轴必须是同一条0到1。

**教师追问示例（针对常见误解）：**
- 只比较分子：“1/2 和 2/5，分子2更大，所以2/5更大，对吗？”——引导学生发现分母不同时不能只看分子。
- 只比较分母：“1/3 和 3/8，分母8更大，所以3/8更小，对吗？”——引导学生通分或数轴验证。
- 使用不同整体：“如果一张纸条代表1，另一张更长的纸条也代表1，比较还公平吗？”——强调必须同一整体。

**注意：** 不将错误回答归因为学生能力低或态度差，而是作为需要澄清的比较依据问题来处理。


### 环节四：练习（10分钟）

**安排：** 学生独立完成练习页基础层三题（约5分钟），再完成应用层三题（约5分钟）。教师巡视，个别提示。

**练习页见下方第二部分。答案与讲解见第三部分，学生页不附结论。**

**教师巡视要点：**
- 基础层：检查是否掌握同分母比较、单位分数比较、简单通分。
- 应用层：检查是否写出比较理由，理由是否基于同一整体或通分等值。
- 不要求每题都用两种方法，学生可选择数轴或通分之一说明理由。


### 环节五：总结（5分钟）

**教师引导回顾：**
1. “今天比较异分母分数，我们用了哪两种方法？”
   - 数轴定位、通分。
2. “数轴方法的关键是什么？”
   - 同一条0到1数轴，同一个整体。
3. “通分方法的关键是什么？”
   - 分子分母同乘一个数，分数值不变，再比较同分母分子。
4. “如果只比较分子或只比较分母，会有什么问题？”
   - 分母不同时，每一份大小不同，不能直接比分子或分母。

**评价方式：**
- 以学生能否口头或书面解释比较理由为主。
- 不排名，不公开个人成绩。
- 可记录“能独立解释”“需提示后解释”“暂不能解释”三类观察，仅用于教师后续教学调整。

**结束语：** 比较分数大小，关键是找到共同的比较依据——同一条数轴或同一个公分母。

## 三、单独答案页

> 说明：本页为教师用答案与讲解，与学生练习页分开。解析可展示数轴与通分两种方法的不同思路，不引入负数、假分数或超纲代数。


### 基础层答案

**第1题**
（1）3/8 < 5/8
（2）7/11 > 4/11

讲解：分母相同，表示每一份的大小相同，分子大的分数大。

**第2题**
（1）1/2 > 1/3
（2）1/5 > 1/8

讲解：分子都是1，分母越大，每一份越小，所以分数越小。也可用数轴：1/2 在 1/3 右侧，1/5 在 1/8 右侧。

**第3题**
（1）1/2 = 5/10，2/5 = 4/10，所以 1/2 > 2/5。
（2）2/3 = 10/15，3/5 = 9/15，所以 2/3 > 3/5。

讲解：通分时分子分母同乘一个数，分数值不变。变成同分母后，比较分子即可。


### 应用层答案

**第4题**
3/4 和 5/7：3/4 > 5/7。

方法一（数轴）：在同一条0到1数轴上，3/4 的位置在 5/7 的右侧，所以 3/4 更大。

方法二（通分）：3/4 = 21/28，5/7 = 20/28，21/28 > 20/28，所以 3/4 > 5/7。

讲解：两种方法都建立同一个比较依据——同一整体下的位置或同分母下的分子。

**第5题**
2/5 和 3/8：2/5 > 3/8。

理由：分母不同时，每一份的大小不同，不能只比较分子（2和3）或只比较分母（5和8）。应通分：2/5 = 16/40，3/8 = 15/40，16/40 > 15/40，所以 2/5 > 3/8。也可在数轴上定位，2/5 在 3/8 右侧。

**第6题**
小明的说法不对。

理由：1/3 和 2/7 的分母不同，不能只因为分子2比1大就判断2/7更大。通分：1/3 = 7/21，2/7 = 6/21，7/21 > 6/21，所以 1/3 > 2/7。数轴上也可见 1/3 在 2/7 右侧。

讲解：只比较分子或只比较分母，都忽略了“每一份大小是否相同”这个前提。比较异分母分数，需要先建立共同依据。
