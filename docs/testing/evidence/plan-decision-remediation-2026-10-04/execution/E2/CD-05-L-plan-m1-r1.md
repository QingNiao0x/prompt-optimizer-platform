# 提示词整理工具对照研究方案（未执行）

## 一、研究方案主文

**研究问题。** 本研究比较三种提示词整理条件对下游任务输出的影响：原始需求、直接增强、交互式计划确认增强。研究不评价任何产品的绝对优劣，仅比较条件间差异。

**设计。** 固定采用二十个任务、每条件独立重复三次、两名盲评者独立评分。所有条件获取相同初始材料。交互式计划确认指系统先提问、实验操作者按预先制定答案卡作答，再生成最终提示词，不是静态任务分解列表。实验尚未运行，本方案不报告任何结果。

**分组与公平比较。** 原始组接收原始需求与初始材料；直接增强组接收由同一初始信息得到的优化提示词；两组均不得接触计划确认组后来回答的业务选择。计划确认组额外获得确认答案，因此必须另设信息量匹配对照：该对照获得相同已确认事实，但不经历问答过程，用于减少新增信息与交互组织方式之间的混淆，避免把多得到答案带来的收益误判为单纯模型能力。计划确认组须记录每个问题、选项、推荐依据和答案，不只保存最终提示词；错误推荐被答案纠正后仍计入交互阶段风险。

**材料与来源标签。** 任务材料必须保留真实实现、用户说明、测试示例与待办这几种来源标签；不得在人工评分前人为删除不利的测试污染反例。资料引用应能让接收任务的人找到对应依据；测试示例、旧版草稿与正式说明分开标注。

**执行与记录。** 每个条件的三次重复开启隔离会话，随机化顺序并记录模型版本、日期和参数。失败后的重试不能替代第一份失败样本；工具失败与首轮失败均须保留。

**盲评与评分。** 评审看到匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源；为评分可看任务事实，但不得看另一名评审先前评分。一个错误可能同时影响完整性与可执行性，评分表记录主错误与关联维度，避免将同一问题多次计成不同独立失败。开发任务要求下游模型只输出方案，不实际修改仓库；写作任务要求交付文本，因此跨任务不能用代码测试通过率作为统一质量指标。

**指标与统计。** 工具生成速度是过程指标，质量分是结果指标；没有计费日志时不得估算真实 Token 成本，不得把字符数直接换算成实际费用。候选评价统计方法依赖分数是否有序、是否连续和是否重复测量；方案说明选择流程，不在变量尚未确定时锁定某个显著性检验。即使三个模型给出相似结论也不是研究完成证据；方案安排人工评阅与可复核任务标准，并说明专业领域判断尚需专家参与。

**限制。** 本方案尚未执行，无准确率、显著性、成功案例数量或用户结论。两名盲评者分歧处理与一致性评价方式、计划确认组最大轮次与终止规则均未确定，列入预注册待确认清单。资料为演练用合成资料，不代表任何真实单位、患者、当事人、市场或平台运行数据。

## 二、变量与分组附表

| 条件 | 接收信息 | 是否经历问答过程 | 重复次数 | 记录字段 |
|---|---|---|---|---|
| 原始组 | 原始需求＋初始材料 | 否 | 3 | 会话标识、模型版本、日期、参数、下游输出、首轮失败、工具失败 |
| 直接增强组 | 同一初始信息得到的优化提示词 | 否 | 3 | 同上 |
| 计划确认组 | 初始材料＋确认答案＋最终提示词 | 是（先提问，按答案卡作答） | 3 | 上述字段＋每问题、选项、推荐依据、答案、错误推荐及纠正记录 |
| 信息量匹配对照 | 初始材料＋相同已确认事实 | 否 | 3 | 同原始组字段 |

注：原始组与直接增强组不得接触计划确认组后来回答的业务选择。空白或未知项标记为“待确认”，不用模拟值填充。

## 三、评分表及失败记录模板

**评分维度（每项独立评分，但同一错误只计一次主错误）：**

| 维度 | 说明 | 分值/状态 |
|---|---|---|
| 需求保真 | 输出是否忠实于原始需求 | 待定 |
| 业务规则 | 是否遵守任务相关业务规则 | 待定 |
| 输出可用性 | 是否可直接使用或交付 | 待定 |
| 阅读负担 | 理解与审阅所需认知成本 | 待定 |
| 执行边界 | 是否越界（如实际修改仓库） | 待定 |

**失败记录模板：**

| 字段 | 内容 |
|---|---|
| 样本标识 | 条件＋任务＋重复序号 |
| 失败类型 | 工具失败／首轮失败／重试后仍失败 |
| 首轮失败是否保留 | 是／否（必须为是） |
| 主错误 | 描述 |
| 关联维度 | 列出受影响维度 |
| 是否重复计为独立失败 | 否（同一问题只计一次） |
| 备注 | 空白或待确认 |

## 四、预注册待确认清单

1. 交互式计划确认组最大轮次与终止规则：是否设上限、达到何条件终止、超限如何处理。暂不确定，不得默认选择具体轮数或停止阈值。
2. 两名盲评者分歧处理与一致性评价方式：是否引入第三名评审、采用何种一致性指标、分歧样本如何计入结果。暂不确定，不得默认选择第三名评审或一致性指标。
3. 候选统计方法的具体选择：依赖分数是否有序、连续和重复测量，待变量确定后按流程选择，不锁定具体显著性检验。
4. 评分表各维度分值或等级定义：待预注册前确定。
5. 答案卡具体内容与记录字段完整清单：列入附表，待补充。
