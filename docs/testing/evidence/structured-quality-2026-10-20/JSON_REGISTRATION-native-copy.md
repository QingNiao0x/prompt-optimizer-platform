## 背景
登记文本为：李梅，2026-09-01；周安，日期未定。需要从中提取姓名和日期，并按原文出现顺序输出。

## 任务
从登记文本中逐条提取 name 和 date，按原顺序组成 JSON 数组。每条记录对应一个登记对象，只输出该数组。

## 输出要求
- 输出一个 JSON 数组，数组元素为对象，每个对象仅含 `name` 和 `date` 两个键。
- 顺序与登记文本中出现的顺序一致。
- 不输出 Markdown 代码围栏、解释文字或示例。

## 约束条件
每个对象仅含这两个键；未提供日期时date为null，不猜测。

- 明确区分已知事实、用户确认信息和必要假设，不得把猜测写成事实。

## 验收标准
- 输出可被解析为 JSON 数组，且每个元素仅含 `name`、`date` 两个键。
- 记录顺序与登记文本一致。
- 未提供日期的记录，其 `date` 为 null，未以推测值填充。
