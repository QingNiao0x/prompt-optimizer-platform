# 全球AI使用最多的职业/行业：基于所提供材料的查询结果

## 一、先说结论（可直接阅读）

根据本次提供的两份材料，**无法给出一个统一的"全球使用AI最多的职业"或"全球使用AI最多的行业"排名**。原因在于：两份来源衡量的是完全不同的东西——来源A衡量的是**企业采用率**（按行业），来源B衡量的是**某平台对话的任务分布**（映射到职业类别）。二者口径不可直接比较，也不覆盖"全球所有从业者"。

可分别陈述如下：

### 1. 按行业（企业采用率口径，来源A）

- **信息通信业（ICT）：57.3%**，在所列行业中最高。
- **专业和科研服务：36.8%**，次之。
- **OECD企业总体平均：20.2%**。
- 覆盖范围：OECD国家；指标为企业采用AI的比例；时间范围为2025年数据（2026-10-24核对）。
- 注意：这是**企业层面采用率**，不是"行业从业者中使用AI的人数比例"，也不覆盖全球所有国家。

### 2. 按职业（平台对话分布口径，来源B）

来源B分析约100万次Claude.ai免费及Pro对话，将任务映射到O*NET职业类别，对话占比为：

| 职业类别（O*NET映射） | 对话占比 |
|---|---|
| 计算机与数学类 | 37.2% |
| 艺术与媒体 | 10.3% |
| 教育与图书馆 | 9.3% |
| 办公行政 | 7.9% |
| 生命科学 | 6.4% |
| 商业金融 | 5.9% |

- 报告指出使用集中于**软件开发和技术写作**；使用方式约**57%为辅助增强、43%为自动执行**。
- 时间范围：2025-02-10发布的报告。
- **关键限定**：这些比例是**该平台对话的分布**，不是"职业内人员渗透率"，也不是全球所有AI使用者的分布。因此不能据此断言"计算机与数学类是全球使用AI最多的职业"。

## 二、两类结果的区分

| 维度 | 来源A | 来源B |
|---|---|---|
| 衡量对象 | 行业（企业） | 职业类别（任务映射） |
| 指标 | 企业采用AI比例 | 平台对话占比 |
| 最高项 | 信息通信业 57.3% | 计算机与数学类 37.2% |
| 覆盖范围 | OECD国家 | 单一平台（Claude.ai）用户 |
| 时间 | 2025年数据 | 2025-02-10报告 |
| 能否代表"全球" | 否（仅OECD） | 否（仅该平台） |

## 三、来源间差异与不可比性说明

- 两份来源**没有对同一对象给出不同排名**，因此不存在"同一问题不同来源结论冲突"的情形；它们的差异在于**口径不同、对象不同**，不能并列成同一张排行榜。
- 来源A的"信息通信业57.3%"与来源B的"计算机与数学类37.2%"看似指向相近领域，但前者是**企业采用率**，后者是**对话任务占比**，数值不可互相印证或换算。

## 四、资料不足、无法确定的部分

1. **"全球范围内使用AI最多的职业"**：所提供材料中没有任何来源给出全球职业层面的渗透率或使用人数排名，**无法确定**。
2. **"全球范围内使用AI最多的行业"**：来源A仅覆盖OECD且为企业采用率，**不能等同于全球行业排名**；材料中无全球口径数据，**无法确定**。
3. 材料未提供其他来源（如其他平台、其他统计机构）的排名，故**无法进行多来源并列比较**；本回答不补充材料之外的数据或来源。

## 五、如需更完整结论

要回答"全球最多"，需要：覆盖多国、多平台的**职业内渗透率**或**使用人数**数据，并统一统计口径与时间范围。本次材料不具备这些条件，故仅能给出上述分口径结果与限定说明。
