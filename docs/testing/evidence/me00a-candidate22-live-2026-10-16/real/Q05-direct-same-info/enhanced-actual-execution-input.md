## 背景
本部分面向研究生学位论文的研究设计，主题为Plan问答对提示词质量的影响。当前研究处于拟定阶段，尚未实施，因此方法部分只能按拟定方案撰写，不得写成已完成或已纳入样本。

## 任务
撰写中文研究设计的方法部分，说明Plan问答对提示词质量影响的比较研究设计。需保留并说明以下设计要素：
- 4类任务，每类5个，共20个任务；
- 每模式每任务独立重复3次；
- 两名独立评审盲评；
- 比较直接增强与Plan两种模式，并另设两组获得相同确认信息的公平对照；
- 说明随机化、盲法，以及准确性、完整性、清晰度与可执行性四项评价，并说明分歧处理；
- 具体统计检验依据未来数据分布和配对结构选择，可说明候选方法及其适用条件，不预设必然显著。
评价对象为提示词，评审所见材料应围绕提示词质量组织；下游作品可作为验证依据，但不替代对提示词质量的评价。
同信息公平对照需落实到信息流：先取得并封存同一案例的实际确认信息，再让两组获得逐字相同的信息；直接组不追问不等于不能使用已提供答案；不得通过改写某组回答、更换任务或只给某组增加修订轮次来制造公平。
对随机化单位与分配流程、盲评材料组织、评分尺度与分歧处理规则，给出可直接开展的拟议主方案并标明属拟议设计、可调整；统计检验列出候选方法及适用前提，最终选择依据未来数据分布与配对结构确定。

## 输出
交付中文研究设计的方法部分正文，800至1200个汉字，附表另计。正文应包含研究设计与比较条件、任务与重复安排、随机化与盲法、评价指标与分歧处理、统计分析方法等必要小节。不提供代码。
正文篇幅：保留800–1200个汉字，在范围内以约1000个汉字起草，沿用用户原定标题、附表和代码的计数边界。只有用户明确另计的部分才移出该预算，不能写满正文后再附应计入的长表格或代码。未指定固定结构时，可按约4个自然段、每段约250个汉字分配叙述，再按应计入正文的表格和伪代码缩减文字部分；这是组织建议，不新增固定段数验收。按既定内容分配篇幅，避免在任务、规则和未决清单间重复说明。完成后核对实际正文，超长时合并同一完整说明，过短时只展开资料支持的信息，不编造或重复凑字；表格、必要步骤、条件和未决参数不能因缩减篇幅漏交。用户要求只输出成品时，不附自报字数或检查过程。
按原定范围和格式直接交付正文，不先发补材料问卷；材料充分时直接成稿，不足时完成有依据的可修订初稿，不以大片填空模板替代正文。缺口只限制对应内容，不编造数据、引用或结论；重要未决条件集中说明一次，同一缺口不逐节重复标待确认；原要求的表格、代码及篇幅继续保留。
