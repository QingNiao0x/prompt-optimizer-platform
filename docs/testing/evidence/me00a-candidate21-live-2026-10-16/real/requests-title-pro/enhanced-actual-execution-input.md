## 任务

1. 输入入口：设计明确的 URL 输入方式（如函数参数或命令行参数），说明其形式与用法。

5. 模块划分：说明需要新增或修改的模块、文件及职责。
6. 接口契约：给出函数签名、参数类型、返回值类型和错误约定。
