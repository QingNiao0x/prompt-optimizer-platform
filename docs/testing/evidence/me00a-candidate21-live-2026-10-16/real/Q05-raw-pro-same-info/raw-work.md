# 研究设计的方法部分

本研究拟考察Plan类问答提示对生成结果质量的影响，比较直接增强与Plan两种提示策略，并设置两组获得相同确认信息的公平对照，以排除信息量差异对结果的混淆。研究尚未实施，以下为拟开展的设计方案。

## 一、任务与材料

研究设置4类任务，分别为信息抽取、文本摘要、多步推理与方案规划，每类任务编制5个具体题目，共20个任务。每个任务在每种提示模式下独立重复3次，以降低单次生成随机波动的影响。任务与重复的呈现顺序拟采用分层随机化：先按任务类别分层，再在层内随机排列任务；每个任务的3次重复不连续呈现，以避免顺序效应和短期记忆干扰。所有任务材料在研究启动前封存，不向评审和数据分析人员披露模式标签。

## 二、提示模式与公平对照

研究设置四种提示模式。直接增强模式在原始任务指令后附加“请给出准确、完整、清晰且可执行的回答”等质量要求。Plan模式要求模型先给出执行计划，再依据计划生成最终回答。另设两个同信息对照组：对照组A获得与Plan组相同的计划框架信息，但不要求显式输出计划；对照组B获得与直接增强组相同的质量要求信息，但不附加增强措辞。确认信息的取得与封存流程拟为：由不参与后续评审的研究助理从Plan组提示中提取计划框架要素，经双人核对后封存；对照组A仅获得该框架信息，对照组B仅获得质量要求信息。四组提示在任务指令层面保持核心问题一致，仅增强流程不同。

## 三、随机化与盲法

每个任务在四种模式下的12次生成（4模式×3重复）按随机顺序提交给模型，生成顺序由计算机生成的随机数表决定。两名评审对全部生成结果进行盲评，评审不知晓每条结果所属的模式、任务重复序号及研究假设。评审对同一任务的所有模式结果均评分，以支持配对比较。评分材料中不出现任何可识别模式来源的标记。

## 四、评价指标与分歧处理

准确性、完整性、清晰度与可执行性四项指标均采用5点Likert评分，1分为最低，5分为最高。评分前对两名评审进行校准培训，使用与正式任务相似但不相同的练习材料，统一评分标准。正式评分中，若两名评审在同一项目上评分相差超过1分，则启动分歧处理程序：先由两名评审独立复核，若仍不一致，由第三名资深评审裁定。最终分析采用两名评审的均分；若引入第三评审，则采用三人均分。

## 五、统计检验的候选方法

统计方法的选择将依据未来数据的分布特征与配对结构确定。若各指标评分近似正态且方差齐性满足，可采用重复测量方差分析，将提示模式作为四水平组内因素，任务作为随机因素；若需比较Plan与直接增强的差异，可预设线性对比。若数据呈偏态或评分视为有序分类变量，可采用Friedman检验作为整体检验，并以Wilcoxon符号秩检验进行配对事后比较，同时采用适当的校正方法控制多重比较。若需同时考察四项指标的联合差异，可考虑多元方差分析，但需满足协方差矩阵齐性等条件。所有检验均为双侧，显著性水平预设为0.05。本研究不预设任何模式必然显著，仅报告效应方向与置信区间。

## 附表：研究设计要素一览

| 设计要素 | 拟采用方案 |
|---|---|
| 任务类别 | 信息抽取、文本摘要、多步推理、方案规划 |
| 任务数量 | 每类5个，共20个 |
| 重复次数 | 每模式每任务独立重复3次 |
| 提示模式 | 直接增强、Plan、同信息对照A（计划框架）、同信息对照B（质量要求） |
| 呈现顺序 | 分层随机化，重复不连续 |
| 盲法 | 双盲评审，材料无模式标记 |
| 评价指标 | 准确性、完整性、清晰度、可执行性，5点Likert |
| 分歧处理 | 相差>1分复核，仍不一致由第三评审裁定 |
| 候选统计方法 | 重复测量ANOVA（正态）、Friedman+Wilcoxon（非正态）、MANOVA（多元） |
| 显著性水平 | α=0.05，双侧，不预设显著 |
