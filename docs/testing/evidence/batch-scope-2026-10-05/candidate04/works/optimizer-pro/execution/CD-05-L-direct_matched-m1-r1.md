# 提示词整理工具对照研究方案（合成资料，未执行）

## 一、研究方案主文

### 研究问题

本研究比较三种提示词整理方式对下游任务输出的影响：原始需求直接使用、直接增强（对同一初始信息生成优化提示词）、交互式计划确认增强（系统先提问、操作者按预先制定答案卡作答，再生成最终提示词）。交互式计划确认不是静态任务分解列表。研究不评价任何产品的绝对优劣，只比较条件差异。

计划确认组会额外获得已确认答案，因此必须另设信息量匹配对照组：该组获得相同已确认事实，但不经历问答过程。此组用于区分“新增信息”与“交互组织方式”两种来源，避免把多得到答案的收益误判为模型能力。

### 实验设计

二十个任务，每条件三次独立重复，共四条件。每次重复开启隔离会话，随机化条件与任务顺序，记录模型版本、日期和参数。失败后的重试不能替代第一份失败样本，首轮失败必须保留。

原始组接收原始需求与初始材料；直接增强组接收同一初始信息得到的优化提示词；两组均不得接触计划确认组后来回答的业务选择。计划确认组记录每个问题、选项、推荐依据和答案，不只保存最终提示词；错误推荐被答案纠正后仍计入交互阶段风险。信息量匹配对照组获得相同已确认事实，但不经历本平台问答过程。

任务材料保留真实实现、用户说明、测试示例与待办四类来源标签，人工评分前不得删除不利的测试污染反例。测试示例仅用于排版与来源识别，其输出格式、工具、金额和示例准确率不是本题事实。

### 主要指标

评价覆盖五个维度：需求保真（输出是否忠实于原始需求与已确认事实）、业务规则（是否遵守任务内明确规则）、输出可用性（能否直接支撑下游使用）、阅读负担（理解与核对成本）、执行边界（是否越出任务允许范围）。工具生成速度为过程指标，质量分为结果指标；无计费日志时不估算真实 Token 成本，不以字符数换算费用。

一个错误可能同时影响多个维度，评分表记录主错误与关联维度，避免同一问题被计为多个独立失败。候选统计方法依赖分数是否有序、连续及是否重复测量，方案只说明选择流程，不在变量未定时锁定显著性检验。三个模型结论相似不构成研究完成证据，需安排人工评阅与可复核任务标准，专业领域判断尚需专家参与。

### 限制

实验尚未运行，无准确率、显著性、成功案例数量或用户结论。评审看到匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源；可看任务事实，但不得看另一名评审先前评分。盲评不得暴露工具名称。跨任务不能用代码测试通过率作为统一质量指标。本方案为合成资料整理，不代表任何真实单位、患者、当事人、市场或平台运行数据，也不构成专业有效性认证。

## 二、变量与分组附表

| 条件 | 变量定义 | 分组逻辑 | 样本量 | 随机化 |
|---|---|---|---|---|
| 原始组 | 自变量=原始需求+初始材料 | 直接使用，不增强 | 20任务×3重复 | 隔离会话，顺序随机 |
| 直接增强组 | 自变量=同一初始信息生成的优化提示词 | 不接触计划确认组答案 | 20任务×3重复 | 隔离会话，顺序随机 |
| 计划确认组 | 自变量=问答后生成的最终提示词 | 记录问题、选项、推荐依据、答案 | 20任务×3重复 | 隔离会话，顺序随机 |
| 信息量匹配对照组 | 自变量=相同已确认事实，无问答过程 | 控制新增信息量 | 20任务×3重复 | 隔离会话，顺序随机 |

记录字段：模型版本、日期、参数、会话隔离标识、首轮失败标记、重试标记（不替代首轮）。
