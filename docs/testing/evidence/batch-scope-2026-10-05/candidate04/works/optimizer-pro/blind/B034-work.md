## 四、明确限制的备忘录草稿

### 1. 材料充分程度

**已具备的材料**：
- 合成现行资料（current-brief.md），明确了承租方视角、整理目标、三级优先级及若干边界条件。
- 旧版说明（legacy-note.md），记载了草稿A与草稿B的押金差异。
- 排版测试示例（layout-example.txt），已确认与本题事实无关，予以排除。

**材料缺口**：
- 两版合同草稿的完整原文未提供，租金金额、解除条款的具体通知形式、提前量和费用均无法从给定材料中逐项提取。
- 往来邮件的具体内容、发送时间、发送角色及条件性表述未提供。
- 房屋权属证明和授权链证据未提供。
- 示例判决的可核验出处未提供。
- 签署、送达、接受日期均无证据。

### 2. 后续核验事项

以下事项需由执业律师在获取补充材料后核验，本备忘录不作出任何法律结论：

1. **押金数额**：需核验两版草稿的协商过程及邮件确认情况，确定以哪一版为协商基础；未签署材料不产生确定付款义务。
2. **维修范围**：需核验两版条款的完整原文和修改过程，确定承租方责任边界；两版不能拼接适用。
3. **解除条款**：需核验通知形式、提前量和费用的具体内容及条件关系；不能仅取最短通知天数而忽略附加前提。
4. **房屋权属与授权链**：需核验出租方是否持有完整处置权；本备忘录不预先判定其无权出租。
5. **示例判决引用**：需核验出处和相关性；在核验前仅作为待核资料，不作为判例依据。
6. **协商邮件表态**：需按时间、角色和条件逐条整理各方表态，区分已接受、仍在讨论和已提出修改的条款。
7. **合同状态**：需核验是否存在签署、送达或接受的证据；文档日期仅表示编辑时间，不证明上述状态。

### 3. 当前可开始与必须等待的事项

**可开始的工作**：
- 律师可基于本备忘录的差异表和问题清单，向委托方索取两版草稿完整原文、往来邮件全文及权属证明文件。
- 承租方可按两版押金差额（一个月租金）分别测算资金安排，作为内部准备，不构成付款义务。

**必须等待的事项**：
- 确定押金以两个月还是三个月为准——需等待补充材料或律师核验结果。
- 确定维修范围以哪一版为准——需等待补充材料或律师核验结果。
- 确定解除条款的具体内容和条件关系——需等待补充材料或律师核验结果。
- 形成任何关于合同效力、违约责任或胜诉可能性的判断——需等待律师基于真实事实和现行法律依据另行处理。

### 4. 边界声明

本备忘录仅整理材料矛盾、缺失证据和需律师核实的条款范围，不评价任何一方一定胜诉或一定违法，不输出具体法律条文编号或现行效力结论，不承诺执行诉讼、发送律师函或替代专业判断。所有主体、地址、金额均为合成示例，复制后仍应保持匿名。
