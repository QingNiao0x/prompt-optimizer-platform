# 提示词整理工具对照研究方案

## 一、研究问题

本研究比较三种提示词整理方式对下游任务输出的影响：原始需求（原始组）、直接增强（直接增强组）、交互式计划确认增强（计划确认组），并增设信息量匹配对照组。研究不评价任何产品的绝对优劣，只考察整理方式与输出质量的关系。

核心问题：在相同初始信息下，直接增强与原始需求相比，输出在需求保真、业务规则、输出可用性、阅读负担和执行边界五个维度上有何差异；计划确认组额外获得已确认事实后，其输出改善在多大程度上来自新增信息量、在多大程度上来自交互组织方式——后者由信息量匹配对照分离。

## 二、实验设计

**任务与重复**：二十个任务，每条件独立重复三次，共四组（原始、直接增强、计划确认、信息量匹配）×二十任务×三次。三次重复开启隔离会话，随机化执行顺序，记录模型版本、日期与参数。失败后的重试不替代第一份失败样本，首轮失败与工具失败均保留。

**公平比较**：原始组接收原始需求与初始材料；直接增强组接收由同一初始信息得到的优化提示词；两组均不得接触计划确认组后续回答的业务选择。计划确认组由系统先提问、实验操作者按预先制定答案卡作答，再生成最终提示词；须记录每个问题、选项、推荐依据与答案，不只保存最终提示词。错误推荐被答案纠正后仍计入交互阶段风险。信息量匹配对照获得与计划确认组相同的已确认事实，但不经历问答过程，用于减少新增信息与交互组织方式之间的混淆。

**材料**：所有工具获取相同初始材料，保留真实实现、用户说明、测试示例与待办四类来源标签；人工评分前不得删除不利的测试污染反例。

**盲评**：两名盲评者独立评分。评审看到匿名化下游输出与等量任务信息，不展示产品名称、标志与生成来源；可看任务事实，但不得看另一名评审先前评分。

## 三、主要指标与限制

**结果指标**：需求保真、业务规则、输出可用性、阅读负担、执行边界五维质量分。**过程指标**：工具生成速度。二者不可混用。

**失败记录**：一个错误可能同时影响完整性与可执行性，评分表记录主错误与关联维度，避免同一问题重复计为独立失败。

**统计**：候选方法依赖分数是否有序、是否连续、是否重复测量；方案只说明选择流程，不锁定具体显著性检验。

**限制**：实验尚未运行，无准确率、显著性、成功案例数量或用户结论。无计费日志时不能估算真实 Token 成本，不得将字符数换算为费用。三个模型结论相似不构成研究完成证据；须安排人工评阅与可复核任务标准，专业领域判断尚需专家参与。跨任务不能用代码测试通过率作为统一质量指标。

## 附表一：变量与分组

| 组别 | 接收信息 | 是否经历问答 | 是否可见已确认事实 | 隔离要求 |
|---|---|---|---|---|
| 原始组 | 原始需求＋初始材料 | 否 | 否 | 不得接触计划确认组回答 |
| 直接增强组 | 同一初始信息得到的优化提示词 | 否 | 否 | 不得接触计划确认组回答 |
| 计划确认组 | 初始信息＋问答后最终提示词 | 是 | 是 | 记录问题、选项、推荐依据、答案 |
| 信息量匹配组 | 初始信息＋相同已确认事实 | 否 | 是 | 不经历本平台问答过程 |

固定参数：二十任务、每条件三次独立重复、两名盲评者、四组。未决参数见附表四。
