# 合成门诊 2026 年第一季度预约到诊与爽约情况内部运营分析方案（讨论版）

## 0. 材料定位与使用边界

本方案仅用于内部运营讨论，分析对象为某合成门诊 2026 年第一季度的预约事件。资料为合成材料，不含真实患者信息，也没有完整逐条数据；本方案不计算真实医院指标，不涉及诊断、处方、分诊优先级、医嘱或个体治疗，不建议减少任何患者服务权益。

资料引用分层如下，接收任务的人可按此定位依据：

| 层级 | 来源 | 用途 | 注意 |
|---|---|---|---|
| 现行资料 | `materials/hospital_operations/current-brief.md` | 口径、分支、边界的主要依据 | 作为本方案主依据 |
| 旧流程说明 | `materials/hospital_operations/legacy-note.md` | 提前 24 小时取消不计爽约的旧口径 | 仅作历史口径，不自动生效 |
| 新会议草稿 | `materials/hospital_operations/legacy-note.md` 内提及 | 提前 12 小时取消的建议 | 尚未批准，不自动生效 |
| 测试示例 | `materials/hospital_operations/tests/layout-example.txt` | 仅用于排版和来源识别 | 其中 CSV、Python、收入、准确率等均非本题事实，不得引用为事实或工具偏好 |

## 1. 口径表

### 1.1 统计对象与单位

| 项目 | 讨论版口径 | 依据/说明 |
|---|---|---|
| 分析对象 | 某合成门诊 2026 年第一季度预约事件 | 任务给定 |
| 事件单位 | 预约事件编号，一次预约计为一个事件 | 事件编号可区分一次预约 |
| 人数单位 | 去重患者 | 一个患者可多次预约，事件数不等于人数 |
| 主统计单位 | **待确认**：预约事件或去重患者 | 当前尚未决定，不得默认补全；两种单位会影响渠道比较和百分比波动 |
| 渠道范围 | 电话、网页、窗口三类 | 已明确，不再询问 |
| 渠道归属 | 需先定义首次渠道和变更渠道 | 电话与网页可能记录同一次预约的不同操作事件，不能把操作次数当预约量 |
| 到诊状态 | ARRIVED、CANCELLED、UNKNOWN | UNKNOWN 原因未细分 |
| 时区 | 医院本地时区 | 当前汇总表没有时区转换证据，不假设可跨时区直接比较 |

### 1.2 状态归类规则（讨论版）

| 状态 | 讨论版处理 | 禁止做法 |
|---|---|---|
| ARRIVED | 计入到诊 | — |
| CANCELLED | 计入取消；不附加临床解释 | 不解释为治疗结束、病情缓解或不再需要服务 |
| UNKNOWN | 单列为待核验事件 | 不直接计为爽约，不解释为患者责任 |
| 未到期事件 | 在观察窗口未确定前只展示为待核验事件 | 不将尚未到期的预约算入爽约率 |

### 1.3 爽约与取消免责边界

| 项目 | 讨论版口径 | 状态 |
|---|---|---|
| 爽约定义 | 需先定义观察窗口和取消免责边界 | **待确认**，不得默认补全 |
| 观察窗口 | 尚未决定 | **待确认** |
| 取消免责边界 | 旧流程说明为提前 24 小时；新会议草稿建议提前 12 小时 | **争议项，单独呈现**，不擅自采用其中一项 |
| 规则生效判断 | 不按文件修改时间直接断定新规则生效 | 材料权威性未建立 |

### 1.4 渠道比较口径

| 项目 | 讨论版口径 | 说明 |
|---|---|---|
| 首次渠道 | 需定义 | 同一次预约可能有多渠道操作事件 |
| 变更渠道 | 需定义 | 不能把操作次数当预约量 |
| 小样本处理 | 保留数量和限制说明 | 预约事件量不同会影响百分比波动 |
| 显著性 | 没有完整数据不能报告显著的渠道差异 | 资料没有完整逐条数据 |

### 1.5 禁止与限制

- 不把 UNKNOWN 直接计为爽约。
- 不用收费或处罚作为默认整改建议。
- 不给取消行为附加临床解释。
- 不追加医生排行榜或利用服务时间做个体能力评价；医生代码只是流程角色示例。
- 不推断跨科室、跨医院或全市运营表现；本题材料只有一个门诊。
- 不宣称任何方案已提高疗效。
- 不把提醒需求悄悄扩成发送短信的实施任务；如机构后来要求短信提醒方案，需另行确认通知授权和退订流程。

## 2. 流程图说明

### 2.1 预约事件流转（讨论版）

```
预约产生
  │
  ├─ 渠道记录：电话 / 网页 / 窗口
  │     └─ 可能产生多个操作事件 → 需定义首次渠道与变更渠道
  │
  ├─ 预约事件编号（一次预约 = 一个事件）
  │
  ├─ 状态更新
  │     ├─ ARRIVED → 到诊
  │     ├─ CANCELLED → 取消（不附加临床解释）
  │     └─ UNKNOWN → 待核验（不直接计为爽约）
  │
  └─ 观察窗口
        ├─ 窗口未确定 → 只展示待核验事件
        └─ 窗口确定后 → 归为最终状态
```

### 2.2 取消免责判定流程（争议版）

```
取消发生
  │
  ├─ 旧流程说明：提前 24 小时取消不计爽约
  │
  ├─ 新会议草稿：提前 12 小时取消不计爽约（尚未批准）
  │
  └─ 当前处理：争议单独呈现，不擅自采用其中一项
        └─ 待确认：适用口径与审批状态
```

### 2.3 渠道比较流程

```
渠道操作事件
  │
  ├─ 定义首次渠道
  ├─ 定义变更渠道
  ├─ 按预约事件或去重患者汇总（主统计单位待确认）
  ├─ 小渠道保留数量与限制说明
  └─ 无完整数据时不报告显著差异
```

### 2.4 人工复核触发点

| 触发点 | 复核内容 |
|---|---|
| UNKNOWN 状态 | 核查设备同步延迟、现场漏登记或记录缺项 |
| 多渠道操作事件 | 核查首次渠道与变更渠道归属 |
| 取消时间 | 核查时区、取消提前量、适用规则版本 |
| 未到期事件 | 核查观察窗口是否已确定 |
| 小样本渠道 | 核查数量与限制说明是否保留 |
