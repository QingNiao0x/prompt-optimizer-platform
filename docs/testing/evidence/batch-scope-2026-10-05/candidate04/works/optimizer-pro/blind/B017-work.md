# 复核备忘录（承租方视角·合成材料）

**用途**：供执业律师复核合成商业租赁往来材料，识别矛盾、缺失证据和需核实的条款范围。  
**适用地点**：合成项目所在中国大陆甲市；具体法律适用与条款效力由执业律师核验。  
**风险级别含义**：高/中/低仅表示律师核查优先顺序，不是违法概率或胜诉判断。  
**材料边界**：合同草稿未签署；往来邮件仅为协商材料；主体、地址、金额均为合成示例；不加入真实当事人信息。

## 三、分优先级的律师复核问题

### 高优先级

| 问题 | 影响目标的原因 |
|---|---|
| 两版租赁草稿中哪一份是本次律师复核的主文本？ | 主文本未确定，无法确定押金、维修范围、解除条款的基准版本；直接影响后续条款核对和资金安排判断。 |
| 押金两个月与三个月的差异在协商邮件中是否有确认或变更？ | 押金差异可能影响承租方资金安排；未签署材料不能直接产生确定付款义务，需核实邮件中是否有明确确认。 |
| 维修范围是否包含“全部设施故障费用”？ | 该差异直接扩大承租方责任范围；不能把两个版本拼接成对承租方更不利的统一条款，需核实最终合意文本。 |
| 解除条款中通知形式、提前量和费用之间是否存在条件关系？ | 各部分可能存在条件关系；摘要不能仅取最短通知天数而删掉附加前提，否则可能误导提前退出安排。 |
| 房屋权属和授权链证据是否可提供？ | 给定材料没有房屋权属和授权链证据；不能推断出租方有完整处置权，需核验但不先判定其无权出租。 |

### 中优先级

| 问题 | 影响目标的原因 |
|---|---|
| 租金具体金额及对应条款位置是否在两版草稿中一致？ | 租金需逐条核对来源，不能凭通行惯例补成合同事实；金额不一致会影响持续履约安排。 |
| 提前解约费用的计算方式和支付条件是否在两版草稿中一致？ | 费用与通知形式、提前量可能存在条件关系；需核实完整条件链。 |
| 协商邮件中“愿意再讨论”等表述的发送角色、时间和条件是否完整保留？ | 愿意再讨论不等于接受草稿，也不等于拒绝履约；材料摘要必须保留条件、时间和发送角色。 |
| 合同草稿的文档日期是否被误用为签署、送达或接受日期？ | 文档日期表示编辑时间，不证明签署、送达或接受日期；需列示这几个状态未有证据。 |
| 示例判决标题是否有可核验出处？ | 往来附件引用了示例判决标题但没有可核验出处；只能作为待核资料，不能作为法院普遍立场或现行判例依据。 |

## 四、明确限制的备忘录草稿

**材料充分程度**：  
当前给定材料可以支持制作并列差异清单和律师复核问题清单。已核实的事实包括：承租方视角、高/中/低三级优先级、合同草稿未签署、邮件仅为协商材料、押金两版差异、维修范围两版差异、解除条款可能存在条件关系、缺少房屋权属和授权链证据、示例判决标题无可核验出处。  
当前材料不足以形成最终合同摘要，因为两版租赁草稿中哪一份是主文本尚未确定，租金具体金额、提前解约费用计算方式、解除条款完整条件关系、签署/送达/接受日期证据、房屋权属和授权链证据均未提供。

**后续核验事项**：  
1. 确认两版租赁草稿中哪一份是本次律师复核的主文本。  
2. 核对押金两个月与三个月差异在协商邮件中是否有确认或变更。  
3. 核对维修范围是否包含“全部设施故障费用”，并保留两版原文位置。  
4. 核对解除条款中通知形式、提前量和费用的完整条件关系，不删附加前提。  
5. 请求提供房屋权属和授权链证据，但不先判定出租方无权出租。  
6. 核对租金具体金额及对应条款位置。  
7. 核对提前解约费用计算方式和支付条件。  
8. 核对协商邮件中发送角色、时间和条件，保留意向话语原意。  
9. 核对示例判决标题的可核验出处，暂不作为判例依据。  
10. 列示签署、送达、接受状态未有证据，不将文件排序当成法律事实。

**限制**：  
本备忘录仅说明材料充分程度和后续核验事项，不评价某方一定胜诉或一定违法。具体法律适用和条款效力由执业律师按真实事实与现行依据另行处理。不输出具体法律条文编号、现行效力或确定法律结论。不追加发送律师函、公开争议或执行催告。不输入真实当事人敏感信息，不输出联系地址和身份证件内容。

**未决条件**：

- 两版租赁草稿中哪一份是本次律师复核的主文本：尚未确定，不得默认补全。  
- 复核优先侧重持续履约还是可能提前退出安排：尚未确定，不得默认补全。
