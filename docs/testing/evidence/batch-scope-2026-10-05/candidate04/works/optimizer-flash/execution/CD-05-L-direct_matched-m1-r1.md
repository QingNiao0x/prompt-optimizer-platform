# 提示词整理工具对照研究方案（尚未执行）

## 一、研究方案主文

**研究问题。** 本方案比较三种提示词整理条件对下游任务输出的影响：原始组、直接增强组、交互式计划确认增强组，并另设信息量匹配对照。研究不评价任何产品的绝对优劣，只考察条件差异。交互式计划确认指系统先提问、实验操作者按预先制定答案卡作答，再生成最终提示词，不是静态任务分解列表。

**比较条件。** 原始组接收原始需求与初始材料；直接增强组接收由同一初始信息得到的优化提示词；两组均不得查看计划确认组后来回答的业务选择。计划确认组记录每个问题、选项、推荐依据和答案，不只保存最终提示词；错误推荐被答案纠正后仍计入交互阶段风险。信息量匹配对照获得相同已确认事实，但不经历本平台问答过程，用于减少新增信息与交互组织方式之间的混淆。公平比较必须区分“相同初始信息”与“收到确认答案后的信息量匹配”两类问题。

**实验流程。** 已定二十个任务、每条件三次独立重复、两名盲评者，样本数量不再重新选择。每个条件的三次重复开启隔离会话，随机化顺序并记录模型版本、日期和参数。失败后的重试不能替代第一份失败样本。任务材料保留真实实现、用户说明、测试示例与待办等来源标签，不得在人工评分前删除不利的测试污染反例。开发任务要求下游模型只输出方案、不实际修改仓库；写作任务要求交付文本，因此跨任务不能用代码测试通过率作为统一质量指标。

**盲评流程。** 评审看到匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源；可看任务事实，但不得看另一名评审先前评分。评分表记录主错误与关联维度，避免同一问题被多次计成独立失败。

**主要指标。** 工具生成速度为过程指标，质量分为结果指标。质量评价覆盖需求保真、业务规则、输出可用性、阅读负担和执行边界。没有计费日志时不估算真实 Token 成本，不把字符数换算为实际费用。候选统计方法依赖分数是否有序、是否连续和是否重复测量，方案只说明选择流程，不在变量未确定时锁定某个显著性检验。

**限制。** 实验尚未运行，没有准确率、显著性、成功案例数量或用户结论。专业领域判断尚需专家参与；即使三个模型给出相似结论也不构成研究完成证据。资料均为演练用合成资料，不代表任何真实单位、患者、当事人、市场或平台运行数据。交互式计划确认的最大轮次与终止规则、两名评审的分歧处理与一致性评价方式尚未确定，列入预注册待确认清单，不默认补全。

## 二、变量与分组附表

| 条件 | 初始信息 | 是否获得确认答案 | 是否经历问答过程 | 是否可看其他组答案 | 重复次数 | 会话隔离 |
|---|---|---|---|---|---|---|
| 原始组 | 原始需求与初始材料 | 否 | 否 | 否 | 3 | 是 |
| 直接增强组 | 同一初始信息得到的优化提示词 | 否 | 否 | 否 | 3 | 是 |
| 计划确认组 | 原始需求与初始材料 | 是（经问答确认） | 是 | 不适用 | 3 | 是 |
| 信息量匹配对照 | 原始需求与初始材料 | 是（相同已确认事实） | 否 | 否 | 3 | 是 |

**记录字段（计划确认组）：** 问题、选项、推荐依据、答案、是否被答案纠正、交互阶段风险标记。

**记录字段（全部条件）：** 模型版本、日期、参数、会话标识、任务编号、重复序号、首轮输出、重试输出（如有）、失败标记。

**来源标签：** 真实实现、用户说明、测试示例、待办。
