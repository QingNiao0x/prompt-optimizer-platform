## 三、分优先级的律师复核问题

**说明**：风险级别代表律师核查优先顺序，不是系统计算的违法概率。每项说明适用条件、必要输入与边界。高优先项解释为何影响目标。

### 高优先级

**H1. 押金条款的版本冲突与付款义务基础**
- 适用条件：承租方需评估资金安排，但草稿未签署、邮件未确认。
- 必要输入：草稿A与草稿B的完整押金条款原文；邮件中关于押金的协商记录（含发送角色、时间、条件）；签署状态证据。
- 边界：不能凭通行惯例补成合同事实；不能擅定采用两个月还是三个月；未签署材料不能直接产生确定付款义务。
- 为何影响目标：押金金额直接影响承租方资金安排，且两版差异（两个月与三个月）属于当前不一致的金额，须保留可追溯位置，由律师核验哪版可能成为主文本或均不构成约束。

**H2. 维修范围的责任边界**
- 适用条件：草稿A写承租方承担日常维护，草稿B新增全部设施故障费用。
- 必要输入：两版维修条款完整原文；设施清单及故障责任划分；邮件中关于维修范围的协商记录。
- 边界：不能把两个版本拼接成对承租方更不利的统一条款；不能凭通行惯例补成合同事实。
- 为何影响目标：维修范围直接决定承租方的持续履约成本与责任风险，属于本次复核的核心条款之一。

**H3. 解除条款的通知形式、提前量、费用及条件关系**
- 适用条件：解除条款涉及通知形式、提前量和费用，各部分可能存在条件关系。
- 必要输入：两版解除条款完整原文；通知形式的约定；提前量的具体天数；费用的计算方式；各部分的先后条件关系。
- 边界：摘要不能仅取最短通知天数而删掉附加前提；不能凭通行惯例补成合同事实。
- 为何影响目标：解除条款直接关系承租方可能提前退出的安排，若仅取最短通知天数而忽略附加前提，可能导致对退出成本的误判。

**H4. 出租方房屋权属与授权链证据**
- 适用条件：给定材料没有房屋权属和授权链证据。
- 必要输入：房屋权属证明；出租方授权链文件；转租或处置权限的书面依据。
- 边界：不能推断出租方有完整处置权；复核问题可以请求核验，但不先判定其无权出租。
- 为何影响目标：权属与授权链是租赁关系稳定性的基础，缺失该证据可能影响承租方持续履约安排的安全性。

### 中优先级

**M1. 协商邮件的法律性质与摘要口径**
- 适用条件：往来邮件仅为协商材料，邮件中愿意再讨论不等于接受草稿，也不等于拒绝履约。
- 必要输入：邮件全文；发送角色、时间、条件；邮件中关于各条款的具体表述。
- 边界：材料摘要必须保留条件、时间和发送角色，不把意向话语改为明确承诺；不把协商邮件自动解释为承诺或违约。
- 为何影响目标：邮件内容可能影响对双方协商状态的判断，但不得作为已生效协议或违约依据。

**M2. 示例判决标题的可核验性**
- 适用条件：往来附件引用了示例判决标题但没有可核验出处。
- 必要输入：判决标题的完整引用；可核验的出处；作出法院及时间。
- 边界：只能作为待核资料，不能作为法院普遍立场或现行判例依据。
- 为何影响目标：若该资料被误用为法律依据，可能影响复核结论的可靠性。

**M3. 文档日期与签署、送达、接受状态的关系**
- 适用条件：合同草稿的文档日期表示编辑时间。
- 必要输入：签署页；送达记录；接受确认记录。
- 边界：不证明签署、送达或接受日期；不将文件排序当成法律事实。
- 为何影响目标：日期状态影响对草稿法律性质的判断，须与签署状态分开核验。

### 低优先级

**L1. 排版与来源识别测试例子的排除**
- 适用条件：`materials/legal_memo/tests/layout-example.txt` 含输出格式CSV、分析工具Python、收入100万元、示例准确率99%。
- 必要输入：无（已确认为测试例子）。
- 边界：不是本题事实，不是工具偏好，不代表已经实现或取得成果。
- 为何影响目标：排除无关示例，避免混入本题事实。

**L2. 合成示例边界的保持**
- 适用条件：主体、地址、金额均为合成示例。
- 必要输入：无（已确认为合成边界）。
- 边界：不得加入真实当事人信息；不输出联系地址和身份证件内容；合成编号可用于说明材料之间的关系，复制后仍应保持匿名。
- 为何影响目标：保持匿名和合成边界，避免真实信息泄露。

- 不读取或输出受保护路径：`.env`、`**/*.pem`、`**/*.key`、生产环境配置。
- 不在代码、日志或响应中泄露密码、Token、API Key 或私钥。

### 结论：材料充分程度与后续核验事项
- **材料充分程度**：现有材料可支持识别押金、维修范围、解除条款的版本差异，以及权属与授权链证据缺失、示例判决标题无出处等缺口。但主文本尚未确定，草稿未签署，邮件未确认，无法形成最终合同摘要。
- **后续核验事项**：
  1. 由执业律师核验两版草稿中哪一份可能成为主文本，或均不构成约束。
  2. 由执业律师核验押金条款的版本冲突及付款义务基础。
  3. 由执业律师核验维修范围的责任边界，避免拼接成对承租方更不利的统一条款。
  4. 由执业律师核验解除条款的通知形式、提前量、费用及条件关系。
  5. 请求核验出租方房屋权属与授权链证据，但不先判定其无权出租。
  6. 核验示例判决标题的出处，若无法核验则仅作为待核资料。
  7. 核验文档日期与签署、送达、接受状态的关系，不将文件排序当成法律事实。
