# 合成门诊预约到诊与爽约情况内部运营分析方案

**适用期间**：二〇二六年第一季度  
**分析对象**：合成门诊预约事件（非真实患者、非完整逐条数据）  
**材料性质**：合成运营资料，仅用于内部流程讨论，不构成临床判断或医疗建议


## 一、口径梳理

### 1.1 基础统计单位

| 口径项 | 当前状态 | 说明 |
|---|---|---|
| 预约事件编号 | 可区分一次预约 | 一个患者可多次预约，事件数 ≠ 人数 |
| 患者去重口径 | 尚未确定 | 比较渠道时是否按去重患者统计，待业务决定 |
| 渠道范围 | 已明确：电话、网页、窗口 | 不新增、不合并、不追问其他渠道 |
| 到诊状态 | ARRIVED / CANCELLED / UNKNOWN | UNKNOWN 无原因细分 |

### 1.2 状态口径

| 状态 | 运营含义 | 分析处理 |
|---|---|---|
| ARRIVED | 系统记录已到诊 | 计入到诊事件 |
| CANCELLED | 系统记录用户主动取消 | 单独统计，不附加临床解释 |
| UNKNOWN | 原因未细分，可能为同步延迟、漏登记或记录缺项 | **不直接计为爽约**，列为待核验 |

### 1.3 爽约口径边界

| 口径项 | 当前状态 |
|---|---|
| 未到诊观察窗口 | **尚未确定**，不得默认补全 |
| 取消免责边界 | 旧流程：提前24小时取消不计爽约；新会议草稿：提前12小时，**尚未批准** |
| UNKNOWN 是否计入爽约 | **否**，在缺少核验规则时不计算爽约率 |
| 爽约率分母 | 尚未确定（是否剔除 CANCELLED、是否剔除 UNKNOWN 待核验，均未决定） |

### 1.4 时区口径

- 预约取消时间与就诊时间均使用医院本地时区。
- 当前汇总表**没有时区转换证据**，分析中不进行跨时区换算，也不推断时间偏差原因。

### 1.5 渠道比较口径

- 电话预约与网页预约可能记录**同一次预约的不同操作事件**。
- 渠道比较必须先定义"首次渠道"和"渠道变更"规则，不能把操作次数当成预约量。
- 主统计单位（预约事件 vs 去重患者）**尚未确定**，分析报告中两种口径均不默认采用，待业务决定后补充。

### 2.2 UNKNOWN 状态处理缺口

| 编号 | 问题 | 依据 | 影响 |

## 三、拟议数据采集表

以下字段为**拟议**采集内容，实施前需合规评估，**不表示已经建表或已获得数据授权**。

### 3.1 预约事件基础字段

| 字段名 | 类型 | 说明 | 是否当前已有 |
|---|---|---|---|
| 预约事件编号 | 文本 | 唯一标识一次预约 | 已有 |
| 预约渠道 | 枚举（电话/网页/窗口） | 首次记录渠道 | 已有 |
| 预约创建时间 | 日期时间（本地时区） | 预约发起时间 | 已有 |
| 就诊时间 | 日期时间（本地时区） | 预约就诊时间 | 已有 |
| 到诊状态 | 枚举（ARRIVED/CANCELLED/UNKNOWN） | 当前记录状态 | 已有 |
| 取消时间 | 日期时间（本地时区，可空） | 仅 CANCELLED 状态填写 | 已有 |

### 3.2 拟新增字段（需合规评估后实施）

| 字段名 | 类型 | 说明 | 采集目的 |
|---|---|---|---|
| 状态更新时间 | 日期时间（本地时区） | 到诊状态最近一次变更时间 | 追踪 UNKNOWN 核验进度，支持观察窗口判断 |
| 来源系统 | 枚举（电话系统/网页系统/窗口系统） | 记录产生该条状态的操作系统 | 区分渠道记录来源，辅助识别重复操作事件 |
| 渠道变更标记 | 布尔/枚举 | 是否存在渠道变更（如电话改网页） | 支持首次渠道与变更渠道口径分析 |
| 首次渠道 | 枚举（电话/网页/窗口） | 该预约事件首次记录的渠道 | 渠道比较时区分首次渠道 |
| UNKNOWN 核验状态 | 枚举（待核验/已核验为到诊/已核验为未到诊/无法核验） | 人工复核后的状态 | 避免 UNKNOWN 直接计为爽约 |

### 3.3 明确不采集的字段

| 字段 | 原因 |
|---|---|
| 患者姓名、证件号、联系方式 | 隐私边界，不包含可识别信息 |
| 医生姓名、医生个人绩效指标 | 医生代码仅为流程角色示例，不做个体评价 |
| 诊断、处方、分诊优先级、医嘱 | 本题不涉及临床判断 |
| 短信通知授权状态 | 短信提醒方案需另行确认，本次不扩成实施任务 |
