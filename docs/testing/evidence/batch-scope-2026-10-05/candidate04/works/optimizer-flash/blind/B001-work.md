# 提示词整理工具对照研究方案（尚未执行）

## 一、研究方案主文

### 1. 研究问题

本研究比较三种提示词整理条件对下游任务输出的影响：原始需求（原始组）、直接增强（直接增强组）、交互式计划确认增强（计划确认组）。交互式计划确认指系统先提问、实验操作者按预先制定答案卡作答，再生成最终提示词，不是静态任务分解列表。研究不评价某家产品绝对优劣，只比较条件差异。

计划确认组会额外得到答案，因此另设信息量匹配对照组：该组获得相同已确认事实，但不经历本平台问答过程，用于减少新增信息与交互组织方式之间的混淆。公平比较必须区分“相同初始信息”与“收到确认答案后的信息量匹配”两种问题。

### 2. 实验设计

固定二十个任务，每个条件独立重复三次，两名盲评者独立评分，所有工具获取相同初始材料。每个条件的三次重复开启隔离会话，随机化顺序并记录模型版本、日期和参数；失败后的重试不能替代第一份失败样本。

四组材料与信息边界如下：原始组接收原始需求与初始材料；直接增强组接收同一初始信息得到的优化提示词；两组都不能偷看计划确认组后来回答的业务选择。计划确认组按答案卡交互后生成最终提示词，并记录每个问题、选项、推荐依据和答案，不只保存最终提示词；错误推荐被答案纠正后仍计入交互阶段风险。信息量匹配对照组获得相同已确认事实，但不经历本平台问答过程。

任务材料保留真实实现、用户说明、测试示例与待办这几种来源标签；不能在人工评分前人为删除不利的测试污染反例。开发任务要求下游模型只输出方案，不实际修改仓库；写作任务要求交付文本，因此跨任务不能用代码测试通过率作为统一质量指标。

### 3. 主要指标

评价同时覆盖需求保真、业务规则、输出可用性、阅读负担和执行边界。评分表记录主错误和关联维度，避免将同一问题多次计成不同独立失败。工具生成速度是过程指标，质量分是结果指标；没有计费日志时不估算真实 Token 成本，不把字符数换算成实际费用。

盲评安排：评审看到匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源；为了评分可以看任务事实，但不能看另一名评审先前评分。

统计方法选择流程：候选方法依赖分数是否有序、是否连续和是否重复测量；方案说明选择流程，不在变量尚未确定时锁定某个显著性检验。

人工评阅与可复核任务标准：安排人工评阅与可复核任务标准，特别说明专业领域判断尚需专家参与。即使三个模型给出相似结论也不是研究完成证据。

### 4. 限制

实验尚未运行，没有准确率、显著性、成功案例数量和用户结论。本方案不虚构实验结果、引用出处、伦理审批或已经获得的统计显著性，不声称已完成实际论文与研究设计业务验收。最大交互轮次和终止规则、两名评审的分歧处理与一致性评价方式尚未确定，只进入预注册待确认清单，不默认任何轮次、平均分、共识分、第三人仲裁或具体一致性统计量。二十个任务、每条件三次独立重复、两名盲评者及信息量匹配对照保持已定。
