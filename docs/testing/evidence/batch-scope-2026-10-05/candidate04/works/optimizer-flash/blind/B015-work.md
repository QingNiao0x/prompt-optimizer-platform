# 提示词整理工具对照研究方案

## 1 研究问题

本研究比较三种提示词准备条件对下游任务输出的影响：原始需求直接输入、基于同一初始信息直接增强、以及交互式计划确认后生成。研究不评价任何产品绝对优劣，只考察条件间差异。核心问题为：在相同初始材料下，提示词整理方式是否改变下游输出的需求保真、业务规则遵守、输出可用性、阅读负担和执行边界表现；当计划确认组额外获得已确认事实时，该收益是否可归因于新增信息本身而非交互组织方式。

## 2 实验设计

采用四组对照。原始组接收原始需求与初始材料，不加工。直接增强组接收由同一初始信息生成的优化提示词，不接触计划确认组后来回答的业务选择。计划确认组先经系统提问，实验操作者按预先制定答案卡作答，系统再生成最终提示词；该组记录每个问题、选项、推荐依据和答案，错误推荐被答案纠正后仍计入交互阶段风险。信息量匹配对照获得与计划确认组相同的已确认事实，但不经历问答过程，用于分离新增信息与交互组织方式的影响。

二十个任务覆盖开发方案与写作交付两类，跨任务不采用代码测试通过率作为统一质量指标。每个条件对每个任务独立重复三次，开启隔离会话，随机化顺序并记录模型版本、日期和参数。失败后的重试不替代第一份失败样本。任务材料保留真实实现、用户说明、测试示例与待办等来源标签，评分前不人为删除不利反例。

## 3 评价方式

两名盲评者独立评分，评审材料为匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源；评审可查看任务事实，但不能查看另一名评审的先前评分。评分维度为需求保真、业务规则、输出可用性、阅读负担和执行边界。同一错误可能同时影响多个维度，评分表记录主错误和关联维度，避免重复计分。工具生成速度作为过程指标单独记录，质量分为结果指标；无计费日志时不估算真实 Token 成本，不以字符数换算费用。

## 4 统计与限制

统计方法选择流程为：先确认评分是否有序、是否连续、是否重复测量，再据此确定检验方案；在变量性质未确定前不锁定具体显著性检验。人工评阅与可复核任务标准为必要环节，专业领域判断尚需专家参与，模型间结论相似不构成研究完成证据。

本方案尚未运行，不含准确率、显著性、成功案例数量或用户结论。交互式计划确认的最大轮次与终止规则、两名盲评者的分歧处理与一致性评价方式均未确定，列入预注册待确认清单，不默认任何选项。
