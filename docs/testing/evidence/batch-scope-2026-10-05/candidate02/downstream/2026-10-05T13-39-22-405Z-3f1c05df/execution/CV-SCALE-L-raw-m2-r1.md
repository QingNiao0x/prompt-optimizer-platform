# 提示词整理工具对照研究方案

## 1. 研究问题

本研究考察提示词整理工具在“原始需求—直接增强—交互式计划确认增强”三种条件下，对下游任务输出质量的影响。核心问题不是评价某家产品绝对优劣，而是区分两类收益来源：一是仅凭相同初始信息进行提示词优化带来的收益；二是交互式计划确认通过新增已确认事实带来的收益。为此设置信息量匹配对照，避免把“多得到答案”误判为单纯模型能力。

## 2. 实验设计

**任务集**：二十个任务，覆盖开发方案类（下游只输出方案、不修改仓库）与写作交付类（交付文本）。跨任务不采用代码测试通过率作为统一质量指标。

**条件分组**：

- **A 原始组**：下游模型直接接收原始需求与初始材料。
- **B 直接增强组**：下游模型接收由同一初始信息生成的优化提示词，不接触计划确认组后来回答的业务选择。
- **C 计划确认组**：系统先提问，实验操作者按预先制定答案卡作答，再生成最终提示词。记录每个问题、选项、推荐依据和答案；错误推荐被答案纠正后仍计入交互阶段风险。
- **D 信息量匹配对照**：获得与 C 组相同的已确认事实，但不经历本平台问答过程，用于分离新增信息与交互组织方式的效应。

**重复与随机化**：每个条件独立重复三次，开启隔离会话，随机化顺序，记录模型版本、日期和参数。失败后的重试不替代第一份失败样本。

**盲评**：两名盲评者独立评分，看到匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源；可查看任务事实，但不能查看另一名评审先前评分。

## 3. 主要指标

评分同时覆盖五个维度：需求保真、业务规则、输出可用性、阅读负担、执行边界。一个错误可能同时影响多个维度，评分表记录主错误和关联维度，避免同一问题多次计成独立失败。工具生成速度作为过程指标单独记录，质量分为结果指标；无计费日志时不估算真实 Token 成本，不以字符数换算费用。

## 4. 统计与限制

统计方法选择依赖分数是否有序、是否连续及是否重复测量，在变量性质确定前不锁定具体显著性检验。人工评阅与可复核任务标准为必需环节，专业领域判断尚需专家参与。任务材料保留真实实现、用户说明、测试示例与待办等来源标签，不在评分前人为删除不利反例。

| 条件 | 初始信息 | 交互式问答 | 已确认事实 | 下游输入 |
|---|---|---|---|---|
| A 原始组 | 原始需求+初始材料 | 无 | 无 | 原始需求+初始材料 |
| B 直接增强组 | 原始需求+初始材料 | 无 | 无 | 优化提示词（仅由初始信息生成） |
| C 计划确认组 | 原始需求+初始材料 | 有，按答案卡作答 | 问答所得 | 最终提示词（含确认事实） |

**固定变量**：任务集（20个）、每条件重复次数（3次）、盲评者人数（2名）、模型版本与参数记录、隔离会话、随机化顺序。

**记录字段**：条件、任务编号、重复编号、会话标识、模型版本、日期、参数、首轮失败标记、重试次数、生成耗时（过程指标）。
