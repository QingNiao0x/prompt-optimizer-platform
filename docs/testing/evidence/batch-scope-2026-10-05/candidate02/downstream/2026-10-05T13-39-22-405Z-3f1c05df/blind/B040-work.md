# 提示词整理工具对照研究方案

## 1. 研究问题

本研究比较三种提示词准备方式对下游任务输出质量的影响：原始需求直接输入、直接增强提示词、交互式计划确认后生成的提示词。研究不评价任何工具产品的绝对优劣，只考察在相同任务与材料条件下，不同提示词准备路径是否带来可区分的结果差异。

核心混淆因素在于：交互式计划确认组在问答过程中额外获得了经确认的业务答案，其输出差异可能来自新增信息本身，而非交互组织方式。因此设置信息量匹配对照，获得相同的已确认事实但不经历问答过程，以分离“信息增量”与“交互方式”两种效应。

## 2. 实验设计

**任务与材料。** 固定二十个任务，覆盖开发与写作两类。开发任务要求下游模型只输出方案，不实际修改仓库；写作任务要求交付文本。跨任务不使用代码测试通过率作为统一质量指标。每个任务的材料保留来源标签：真实实现、用户说明、测试示例、待办；不得在人工评分前删除不利的测试污染反例。

**条件与分组。** 四个条件：

| 条件 | 接收内容 | 是否经历问答 |
|---|---|---|
| A 原始组 | 原始需求与初始材料 | 否 |
| B 直接增强组 | 由同一初始信息生成的优化提示词 | 否 |
| C 计划确认组 | 交互问答后生成的最终提示词 | 是 |
| D 信息量匹配对照 | 相同已确认事实，但不经历问答过程 | 否 |

A、B两组不得接触C组后续回答的业务选择。C组记录每个问题、选项、推荐依据和答案，错误推荐被答案纠正后仍计入交互阶段风险。D组用于减少新增信息与交互组织方式之间的混淆。

**重复与隔离。** 每个条件独立重复三次，每次开启隔离会话，随机化任务顺序，记录模型版本、日期和参数。失败后的重试不能替代第一份失败样本；工具失败和首轮失败均保留记录。

**盲评。** 评审看到匿名化下游输出和等量任务信息，不展示工具名称、标志和生成来源。评审可查看任务事实，但不能查看另一名评审的先前评分。

## 3. 主要指标

评价同时覆盖五个维度：需求保真、业务规则、输出可用性、阅读负担、执行边界。评分尺度采用顺序尺度，具体等级与评分锚点尚未确定，不自行指定。一个错误可能同时影响多个维度，评分表记录主错误和关联维度，避免同一问题重复计为独立失败。

工具生成速度是过程指标，质量分是结果指标。没有计费日志时不估算真实 Token 成本，不将字符数换算为实际费用。

## 4. 统计方法选择流程

候选统计方法依赖分数是否有序、是否连续、是否重复测量。当前评分尺度已确定为顺序尺度，但具体等级与锚点未定，因此不锁定显著性检验。待评分表定稿后，按以下流程选择：确认分数有序性、连续性与重复测量结构，再匹配相应方法。

## 5. 限制

实验尚未运行，无准确率、显著性、成功案例数量或用户结论。即使三个模型给出相似结论也不构成研究完成证据；方案安排人工评阅与可复核任务标准，专业领域判断需专家参与。以下条件待预注册前明确：交互式计划确认的最大轮次与终止规则；两名评审的分歧处理与一致性评价方式；评分表具体等级与锚点。这些未决条件直接影响记录字段、风险计数口径、一致性指标和统计选择，不默认补全。


# 附表一：变量与分组

| 变量 | 类型 | 取值/状态 | 说明 |
|---|---|---|---|
| 提示词准备方式 | 自变量，四水平 | A原始 / B直接增强 / C计划确认 / D信息量匹配 | 组间比较 |
| 任务类型 | 控制变量 | 开发 / 写作 | 二十个任务中分布待材料目录确认 |
| 任务材料来源标签 | 控制变量 | 真实实现 / 用户说明 / 测试示例 / 待办 | 必须保留，不得删除反例 |
| 重复次数 | 控制变量 | 每条件3次 | 隔离会话 |
| 模型版本、日期、参数 | 记录变量 | 文本 | 每次运行记录 |
| 交互轮次 | C组记录变量 | 数值 | 最大轮次与终止规则待确认 |
| 问题、选项、推荐依据、答案 | C组记录变量 | 文本 | 错误推荐被纠正仍计入风险 |
| 下游输出质量分 | 因变量 | 顺序尺度 | 具体等级与锚点待确认 |
| 工具生成速度 | 过程指标 | 时间 | 不进入质量比较 |
| Token成本 | 不采集 | — | 无计费日志，不估算 |
| 首轮失败 | 记录变量 | 是/否 | 重试不替代首轮失败样本 |
| 工具失败 | 记录变量 | 是/否 | 保留记录 |

**分组信息对照：**

| 条件 | 相同初始信息 | 已确认事实 | 问答过程 |
|---|---|---|---|
| A | 有 | 无 | 无 |
| B | 有（经优化） | 无 | 无 |
| C | 有 | 有 | 有 |
| D | 有 | 有 | 无 |

C与D的比较隔离交互方式效应；A与B的比较隔离直接增强效应；B与D的比较需注意信息量不同，不可直接归因于单一因素。
