### 1.2 流程图说明

**流程：从预约事件到可报告指标的判定链**

```
[预约事件产生]
   │  渠道：电话 / 网页 / 窗口（M2）
   │  可能产生多个操作事件（M6）
   ▼
[渠道归属判定]
   │  须先定义：首次渠道 / 变更渠道（M6）
   │  ⚠ 未定义前不得做渠道比较
   ▼
[状态判定]
   ├─ ARRIVED ──────────────► 计入到诊
   ├─ CANCELLED ────────────► 进入取消免责边界判定（M12）
   │                              │
   │                              ├─ 提前量 ≥ 免责阈值？→ 不计爽约
   │                              └─ 提前量 < 免责阈值？→ 计爽约
   │                              ⚠ 阈值24h vs 12h 未决，不得采用
   │
   └─ UNKNOWN ──────────────► 不得直接计爽约（M9）
                                  │
                                  ▼
                          [来源核查 / 待核验队列]
                                  │
                                  ▼
                          [观察窗口判定]（M11）
                                  │
                    ┌─────────────┴─────────────┐
                    │                           │
              窗口已到期                    窗口未到期
                    │                           │
                    ▼                           ▼
            可归为最终状态                仅展示为待核验事件
                    │                    （不得计入爽约率分母）
                    ▼
            [纳入爽约率计算]
                    │
                    ▼
            [主统计单位选择]（M13）
                    │
          ┌─────────┴─────────┐
          │                   │
      预约事件              去重患者
          │                   │
          └─────────┬─────────┘
                    ▼
            [渠道比较与报告]
                    │
                    ▼
        [小样本限制说明 + 不报告显著差异]（M14）
```

**流程图要点说明**：
1. 渠道归属判定必须在状态判定之前完成，否则同一预约的多次操作会被重复计数（M6）。
2. UNKNOWN 走独立分支，不进入爽约分子，先进入待核验队列（M8、M9）。
3. 观察窗口是"待核验"与"最终状态"之间的闸门，窗口未确定前所有未到期事件只展示、不计算（M11）。
4. 取消免责边界是 CANCELLED 分支内的独立判定节点，阈值未决（M12）。
5. 主统计单位选择在纳入计算前完成，事件与人数不可混用（M13）。

### 2.2 提前24小时与提前12小时取消不计爽约的争议（单独呈现）

**争议焦点**：取消预约后，提前多久取消可免于计入爽约？

| 维度 | 旧流程说明 | 新会议草稿 |
|---|---|---|
| 来源 | 【旧版】materials/hospital_operations/legacy-note.md | 【旧版】materials/hospital_operations/legacy-note.md（草稿部分） |
| 建议阈值 | 提前24小时取消不计爽约 | 提前12小时取消不计爽约 |
| 审批状态 | 旧流程说明，适用口径待核对 | **尚未批准** |
| 权威性 | 材料权威性并未建立 | 材料权威性并未建立 |
| 处理方式 | **不得擅自采用其中一项** | **不得擅自采用其中一项** |

**争议处理原则**：
1. 两份材料的适用口径和审批状态应按本题说明核对，**不能只凭日期决定**（【现行】+【旧版】）。
2. 报告需将争议**单独呈现**，不能按文件修改时间直接断定新规则生效（【现行】）。
3. 在争议解决前，CANCELLED 事件在爽约率计算中应**单独列示**，不并入爽约分子，也不直接免责。
4. 建议在运营会议上将此项作为**待决事项**提出，由流程负责人与合规方共同确认后再更新口径。

**争议对指标的影响示意**（合成示例，非真实数据）：

| 取消提前量区间 | 按24小时口径 | 按12小时口径 | 当前处理 |
|---|---|---|---|
| ≥24小时 | 不计爽约 | 不计爽约 | 待确认 |
| 12–24小时 | 计爽约 | 不计爽约 | **争议区间，单独列示** |
| <12小时 | 计爽约 | 计爽约 | 待确认 |

## 三、合成数据采集字段建议

> **重要声明**：以下为**拟议**字段建议，**尚未建表，尚未获得数据授权**。实施前仍需合规评估（M17）。表格只展示合成汇总信息，不包含患者、医生的可识别信息或敏感诊疗明细。

### 3.1 拟议采集字段

| 字段名 | 类型 | 说明 | 用途 | 合规备注 |
|---|---|---|---|---|
| 预约事件编号 | 字符串 | 区分一次预约，非患者标识 | 事件计数 | 合成编号，不可反推个人 |
| 患者去重键 | 哈希/代理键 | 用于去重患者统计，不可逆 | 人数统计 | 需合规评估是否可采集 |
| 预约渠道 | 枚举 | 电话/网页/窗口 | 渠道分析 | 已知三类 |
| 首次渠道 | 枚举 | 该预约首次记录的渠道 | 渠道归属 | 需先定义规则 |
| 变更渠道 | 枚举 | 后续操作渠道（如有） | 渠道变更分析 | 需先定义规则 |

| 状态更新时间 | 时间戳 | 状态最后一次变更时间 | 观察窗口判定 | **拟议新增** |
| 取消时间 | 时间戳 | 用户主动取消时间（本地时区） | 免责边界判定 | **拟议新增**；无时区转换证据 |
| 就诊时间 | 时间戳 | 预约就诊时间（本地时区） | 提前量计算 | 无时区转换证据 |
| 来源系统 | 字符串 | 记录该事件的系统标识 | 来源核查 | **拟议新增** |
| 科室类型 | 枚举 | 门诊类型（本题仅一个门诊） | 分层分析 | 不推断跨科室 |
| 医生代码 | 字符串 | 流程角色示例 | 流程分析 | **非绩效评估**，不做排行榜 |

### 3.2 字段采集注意事项

1. **状态更新时间**与**取消时间**是判定观察窗口和免责边界的关键字段，当前汇总表可能缺失（M17）。
2. **来源系统**字段用于 UNKNOWN 的来源核查，区分设备同步延迟、现场漏登记或记录缺项（M8）。
3. **患者去重键**涉及隐私，需合规评估是否可采集及存储方式；如不可采集，则主统计单位只能限于预约事件（M13）。
4. **医生代码**仅作流程角色示例，不得用于个体能力评价或排行榜（M15）。
5. 所有时间字段均为医院本地时区，当前无时区转换证据（M4）。
