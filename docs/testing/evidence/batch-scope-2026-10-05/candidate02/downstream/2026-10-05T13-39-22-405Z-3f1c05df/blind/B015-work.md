# 合成门诊预约到诊与爽约情况内部运营分析方案（二〇二六年第一季度）

> 适用对象：运营分析、门诊流程管理、数据质量与合规复核人员  
> 材料性质：合成汇总资料，不含真实患者信息，不用于临床判断或个体医疗决策  
> 分析范围：仅限该合成门诊二〇二六年第一季度预约事件；不涉及诊断、处方、分诊优先级、医嘱或个体治疗


## 一、口径梳理

### 1.1 基础统计单位

| 口径项 | 当前可用定义 | 是否已定 | 说明 |
|---|---|---|---|
| 预约事件 | 以预约事件编号区分一次预约 | 已定 | 一个患者可多次预约，事件数不等于人数 |
| 去重患者 | 同一患者多次预约时只计一次 | 未定 | 是否作为主统计单位尚未决定 |
| 渠道比较主单位 | 预约事件或去重患者 | 未定 | 本次不默认采用其中一种；报告中两者并列展示时须标注限制 |

### 1.2 到诊状态口径

| 状态 | 含义 | 本次处理方式 |
|---|---|---|
| ARRIVED | 系统记录已到诊 | 可计入到诊事件 |
| CANCELLED | 系统记录用户主动取消 | 单独统计，不并入爽约；不附加临床解释 |
| UNKNOWN | 到诊状态未知，原因未细分 | 不直接计为爽约；是否进入分母尚未确定；观察窗口未确定前仅展示为待核验事件 |

### 1.3 爽约与取消免责边界

| 口径项 | 状态 | 处理方式 |
|---|---|---|
| 爽约定义 | 未最终确定 | 不将 UNKNOWN 直接计为爽约 |
| 观察窗口 | 尚未确定 | 不默认任何时长；未到期预约不纳入爽约率 |
| 取消免责边界 | 尚未确定 | 旧流程说明与会议草稿差异单独呈现，不擅自采用 |

**旧流程说明与会议草稿差异：**

| 来源 | 内容 | 状态 |
|---|---|---|
| 旧流程说明（legacy-note.md） | 提前24小时取消不计爽约 | 旧版说明，适用性未定 |
| 新会议草稿 | 建议提前12小时取消不计爽约 | 尚未批准，不视为生效规则 |

> 两份材料的适用口径和审批状态应按本题说明核对，不能只凭日期或文件修改时间断定新规则生效。

### 1.4 渠道口径

| 渠道 | 已明确 | 备注 |
|---|---|---|
| 电话 | 是 | 电话与网页可能记录相同一次预约的不同操作事件 |
| 网页 | 是 | 渠道比较必须先定义首次渠道和变更渠道 |
| 窗口 | 是 | 不能把操作次数当成预约量 |

### 1.5 时间口径

| 项 | 口径 |
|---|---|
| 预约取消时间 | 医院本地时区 |
| 就诊时间 | 医院本地时区 |
| 时区转换证据 | 当前汇总表没有时区转换证据，分析中不推断跨时区情况 |


## 二、流程图说明

### 2.1 预约事件状态流转（基于现有资料）

```
预约创建（电话/网页/窗口）
        │
        ▼
   ┌─────────────────┐
   │ 等待就诊         │
   └─────────────────┘
        │
        ├──► 患者主动取消 ──► CANCELLED（单独统计，不并入爽约）
        │
        ├──► 到诊登记 ──────► ARRIVED
        │
        └──► 状态未明 ──────► UNKNOWN（待核验，不直接计为爽约）
                                   │
                                   ▼
                          观察窗口未确定，暂不归入最终状态
```

### 2.2 渠道记录流程注意点

- 电话预约与网页预约可能对同一次预约产生不同操作事件。
- 渠道比较前必须定义"首次渠道"和"变更渠道"，不能把操作次数当成预约量。
- 当前汇总表没有渠道变更记录字段，拟议采集表中需补充（见第三部分）。

### 2.3 取消事件的处理边界

- CANCELLED 表示系统记录到用户主动取消，不意味着治疗结束、病情缓解或不再需要服务。
- 分析报告不能给取消行为附加临床解释。
- 取消是否计入爽约，取决于取消免责边界（24小时旧流程 vs 12小时会议草稿），该边界尚未确定。


## 三、拟议数据采集表字段建议

> 以下为拟议字段，实施前仍需合规评估；不能写成已经建表或已获得数据授权。

### 3.1 预约事件基础字段

| 字段名 | 建议类型 | 用途 | 是否含敏感信息 |
|---|---|---|---|
| 预约事件编号 | 文本/去标识化 | 区分一次预约 | 否 |
| 患者去标识化编号 | 文本/去标识化 | 区分去重患者（仅用于统计，不展示个体） | 需去标识化 |
| 预约渠道（首次） | 枚举：电话/网页/窗口 | 渠道比较 | 否 |
| 预约渠道（变更后） | 枚举：电话/网页/窗口/无变更 | 识别渠道变更 | 否 |
| 预约创建时间 | 日期时间（本地时区） | 计算提前量 | 否 |
| 就诊时间 | 日期时间（本地时区） | 计算观察窗口 | 否 |
| 到诊状态 | 枚举：ARRIVED/CANCELLED/UNKNOWN | 核心状态 | 否 |
| 状态更新时间 | 日期时间（本地时区） | 判断状态时效性 | 否 |
| 取消时间 | 日期时间（本地时区，可空） | 计算取消提前量 | 否 |
| 来源系统 | 文本 | 区分电话/网页/窗口系统记录 | 否 |

### 3.2 数据质量核验字段

| 字段名 | 建议类型 | 用途 |
|---|---|---|
| UNKNOWN 原因分类 | 枚举：设备同步延迟/现场漏登记/记录缺项/待核查 | 区分系统问题与患者行为 |
| 状态最后核查时间 | 日期时间 | 判断是否已过观察窗口 |
| 数据来源系统标识 | 文本 | 追溯记录来源 |

### 3.3 明确不采集的字段

- 患者姓名、身份证号、联系方式等可识别信息
- 医生个人绩效相关字段（医生代码仅作为流程角色示例，不追加医生排行榜）
- 诊断、处方、分诊优先级、医嘱、治疗结果等临床信息
- 利用服务时间做个体能力评价的字段

## 五、人工复核及隐私边界清单

### 5.1 人工复核清单

| 复核项 | 复核内容 | 触发条件 |
|---|---|---|
| UNKNOWN 状态核查 | 逐条核查 UNKNOWN 事件的实际到诊情况 | 所有 UNKNOWN 事件 |
| 取消时间合理性 | 取消时间是否早于就诊时间、是否在合理提前量范围内 | 所有 CANCELLED 事件 |
| 渠道记录一致性 | 同一预约事件在电话/网页/窗口系统间的记录是否一致 | 存在多渠道操作记录的事件 |
| 状态更新时间时效性 | 状态更新时间是否已超过拟议观察窗口 | 所有未到最终状态的事件 |
| 时区一致性 | 取消时间与就诊时间是否均为本地时区、有无时区转换痕迹 | 全部数据 |
| 旧流程与会议草稿适用性 | 确认当前生效的取消免责规则版本 | 涉及取消免责边界计算时 |

### 5.2 隐私边界清单

| 边界项 | 要求 |
|---|---|
| 患者可识别信息 | 不采集、不展示姓名、身份证号、联系方式等 |
| 医生个人绩效 | 医生代码仅作流程角色示例，不追加医生排行榜，不做个体能力评价 |
| 敏感诊疗明细 | 不包含诊断、处方、分诊优先级、医嘱、治疗结果 |
| 取消行为解释 | 不给取消行为附加临床解释（不推断病情缓解或不再需要服务） |
| 患者责任归因 | UNKNOWN 状态不解释为患者责任 |
| 处罚性建议 | 不默认采取罚款、降低预约资格或公开患者记录 |
| 短信提醒 | 如后续要求短信提醒方案，需另行确认通知授权和退订流程；本次不扩成发送短信的实施任务 |
| 数据授权 | 拟议采集表实施前需合规评估，不能写成已经建表或已获得数据授权 |
