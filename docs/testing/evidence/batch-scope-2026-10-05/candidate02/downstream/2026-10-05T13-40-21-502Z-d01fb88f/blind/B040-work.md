# 研究方案主文

## 研究问题

本研究比较三种提示词准备方式对下游任务输出质量的影响：原始需求直接使用、直接增强（基于同一初始信息优化提示词）、交互式计划确认增强（系统先提问，实验操作者按预先制定答案卡作答，再生成最终提示词）。核心问题为：交互式计划确认是否在需求保真、业务规则遵守、输出可用性、阅读负担和执行边界五个维度上优于或不同于直接增强；若存在差异，该差异是否来自新增已确认事实，而非交互组织方式本身。

## 实验设计

固定二十个任务，每个条件独立重复三次，共二百四十份下游输出。四个条件为：

- **原始组**：接收原始需求与初始材料，不接触任何后续确认答案。
- **直接增强组**：接收由同一初始信息生成的优化提示词，不接触计划确认组后来回答的业务选择。
- **计划确认组**：系统按答案卡提问，操作者作答后生成最终提示词；记录每个问题、选项、推荐依据和答案，错误推荐被答案纠正后仍计入交互阶段风险。
- **信息量匹配对照**：获得与计划确认组相同的已确认事实，但不经历本平台问答过程，用于分离新增信息与交互组织方式的效应。

每次重复开启隔离会话，随机化任务顺序，记录模型版本、日期和参数。失败后的重试不能替代第一份失败样本。两名盲评者独立评分，评审看到匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源；评分时可查看任务事实，但不能查看另一名评审先前评分。

## 主要指标

结果指标为五维度顺序尺度评分。过程指标包括工具生成速度、交互轮次和失败率，与质量分分开分析。无计费日志时不估算真实 Token 成本，不将字符数换算为实际费用。评分表记录主错误和关联维度，避免同一问题多次计成不同独立失败。

## 统计方法选择流程

候选统计方法依赖分数是否有序、是否连续和是否重复测量。评分尺度已确认为顺序尺度，但具体等级与评分锚点、最大交互轮次和终止规则、分歧处理流程、一致性评价指标均未确定。方案在变量确定后按以下流程选择：先确认评分等级数和锚点，再判断是否满足连续性与重复测量结构，据此选择相应的非参数或混合效应方法，不预先锁定某个显著性检验。

## 限制

实验尚未运行，无准确率、显著性、成功案例数量或用户结论。开发任务要求下游模型只输出方案，不实际修改仓库；写作任务要求交付文本，跨任务不能用代码测试通过率作为统一质量指标。任务材料保留真实实现、用户说明、测试示例与待办来源标签，不在人工评分前删除不利的测试污染反例。专业领域判断需专家参与，人工评阅与可复核任务标准为必需环节。

**分组信息对照**

| 条件 | 接收内容 | 是否经历问答过程 | 是否获得确认答案 |
|---|---|---|---|
| 原始组 | 原始需求与初始材料 | 否 | 否 |
| 直接增强组 | 同一初始信息生成的优化提示词 | 否 | 否 |
| 计划确认组 | 问答后生成的最终提示词 | 是 | 是 |
| 信息量匹配对照 | 相同已确认事实，不经问答过程 | 否 | 是 |

**答案卡记录字段**：问题文本、选项列表、推荐依据、操作者答案、是否纠正错误推荐、轮次编号、时间戳。

**材料目录**：任务材料按来源标签分类存放，保留真实实现、用户说明、测试示例与待办四类标签；测试示例与正式说明分开存放。材料对应关系：`materials/research_design/current-brief.md` 为现行研究设计条件；`materials/research_design/tests/layout-example.txt` 仅为排版与来源识别测试例子，其中输出格式、分析工具、收入金额和准确率数字均非本题事实。
