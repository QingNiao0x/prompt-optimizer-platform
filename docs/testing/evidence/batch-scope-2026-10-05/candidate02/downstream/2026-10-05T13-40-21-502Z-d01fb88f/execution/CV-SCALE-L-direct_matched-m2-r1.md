# 提示词整理工具对照研究方案

## 1 研究问题

本研究比较三种提示词准备方式对下游任务输出质量的影响：原始需求直接输入、直接增强提示词、交互式计划确认后生成提示词。研究不评价任何产品绝对优劣，只考察在相同任务材料下，不同提示词准备路径是否带来可观察的输出差异。核心问题为：在需求保真、业务规则、输出可用性、阅读负担和执行边界五个维度上，三种条件及信息量匹配对照之间是否存在差异。

## 2 实验设计

**任务与材料。** 固定二十个任务，覆盖开发与写作两类。开发任务要求下游模型只输出方案，不实际修改仓库；写作任务要求交付文本。跨任务不以代码测试通过率作为统一质量指标。任务材料保留真实实现、用户说明、测试示例与待办四种来源标签，评分前不得人为删除不利的测试污染反例。

**条件设置。** 设四个条件：原始组、直接增强组、计划确认组、信息量匹配对照组。原始组接收原始需求与初始材料。直接增强组接收基于同一初始信息生成的优化提示词，不接触计划确认组后来回答的业务选择。计划确认组由系统先提问，实验操作者按预先制定的答案卡作答，系统再生成最终提示词；该组记录每个问题、选项、推荐依据和答案，错误推荐被答案纠正后仍计入交互阶段风险。信息量匹配对照组获得与计划确认组相同的已确认事实，但不经历问答过程，用于区分新增信息本身与交互组织方式的影响。

**重复与隔离。** 每个条件对每个任务独立重复三次，共 240 次下游生成。每次重复开启隔离会话，随机化顺序，记录模型版本、日期和参数。失败后的重试不能替代第一份失败样本；工具失败和首轮失败均保留。

**盲评。** 两名盲评者独立评分，评审看到匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源。评审可查看任务事实，但不能查看另一名评审先前评分。盲评不得暴露工具名称。

## 3 主要指标

五个评价维度：需求保真、业务规则、输出可用性、阅读负担、执行边界。评分尺度采用顺序尺度，具体等级与评分锚点尚未确定，不预先指定。一个错误可能同时影响多个维度，评分表记录主错误和关联维度，避免同一问题多次计成不同独立失败。工具生成速度作为过程指标单独记录，质量分为结果指标；没有计费日志时不估算真实 Token 成本，不把字符数换算为实际费用。

## 4 统计与一致性

候选统计方法依赖分数是否有序、是否连续和是否重复测量。本方案只规定选择流程：评分尺度确定后，根据数据属性选择相应方法，不在此锁定某个显著性检验。两名评审的分歧处理流程与一致性评价指标尚未确定，不默认任何指标。

## 5 限制

实验尚未运行，无准确率、显著性、成功案例数量或用户结论。即使多个模型给出相似结论也不构成研究完成证据；方案安排人工评阅与可复核任务标准，专业领域判断尚需专家参与。交互式计划确认的最大轮次和终止规则尚未确定，不默认任何轮次或提前终止条件。评分尺度等级与锚点未定，相关分析需等待预注册确认后执行。


## 附表A：变量与分组

| 变量 | 类型 | 取值/说明 |
|---|---|---|
| 提示词准备方式 | 自变量 | 原始需求；直接增强；交互式计划确认；信息量匹配对照 |
| 任务 | 固定因素 | 二十个任务，开发与写作两类 |
| 重复次数 | 固定因素 | 每条件每任务三次独立重复 |
| 模型版本、日期、参数 | 记录变量 | 每次生成时记录 |
| 需求保真 | 因变量 | 顺序尺度，具体锚点待定 |
| 业务规则 | 因变量 | 顺序尺度，具体锚点待定 |
| 输出可用性 | 因变量 | 顺序尺度，具体锚点待定 |
| 阅读负担 | 因变量 | 顺序尺度，具体锚点待定 |
| 执行边界 | 因变量 | 顺序尺度，具体锚点待定 |
| 工具失败/首轮失败 | 记录变量 | 保留，不替代第一份失败样本 |
| 生成速度 | 过程指标 | 单独记录，不进入质量分 |

| 组别 | 输入信息 | 是否经历问答 | 备注 |
|---|---|---|---|
| 原始组 | 原始需求与初始材料 | 否 | 不得接触计划确认组答案 |
| 直接增强组 | 同一初始信息生成的优化提示词 | 否 | 不得接触计划确认组答案 |
| 计划确认组 | 初始材料＋问答确认后生成提示词 | 是 | 记录问题、选项、推荐依据、答案 |
| 信息量匹配对照组 | 初始材料＋相同已确认事实 | 否 | 不经历问答过程 |

**答案卡记录字段（计划确认组）** ：任务编号、问题序号、问题原文、选项列表、系统推荐依据、操作者选择、是否纠正系统推荐、纠正原因、最终确认事实。

**材料目录** ：真实实现、用户说明、测试示例、待办四类来源标签分别归档；测试示例与正式说明分开存放。
