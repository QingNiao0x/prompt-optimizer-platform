# 提示词整理工具对照研究方案

## 1. 研究问题

本研究比较三种提示词准备条件对下游任务输出的影响：原始需求直接输入、经直接增强后的提示词、经交互式计划确认后生成的提示词。核心问题不是“哪家产品更好”，而是：在相同初始材料下，不同提示词整理方式是否带来可区分的结果质量差异；当交互式计划确认额外获得业务确认答案时，新增信息与交互组织方式各自贡献多少。

## 2. 实验设计

固定二十个任务，每个条件独立重复三次，共二百四十次下游生成。两名盲评者独立评分。所有工具获取相同初始材料。

四个条件：

- **A 原始组**：下游模型直接接收原始需求与初始材料。
- **B 直接增强组**：接收由同一初始信息生成的优化提示词，不接触计划确认组的业务选择。
- **C 计划确认组**：系统先提问，实验操作者按预先制定答案卡作答，再生成最终提示词。记录每个问题、选项、推荐依据和答案；错误推荐被答案纠正后仍计入交互阶段风险。
- **D 信息量匹配对照**：获得与 C 组相同的已确认事实，但不经历本平台问答过程。用于区分新增信息与交互组织方式的影响。

A、B 两组不得接触 C 组后来回答的业务选择。每个条件的三次重复开启隔离会话，随机化顺序，记录模型版本、日期和参数。失败后的重试不能替代第一份失败样本。

## 3. 主要指标

质量评分采用顺序尺度，具体等级与评分锚点尚未确定，不自行指定。评分维度为：需求保真、业务规则、输出可用性、阅读负担、执行边界。一个错误可能同时影响多个维度，评分表记录主错误和关联维度，避免同一问题重复计为独立失败。工具生成速度作为过程指标单独记录，质量分为结果指标。无计费日志时不估算 Token 成本，不以字符数换算费用。

## 4. 盲评与一致性

评审看到匿名化下游输出和等量任务信息，不展示产品名称、标志和生成来源。评审可查看任务事实，但不能查看另一名评审的先前评分。分歧处理流程与一致性评价指标尚未确定，不锁定具体指标。

## 5. 统计方法选择流程

候选统计方法依赖分数是否有序、是否连续、是否重复测量。方案只说明选择流程：待评分尺度与锚点确定后，依据测量属性选择相应方法；在变量属性未确定前不锁定显著性检验。

## 6. 限制

本研究为合成资料演练，不代表真实平台运行数据。专业领域判断尚需专家参与，模型输出相似不构成研究完成证据。交互式计划确认的最大轮次和终止规则尚未确定，不默认任何轮次或提前终止条件。


## 附表一：变量与分组

| 变量 | 类型 | 取值/说明 | 状态 |
|---|---|---|---|
| 提示词准备条件 | 自变量 | A 原始 / B 直接增强 / C 计划确认 / D 信息量匹配 | 已确定 |
| 任务 | 控制变量 | 二十个固定任务 | 已确定 |
| 重复次数 | 控制变量 | 每条件三次独立重复 | 已确定 |
| 模型版本、日期、参数 | 记录变量 | 每次生成记录 | 已确定 |
| 交互轮次 | 记录变量 | C 组实际轮次 | 记录，上限未定 |
| 交互终止规则 | 过程变量 | 尚未确定 | 待确认 |
| 质量评分 | 因变量 | 顺序尺度，等级与锚点未定 | 待确认 |
| 生成速度 | 过程指标 | 单独记录 | 已确定 |
| 失败样本 | 记录变量 | 首轮失败保留，重试不替代 | 已确定 |

分组信息量对照：

| 条件 | 初始材料 | 已确认业务事实 | 交互问答过程 |
|---|---|---|---|
| A 原始组 | 有 | 无 | 无 |
| B 直接增强组 | 有 | 无 | 无 |
| C 计划确认组 | 有 | 有 | 有 |
| D 信息量匹配对照 | 有 | 有（与 C 相同） | 无 |
