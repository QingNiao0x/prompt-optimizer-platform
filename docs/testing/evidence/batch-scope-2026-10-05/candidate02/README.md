# 候选02业务验收原始证据

此目录冻结候选02的公开合成业务评测，**不是最新候选03的验收结论，也不是上线放行证明**。各业务文件保持原始字节，未以成功重跑替换首次失败。

- `api/known02/`：既有失败场景的 Plan、直接增强与最终增强 JSON、公开模型目录、输入清单及20份候选源码快照。
- `api/scenes-M02/`：16道跨行业中等长度题的两个已开放 DeepSeek 模型结果与输入清单；长题未完成资料不混入。
- `answers/`：实际问题ID绑定的逐题审核答案与中等题审阅说明；没有答案卡支持的新条件保持未决。
- `downstream/`：两次独立下游真实执行的输入、任务、作品、失败JSON、匿名任务/作品、映射、首半与后半AI辅助审阅及原配对报告。
- `external-reviews/`：对应外部模型的原始评分与下游输入。

本包共复制 **605** 份原始业务文件、**8,755,881** 字节（8.35 MiB）。每份均通过源文件/复制件SHA256一致性检查；来源、目标与摘要见 [源文件SHA256清单](./源文件SHA256清单.json)，纯校验列表见 [SHA256SUMS](./SHA256SUMS.md)。目录说明与生成的校验清单不属于模型原始返回，不列入自身校验。

保留边界：

- 首轮失败、非SUCCESS的执行JSON以及原有匿名评分完整保留；缺少作品正文的失败不能被成功作品平均分隐藏。
- 下游执行状态分布：`{"SUCCESS": 103, "FAILED": 1}`。这是文件中的运行状态，不代表专业业务验收。
- 匿名模型/Agent评分是辅助证据；独立人工及医院、医学、法律等专业评审仍为 **PENDING**，没有把待评审项改写成PASS。
- 模式比较须区分原始信息组与确认信息匹配组；Plan新增了用户回答时，不可把多了信息的结果直接当成提示词改写优势。
- 未归档 `auth`/`credentials`、`.claim.json`、运行配置、密钥、Java class、服务器日志；候选源码快照只含明确授权的公开 `.java` 文件。
- 本目录的局部 `.gitattributes` 禁止 Git 换行转换，避免检出证据时改变原始字节与 SHA256；不影响目录外的源码和文档。
- 静态敏感信息扫描没有匹配疑似凭据，但这不能代替专业安全审计。候选03及随后合并的评审报告由主任务另行记录，不覆盖本包。
