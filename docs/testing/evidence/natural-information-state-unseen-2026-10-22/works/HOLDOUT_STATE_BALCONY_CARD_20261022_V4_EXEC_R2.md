## 照着做的步骤

### 薄荷：每天傍晚（周一至周日）
1. **检查**：用手指轻摸薄荷表土，同时查看托盘。
2. **判断与动作**：
   - 表土**摸着干** → **少量浇水**。
   - 表土**仍湿** → **当天不浇**。
3. **托盘**：查看托盘是否有积水；有积水就按日常检查处理，不虚构结果。今天托盘尚未查看，从今天起纳入日常检查即可。

### 绿萝：只在周三、周六
1. **检查**：用手指轻摸绿萝表土。
2. **判断与动作**：
   - 表土**干** → **浇水**。
   - 表土**湿** → **跳过**，当天不浇。
3. **其他日子（周一、周二、周四、周五、周日）**：不检查、不浇水，不增加检查日。
4. **托盘**：今天已检查为空、无积水；后续按实际查看结果处理，不预设。

## 执行提醒
- 两盆都只以**表土实际干湿**为准，不按天数猜干湿。
- 薄荷每天只检查一次，固定在傍晚；绿萝只在周三、周六检查。
- 每天全部操作控制在 5 分钟内，检查完即结束，不做额外操作。
