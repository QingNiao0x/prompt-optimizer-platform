# 阳台照料清单（周一至周日）

**总原则**
- 每天操作控制在 **5 分钟以内**。
- 不换盆、不购买任何东西。
- 不预设今天该浇或不该浇，只看表土干湿再决定。
- 薄荷：每天傍晚检查；绿萝：只在周三、周六检查。
