## 操作说明（照着做）

### 薄荷（每天傍晚，周一至周日）
1. **检查**：用手指轻摸薄荷表土。
2. **判断与动作**：
   - 摸着**干** → **少量浇水**。
   - 仍**湿** → **当天不浇**，只完成检查。
3. **托盘**：顺带查看薄荷托盘有无积水；有则按日常习惯处理，无则不动。今天尚未查看，不预设结果。

### 绿萝（只在周三、周六）
1. **检查**：用手指轻摸绿萝表土。
2. **判断与动作**：
   - 摸着**干** → **浇水**。
   - 仍**湿** → **跳过**，当天不浇。
3. **托盘**：周三、周六检查时顺带查看绿萝托盘有无积水；其他日子不检查、不浇、不处理。
4. **不新增检查日**：周一、周二、周四、周五、周日不对绿萝做任何检查或浇水。
