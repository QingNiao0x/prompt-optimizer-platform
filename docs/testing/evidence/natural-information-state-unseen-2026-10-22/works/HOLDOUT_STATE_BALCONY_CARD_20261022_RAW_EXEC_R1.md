# 阳台照料清单（周一至周日）

**总原则**
- 每天最多 5 分钟，只做“检查 + 必要时浇水”。
- 不换盆、不买新东西、不增加新的检查日。
- 判断标准统一：**手指轻碰/插入表土约 1–2 厘米，摸着干才少量浇水；仍湿就当天不浇。**
- 浇水只浇到表土湿润即可，不追求浇透；托盘如有积水，顺手倒掉。
- 薄荷每天傍晚检查；绿萝只在周三、周六检查。

## 每天固定动作（按顺序做，约 1–3 分钟）

1. **看托盘**：有积水就倒掉。
2. **摸表土**：只摸当天该检查的植物，约 1–2 厘米深。
3. **决定是否浇水**：
   - 干 → 少量浇水，浇到表土湿润。
   - 湿 → 当天不浇，直接结束。
4. **收尾**：把托盘放回原位，洗手。
