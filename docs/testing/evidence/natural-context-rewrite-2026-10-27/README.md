## 准备真实输入

浏览器先通过工作台选择新合成项目，执行真实本地索引与检索，捕获实际请求DTO。这一步可在发送模型请求前暂停；不能由脚本另造更简单的上下文代替浏览器结果。合成项目及其干扰文件由本轮夹具提供，不外发用户原附件或真实业务源码。

把实际捕获内容整理成以下 bundle，写在本轮证据或临时目录。`approvedEnhancementInput` 为实际DTO；`approvedModelRequest` 为三臂共同参数和材料的完整执行请求。评分卡仅留在检查程序，不进入增强或执行载荷。

```json
{
  "syntheticOnly": true,
  "cases": [{"id": "C01", "rawPrompt": "合成需求", "contextDescription": ""}],
  "jobs": [{
    "id": "C01_V45_GEN",
    "phase": "GENERATION",
    "caseId": "C01",
    "version": "45",
    "approvedEnhancementInput": {"rawPrompt": "实际捕获的完整请求"}
  }]
}
```

执行 `node freeze-live.mjs live <bundle相对仓库路径>` 只冻结新阶段，不启动服务或调用模型。首次真实调用前，核对具体题目、合成文件、官方目的地、平台模型及实际上游模型与参数。此入口仍服从运行环境的真实审批结果。

## 启动和调用

先完成产品编译。`start-live.ps1 -Stage live -SkipCompile` 使用已核实的真实JDK目录，复制当前编译产物成不可变运行副本，编译独立计量入口并启动9013。它不会执行Flyway、创建账号或重启日常服务。浏览器可使用独立Vite端口5183代理到9013，避免与注册链路测试争用端口。

`invoke-live.ps1 -Stage live -Job LOGIN` 从既有DPAPI夹具向本机进程注入合成账号凭据，通过正常CSRF和验证码登录一次。会话和供真实浏览器复用的 `browser-storage-state.json` 只写入本轮 `tmp/.../auth` 私有目录，不输出Cookie或提交。后续 `invoke-live.ps1 -Stage live -Job C01_V45_GEN` 复用该会话，先核对真实身份和工作区，再执行已经冻结的作业；会话失效时停止并提示重新登录，不隐式重复模型作业。

密码、会话和模型密钥不进入公开原件。模型请求在服务器传输层先占预算再发送，空预留与失败均计数，达到任务总数200时阻断。验证码图片只保存在临时账号目录。

`invoke-live.ps1 -Stage live -Job COUNT` 仅只读统计。旧阶段总账只读，不重开闭批入口；阶段完成后另存本轮统计与关闭记录。

1. 先核对后台实际阶段包含正文生成，目标文件进入上下文，最终正文没有批量源码拼贴，展示、复制和历史内容一致。
