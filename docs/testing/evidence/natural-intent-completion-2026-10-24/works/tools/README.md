# D03匿名分页作品检查

本目录工具依据`../../regression/cases.json`中D03原始执行材料与验收编写，不读取候选提示词、版本或匿名映射，也不调用模型。

保留旧闭批检查器的五组行为预期，新增原契约内的省略options、空数组、空白和非字符串keyword、严格ACTIVE、原始顺序、单条分页及整页边界。每组分别用可变和冻结输入执行，核对完整返回记录、原数组和元素值、固定返回字段、页码与总数；这避免仅冻结输入并比较id时隐藏元素写入或值改变。

运行`node selfcheck-pagination.mjs`先验证独立参考实现及12份故意错误夹具，结果仅写入新文件。参考实现与故障不属于任何候选作品；它们的检查轮次不算产品收益。

匿名作品生成后运行：

```text
node check-pagination-works.mjs <只含work-数字.md的匿名目录> <新的输出JSON路径>
```

工具沿用选最后一个完整分页实现的约定，记录代码块数量。若源码超出纯函数执行范围或提取不确定，结果为`UNEXECUTED_NEEDS_REVIEW`，需人工查看，不能算通过或直接判业务失败。执行只提供VM内创建的合成数据，关闭动态代码生成，不注入宿主文件、网络或进程入口；实际执行前仍需人工确认所选代码是纯分页函数。

行为通过只说明本契约内的分页行为成立，不证明说明文字正确、未虚报测试，也不证明提示词质量、成本收益或候选采用。作品的必要修改量、无关改动及说明负担需另行审阅。
