# 共享拍摄包借还操作卡

> 打印后贴在器材柜门内侧或柜门旁。整套借出、整套归还；手机自带，不在包内。

---

## 一、拿包前：先看柜上状态

1. **看柜层标记**：包放在标有“**可借**”的一层，才可拿走。
2. 若标的是“**待补/异常**”：不要拿走，先看卡下方“缺件与异常处理”，并在工作群说明情况。
3. 确认要**整套借出**，不是只拿其中一件。

---

## 二、借出核对（按取用顺序）

> 在卡上“借出勾选栏”逐项打勾；缺件或异常写到“缺件/待补记录”栏。

1. **先确认包体与清单**
   - [ ] 带拉链收纳包 1 个，拉链可用
   - [ ] 包内清单卡/本卡所列 5 项与实物对应
2. **再逐项核对配件**
   - [ ] 桌面三脚架 1 个
   - [ ] 手机夹 1 个
   - [ ] 夹式麦克风 1 个
   - [ ] USB-C 连接线 1 根
3. **最后确认存放条件**
   - [ ] 包内大格、两个小网袋位置无空位（每件都在固定归位处）
   - [ ] 拉链可正常拉合，包体无破损
4. **群内登记（只记录，不是审批）**
   - 在现有工作群发消息：**谁拿走 + 预计何时归还**。
   - 发完即可拿走，**不需要等人批准**。
5. **改柜层标记**
   - 把包放回柜内后，将该层标记改为“**已借出**”（用现有白纸+胶带+记号笔）。

---

## 三、归还核对（按放回顺序）

> 在卡上“归还勾选栏”逐项打勾；有缺件或异常必须写清。

1. **先确认包体与清单**
   - [ ] 收纳包 1 个，拉链可用、包体无新增破损
   - [ ] 包内 5 项清单与实物对应
2. **再逐项核对配件并归位**
   - [ ] 桌面三脚架 1 个 → 放回固定位置
   - [ ] 手机夹 1 个 → 放回固定位置
   - [ ] 夹式麦克风 1 个 → 放回固定位置
   - [ ] USB-C 连接线 1 根 → 放回固定位置
   - [ ] 大格、两个小网袋均无空位
3. **最后确认存放条件**
   - [ ] 拉链拉合
   - [ ] 整包放回器材柜原层
4. **群内登记（只记录，不是审批）**
   - 在现有工作群发消息：**已放回 + 有无缺件或异常**。
   - 有缺件/异常要如实写，**不得标成完好可借**。
5. **改柜层标记**
   - 全部齐全且正常 → 该层标记改为“**可借**”。
   - 有缺件/异常 → 该层标记改为“**待补/异常**”，并在卡上记录。

---

## 四、缺件或异常：标记与处理

1. **发现缺件**：在“缺件/待补记录”栏写：缺什么、发现时间、发现人。
2. **发现异常**（如拉链坏、麦克风无声、线破损）：写：哪件、什么现象、发现时间、发现人。
3. **柜层标记**：立即改为“**待补/异常**”，不要放成“可借”。
4. **群内说明**：在现有工作群如实告知，让下一位知道不能按完好整套借。
5. **不要自行购买或替换**；等团队按现有条件处理后再改回“可借”。

## 六、存放条件提醒

- 整套放回**办公室器材柜**；上下两层均可放，按柜层标记区分状态。
- 包内用**大格 + 两个小网袋**固定归位，归还时每件回原位。
- 只用现有**白纸、透明胶带、记号笔**做柜层和位置标记，不新增采购。
- 柜层标记只有两种可用状态：**可借** / **待补/异常**；借出期间标 **已借出**。

---

**一句话流程：看柜标 → 借出逐项勾 → 群里说谁拿/何时还 → 改“已借出”；还回逐项勾 → 群里说已还/有无缺件 → 齐全改“可借”，缺件改“待补/异常”并记录。**
