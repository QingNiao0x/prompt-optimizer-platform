## 三天晚饭安排（两人份，30–40分钟开饭）

### 先看库存与使用顺序
- **第1天必须用掉**：去骨鸡腿肉350克。
- **最迟第2天用完**：北豆腐400克、鲜蘑菇150克。
- **三天内尽量吃掉**：西红柿600克、西兰花350克、卷心菜500克。
- **可留到以后**：大米、挂面、鸡蛋、胡萝卜、土豆不必硬塞。
- **设备**：电饭煲、双灶、炒锅、煮锅都有，适合“一锅主食＋一炒一煮/一锅出”的省事组合。

**总体思路**：第1天用鸡腿肉做主力，同时消耗一部分西红柿和卷心菜；第2天集中用豆腐和蘑菇，配西红柿、西兰花；第3天用剩余西红柿、西兰花、卷心菜收尾，主食灵活搭配米饭或面条。三天不追求清空所有库存，只优先处理易到期的肉、豆腐、蘑菇和蔬菜。

## 第1天：鸡腿肉西红柿卷心菜焖饭＋快手西兰花

**晚饭吃什么**
- 主菜饭：鸡腿肉西红柿卷心菜焖饭（一锅出）
- 配菜：蒜蓉西兰花
- 主食：焖饭本身即主食，不再另煮饭

**两人份用量**
- 去骨鸡腿肉350克（全部用掉）
- 大米180克
- 西红柿300克
- 卷心菜250克
- 西兰花150克
- 葱姜蒜、生抽、盐、食用油适量

**省事做法**
1. 电饭煲里放米180克，淘洗后按正常米饭水量略少一点加水。
2. 鸡腿肉切小块，用生抽、少许盐、姜丝抓一下；西红柿切块，卷心菜切粗丝。
3. 炒锅少油，下葱姜蒜炒香，放鸡腿肉炒到变色，再放西红柿炒出汁，放卷心菜略炒软，加生抽和盐调味。
4. 把炒好的鸡肉蔬菜连汁倒进电饭煲，铺在米上，按煮饭键。煮好后焖5分钟再拌匀。
5. 煮饭期间，另用煮锅烧水，西兰花切小朵焯1–2分钟捞出；炒锅洗净后少油爆蒜末，下西兰花快速翻炒，加盐即可。

**搭配与减浪费**
- 鸡腿肉第1天全部用完，符合期限。
- 西红柿用300克、卷心菜用250克、西兰花用150克，都是三天内要尽量吃的蔬菜。
- 焖饭一锅出，少洗锅；西兰花作为清爽配菜，避免整桌只有焖饭。

## 第2天：西红柿豆腐蘑菇烩菜＋米饭＋凉拌卷心菜

**晚饭吃什么**
- 主菜：西红柿豆腐蘑菇烩菜
- 主食：米饭
- 配菜：快手凉拌卷心菜
- 可加：每人一个水煮蛋（可选，不强制）

**两人份用量**
- 北豆腐400克（全部用掉）
- 鲜蘑菇150克（全部用掉）
- 西红柿250克
- 卷心菜150克
- 大米180克
- 鸡蛋2个（可选）
- 生抽、米醋、盐、糖、葱蒜、食用油适量

**省事做法**
1. 电饭煲煮米饭180克。
2. 豆腐切厚片或方块，蘑菇切片，西红柿切块。
3. 炒锅少油，豆腐两面略煎到微黄后盛出；锅里补一点油，下葱蒜炒香，放蘑菇炒软，再放西红柿炒出汁。
4. 倒回豆腐，加少量水、生抽、盐，盖盖小火烩5–8分钟，收汁到家常浓度即可。
5. 卷心菜切细丝，用盐抓一下，倒掉多余水；加米醋、少许糖、生抽、蒜末拌匀。
6. 若加鸡蛋，煮饭时用煮锅顺手煮2个蛋，剥壳对半切配着吃。

**搭配与减浪费**
- 豆腐和蘑菇第2天全部用完，符合“最迟第2天”的要求。
- 西红柿继续消耗250克，卷心菜再用150克。
- 烩菜汤汁适合拌饭，不需要额外做汤；凉拌卷心菜省火、解腻。
- 鸡蛋是可选加项，不加也不影响这顿饭完整。

## 第3天：西红柿鸡蛋西兰花盖面＋清炒卷心菜

**晚饭吃什么**
- 主菜：西红柿鸡蛋西兰花盖面
- 配菜：清炒卷心菜
- 主食：挂面

**两人份用量**
- 挂面200克（全部用掉）
- 鸡蛋4个
- 西红柿50克（第1、2天共用550克，剩余约50克，正好收尾）
- 西兰花200克（第1天用150克，剩余200克全部用掉）
- 卷心菜100克（第1、2天共用400克，剩余约100克收尾）
- 葱蒜、生抽、盐、食用油适量

**省事做法**
1. 煮锅烧水，先煮挂面；面快熟时把西兰花小朵放入同锅焯1分钟，一起捞出沥水。
2. 炒锅少油，鸡蛋4个打散炒成块盛出；锅里补少许油，下葱蒜炒香，放西红柿50克炒软，加少量水、生抽、盐。
3. 倒回鸡蛋，放西兰花，快速翻匀成浇头；若汁少可加两勺面汤。
4. 把浇头连汁盖在面上。卷心菜切丝，另用炒锅少油快炒，加盐出锅。

**搭配与减浪费**
- 第3天把剩余西红柿、西兰花、卷心菜收尾，避免蔬菜放坏。
- 挂面200克两人一顿正好，不再额外煮饭。
- 鸡蛋用量4个，属于家常盖面用量；若想更省，可减到3个，不影响做法。
- 西兰花一部分同锅焯面，少开一口锅；卷心菜快炒几分钟即可。
