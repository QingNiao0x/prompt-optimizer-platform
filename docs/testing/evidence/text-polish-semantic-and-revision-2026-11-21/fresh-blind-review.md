# 新稿匿名初评

开发侧初评读取原文、同一编辑要求和经过乱序的 A/B/C 正文后先记录如下。评价首要问题是否解决，同时记录正文流畅、语义和要求执行情况。正式采用的两位独立评阅者尚未完成。

| 样本 | 明显解决主要阅读问题 | 正文与语义核对 |
| --- | --- | --- |
| 河东站抄表 | B | B 消除了入口处的等待，换表后补录减少在首句出现。笼统说明又出现在观察和比较条件之间，仍影响衔接。A/C 在开场均只整理措辞或标点。其他站、人员不同、只查白班和归因未知均保留。 |
| 通行证交回 | B | B 先写周三中午前交到北门，再写代交，实际办事信息更易找。后面夹入「现将……说明如下」，仍像两段接错。各稿代交资格、核对后签收和号码不清暂存均保留。 |
| 碗沿随笔 | A | A 先写擦碗时碰到豁口及认出旧碗，读者直接进入场景。后置的「最舍不得的一眼，总想写下来」搭配稍硬，但仍保留作者感受和原结尾。B/C 只是缩短铺垫。 |
| 回访方法 | 无整体明显改善 | B 把纳入条件放在开头，查询更快；随即插入一整句不自然的「为便于后续分析条理开展」，把纳入与标记步骤隔开。A/C 用冒号在一句内交代纳入条件，同样容易找到。各稿日期与方式、分开标记、核对和暂排除均保留。 |
| 借伞调研 | A/B | A/B 字面一致，直接汇报只查周四晚和观察结果，C 仍保留套话。各稿不推断原因，保留引语、来源和不能外推的限定。 |
| 装订台 | C | C 最早出现压杆动作，后面插入原场景说明打断流程。A/B 原范围和 C 一致，许可、抽出方向、停工条件和通知对象均保留。 |
| 自然稿 | 三篇持平 | 逐字保留。 |
| 临时钥匙 | 三篇持平 | 更换逗号、分号，对阅读影响有限。登记、截止、提前终止、签字和引语均保留。 |

本次初评未发现重要语义变化。「不移动书脊」的操作适用条件虽然留在装订段内，重排后读者可能先看到通用动作，再读到范围，作为表达风险留待复核。
