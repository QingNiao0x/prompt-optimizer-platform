# 中文轻度定向修订的新稿对照条件

已见三篇经一次修订均先呈现了读者需要的信息。报告和论文仍在段尾或句中保留了不必要的说明套话，随笔保留作者想记下这一幕的意思。三篇复查未发现重要语义变化。修订增加 3 次请求、1899 Token、3305 ms，仅为小样本机制验证。

新稿先固定八篇，四篇核心稿分别为行业报告、工作材料、随笔与方法论文，另有调研混合文体、陌生操作说明、自然稿、严格限定稿。每篇分三份：v3、定点编辑初稿、基于同一初稿的一次定向修订。两份初稿完全同输入，开场目标同时写入两边的用户要求。修订输入中的目标与用户要求一致，只有 P2 可换，正文其余部分由代码复用。人工评分答案不发送。模型与参数全程一致。

匿名评阅对比相同原稿的三份正文。重点记录开场和整体阅读是否改善、表述是否更拖沓、所有独立意义是否保留。相对 v3 采用门槛仍为四篇核心稿至少三篇主要问题解决、至少两个用途胜于 v3、胜多于负、重要语义错误为零，并保留独立评阅要求。自然稿允许持平。样本范围仅限中文轻度且有首段编辑目标的请求。

最多允许初稿 32 次真实尝试，修订 8 次。已开始的请求落入账本，闭合后不得重跑。阶段目标是确定额外的一次请求能否带来可复现的阅读收益，并记录耗时、Token 和语义代价。
