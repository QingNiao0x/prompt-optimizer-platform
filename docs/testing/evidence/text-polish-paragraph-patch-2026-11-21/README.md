# 中文轻度定点编辑候选对照

候选 `text-polish-paragraph-patch-v1` 通过显式策略配置进入受控实例。仅中文轻度请求可选用。上游输入保留完整文章与用户要求，另附服务端段号。回复只交代哪些段要替换，服务端拒绝重复或越界段号和换行结构变化，按原有分隔符组装完整正文。现有原样锁定校验仍作用于组装结果。其他幅度和语言从同一显式配置回退至 v3。

639 项文章及试用模块后端回归通过，覆盖重复段定位、未改段和空白原样、未知或重复段号、退回整篇 JSON 的结构冲突，以及协议修复沿用同一份段号和首次策略。

## 对照结论

新增八篇中文轻度稿，每篇对照一次 v3 和定点编辑候选。实际模型及参数固定为 DeepSeek Flash、温度 0.2、关闭思考、非流式和 JSON。业务输入及原文一致，候选额外发送段号索引以执行替换协议。另为同一份候选成稿做一次影子核验，评阅卡只用于人工评分。[固定题集](samples.json) · [匿名初评](blind-review.md)

候选四篇核心待改稿中 **1/4** 篇解决主要问题，v3 为 **0/4**。八篇相对阅读 **2 胜、6 平、0 负**。展板领取先写截止时间及签收动作，拟音说明压缩了铺垫，但「有两种走法」是否把本次范围泛化仍需核对。报告、随笔和论文的主要开场障碍仍在。木尺混合稿两组都变直接，自然稿两组都逐字保留，严格限定稿均保住许可、时限、职责和引文。结果来自一位开发侧盲评者。两位独立真人评阅仍待完成。

| 影子结果 | 篇数 | 复核 |
| --- | ---: | --- |
| 未发现差异 | 4 | 展板、随笔、自然稿、凭证限定稿与初评的核心语义检查相符。 |
| 待核 | 3 | 夜班报告、方法论文、拟音说明都把「不含独立含义的段号」数组写成对象数组。严格解析正确拒绝，实际未能提供可用判定。 |
| 差异 | 1 | 木尺稿被判为来源归属变化。引文、管理员身份和登记范围原样保留，核验器把段首的过渡调整当成来源变化，属于本轮初评误拦。 |

影子核验对候选只读，产出供比较。这批稿没有验证出减少重要语义错误的收益。若以该核验结果直接筛选，八篇中四篇会进入保留原稿或待核，其中包含一篇有阅读收益且语义经初评保留的混合稿。
