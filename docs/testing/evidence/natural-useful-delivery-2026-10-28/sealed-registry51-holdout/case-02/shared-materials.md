# 共同材料二：一家三口的工作日晚餐

本文件是增强提示词和执行作品共同使用的完整材料，两端提供相同版本。这是普通家庭的家常安排，不涉及疾病饮食、减重或专业营养治疗。

家里是两位成年人和一个十岁孩子，周一到周五晚餐按三人准备，早餐、午餐不在本次安排范围。三人食量一般，希望每晚有吃得饱的主食和蔬菜，蛋、豆制品、肉或鱼可以灵活搭配，不要求固定几菜一汤，也不要求顿顿做新菜。两位大人想减少临时决定吃什么的负担，希望能知道该买什么、哪些事提前做，到了当天能顺着做完。

全家都能吃普通米饭、面条、鸡蛋、豆腐、鸡肉和猪肉，没有已知食物过敏。孩子不喜欢带明显鱼刺的菜，也不吃很辣的食物；其中一位大人不喜欢香菜，另一位想吃辣时可以自己在餐后加调味，不需要另做一套正餐。家里没有要求完全素食或只吃某一类食材。希望口味有些变化，但不必为了五天不重复而买很多只用一次的酱料，也不要把不喜欢某道菜解释成医学禁忌。

家里已有大米约两公斤、挂面约五百克、鸡蛋八个、两盒各约四百克的鲜豆腐、菠菜一把约三百五十克、胡萝卜两根约三百克、冷冻玉米粒约五百克。鲜豆腐和菠菜希望在前两天优先用掉，其他现有食材不必为凑数字全部用完。常用油、盐、酱油、醋和少量蒜姜够用，这些基础调味品不计入采购预算。周日买菜前会核对数量，如少了一点可以在采购时补齐，不需要因为估计数不是称重结果就停下整份计划。

新增食材和必要小调料的五天合计预算为三百五十元，不是每天的额度。附近普通超市和菜店能买到常见食材，不需要网购、进口食材或品牌限定。给出合理的用量和费用估计即可，不要求查实时价格或精确到每一元；最好留一点余量，避免预算刚好用尽。家里愿意吃一次相近菜式的变化版，也能接受把部分已处理食材用在后一天，但不想连续三晚吃同一锅成品。

厨房有两个灶眼、一口炒锅、一口普通汤锅和能正常使用的电饭煲，没有烤箱、空气炸锅或洗切设备。冰箱冷藏区可再放两个中等保鲜盒和当天的少量生鲜，冷冻区也只有两个扁饭盒的空位。不要把大量一周成品都做完塞进冰箱，或默认还能冷冻许多大包装肉。需要短期保存的食材请安排清楚先后和分装，生熟分开，不依赖家里有人中途回家操作。

周日傍晚可以集中花五十分钟做准备，周日也能完成主要采购；周三晚饭后还能补买一次易坏或没买够的东西。平日从开始动手到上桌，周一大约有三十五分钟，周二只有十五分钟，周三三十分钟，周四二十分钟，周五四十分钟。这些时间不包含饭后洗碗，电饭煲可按它本身的功能提前预约做米饭。不要把周日预处理算成零成本时间，复杂的切配、腌制或预煮如果需要提前做，要放进可用准备时间内。

周二一位大人会晚约一小时到家，另外两人先吃，希望留出一份晚到后方便加热的饭菜，不另外再开火做完整一餐。周四有亲戚说可能来吃晚饭，目前还没确认；本次先按三人正常安排，给一个确认来人后容易加量或补一道菜的办法即可，不要默认四个人整周都在。孩子提过周五想吃披萨，只是建议，全家没确定，现有厨房也没有烤箱，可以采用适合现有条件的做法或另选普通晚餐。

朋友推荐过周日把五天饭菜全部做好再冷冻，家里尚未决定采用，而且目前空间有限；这不是本次必须执行的方案。家里愿意做必要备餐，但更希望在现有时间和储存条件内找到省心的安排。没有其他必须先问清的菜名、品牌或固定采购清单，普通的菜式选择和步骤设计已经委托给你。
