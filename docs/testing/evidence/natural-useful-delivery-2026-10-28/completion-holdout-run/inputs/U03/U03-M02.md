# 试行期间留下的十二条反馈

下面是志愿者从群消息和现场便笺中整理出的十二条反馈。整理时没有保存家庭编号，同一家庭可能留下不止一条，未主动反馈的家庭没有另做访问，文字只做了匿名和断句处理。

F01：周六拿到小推车，搬花盆很方便。如果每次都能看见柜里现在有什么，就不用先在群里问一圈了。

F02：我问电钻还有没有，下午没回复，以为都借出去了，第二天志愿者说其实有。我后来已经向邻居借到了。

F03：晚上七点来还梯子，门已经关了。才发现群公告写的是周二、周四，我记成了每天晚上都有人。希望领的时候就知道哪天能还。

F04：只用半小时也要赶固定时段，工作忙时确实不方便。不过能借到的话，比自己买一个省事。

F05：我前一天问能不能多借一天，群里没人回。第二天有人说我超时了，我也不知道该按哪个消息算。

F06：大家把电钻、梯子叫的名字不一样，我说小梯子，登记里写的是人字梯，差一点以为柜里没有。

F07：领工具的时候找充电器找了十分钟，志愿者也着急。要是配件和工具能放一起，可能好找些。

F08：最好再买两把电钻，周末肯定都用得上。我只问过一次，那天没借成。

F09：有人晚还就全体不许再借，才能长记性吧。我没有遇到过，只是看到群里在讨论。

F10：我周四还工具很顺利，志愿者还提醒检查有没有少东西。流程讲清楚其实不复杂，继续办我还会用。

F11：我没在群里问过，消息太多，怕打扰别人。公告最后一次更新是试行第一周，不知道现在照不照那个办。

F12：能不能把三天统一改成一周？有时拆开了才发现还缺个零件，一下做不完。但如果别人急用，也可以提前联系我商量。
