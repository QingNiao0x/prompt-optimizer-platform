# 工具借用服务的运行背景

青禾社区共享柜是虚构的邻里项目，试行了五周。柜内有电钻两把、折叠小推车两辆、人字梯两架，以及几套普通手工具。服务对象是已登记的本社区家庭，目前有32户完成登记。工具没有统一在线预约页面，居民在群里询问，志愿者看到后在共享表格里登记，领取和归还时再核对实物。表格目前只有工具名、借用家庭编号、借出时间、约定归还时间和实际归还时间，未单独记录未借成的询问。

两名志愿者轮班值守，每周二、周四18:30至19:30和周六9:00至11:00办理领还。柜子在社区活动室内，其余时间不能进入，也没有自助取还条件。普通工具每次借用三天，同一家庭同时最多借一件。值守时可确认是否有人等候；遇到有人临时要求延长，志愿者有时直接在群里答应，有时请对方先归还再问，尚未形成一致做法。

五周共有58次成功借出，其中51次在约定期限内归还，7次逾期；这7次里有2次事先在群里问过延期。一次完整借出到归还记为一次，不能从58次推得有58个不同家庭。曾有一把电钻因缺少充电器停借两天，后来在柜子深处找回，尚无工具丢失。没有记录居民未借到工具后去哪里解决需求，也没有记录每条群消息对应哪一次借用。

下一轮仍由原来的两名志愿者承担，固定值守时段不能增加。可以继续用现有群和共享表格，允许调整登记方式、说明文字和柜内摆放。社区可拿出300元购买标签、收纳或其他小耗材，近期没有购买新工具、开发软件或新增收费系统的预算。社区希望服务可靠、居民容易理解，志愿者的额外处理工作也不要越积越多。
