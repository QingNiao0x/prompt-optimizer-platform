## 文件分工

- tasks.json：两条原始提示词与明确的附件映射，不包含答案或额外生成指令。
- materials/：每题两份完整材料；增强和作品阶段均使用同一内容与顺序，不截断、不摘要替换。
- answer-cards.md：独立审阅依据及必要修改记录方法，只供产品门、匿名作品审阅使用。
- execution-contract.md：三臂信息、输出范围、重复编号、预算和停止约定；执行前冻结实际模型参数与请求哈希。
- manifest.json：八份载荷文件的原始 UTF-8 字节 SHA256、字节数与文本字符数；不包含自身或 seal.json。
- seal.json：manifest.json 的 SHA256、候选冻结元数据和独占封存说明。
