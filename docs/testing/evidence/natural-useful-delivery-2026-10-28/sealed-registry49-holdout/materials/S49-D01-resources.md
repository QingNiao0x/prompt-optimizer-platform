# 新店开门活动：场地与资源清单

活动当天只有店主和一名助教，两个人都要兼顾讲解、接待与收拾，不能再加人。新空间消防核定同一时间最多十四人在内，包含两名工作人员；大桌能舒适坐八个人，旁边有作品架和一个小茶角。参观可以用作品架前的空地，走道、楼梯和院子都不能摆摊或排长队。常规拉坯课当天不开，窑炉区只隔着玻璃看，不让客人进入操作；不适合在活动里安排每人单独拉坯教学。

活动支出上限600元，现有茶壶、杯子、投影、纸笔都可用。新买茶点和简单纸质手作材料大约各需150—200元，设计时按估算写即可，不需要凑满预算。手里有三十张空白明信片、彩纸和胶棒，可做和新空间有关的小拼贴，做完能当场带走；这只是现成材料，不一定非要用。陶泥、上釉和烧制都牵涉后续排期，如果选这种体验，须算清两个人是否照顾得过来，以及客人何时怎样取件；为了简单，不做陶泥体验也完全可以。

店主想让熟客的旧作品也出现，可以在作品架摆几件已经获得展出同意的作品，现有授权只涵盖店内展示，没有社交平台发布授权。活动可以拍空镜和工作人员；拍客人、带姓名的作品或发合影，要先问清本人愿不愿意，来参加不等于同意宣传。拒绝拍摄的人照常参加。

一位熟悉的花艺老师说也许能来串场，但日期还没确定；目前不能把她列为嘉宾，也不用等她答复才把方案写出来。我们没有活动报名费，担心临时不来，可以设计一句温和的取消提醒，但不收押金，也不让客人提交身份证、单位等无关信息。店员希望最终能拿到一份照着执行的活动安排和一条可发给老客的消息；消息里搬迁与上课、取件要说清，别只顾邀请热闹。报名数、到场反应和新增销售都还没发生。
