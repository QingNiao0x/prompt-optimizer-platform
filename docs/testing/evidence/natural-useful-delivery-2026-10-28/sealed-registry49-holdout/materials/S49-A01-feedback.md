# 首场记录与反馈摘录

十八位店长全部参加，十六位交了匿名反馈。以下六句是为筹备会挑出的不同意见，不代表各观点的比例，不能按引述数量计算支持率。

- 新任店长甲：“商品选好了，下一页就已经提交了。老师在电脑上点得太快，我手机找不到批次在哪。”
- 新任店长乙：“我最怕把还能卖的东西报掉。题我都答对了，回店碰上临期酸奶还是问了群。”
- 资深店长甲：“听了半小时基本按钮，真正想问的超过两百和填错单子，到最后没时间。”
- 资深店长乙：“别再加课了。能给我一张查得着的卡，碰到例外知道找谁就行。”
- 新任店长丙：“最好让我跟着做一遍，卡里放个完成的样子，知道做到哪才算好了。”
- 资深店长丙：“讲师说了有问题随时打断，但群里消息滚太快，我没等到回复就去接货了。”

课后第二天，运营在巡店时让十八人各做一次模拟：为一批确已变质的商品报损，单笔240元，再处理一笔尚未确认、数量填错的单子。八位新任中三位能独立完成两步，五位需要提示；十位资深中六位能独立完成，四位需要提示。这个小检查没给错误逐项编码，也没有课前同题记录；它能提示实际操作还有缺口，不能证明是哪一段讲授造成的，也不能当成全公司水平。一次问卷中的满意不等于会处理例外。

运营当周接到的求助中，批次选择、200元边界、已提交后纠错都有；同一个人可能问多次，暂时不能算求助率。运营可以从下周的巡店记录中看三件事：能否不靠提示完成同类操作、金额越界是否正确转交、纠错是否走对入口。经理希望下周先把大家最容易卡住的地方讲通，也保留懂基础的人继续参加的价值；不用为每句意见都加一个环节，更不要让课堂变成新任和资深互相等待。现在要的是改好的下一场，而不是先做一轮更大的调查。
