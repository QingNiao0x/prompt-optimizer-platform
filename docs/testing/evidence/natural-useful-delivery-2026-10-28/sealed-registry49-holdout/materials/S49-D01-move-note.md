# 青檐陶艺搬迁信息：店主发给同事的便笺

我们做成人小班陶艺两年了，老客很多是下班后慢慢做东西的人。大家喜欢的是有人耐心讲、可以带着没完成的作品再来，不是来打卡买套餐。说话像平常发给熟客的消息就好，不想写“焕新盛启”那种口吻，也不想把搬店写成要停业很久。旧课程、剩余课时和储值都照常，不需要重新报名或补差价。

旧址是梧桐路18号一楼，11月6日上完最后一节课后关闭；11月7—8日搬家，不开放上课或取件。11月9日起在新址正常上课、取作品。新址是梧桐路76号青禾院内二楼，从临街蓝色小门进去，沿右边楼梯上二楼，入口不是旁边咖啡店；二楼没有电梯。两个地址都是这个合成情境里的业务信息，不需要查询地图或补造交通线路。

未领的作品会全部带到新址，11月9日起领取；原来约了11月7—8日取件的几位老客，由店员另行协商时间，目前还没逐个联系完。公开消息不必列这些人的信息，也别写成已经全部处理好。没有收到烧制完成通知的作品仍需等通知，搬家不代表全部烧好了。原来预约11月9日及以后课程的，时间和老师照旧，直接去新址即可。

我们想在11月14日14:00—16:00做个小型开门活动，主要请老客来认门、看看新空间，也欢迎每位老客带一位成年朋友，但同样要占名额。想轻松一点，不做折扣促销，不要求买课，不设入场消费。活动具体玩什么、怎样预约和排时间都交给你设计。可以直接回复店铺原来的微信预约，不用新建小程序。活动方案定了才会发邀请；请把你提出的名额、环节当成设计建议，不要写成店里已经办过或已经获得客人认可。
