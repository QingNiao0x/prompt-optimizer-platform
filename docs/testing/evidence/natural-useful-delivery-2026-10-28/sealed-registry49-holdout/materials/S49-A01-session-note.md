# 下周门店报损流程培训：筹备便笺

我们有六家轻食门店，新报损流程已经试用一周。下周再办一场线上课，参加的是同一批十八位店长：八位是近三个月接任，十位已做店长一年以上。课定在周二15:00—16:00，门店已调好班，只能用这一个小时，不能拆成两场强制培训。目标是让大家能自己处理当天报损，不是介绍系统所有功能。

本次版本的操作顺序是：选商品和批次，填数量及原因，核对系统按进货价带出的金额，再提交。店长能确认本店不超过200元的单笔报损；超过200元须转区域负责人，不能拆成几笔规避。临期但仍可售的商品先按现有促销流程处理，不直接算报损。图片只拍商品与批次标识，不拍顾客和收银小票。提交前可修改；提交后数量填错走撤回再提交，区域已确认的单据要联系区域处理，不能自行删除。

上次一小时安排：背景及价值10分钟、讲师连续演示25分钟、十道选择题15分钟、自由提问10分钟。演示用了两个商品，但都低于200元，没有演示撤回或已确认单据。选择题可反复看讲义作答，不能据此断定会实际操作。

下周仍由一位培训师讲，一位运营同事看群消息。会议软件有投票和群聊，没有分组教室；参训者在店里主要用手机看。可以提前发一张手机上能读清的操作卡，但不要求课前学习，也不把看卡作为听懂课堂的前提。演示环境有不含真实业务数据的练习账号，每人都能在自己手机上试；运营同事可以收文字或选项答案，没能力同时逐个远程接管。下一周可利用日常巡店核对操作，不另加一套打卡任务。
