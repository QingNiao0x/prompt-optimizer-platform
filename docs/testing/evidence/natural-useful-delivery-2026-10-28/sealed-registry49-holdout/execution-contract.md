# 封存后作品执行合同

这是事先的公平执行与记录合同，不是模型任务正文，也不授权本作者执行模型。答案卡不向任一生成臂公开。所有材料使用 tasks.json 指定路径的完整 UTF-8 文本与顺序。

## 阶段与调用上限

1. 协调者在已知失败回归和正常变体门通过后记录解封时间，验证本目录八份载荷、manifest.json 与 seal.json 的 SHA256，再读取题目。若封存已被破坏，停止作为留出使用，不能重写后保留旧封存称谓。
2. 执行前在本封存目录外独占保存 execution-freeze.json：实际增强和作品模型/供应商的稳定标识、采样参数、max output tokens、公共system完整字节哈希、材料拼接规则、请求构造版本、各观察ID及执行顺序。未知实际参数由执行方记录真实值，不能用本合同捏造。本合同固定作品模型三臂相同、输出上限各2600 tokens、工具权限相同；不因某臂输出更长而临时增加额度。增强31/49也在同一模型与参数下各题各生成一次；如增强协议需要不同输出上限，执行前一次冻结并两者相同，不按看到的正文调节。
3. 先获得四份增强正文：S49-A01-R31-ENH、S49-A01-R49-ENH、S49-D01-R31-ENH、S49-D01-R49-ENH。每份只生成一次，冻结采用的完整正文、协议响应、实际发送来源、材料和请求哈希，不在下游重复前再增强。BODY/完整响应问题保留原件；不得人工修正文后算原候选成功。
4. 每题原始/31/49各两次独立作品，总12个预编号作品观察；四次增强加作品规划16次模型调用，不含失败修复或另行付费评审。任何实际调用均进入协调者本轮总账。没有新增授权的质量重试；若平台内部协议修复无法关闭，须执行前冻结其最大次数并从正式任务剩余额度预留，修复与失败照实计数，不隐入“一次生成”。本题包本身新增调用0次。
5. 作品顺序预定：A01-R1为RAW、R31、R49；D01-R1为R49、RAW、R31；A01-R2为R31、R49、RAW；D01-R2为RAW、R49、R31。使用 tasks.json 的完整观察ID，不改名补抽。每次作品是新会话，无其他臂正文、历史作品、答案卡或评审反馈。

## 同信息作品输入

每一臂的user输入仅由该臂提示词、同题两份材料、相同的材料边界标记按相同规则组装。RAW使用rawPrompt原文；R31和R49分别使用冻结后的工作台可复制优化正文，不加入解析调试信息、理由、协议字段或来源列表代替正文。材料以“参考材料1/2 + 标题 + 完整正文”的顺序共用。原始臂获得完整材料，不拿掉已存在的事实或条件制造差距；增强阶段也必须可见同一两份完整材料。

作品允许完成用户委托的分析、课程安排、活动设计及成稿，并可作明确的合理设计选择；不得调用网页、文件写入、代码执行或外部发布。三臂相同的公共system只需说明：依据所给提示词与材料直接完成作品，使用中文，无外部工具；拟议设计与实际事实分清，不编造未给定的调查/效果，不因可合理设计的细节停下等提问。不得加入答案卡里的专门检查案例、要求独立卡片、额外章节数或超出原始范围的工作。冻结实际system全文与请求原字节，使system是否偷增业务要求可复核。

2600 tokens是输出容量上限，不是要求写满；两题都无需长篇报告、全套课件、采购明细或所有可能方案。输出截断、空响应、工具失败、协议修复与拒绝均保留为该观察事实；不能静默扩大预算或重做。内容过长可在审阅时记录其可用性影响，不事后降低完成要求。

## 产品门与停止条件

增强结果先过预先答案卡的共用产品门，才为该结果执行对应作品；严重意图、事实、权限、硬要求违约或最终生成失败先保留并定位，停止受影响候选/题的作品调用并结算未用额度，不以换题、人工补料或更多采样补胜。其他臂和题是否继续由协调者依 acceptance-plan.md 判断，必须注明受影响范围，不将未执行记成通过。

若直接通过产品门，按以上预编号次数执行；正常胜负反转、持平或原始臂已足够好都不是加采样理由。解封题发现缺陷之后不能拿本题调优再把修复后的结果标为未见泛化证据。不得把本次对照静默变成候选默认切换授权。

## 原件、匿名评阅与比较

逐次保存完整request/response原字节、传输归一化规则、模型/参数、计费token、时间、状态、来源与请求哈希。对原始/31的等效提示词照实标记：各观察原件保留，但不宣称同提示词条件下的采样差异是增强收益。本文允许既定两次独立观察，不授权看到失败后共享/替换观察。

作品收齐或按门停止后，在本目录之外生成匿名映射并隐藏提示词来源，使用冻结答案卡逐份记录必要修补与可选风格。内部代理评审仅称内部AI审阅，不冒充外部专家、用户试用或真人编辑用时。评审不向生成臂回流，不修改封存题、判据或失败原件。工程、可靠性、作品质量、候选采用及默认切换分别报告。没有数据的格子写未执行或未验证。
