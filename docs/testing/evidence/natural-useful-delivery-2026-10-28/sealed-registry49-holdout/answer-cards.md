# 独立答案卡：产品门、实际交付与必要修补

本文件仅供封存后审阅，不得进入增强请求、下游 system、作品材料或重试指导。没有唯一范文。所有臂按相同业务标准审阅，不能因为某臂没有采用增强提出的额外内容就判原始臂缺项；增强自己增加的规模、格式或附件不是业务硬要求。两题均已给出可完成工作所需的信息，不要求联网、额外调研或先补材料。

## 共用产品门

逐题保留实际请求原件及材料字节哈希，分别确认增强可见材料与作品可见材料。必要来源是 tasks.json 为该题映射的两份材料：允许增强正文简洁融合，不要求逐字粘贴全文；事实与条件必须可追溯。不得把另一题材料混入。原始提示词、31正文和49正文均使用同一完整作品材料，不用作品端补齐掩盖增强端缺失。若采用工作台，实际索引、检索片段、BODY_GENERATION、页面、剪贴板与历史证据按验收计划记录；没有经过的步骤明确标成未验证，不能凭API成功补判。分析与设计两题的原目标、明确否定、日期/数值边界、权限和交付范围都须保留。生成阶段不能交成执行答案、问卷或等待资料清单。

有效的正文增量应落到材料中真实的工作缺口：例如把需要解决的矛盾转成可执行的处理，或把委托设计转成能实施的方案要求。仅复述材料、加标题、加通用“核实依据”或让作品更长不算收益。正文持平、保留原文均允许。若正文自行加上更严的篇幅、步骤数、学员作业或交付物数量，记录其来源及是否限制了原需求；不要把该新增要求升级成答案卡义务。

## S49-A01：可观察验收

交付应是一份简洁的反馈判断加一版下周可用的一小时培训安排。可以连写，也可用表格；不要求全程逐字讲稿、完整幻灯片或新建培训系统。安排必须含具体教什么、怎样带着做、怎样知道学会了，让讲师不必把“互动”“强化实操”重新从零设计。示例数量和环节顺序开放。

必要核对：

1. 判断能解释新任跟不上与资深觉得基础冗长为何能同时成立，并识别基础路径、例外处理和提问反馈各自的实际缺口。不得把某组统一说成态度差或“资深都已经会了”。十八人的操作观察是新任3/8、资深6/10独立完成两步；可不换算百分比，若引用计算须正确。六条引述不代表频率，不能声称匿名反馈证明某意见占多数；无课前对照，不下培训造成能力下降等因果结论。
2. 安排总计60分钟，兼顾共同必会与差异化需要。应具体补足手机可跟做、200元以上转交、提交后纠错这些原有缺口；临期先按促销流程和商品照片范围仍须得到正确处理。可以把部分准确规则放在随堂口头说明或给出的操作卡，不强求每项单列时间段。不得让必须会的例外仅成为资深选学内容。
3. 一次同场培训、一讲师加一运营、手机参训、无分组教室均可执行。不要把强制课前预习、新增强制课或更多人力作为方案成立的前提；自愿延伸材料允许。步骤顺序可以优化，但不得取消原流程需要的商品/批次、数量/原因、核对金额或改变审批权限。200元本身由店长确认，240元转区域；不能拆单，已确认单据联系区域，尚未确认可撤回重提，不能一律删除或一律让店长改已确认单。
4. 至少有一个具体、可判断结果的课堂操作/情境检查，用来发现实际会不会处理，而非只问满意不满意、懂不懂；答案、预期动作或观察要点要能从作品中看出，不能让讲师再编核心检查。后续核对可嵌入现有巡店，不要求额外打卡或大调查。不同检查案例只要能检验相同关键能力即可，不强制复刻240元题。
5. 提问方式能让手机参训者有机会被接住，且两名工作人员能承受。可以用分段收题、固定停顿、选项汇总或其他可行方式，不要求每人逐一发言。若推荐操作卡，至少写出当场执行会用到的关键内容或结构加具体规则；不因未附独立精美卡片判错。提出的教学安排须标明为改进建议，不能虚构已实施效果。

硬错误：改错报损/审批/纠错规则；给出无法在共同一小时和既有人手实现的核心方案；把关键能力变成必须自学；冒充不存在的调查比例、因果或成效；只提补材料/调研而不交改好的安排。遗漏局部规则或执行细节是否达到硬错误，以是否导致错误操作、使安排不可用为界。

必要修补示例：把“200元及以上报区域”改为“超过200元”；给空泛的“15分钟实操”补上手机跟做步骤及成功判定；将超过一小时的安排压回60分钟；把需要新增人手的逐个远程接管改成可统一观察的方法；纠正错误比例。这里是修补类型，不是指定教学设计。若作品已用别的合理方法解决，不要求照改。

可选风格：是否取课程名、是否有表格、话术更活泼或更正式、是否逐字开场、示例商品选择、是否另附一页摘要、同样可行的环节排序。格式变好但无需业务修补时，只记格式收益，不记必要修改减少。

## S49-D01：可观察验收

交付应包括能照着执行的轻量开门活动方案和一条完整老客消息。接受同一文字内清楚分段，不要求海报、社交平台矩阵或完整营销漏斗。店主已委托设计活动玩法、名额和安排，作品可以合理作出选择，无需把这些决定全部退回提问。

必要核对：

1. 活动能在11月14日14:00—16:00落地，两名工作人员、总支出不超600元、同时在场不超14人含两工作人员。大桌只有8个舒适座位；可以限8位客人、安排可行轮换或采用不依赖全部落座的方案，没有唯一人数或玩法。若允许老客带成年朋友，朋友同样占预约名额，不能一边写限额一边无上限携伴。消息中的预约名额须与方案一致。
2. 至少说明活动做什么、主要时间顺序、两人如何分工、怎样用现有微信报名及简单取消提醒，足以着手执行。费用可分组估算，不要求逐项采购单或刚好用满。允许不用拼贴，也不强求陶泥体验；若选后续烧制项目，不能承诺当天拿走或漏掉后续取件安排。不能加人、安排客人进入窑炉区、堵走道或设计每人单独拉坯教学作为核心环节。
3. 不以折扣、买课、入场消费、押金或无关个人资料维持活动。没有嘉宾承诺；花艺老师未确认，不作为必到嘉宾或方案成立前提。新设计的主题、环节、限额可以在方案中明确为建议，并在随后的邀请草稿里按该设计完整表达；不把这些正常创作判成事实造假。不得声称已经报名满、已有客人好评或产生销售。
4. 老客消息要读得出旧址11月6日最后营业、7—8日不接待、9日起新址恢复，上课与取件去哪儿、未完工仍等通知、已约9日以后课程照旧且不需重报/补差价。消息须给新址梧桐路76号青禾院内二楼，蓝色小门进、右侧楼梯、不是咖啡店入口、无电梯这些有实际到达意义的信息可自然组织；旧址完整门牌是否重抄不作硬要求。7—8日原预约取件者另行协商，不能谎称全部联系完成。允许一句简洁“这两天原约取件我们会单独联系”，不要求公开列客户情况。
5. 邀请与迁址消息兼顾，不因活动热闹掩盖客户现有课程/作品怎么处理；语气友好清楚，不把只是两天搬迁写成长时间停业。活动是免费、非强制购买；不参加活动的老客仍照常享有原课程与取件安排。隐私边界可写在内部执行注意中，不必堆进客户消息：店内展出授权不能扩成公开发作品/人像授权；参加不等于同意拍摄或宣传，拒绝者照常参加。没有摄影安排时，不强制新增复杂授权流程。

硬错误：迁址日期/地址/既有课程权益/取件状态说错；活动核心依赖超预算、超场地或额外人手；承诺未确认嘉宾、未发生的报名或效果；违反收费、窑炉或拍摄权限边界；只给文案方向、活动提纲或大量待填空而没有可用成稿。消息遗漏到达楼层、无电梯或恢复日期等会导致客户跑错/白跑的信息属于必要修补，不以“文风简洁”免除。

必要修补示例：给可落地但未说明谁负责的关键环节补两人分工；为无上限携伴补同占名额及报名口径；把“一起当天带走新做陶器”改成可履行的活动及取件安排；补上消息里漏掉的搬迁停接待日期、入口或课程权益；删掉未确认嘉宾及未经同意的宣传承诺；收回不必要的押金。若原方案已有另一种可行安排，不要求换成上述示例。

可选风格：主题名称、标题与分段、是否使用表情、欢迎语、采用拼贴还是导览交流、先搬迁还是先邀请、具体茶点、是否将已有预算细分成三项。只要成稿清楚自然，不按唯一文案或活动玩法扣分。

## 作品比较及必要修改记录

先匿名逐份判能否直接交付，再比较，不从篇幅、标题或候选身份倒推。为每个需要修补之处保存作品原句、材料依据、受损的原要求、最小修补动作及影响；分为事实/规则、计算、语义遗漏、可行性、格式和可选文风。硬错误与其他必要业务修补分开，格式整理也单列，不用任意加权总分抵消硬错误。一个原因传播到多处可列出所有位置，但独立缺陷计一次；两个独立条件漏掉不能强行并为一个。

不把原任务本来要完成的设计劳动算成返修量，不测算未经真人实测的编辑分钟数，不以字数或修改行数定胜。对称标注每臂最小修补，不给优胜臂宽松解释。两份均可直接交付时，记业务持平；一份虽更好看但无必要修补减少，也只记风格/格式差异。

原始与31提示词若同字节或实质等效，保留各观察ID和原件，但把作品差异视为同一提示词条件下的采样差异，不归功于增强。关键两次作品胜负反转时按预定次数收口为未定；少量重复不证明统计显著或普遍因果。两题分别留结论，不能以一种任务的收益冒充跨任务稳定收益。候选协议可靠性与作品质量分别报告，采用仍遵守 acceptance-plan.md 的完整条件。
