# 阶段协议复用：只读调查，未采用

阶段DTO可以把`bodyQuotes`放在所属要求内，由服务端生成内部下标；这不要求移除来源、全部实际题答或组装前后覆盖保护。但不能直接将47加入`StageInstructions.supports`：Provider的RoutingRepair入口会先返回旧`taskUnderstanding`解析，48诊断也使用旧Coverage路径。若另做候选，须同时切换输出指导、读取器和诊断路径，归一化后继续走相同内部校验。

本轮没有实施此迁移，也不因可减少协议负担就声称正文更好。

- [历史阶段协议摘要](../natural-phase-protocol-2026-10-22/results-summary.md)：4与21最终有效率均9/10，21总token减少约11.6%，属于限定成本信号，不是稳定正文收益。23相对22主要移除框架参考，不是新协议本身。
- [24失败归因](../natural-phase-compatibility-2026-10-22/retry-diagnosis.json)：仍出现正文锚点错字及同文多题答来源遗漏，不能承诺就地绑定消除逐字引文成本。
- [本轮单次去记录实验](./protocol-ablation/results/ABQ01_BODY_ONLY.json)：移除任务记录后，查询正文仍以来源和统计口径组织。它不支持“删除协议就能解决内容重点”的强假设，也不足以估计稳定因果效应。

尚未验证的窄假设是：47正文语义和48定点修复不变，只将覆盖就地绑定，是否减少错索引、跨阶段字段及修复成本，且不伤正文和实际作品。该假设不自动开工。本轮先修复已经复现的有界修复缺陷，再单独验证增强writer的思考模式；不叠加两个变量。
