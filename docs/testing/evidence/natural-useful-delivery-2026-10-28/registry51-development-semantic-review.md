## Q01：查询全球使用 AI 最多的职业 / 行业

原输入为“请帮我查询全球使用AI最多的职业/行业”，没有提供统计资料、时间或口径。正文开头是：

> 请帮我查询全球范围内使用AI最多的职业和行业，并给出查询结果。

随后要求“说明哪些职业或行业在AI使用上排名靠前”，并尽量交代数据、调查或报告来源、使用频率 / 采用率 / 使用人数等口径以及大致时间；不同来源不一致时说明差异。主交付仍是职业与行业的查询结果，补充口径服务于结论，没有要求先选定一种口径、先收集全套资料或只交调研方案。

正文没有预先认定全球第一、编入百分比或假装已有统计。结尾“若无法获得可靠的全球性数据，请如实说明数据缺口，不要编造来源或数字”是证据边界，没有撤销前文查询及给出结果的任务。后续作品仍需实际核对来源是否只覆盖局部地区、样本或单一维度；当前提示词本身没有把这些局部数据升格为全球事实。

结论：可进入实际查询作品 / normal。此处没有验证任何职业或行业的真实排名，也没有要求下游固定榜单数量、来源数量或报告体例。

## U02：两周周末亲子共读试办方案

原输入已委托 AI 安排活动形式。正文保持这一委托：“活动形式由你安排”，并要求“让店主和店员拿到后能直接分工、准备和现场执行”。流程、选书、带场、分工、费用与简短记录均作为待设计的方案要求，没有伪装成店主已确认的决定或活动已发生的事实。

关键约束与执行补全如下：

| 原要求 | 实际正文核对 |
| --- | --- |
| 连续两个周六，14:00—17:00 内任意连续一小时 | 首段保留“连续两个周六下午”，第 1 项明确“活动只占用14:00至17:00中任意一个连续的一小时，其余时间留给正常营业和整理”。没有扩成三小时或只安排一周。 |
| 6—9 岁、每孩一位成人、最多八组 | 第 1 项完整保留适龄、同行人数和容量。对报名不足或超额要求处理办法，没有虚构报名及到场数量。 |
| 一人持续主持，另一人营业 / 收银 | 第 3 项明确只有店主和一名店员，“一人主持活动，另一人继续接待顾客和收银，不能长时间两人同时带活动，也不额外聘请老师”。前、中、后任务和交接属于对可执行性的合理补全，没有增加人手。 |
| 营业及通道保持、现有物资、无额外场地设备 | 第 4 项保留通道、书架前 / 收银台旁范围及销售区干扰条件，准确列出现有物资，并保留无投影、音响、游戏场地和不安排餐饮。 |
| 两周新增支出合计最多 600 元，免费无购书门槛 | 第 6 项明确“两周合计可新增支出600元”，限必要耗材及简单宣传；末段保留免费、无购书门槛、无赞助及不以售书评价。此处是两周总额度，正文没有要求必须花满或额外收费。 |
| 面对未知书名、参与差异及未知效果继续设计 | 第 2 项保留自带书名未知、儿童参与差异和成人陪伴差异，要求可操作的选书 / 分书及带场办法；没有以未知为由暂停设计。 |
| 试办关注参与、投入、人员承担能力 | 第 7 项要求当场或当天可完成的简短观察记录；末段明确不估算整个社区市场规模。记录是下轮判断的材料，没有预先声称活动有效。 |

末段的分工表、物资与预算清单、登记及记录样式，以及常见情况处理，与“店员能照着执行”直接相关，可作为本题组织方式接受。它们不是原判据要求的固定格式，也不能因提示词列得完整就认定下游已能执行。正文篇幅较长、较多重述材料，本轮没有发现由此产生的冲突、空模板、全任务推迟或重要条件误写；不把篇幅增加本身计为收益。

结论：可进入实际方案作品 / normal。后续需看真正交付的两周安排是否在一小时、单人主持与营业并行、总费用和现有物资内落地；当前交付仍是要求下游设计方案的优化提示词。
