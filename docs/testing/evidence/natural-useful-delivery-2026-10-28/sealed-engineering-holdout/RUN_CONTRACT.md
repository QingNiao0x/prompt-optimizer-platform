# 工程题统一执行合同

- 原始臂和优化臂必须得到相同的 inputs/project 全部文件，使用相同的项目导入范围、模型版本、参数、工具能力和输出上限。完整工程不能只向某一臂开放。各臂使用同一原始交付格式；优化臂只替换需求正文，不替换工程。
- 候选、模型、调用上限和阶段授权先在本目录外冻结，随后明确解封。该题不会自行授予真实调用或扩大预算的权限。一次正式执行保留首轮作品，不凭重试挑最好结果。
- 下游作品上限统一为 10000 output tokens。不得因某一臂输出更长而另加奖励，或单独增加 token、额外提示、补附件。实际模型若无法支持这一上限，应在运行前对全部臂统一确定可支持值。
- 执行器只接收 inputs/prompt.md 与 inputs/project；不接收答案卡、参考修复、检查器、自测结果或其他臂作品。全项目均为合成数据，不允许联网补业务事实。
- 作品是 JSON 文件替换包，检查器严格解析文本并验证允许修改路径，在内存中应用，不执行作品提供的脚本、npm 脚本或配置。不允许 shell、宿主 fs、process、Buffer、网络、动态 host import 或包安装能力。
- 使用当前工作区已有 Vue 3.5.41、TypeScript 5.7.3、@vue/compiler-sfc 3.5.41 编译。先由可信检查器编译 TS 和 Vue SFC，再把 CommonJS 模块函数与真实 Vue runtime 浏览器构建放入独立 VM 上下文。相对依赖只能解析到已给工程；vue 是唯一包依赖。
- Vue 页面由真实 Vue createRenderer 挂到 VM 内构造的内存宿主树，触发真实组件事件并检查响应和仓库状态。这证明组件脚本、模板绑定及交互链路，不证明真实浏览器布局、CSS 或无障碍效果。
- Node vm 在这里用于关闭作品可见的宿主能力，检查器不把宿主对象或函数注入 VM。字符串代码生成和 wasm 禁用，执行有超时。它不是宣称能抵御 Node/V8 漏洞的操作系统安全边界；不可信第三方作品仍应在额外进程/容器隔离中运行。
- 先记录检查器原版本失败、参考修复通过和错误变体/越界探针结果，再进行正式作品验收。检查器自身异常与作品失败区分。保留真实输入、增强响应、组装及复制文本、完整作品、文件哈希和检查原件。
- 按答案卡的业务、边界、交互及误改项分别报告，引用实际结果。编译通过、文件数量多或总分高都不能抵消核心业务失败。该单题只支持对应工程能力判断，不代表普遍真实用户效果。
