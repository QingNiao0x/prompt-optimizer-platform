# 社区器材借用台（合成工程）

这是一个完整的小型 Vue 3 + TypeScript 单页工程，所有地点、器材、借用单和金额均为虚构，不连接后端、模型或网络服务。两个当前业务入口是“新建借用”和“修改借用”，另有押金预览页面。数据仓库为可注入、每次读取都返回副本的内存实现，刷新页面会恢复初始数据。

依赖版本固定在 package.json，与本次环境已有依赖一致。不要安装或下载依赖。若在已有 Vue 工作区导入，可复用现有 node_modules；评测检查器会自行加载现有依赖并编译内存中的源码，不执行该工程的 npm 脚本、配置文件或作品脚本。

src/views 是当前页面，src/composables 管理页面状态，src/application 编排业务，src/domain 保存规则，src/data 提供合成仓库。src/legacy 是已退役旧台账；src/events 是另一套活动名额逻辑。它们不参与器材借用链路。押金页面只读，独立于器材可借数量。

当前版本有待用户修复的问题，验收要求见工程外的原始需求。请按现有边界修复，不把旧模块和当前链路合并。
