# 共同材料一：松桥小区中庭养护

本材料同时提供给提示词增强端和作品执行端，内容完全相同。以下是本次写作可使用的完整事实材料。

松桥小区有四栋住宅，中庭连接西门、东门和各楼栋门厅。中庭中央是一块铺装地面，边上有两排座椅和一小片花坛。过去两个月，物业收到几次关于雨后积水、两处地砖翘起的反馈。日常经过这里的居民很多，其中包括推童车的家庭、使用助行器或轮椅的老人。这次说明面向全体居民，尤其要照顾不熟悉临时路线的人。没有必要在说明中交代小区建设历史或展示物业工作成绩。

物业和业委会已经确认：本轮只处理中央铺装区的两处地砖、一个排水口和旁边松动的座椅固定件，不做花坛改造，也不增加游乐设施。材料没有给出积水的专业成因结论，不能把某个原因当成已经查明。费用从本年度已经批准的日常养护预算支出，本次不向居民另收费用。具体施工单位名称、合同金额和验收人员名单没有纳入这份资料，不需要替他们补上。

目前的计划工期为十一月二日至十一月九日，每天作业时段为上午九点至十二点、下午两点至五点。预计十一月二日上午开始围挡，十一月九日完成后安排现场检查。遇连续降雨或检查发现需要返工时，进度可能顺延。开始前以及需要调整时，物业会在业主群和各楼门厅公告板同步更新。尚未确认的完工日期不能变成保证，也不能先写成全部设施十一月十日必然恢复使用。休息时段不安排切割、钻孔等明显噪声作业；资料中没有承诺整个作业过程毫无噪声。

围挡只覆盖中央铺装区，西门继续开放，但从西门穿过中庭去一、二号楼的原直线路径暂停使用。一、二号楼居民可改走东侧连廊，经东门出入，沿途是连续平路，没有台阶；这条路线已由物业实地确认，作业期间保留至少一点五米净宽，每天开工前检查。三、四号楼原有的东侧通行路线照常使用。围挡搭好后会在西门内侧和一、二号楼门厅放引导牌。不要引导居民跨越围挡、借施工缺口抄近路，也不要把西门写成整门关闭。居民不需要记住所有施工细节，但应能据此找到能走的路。

物业服务台在一号楼一层，每天上午八点半至下午六点有人；居民可当面反映临时路线不便或围挡松动，也可把书面意见放进各楼门厅公告板旁的意见夹。物业每天下午五点收取意见并在次日中午前回复留有联系方式的居民。遇到急需协助通行的情况，可到东门值班室求助，该值班室全天有人。不在公开说明里虚构电话号码、二维码或网上登记入口，也不要让居民公开自己的房号、病情等信息才能反馈。

另有两项建议仍在讨论：一位居民建议在周六下午安排二十分钟的现场说明，另一位建议完工后增设一把长椅。前者的时间、地点和是否举办都未确定，后者不在本次养护范围内，业委会只同意把它记入后续议题。写作时可以不展开这些建议；如果提到，须让居民清楚它们并非本轮已经安排的服务或施工内容。对临时通行有特殊困难的居民，希望他们尽早通过现有渠道反映，由物业逐户沟通，不承诺资料中没有确认的接送、陪护或上门服务。
