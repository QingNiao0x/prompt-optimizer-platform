# 共同材料二：栎树文化馆亲子纸影故事活动

本材料同时提供给提示词增强端和作品执行端，内容完全相同。以下是馆方目前确认的条件与尚未确定的事项。

文化馆计划在十一月十五日下午两点至两点五十分，办一场免费的家庭纸影故事活动。已经接受十二组家庭报名，每组是一位成人带一名六至九岁的儿童，按二十四名参与者准备；临时缺席有可能发生，但不另设现场加人名额。大多数孩子没有做过纸影，也没有表演经验。活动目标是一起做出简单的纸影角色，并用它讲一段由家庭自己决定的小故事，不考察绘画、剪纸技巧，也不评选第一名。馆方希望有具体玩法，不需要专业戏剧课或完整演出制作方案。

活动使用一楼的多功能小厅，房间约六米乘八米，有四张长方桌、二十八把椅子，桌椅可以移动。门在短边靠右，是唯一出入口，门前和室内连接门口的通道必须保持畅通，不能用布幕或材料箱挡住。窗帘可以拉上一部分来改善影子效果，但室内仍要能看清走动的人和地面，不允许为了影子效果把全场熄黑。插座位置不适合让电线穿过活动区域，因此方案不得依赖插电灯具、电脑、投影仪或音响。场地可以在一点二十分开始布置，三点二十分之前恢复原样。

现成材料包括：六支能正常工作的电池手电筒、两块约一米二乘一米五的白色布、四个夹子、六十张厚卡纸、八十张普通画纸、五十根圆头手工木棒、彩笔、两卷纸胶带和十二把儿童圆头剪刀。手电筒的现有电池已检查，可以支撑本场使用。布可以作影幕，也可以另想不妨碍通行的安全用法，不要求一定同时挂起两块布。现有物品可在各组之间共享，不需要每家独占一套。没有刀具、热熔胶枪或专业支架，不能把这些当成现场必备条件。

馆方另外有二百元耗材预算，可在活动前买普通纸张、胶点或备用电池等常见用品。方案可以选用，也可以不花完。预算是总额，不是每组二百元；不要求精确到某家商店的报价，但新增用品的数量和费用应有合理的估算，不能依赖尚未确认的赞助。家庭不需要自带材料或额外付费。纸影角色和纸面故事可以带回家，手电筒、布和剪刀等馆内物品需要在活动结束时集中归位。

当天只有三位志愿者，分别是经常带活动的主持人、一位负责材料的志愿者和一位协助现场的志愿者。他们都不具备专业戏剧指导背景，可以照着清楚的步骤示范、提醒和帮忙。不要假定另有摄影师、儿童托管人员或能临时接手的第四位工作人员。成人必须全程陪同自己的孩子，志愿者不会替家长单独照管儿童。使用剪刀时由陪同成人留意，手电筒不对着他人眼睛照射，排队或走动时也应能看清地面。

报名备注里，有家长希望孩子带走一件作品，也有家长更在意一起交流。馆方不要求统一故事主题或统一造型，普通家庭能理解的不同玩法都可接受。不能把上台独自表演设为每个孩子必须通过的一关；愿意的家庭可以自愿分享，不愿公开讲的也应有完成活动的方式。可以给开头示例或简单启发，但不要替所有家庭规定同一个结局。活动不安排食品或饮料制作。

尚未确定是否会有对声音敏感或需要行动协助的参加者，目前没有收到具体申请。馆方愿意在开始前简单询问需要，并在现有场地和人员范围内调整，不能把未确认的个别情况写成已知事实，也不宜因此推迟整场方案。馆方允许记录空场布置和材料制作过程；若要拍到家庭的脸或公开作品署名，需另行征得本人及儿童监护人同意，本次没有统一摄影授权。活动不依赖拍照、线上发布或手机互动才能完成。
