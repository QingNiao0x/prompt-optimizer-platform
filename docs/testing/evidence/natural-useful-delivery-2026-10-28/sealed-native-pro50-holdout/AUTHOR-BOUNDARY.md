# 独立新题作者封存边界

本包由独立新题作者创作，包含两道不同内容交付任务。作者没有读取产品代码、开发题、现有模型结果或其他封存题，没有运行模型、API 或浏览器。作者只对本包作内部一致性审阅，不把该审阅称作外部专家评审，不声称真实用户修改时间。

每题的一份完整共同材料同时给增强端和作品执行端；原始基线与增强提示词执行时得到相同完整材料和相同执行合同。事前评价卡只给后续评价者，不进入增强或执行输入。原始提示词、材料及评价判据在任何生成前封存。主任务在 normal 过门前不得打开本包内容；封存消息只披露数量、路径、时间和校验值。

合理设计变体不是推荐答案卡。以原始委托、资料和实际作品判断可用性，不因方案与作者不同而扣分。充分原文可直接成功，不以增加篇幅或强行结构化作为优化收益。没有联网、专业隐藏知识或唯一答案的依赖。
