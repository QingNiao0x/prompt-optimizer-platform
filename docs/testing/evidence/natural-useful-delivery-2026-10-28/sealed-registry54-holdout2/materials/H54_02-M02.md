# 现场回看和当前流程

现在的流程是拣货员按订单取货并扫码，打包员在台上核对型号、数量与配套件，然后装箱、打印面单、贴单并将包裹放入已完成区。系统扫码只对主商品的编码，不会逐个提醒每袋配套小件。不能因为要提速就取消原扫码和打包核对。

回看部分差错时发现，九条错品中有六条涉及外包装相似的两种转接头，它们相邻摆在同一个货架格；回看能看到拿错了实物，但不能仅凭这些画面确定是标签、注意力还是上游混放造成。班长检查该货架时看到两处标签已经褪色，另有三个格子同时放了新旧两种外包装，商品编码未改变。记录没有覆盖所有货架。

漏件涉及三种套装。当前台面只有整套成品照片，没有逐件数量提示。一次现场观察中，打包员发现纸袋内少一个小垫圈并补齐，这单没有进入差错记录。它说明现有核对也能起作用，不是七条漏件都由同一种配件造成的证明。

两条台面都会在订单打印后暂存尚未贴上的面单。忙时有人把下一单货物放到旁边等候；一次现场观察中相邻两张面单被拿反，操作员贴前核对时及时纠正，没有发走。五条实际贴错面单记录并没有完整录像，不能把这次观察当作五次错误已证实的共同原因。
