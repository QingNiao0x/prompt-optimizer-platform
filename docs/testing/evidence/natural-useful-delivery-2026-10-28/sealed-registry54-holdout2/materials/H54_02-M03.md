# 下一轮可用条件

班组希望先用接下来的五个班次做一轮小改进，随后看情况决定是否保留。仍是原来的拣货与打包人员，不增岗，不把全部订单停下来重新逐单翻箱，也不能更换仓管系统或改供应商商品编码。正常出库要继续，改善不能靠默认加班维持。

现有物资有标签打印机、空白黄色标签、透明小袋、纸质异常夹和几块闲置隔板，可以调摆放、补说明和改台面组织。没有新软件和新采购的审批。班长每班最多可以拿出15分钟集中整理异常和查看执行情况，其余时间仍需带班；不宜让他逐单签字。原有扫码和打包核对步骤必须保留，执行者可以合理安排可在此资源下试行的辅助做法。

给班组的安排要说清先做哪些、哪些暂缓、谁在什么环节做、怎么知道有无改善，具体取舍由分析者判断，不需要先等班组投票。不是要估算全年节约额、承诺错误必然归零或给个人排名。可以设计负担很小的记录，但不要要求另建一套难以持续维护的台账。已经明确的改进可以先安排；原因还不能确定的地方要区分判断与验证，不必等所有原因查明才交整份安排。
