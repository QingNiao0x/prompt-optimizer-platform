# 出库抽查口径和结果

以下是虚构“禾线配件仓”的合成内部资料，用于本轮改进讨论。仓库有两条常规出库台，这次从四个班次已完成的出库包裹中各按相同间隔抽取60单，共240单，再按订单与实物核对。它不是全部出库订单，也不是客户投诉总量。每单只算一个包裹；发现任意一类差错就计为一单有差错。同一单若有两类错误，两类都登记。

合计18单有差错、21条分类差错记录；其中3单各有两类，其余有差错单各一类。分类记录不能直接当作有差错包裹数。四个班次的产品组合与急单占比不同，现有表没有记录各班次完整的工作量、工时或个人操作量，不能直接把班次高低判为某个人更粗心或效率更差。

错品指装入商品型号或规格不符；漏件指订单要求的数量或配套小件不足；贴错面单指货物核对正确后用上了另一单的面单。普通外箱小凹痕不属于这三类，单独移交包装组。此次没有对所有客户逐一回访，未抽到的订单状态不明，不据此宣称整体客户满意或其他订单零差错。
