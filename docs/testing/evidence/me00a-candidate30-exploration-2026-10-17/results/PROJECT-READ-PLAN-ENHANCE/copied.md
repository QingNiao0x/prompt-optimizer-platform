目标项目是基于低代码平台 JeecgBoot 构建的布病系统。前端使用 Vue3 与 TypeScript，后端使用 Spring Boot 3，数据库涉及 PostgreSQL、Redis，构建工具为 Maven（原文数据库写作“pgsq”，按 PostgreSQL 理解，实际以项目配置核实为准）。

模块划分（用户描述）：
- 后端：`brucellosis` 目录为重构后的新模块，`oldbrucellosis` 目录为遗留旧模块。
- 前端：`brucellosis` 目录为重构后的新模块，`brucella` 目录为遗留旧模块。
- 患者治疗相关的新旧模块，每次需求修改都需在两个模块中同步。
