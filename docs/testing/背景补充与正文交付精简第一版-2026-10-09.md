调用生产编排、上下文分析、模板选择、OpenAI 兼容 Provider、校验和组装；身份与模型目录为冻结的组件夹具，实际模型经真实 HTTP 调用。**不是普通账号登录、数据库、历史或浏览器端到端验收；本轮未开启 Plan／示例。** 模型目录依据本地路由配置投影，不代表管理员在线发布目录已验证。仅使用 Windows 用户环境中的 DeepSeek 凭据，不读取 `.env`，归档不含请求头、Cookie、密钥或推理正文。

已同步根 README、能力设计、最小干预方案、文档导航与近期待办，修正“全部尚未实施”和“短邮件只是静态风险”等过期描述；历史证据不回写为通过。

2. **ME-03：有效事实与少改**。同时读取原始需求、相关上下文和有效答案，避免空上下文覆盖已知技术；充分任务只补真正缺项，开放研究保留候选方法帮助，重要未知仍提问。模型错误暂作真实反例，不以通用删词掩盖。

4. **ME-06：冻结正式候选**。分别固定增强模型和执行模型，在同目标、同材料、有效答案、相同设置下比较实际作品，扩展中长行业题和未参与修复的新题；补普通身份、Plan＋示例、上传、二次检索、编辑／历史／复制及全仓库回归。

这版不是平台全量修复或发布批准。下一轮应先定位平台实际新增与语义覆盖的缺陷，并说明拟如何处理模型原文错误，不新增无限模型校验链，也不以更多通用限制代替业务闭环。
