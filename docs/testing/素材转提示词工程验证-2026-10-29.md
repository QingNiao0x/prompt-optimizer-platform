# 素材转提示词工程验证

日期：2026-10-29。授权范围为在原图像工作台实现通用资料、历史、关键操作统计，并同步首页及项目文档。沿用 `/image-to-prompt`，没有增加独立工作台导航。未提交、推送、部署或重启日常 API；本次没有真实模型调用，历史已关闭的付费批次不作为本轮语义质量证明。

## 工程实现

- 新增代码／页面、文档／内容、其他任务；代码、配置、受支持 Office/PDF 文字层、粘贴及文件夹中显式选择的文本文件，先本地提取、脱敏并生成片段，再独立审阅选择。网页使用 HTML 快照或正文，不抓取任意 URL、不执行脚本。
- 文字资料与视觉参考可混合；沿用图像/页/帧独立审阅及像素遮挡。通用任务不套用视觉直接还原的限制，关闭 Plan 也可表达技术栈、内容或实现变更，开启后仅确认关键未知。
- 通用来源采用独立 asset/unit 引用，不伪造成图片；任务输入与来源、角色、替换关系、接收模型绑定服务端同意凭据。范围、任务或模型改变后重新确认，计划只接受服务端原题的实际答案。
- 结果保存 sourceSources 选定证据、目标、题答及来源风险；沿用原历史分类、编辑修订、失败保稿、再次优化、逻辑删除及用户/租户/工作区隔离。过期原件不由历史重新识别。
- 使用原 IMAGE_PROMPT_* 事件兼容素材工作台，新增直接提交、Plan 完成和再次优化细分；服务端按操作或计划 ID 去重，细分事件不重复累计关键使用。复制在剪贴板成功或确有手动复制后报告 RESULT_EXPORTED，后台复制卡片明确为全部工作台登录用户成功复制总数，不伪推历史事件中的工具维度。
- 首页、公共导航与页面名称改为“素材转提示词”；README 项目简介/边界、文档索引、当前待办及使用指南同步。旧视觉路径和历史版本评测记录保留，不追溯改写其质量结论。

## 验证

### 前端

受影响 Vitest 共 **68 个不同用例**通过：store 43、请求适配 15、统计投递队列 10。首次组合为 67 项，补充“通用切回视觉及旧图片角色/范围变化撤销同意”后，store 43 项复验通过，不把重复测试累计为新覆盖。

生产构建 `npm.cmd run build` 通过，包含 `vue-tsc -b` 与 Vite。既有 Rollup PURE 注释位置及分包体积提示仍存在，不影响构建成功。

浏览器 **90 个不同用例**最终通过，使用桌面 Chrome 与手机视口、合成文件及受控 API：

| 范围 | 不同用例数 | 依据 |

兼容批次首次为 56/66，通过核查发现 10 项失败来自测试定位或旧夹具：旧“图像历史”名称、英文弹窗关闭名、首页仍预期访客强制去登录页、试用夹具未登记已存在的账号偏好加载。修正测试后，10 项连同新资料 10 项共 20 项复验全部通过；没有为匹配旧测试修改产品访问规则。

新资料初次脚本点击隐藏 Checkbox 原始 input 导致超时，改为点击真实可见标签后通过。实际截图又发现新资料长弹窗在手机上被顶栏遮住，已将三种通用资料弹窗移至 body、限制视口高度、保留标题和操作、正文滚动；新增标题/底部按钮在视口中的几何断言并复验通过。

### 后端

统一受影响 Java 验证 **131 项全部通过，无失败、错误或跳过**：含原视觉/媒体、真实 FFmpeg 抽帧、新来源准备与工作流、真实模型协议的受控 HTTP 响应、认证/CSRF、新旧历史行为，以及统计客户端/事件/本机 PostgreSQL 聚合。PostgreSQL聚合9项使用隔离测试事务回滚，不代表生产迁移已执行。

新服务用真实 DOCX、PDF 和空 PDF 检查提取行为。跨 16k Office 连续提取回调的凭据检测用例先复现漏脱敏，修复为同一逻辑段有界合并后扫描，再6k分片；修复范围只在新资料服务，未改共享文档提取器。

首轮3个视频场景因工具条件跳过，统一复验显式使用现有 FFmpeg/ffprobe 后均通过。一次受限环境下 Mockito attach pipe 拒绝访问导致测试启动停滞；停止该测试进程后以正常权限运行原测试命令通过，不将工具失败算作产品通过。

最终审阅另确认并修复新 `/text` 接口在反序列化前缺少 HTTP 请求体限额的问题：仅该方法通过专用 Advice 在 Jackson 前限制32MiB原始JSON字节，同时业务净文字仍限5MiB；声明长度和无长度流均须受控。最后定向17项全部通过，含4个新增独立用例（Advice 3项、Controller 1项），累计 **135 个不同后端用例**通过；17项中的13项已包含在131项内，不累计为148项。

## 数据库与运行边界

V47 为新的前向注释迁移，更新 audit_event 及 image_prompt_record 的表、mode、payload 说明，记录 sourceTask/sourceSources 和新增事件含义；不修改旧迁移、旧记录或约束，本次未应用。需要更新并重启后端后才能使用新接口；前端开发热更新不代表日常 API 已加载新代码。

文字入口每任务20来源、单文本5MiB/Office-PDF50MiB、集合5000项/净文字5MiB/单项500000字符，提取600000字符或1000片段后明确部分覆盖，最终40片段/120000字符。字符上限不是任意模型的Token窗口保证。文件夹是用户选择文件后提取并选择片段，未新增完整AST调用图、全仓库自动检索或源码执行。

当前没有真实模型的通用代码/文档转换质量或下游作品验收，也没有动态网页抓取、音轨或任意专有格式支持。扫描PDF无文字时明确提示另行视觉识别，不能宣传直接完成全文OCR。
