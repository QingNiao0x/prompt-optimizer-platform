# 自然增强正文职责与诊断减负实现

本轮按用户授权最多100次真实调用实施四项任务。工程代码与长期对照入口已完成，正文候选未达到采用条件，源默认继续为 core-repair-v5。没有重启日常服务或发布生产。

## 实现范围

| 任务 | 实现与验证 |
| --- | --- |
| 完整指导审查 | 新增 BALANCED → core-balanced-v1。正文指导明确允许完善原成果内部内容，事实须有来源，普通设计以任务和上下文为依据。真实发出的 system 原文保存在本批 current-system.txt、candidate-system.txt，分别3469、2468字符。旧版常量保持可回放 |
| 强制保护与诊断分级 | 候选取消框架必填，充分程度允许缺省或未知，内部记为 NOT_ASSESSED，不用于生成门控或质量通过。仅接受有界安全标量，诊断对象、数组和疑似凭据仍拒绝。来源、完整实际题答、正文覆盖、权限组装和用户目标归属继续检查 |
| 局部修复复用 | 候选接入既有 NaturalPromptMetadataRepair。服务端持有首稿，只允许修改已定位的 evidence/dimensions 路径。正文和要求文本不可写，补丁后重新运行 DTO、来源、题答和覆盖保护。范围准备没有首稿时仍使用原有有界协议修复 |
| 长期对照 | scripts/evaluation/natural-balanced/run.mjs 同时比较原始直接执行、简洁改写、v5与候选。check-works.mjs 复用已有代码行为检查并核对只交付实际修改文件。输出目录只运行一次，落盘计数、失败保留和总上限均在调用前生效 |

BALANCED可由服务端配置 NATURAL_ENHANCEMENT_PROFILE=BALANCED 显式选择。当前未采用其正文策略，日常默认继续为 PROTOCOL_SCOPE_REPAIR。结构化链、素材转提示词与文章祛AI味不使用此候选配置。

102项不同定向Java检查通过，覆盖候选7、既有Plan阶段19、元数据修复19、历史元数据Provider9、配置9、自然服务39。最后新增测试只复验候选套件，不重复累计测试数。

- U02、V02历史真实首稿和补丁经候选Provider回放，修复后首稿逐字不变。
- 非法补丁改写正文、修好来源但仍缺正文覆盖继续拒绝。缺省/未知诊断可交付，诊断对象仍拒绝。
- 零问题Plan保持正常，阶段字段、原始来源及题答保护复用既有回归。
- 历史夹具初次回放误用了旧模型身份与模拟路由，调用前失败。修正模拟路由后又发现用户GOAL归属保护未接入候选，已复用现有检查补齐。最终五份真实候选响应全部用终稿保护离线回放通过。真实调用发生在这一保护补接之前，未重采模型结果。

真实调用没有经过本轮工作台登录、复制和历史闭环。身份、租户、Plan所有权与权限的证据来自受影响应用层回归，不将Provider验证写成日常入口验收。

## 真实对照结果

调用使用已授权既有合成需求和材料，经 DeepSeek 官方端点执行。共49/100次，产品增强20、简洁改写5、作品24。所有臂温度0.2，thinking=disabled，输出上限10000，保留完整输入和首次结果，协议及质量重试均为0。累计输入55856、输出19214、总计75070 tokens，未取得金额账单。51次未用，未继续扩大同一假设采样。

五条路径为无附件查询、代码上下文、Plan实际回答后生成、阅读后等待、明确报告。v5与候选各5/5交付。这是限定Provider样本的交付结果。

| 案例 | 实际观察 | 结论 |
| --- | --- | --- |
| 查询 | v5仍偏来源、口径与限制。候选仅返回原句加标点，没有实质补充 | 目标短板未解决，停止该题作品调用，不把短正文计为收益 |
| 阅读等待 | 候选保留阅读、理解、等待及不改文件、不写项目说明 | 此例保真通过，不算新增补全收益 |
| 代码作品 | 四臂各两份。日期和逐行导入行为检查均通过。原始、v5和候选均多交form/import两个未修改文件，简洁臂只交date文件 | 简洁臂此例交付负担更低，候选没有减少修改量 |
| Plan作品 | 候选第一份把不承诺额外赔偿改成经审慎评估、不涉及额外赔偿。v5第一份写为暂不提供额外赔偿。原始也出现同类变化。简洁增强正文新增任何补偿禁令 | 原文到增强及增强到下游分别记录，不能把诊断减负当成语义保证 |
| 报告作品 | v5与候选优化正文逐字相同。候选下游自行新增不包含修复方案，而原文只要求不执行修复。各臂还存在从两次记录推断稳定复现的表述 | 下游范围收窄和证据强度需修改，未证明候选稳定收益 |

代码检查器首版把上下文的固定片段标签当作源代码，导致原文件比较失真，也让简洁臂的未修改文件装载失败。第二版统一去除片段标签后复算，只交付实际修改文件按原需求检查。两版结果均保留，没有重采模型作品。非代码作品的自动检查仅核实响应交付，语义问题由开发助手阅读记录，未进行独立真人评阅。

采用决定为正文候选不采用。工程减负和局部修复已可通过独立配置审阅，当前未切换默认。全部需求均为已见合成案例，没有独立留出题、真人修改量或大型私有项目502复验。不能根据本轮宣称整体提示词质量提高。
