## 浏览器专项覆盖

1. 主按钮仅复制，五个平台入口复制后打开准确的固定 URL；目标页面初始输入框保持空白。
2. 调用真实剪贴板 API，并用键盘粘贴动作比对完整中文、换行、JSON 代码块、emoji 和 80 条合成任务说明。
3. 目标页面的 `opener` 为空，跳转不发送来源头；URL 与导出事件不包含提示词正文。
4. 剪贴板 Promise 拒绝、同步异常、API 缺失：显示完整只读文本，全选范围正确，不访问平台或记录导出。
5. 弹窗被拦截或打开异常：复制仍成功，提供对应平台的手动链接，点击链接不重复计数。
6. 权限等待期间仅保留空白页，禁用重复复制；写入成功后才访问目标地址。
7. 用户关闭预留页后不自动重开，完成复制后提供手动链接。
8. 编辑保存、重新生成和离开工作台：关闭旧预留页，不把旧复制反馈标到新结果上；编辑后复制完整新内容。
9. 事件上报 503 不阻断复制，恢复后沿用同一事件 ID 和发生时间，清空已确认的本地队列。
10. 320px 深色界面中五个菜单项、44px 触控目标及完整手动复制弹窗保持可用。

首轮 Chrome 结果为 22/24：两个正常路径用例的模拟平台页面没有声明 UTF-8，中文 `aria-label` 被浏览器错误解码。修正的是测试夹具的 HTTP Content-Type 与 HTML charset。失败用例复验 2/2 通过，随后最终完整 Chrome 24/24、Edge 12/12 通过，未修改产品代码来绕过失败。

## 复现方式

浏览器专项的 Chrome/Edge 命令见[运行说明](./前端浏览器端到端测试.md#复制与平台跳转专项)。不同浏览器任务须顺序运行，避免系统剪贴板被另一组测试覆盖。

在 `apps/web` 下执行：

```powershell
npm.cmd test -- src/stores/optimization.test.ts src/features/analytics/analyticsDeliveryQueue.test.ts
npm.cmd exec -- tsc --noEmit --target ES2022 --module ESNext --moduleResolution Bundler --lib ES2023,DOM --types node --strict --skipLibCheck e2e/prompt-copy.spec.ts
npm.cmd run build
```

在已授权的本地 PostgreSQL/Redis 环境、`services/api` 目录下执行：

```powershell
mvn -q "-Dtest=AnalyticsRealBrowserAcceptanceTest" "-Danalytics.browser.enabled=true" "-DargLine=-Djdk.net.unixdomain.tmpdir=E:\MyProject\prompt-optimizer-platform\tmp" "-Dspring.datasource.url=jdbc:postgresql://localhost:5432/prompt_optimizer" "-Dspring.flyway.enabled=false" test
```

`jdk.net.unixdomain.tmpdir` 沿用本机既有测试配置；其他机器需使用自身可用目录。前端测试使用独立端口 5193，真实联调使用独立 Vite 5192 与随机后端端口，不停止现有开发服务。动态测试账号数据最终回滚，Flyway 明确关闭。

临时产物位于 `apps/web/test-results/prompt-copy-chrome-final/`、`apps/web/test-results/prompt-copy-edge-final/` 和 `services/api/target/analytics-real-browser-acceptance.json`。这些产物可能被后续运行覆盖，本文件保留本轮数量、版本、失败原因和验证边界；不归档含环境属性的原始 Surefire XML 或认证材料。
