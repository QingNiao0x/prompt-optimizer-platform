# 示例参考功能删除验证

按用户要求删除“示例参考”功能及前后端实现。以主工作区 `d65558d2` 为基线，在 `codex/remove-example-reference-20261022` 分支完成；未合入其他隔离工作树的质量候选。

## 修改范围

- 前端删除工作台开关、Props/事件、Pinia 状态、请求字段、生成来源比较和历史恢复选项，同步类型及夹具。
- 后端删除 `includeExamples` 业务字段及传递参数，移除 `ExampleContract`、`ExampleResultIntegrator`、Mock 自动示例段和自然模式自动示例条款。
- 从任务视图及其模型投影删除示例契约，从场景模板、交付画像和模型输入删除 `exampleGuidance`；框架不再依赖示例开关。
- 历史详情、新记录和再次增强不再读取、返回或新增示例开关；旧客户端字段仅通过 DTO 忽略注解兼容，不建立取值或恢复功能。

用户在原始提示词及实际题答中明确的示例要求仍属于任务。`EXAMPLES` 段落代码保留用于明确要求和旧历史读取；它不再由平台开关自动生成或补齐。明示禁例、严格格式和禁虚构的基础保护迁入既有 `RequirementBoundaryContract`，仅依据用户输入，不建立关闭开关等于禁止一切示例的缺省规则。辅助段违反明示限制时按原协议失败处理，不静默删除后宣称响应合格。

已保存优化正文、历史证据、测试原件和旧迁移未回改。新增 `V22__retire_example_reference_option.sql` 只维护现有 JSONB 列的注释，说明当前增强选项及退役旧键；迁移尚未应用，不修改表结构或历史数据。
