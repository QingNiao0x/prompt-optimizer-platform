# 结构化增强职责收敛与真实复验

## 结论与范围

本轮只修改显式 `PromptFormat.STRUCTURED` 的生成指导、旧组装器及V2结构化投影。默认／COMPACT独立自然增强、自然Plan、模型目录、权限、上下文隔离、数据库及历史持久化均未改。起点为干净工作区 `e95f99f38ba551683e7a3891cb60c92a02965542`；没有覆盖其他会话改动。

已经修复确定的公共机制：结构化不再叠加十二框架布局、不给空模块补通用正文、可清空完全重复的辅助槽；模板默认验收和可选示例不再成为第二份生成要求；完整服务端确认在结构化执行原句上明确标记完成，部分／未来确认不升级。显示、编辑、原生复制及实际历史已有对应验证。

**本轮实现及限定验证完成，整体结构化质量仍未通过。** 查询提示词仍冗长，来源事实及规则的语义覆盖仍可能触发保守补写；模型仍会跨节重述。不能宣称所有重复消失、稳定优于原文或正式发布通过。

## 共同根因与最小修改

| 根因 | 修改与边界 |
| --- | --- |
| 框架布局与固定模块同时指导结构化生成 | `PromptRewriteStrategy`仅在COMPACT旧兼容分支选择十二框架；STRUCTURED使用模块分工，原任务、确认、专业边界仍沿用当前视图。没有新增行业或问法匹配。 |
| 辅助槽允许空，但两个压缩器保留去重后为空的原段 | 增加显式结构化调用参数；仅在已有完整覆盖时清空辅助槽，最终仍经过输出保真与权限恢复。默认重载、COMPACT及自动模式保持原行为，代码／表格／引用／独立条件继续保护。 |
| 模型按缺口决定验收，模板却另给默认验收及可选示例 | 只在STRUCTURED模型载荷中置空模板的默认验收／示例指导；原文验收和有效示例契约仍完整输入。Mock与旧assessment兜底同步限定，不清空模型实际给出的独立验收。 |
| V2再填满五模块，待确认清单被重复塞入背景 | 仍按背景、任务、输出、约束、验收五类组织，有独立内容才呈现。不增造背景／通用验收；未决信息留在API清单及正文必要执行前提。只有同源提醒已在执行正文逐字完整独立表达时省去重复；未覆盖文字保留在约束，引用／代码等不能作为覆盖证据。 |
| 真实Plan执行要求只以题干标签＋答案呈现，旧“先确认”规则仍在 | C2下游实际重新提问。C3仅对服务端完全确认、同题绑定的执行原句标记“本次已完成确认”，表示确认动作完成，不表示项目或研究已实施；不删除权限原句、不修改问题筛选、不猜测部分答案。 |

修改不依赖具体职业、会议、地区、工具或某一句问法。源码与策略哈希分别冻结；原始题答、来源、首次失败和所有版本原件均保留。
