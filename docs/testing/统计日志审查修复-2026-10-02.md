# 统计日志审查修复（2026-10-02）

本轮在审查获准后修复 Admin Analytics 的统计、输入边界和展示问题。证据来自当前代码、真实本地 PostgreSQL 回滚测试及浏览器夹具测试；不代表生产或真实支付验收。

## 修复内容

| 问题 | 修复与回归证据 |
| --- | --- |
| 排行漏算仅访问或仅退出的活跃日 | `AdminAnalyticsMapper.xml` 移除聚合前的事件类型过滤；关键操作数、登录数继续分别使用 `FILTER`，`HAVING` 保留有关键操作才入榜。真实库夹具中原来 3 天被算成 1 天，修复后为 3 天，操作数和登录数均仍为 1。 |
| 旧版历史重新优化未采集提交事件 | `OptimizationHistoryController` 接入现有 `AnalyticsEventService`，与直接优化接口一样在执行前记录 `OPTIMIZATION_SUBMITTED`。验证一次直接优化及一次历史重新优化恰好产生两条提交事件；跨用户读取历史仍返回 404。该指标表示提交尝试，不能解释成成功完成次数。 |
| 极端年份导致日期运算异常 | `AnalyticsPeriodResolver` 只接受公历 `0001–9999` 年的四位 `YYYY-MM-DD`；校验周/月展开后的完整周期。扩展年份、年零、非法日期及越界周期返回 400，不进入 SQL 查询。 |
| 自定义范围可能生成数百万日桶 | 单次仪表盘与日志查询最多包含 366 个自然日，起止日期均计入；366 天通过，367 天被拒绝。永久数据仍可分段查询，未增加清理任务。 |
| 清空自定义日期后读取 null.length | 页面显式支持日期控件的 null；查询前验证完整日期及账号 UUID，错误提示后停止请求。浏览器回归检查无页面异常及无额外请求。 |
| 日志日期受浏览器时区影响 | 用响应的 `period.zoneId` 格式化发生时间，并展示统计时区。洛杉矶浏览器中的上海统计日正确显示 `2026-10-01 00:30:00`。 |
| 全零小时/月序列被当成峰值 | 只把正数操作桶作为峰值候选；按数值判断空状态。夹具改成实际 SQL 返回的补零日、24 小时及 12 月序列，验证零数据没有峰值标签。 |
| TODAY 单点折线不可见 | 单日序列显示点标记；浏览器检查真实 ECharts 实例的 `showSymbol` 及单点数据，不仅检查 canvas 是否存在。 |

## 指标与交互契约

- 用户标识继续为登录账号 ID；管理员计入，匿名事件不计入账号指标或排行。平台管理员可以跨租户查看汇总，普通用户与未登录请求仍分别返回 403、401。
- 注册账号为当前存量；新增账号按创建日期；活跃账号为期间有任一审计行为的账号；实际使用账号及频率排行仍按既有六类关键操作计算。
- 平均日活仍为各自然日活跃账号数之和除以全部自然日数，包含零活跃日，以 `HALF_UP` 保留两位小数。补充 `1 / 3 = 0.33` 回归。
- TODAY/YESTERDAY 为当地自然日，THIS_WEEK 从周一到今天，THIS_MONTH 从月初到今天；LAST_MONTH 为完整上月。数据库继续使用左闭右开时间区间。
- DAY/WEEK/MONTH 排行为锚点所在完整日/周/月，页面显示实际返回的排行日期。跨年周、闰月和日光节约时间的 23/25 小时日均有边界测试。
- 月图固定为截至今天的近 12 个月，沿用账号筛选；页面明确说明它与顶部日期范围的区别。
- 仪表盘各查询放在 `REPEATABLE_READ` 只读事务内，使用同一数据库快照；没有新增缓存或 Redis 数据。
- 三个管理员 GET 接口的路径和响应结构不变。查询 DTO 增加 Bean Validation 长度上限；服务继续校验值域、分页与日期语义。超过 366 天或超出受支持年份属于新增的 400 边界。

## 页面完善

- 每日趋势补齐 `actualUsers`、`newAccounts`，共五条可切换图例；横轴包含年份，避免跨年歧义。
- 设备区域同时展示登录次数和设备内去重账号数，提示跨设备不可直接相加。
- 日志展示显示名称及事件 ID，时间按统计时区显示。操作类型旁增加“筛选日志”，沿用已生效账号/日期；顶部筛选按钮和回车仍为显式提交。
- 展示成功查询的日期、账号及统计时区；输入草稿或失败查询不会改变已生效条件。保留在途请求序号保护、错误状态和分页行为。
- 充值预留图表按币种切换，套餐以 `planCode` 分组，显示成功支付笔数，不叠加不同币种或合并同名不同代码套餐。真实充值数据源仍关闭；这部分只验证展示逻辑。
- 前端事件类型补齐后端已有的 `ADMIN_MODEL_CHANGED`。它仍是预留代码，本轮未添加模型配置变更的采集流程。
- 沿用 Element Plus、现有主题变量和响应式栅格；缩短手机指标卡片，把充值未启用提示移到对应卡片。共享样式及其他页面布局不变。
