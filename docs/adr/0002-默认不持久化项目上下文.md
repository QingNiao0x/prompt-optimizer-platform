# 项目上下文默认不持久化

状态：accepted。用户上传的项目源码和文件片段默认只服务当前优化请求，优化完成后释放；用户主动保存历史时最多保存经过截断、脱敏的上下文摘要，不默认保存原始源码。这个决定牺牲了部分“完整回放”便利性，但降低了源码泄露、合规和备份扩散风险，是商业化产品建立信任的基础。

## 后续影响

- Context Snapshot 必须有明确 TTL、大小上限和删除兜底。
- 历史详情不能假设一定能恢复原始项目文件。
- 上传文件列表和当前项目选择只属于当前页面生命周期，刷新或重新打开页面时不得自动回填。
- 浏览器 IndexedDB 中的本地索引与页面展示状态分离，按用户选择的保留期限或设置页清理操作管理。
- IDE 插件可以在本地分析源码，再只上传摘要，从而进一步减少服务端敏感数据。
