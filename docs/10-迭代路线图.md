# 迭代路线图

## Phase 0：文档与契约（当前）

- 固化领域语言、产品范围、架构、数据模型和 API 契约。
- 创建前后端工程骨架和本地基础设施目录。
- 评审隐私、额度和 Provider 接入边界。

## Phase 1：可用 MVP

- Vue 优化工作台、历史页、设置页。
- Spring Boot 优化接口、Context Analyzer、OpenAI 兼容 Provider。
- PostgreSQL 基础表、Redis 限流和短时上下文。
- 至少一个真实 Provider 的端到端联调。
- 文件上传安全校验和敏感信息掩码。
- 一键增强、四要素结构化输出和 4 个内置 Prompt 模板。
- 项目上下文、会话历史和权限红线的请求级注入。
- 前端二次编辑、撤销、复制和再次增强。

## Phase 2：登录与团队

- 注册、登录、刷新令牌、工作区和成员角色。
- Provider 配置按租户隔离。
- 历史分页、删除、保留期限和审计。
- 会话历史、增强结果版本和差异对比。
- 工作区级项目记忆和团队编码约束。
- 配额显示和用量统计。

## Phase 3：商业化

- 免费试用、套餐、订阅和支付回调。
- 平台 Key 与 BYOK 的计费策略。
- 团队模板、组织级偏好、提示词版本和质量评分。
- 自定义模板、模板组合和权限策略管理。
- 管理后台、成本分析和异常用量告警。

## Phase 4：生态与 IDE

- VS Code / IntelliJ 插件。
- 本地 Context Analyzer，后端只接收摘要。
- API Token、Webhook 和 OpenAPI SDK。
- 企业版私有部署、数据驻留和供应商白名单。

## 每阶段的退出标准

- 有可执行的接口契约和迁移脚本。
- 有最小安全测试：租户越权、密钥泄露、文件路径穿越、限流绕过。
- 有 Provider 失败和数据删除场景的自动化测试。
- 有成本与延迟观测，不只验证功能正确性。
