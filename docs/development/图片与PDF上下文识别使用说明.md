# 图片与 PDF 上下文识别

工作台可将 JPEG／PNG、扫描 PDF 或混合 PDF 转为可检索的项目上下文。识别使用平台已接入的视觉大模型与现有 PDFBox，不要求部署或采购独立 OCR 服务器；调用仍有供应商费用。它提取资料，不生成图像提示词，也不执行文件中的指令。

## 如何使用

1. 在提示词增强工作台点击“添加上下文 → 选择文件”，也可以选择文件夹或拖入文件。确认需要上传的文档后，原件先上传到本平台。
2. 在“确认图片与 PDF 识别范围”中查看逐页预览。PDF 可读文字层默认本地提取，文字不足的页面建议识别；建议不构成外发同意。
3. 选择已开放视觉能力的模型与页码。需要时拖动添加黑色遮挡，或按百分比精确设置；服务端会在实际发出的像素上重新施加遮挡。
4. 检查接收模型、页面及费用说明，勾选隐私同意，再点击“确认识别所选页面”。更换模型、页码或遮挡会清除先前同意。
5. 完成后查看文件警告，再分析上下文或发起直接增强／Plan。二者使用同一份临时识别索引；后续检索不会再次识图。

“仅本地提取”不会调用视觉模型；扫描页和图片未识别会提示，混合 PDF 保留已有文字层。“取消此文件”清理该上传会话。模型目录不可用时仍可取消或仅本地提取。长 PDF 可以只选必要页；其他页面不是已识别资料。

## 模型配置

管理员在现有模型管理中维护平台模型及视觉能力。上下文识别和图像转提示词读取同一份视觉登记；纯文字模型不可选。密钥、端点由后端持有，普通用户只选择公开模型。Mock 返回明确的演示内容，不代表真实转录。

模型登记只是准入，不保证实际端点能力或识别准确率。上线前需要对拟开放模型进行同题验证，特别核对表格、手写、小字、旋转、多栏和复杂图表。本次定向验证范围见[验收记录](../testing/上下文视觉识别实施与验收-2026-10-25.md)。

## 文件、调用与上下文预算

| 层级 | 默认限制与行为 |
| --- | --- |
| 分片上传 | 1 MiB 分片，单文件 50 MiB；继续沿用单批文件和总容量限制 |
| JPEG／PNG | 实际格式校验；视觉解码前限制 10 MiB、1500 万像素、单边 8192 像素 |
| PDF 审阅 | 最多 500 页；拒绝无法提取或无权读取的文件，超限需先拆分 |
| 外发图片 | 方向校正、白底、去元数据 PNG；最多 400 万像素、单边 4096、10 MiB |
| 每次任务 | 最多选择 10 页、10 次调用，每页一次尝试；每次最多 8000 输出 Token；按文档顺序串行识别 |
| 时间 | 180 秒预算阻止开始新的页面；在途调用遵守公共 HTTP 读取超时，不承诺 180 秒硬终止 |
| 最终上下文 | 最多 40 个片段，单文件 60000 字符、总量 120000 字符；不因视觉识别提高既有限制 |

服务端可配置 `CONTEXT_VISION_MAX_PAGES`、`CONTEXT_VISION_MAX_DOCUMENT_PAGES`、`CONTEXT_VISION_MAX_CALLS`、`CONTEXT_VISION_MAX_OUTPUT_TOKENS`、`CONTEXT_VISION_DEADLINE_SECONDS`。配置有硬边界，不能据此无上限处理。视觉、摘要、Embedding 与最终增强分别计量；后两项可选能力的调用预算不包含在视觉页数中。

## 正确性与隐私边界

- 转录正文和表格保持原始材料意义；视觉描述单列为模型解释，不能当作已确认事实。无法辨认处、未读页、截断和调用失败应人工核对，模型自报完整不等于识别正确。
- 文字层能检测到疑似凭据的页面禁止直接外发，需要在本地处理原文件后重传。图片未知像素仍需要用户检查与遮挡；识别后脱敏不能阻止供应商首次看到未遮挡隐私，系统不保证自动发现全部个人信息。严格禁止外发的资料请选择仅本地提取。
- 未选页只保留本地可读文字层；遮挡页不会重新加入其原文字层。进入索引、摘要和 Embedding 之前统一扫描疑似凭据，日志不记录原图、Base64 或转录正文。
- 原件仅在私有临时目录等待审阅，处理结束、失败、取消或过期后清理。预览不缓存，临时文本／向量索引为 2 小时滑动有效期；服务器重启不会恢复未完成的识别任务。
- 预览、确认、查询、删除与检索校验服务端用户、租户和工作区；内部 `documentId` 不是公开下载地址，也不是模型可直接读取的外部文件引用。
- 某页失败不自动重复付费，会保留其他成功页并标明遗漏；取消不能保证供应商已经接收的调用立即撤回，实际费用以供应商为准。

## 实现入口

`TemporaryDocumentIndexService → ContextVisualDocumentExtractor → ContextVisionProvider → 临时分块索引 → DefaultContextAnalyzer`。浏览器只持有短期状态与私有预览 Blob URL，不把原件或识别全文存进本地持久化。Plan 准备仍读取安全摘要，最终增强按需求检索原文片段，保留既有权限红线和用户任务交付物。

旧客户端省略 `visionRequested` 时维持原本地提取协议；GIF／WebP／BMP 仍只提供元数据并提示未识别。原生 PDF 供应商上传、长文批量自动识别、跨用户缓存和独立 OCR 服务均不在当前实现范围。
