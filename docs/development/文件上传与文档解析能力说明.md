# 文件上传与文档解析能力说明

## 已支持

- 纯文本：`txt`、`md`、`rst`、`tex`、`adoc`、`csv`、`tsv` 等。
- 前端和工程文件：`mjs`、`cjs`、`mts`、`cts`、`less`、`sass`、`pug`、`hbs`、`ejs`、`svg`、`gitignore`、`editorconfig`、`prettierrc`、`eslintrc` 等。
- Java 和模板文件：`jsp`、`tag`、`ftl`、`vm`。
- Python：`pyi`、`pyx`、`Pipfile`、`poetry.lock`。
- .NET：`csproj`、`sln`、`razor`、`cshtml`、`xaml`。
- Ruby/PHP：`erb`、`phtml`、`blade.php`。
- Office：`doc`、`docx`、`xls`、`xlsx`、`ppt`、`pptx`。
- PDF：普通文字版 PDF 使用 PDFBox 提取文字。

## WPS 格式边界

`.et`、`.dps`、`.wps` 会被识别并上传。对于基于 ZIP/XML 的文件包，后端会尝试提取 XML、HTML 和文本条目；无法识别的旧版专有二进制格式会提示用户另存为 `docx`、`xlsx` 或 `pptx`，不会把乱码当作有效内容。

## 图片边界

PNG、JPEG、GIF、BMP 等图片可以上传，当前后端提取图片格式、尺寸、颜色模型和像素位深等元数据；WebP 是否能提取元数据取决于 Java 运行环境是否提供对应图片解码器。当前版本尚未集成 OCR，也没有把图片像素发送给视觉模型，因此不能保证识别图片中的文字、表格、流程图或学术论文扫描页。

## 大文件和索引策略

- 普通文本单文件上传上限为 1 MB；Office、PDF、WPS 和图片单文件上限为 10 MB。
- 单次二进制上传总预算为 20 MB，避免浏览器和后端请求体失控。
- 本地项目索引使用流式读取，优先在类、函数、方法和配置边界分块；无法识别结构时按字符窗口分块。索引保存全部已读取文本分块，模型请求仍按提示词相关性、当前文件、固定文件和依赖关系选择有限片段。
- 无法按语言结构解析的大文件按字符窗口分块，并保留文件路径、语言、导入和符号元数据。

## 默认排除

- 依赖和构建目录：`.git`、`node_modules`、`target`、`dist`、`build`、缓存目录、日志目录。
- 日志和临时文件：`*.log`、`*.tmp`、`*.cache` 等。
- 敏感文件：`.env`、`.env.local`、私钥、证书容器、凭据文件等。界面会显示跳过数量，不会将这些文件上传到后端。

## 使用建议

- 学术论文优先上传文字版 PDF；扫描版 PDF 需要后续 OCR 功能。
- WPS 旧版文件无法提取时，使用 WPS 的“另存为”转换成 `docx`、`xlsx` 或 `pptx`。
- 图片中的文字和表格需要后续启用 OCR 或 Vision 模型后才能进入可检索上下文。
