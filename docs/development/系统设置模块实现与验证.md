# 系统设置模块实现与验证

更新日期：2026-10-27。本文记录本次已实现能力及验收范围，不代表已部署到正式环境或完成法律合规审查。

## 使用入口与范围

普通用户登录后从公共导航进入 `/settings`。页面新增 `components/home/SystemSettingsPanel.vue`，沿用现有 Element Plus 和玻璃样式；保留原手机号绑定卡片及项目上下文、本地索引设置。匿名用户仍进入登录引导，管理员功能仍由原有权限规则隔离。

- **通用设置**：中文、英文。账户偏好写入数据库，同时仅将语言标识缓存到本机；跨设备登录后读取账号偏好。本轮翻译覆盖系统设置和公共导航，其他工具正文、手机号绑定旧卡片及正式协议仍保留中文，页面有明确说明。
- **账号管理**：修改显示名称（沿用80字符规则），验证新邮箱后绑定或更换邮箱，设置或变更用户名。用户名与邮箱统一通过 `UserIdentityKey` 规范化，不使用资料字段代替身份表认证。
- **安全操作**：重新验证当前密码后登出所有设备；注销还需输入 `DELETE` 并在确认框再次确认。邮箱或用户名变更成功后也需要所有设备重新登录。
- **协议入口**：复用公开 `/terms` 和 `/privacy`；同步说明新的设置与逻辑注销行为。备案编号仍需在 `src/config/legal.ts` 填写实际获批编号；现有公开联系方式应由运营方核对可收信，代码中不添加部署凭据。

## 数据与接口

新增前向迁移 `V46__account_settings_and_session_revocation.sql`，不改历史迁移或原正式配置结构：

| 对象 | 职责 |
| --- | --- |
| `user_account.locale` | `zh-CN`（默认）或 `en`，账户级语言偏好 |
| `user_account.security_version` | 默认0；安全变更递增，认证主体保存登录版本 |
| `user_account.deleted_at` | 逻辑注销时间；非空时必须为 `DISABLED` |
| `user_identity` | 保留原全局唯一键与撤销身份的占用关系；旧身份变为 `REVOKED`，不转移给其他账号 |
| `email_binding_challenge` | 邮箱绑定专用挑战；仅存目标/浏览器HMAC指纹、验证码摘要、状态和消费时间 |
| `email_binding_rate_limit` | 账户、邮箱和连接来源IP的数据库原子发送预算 |

全部接口位于 `/api/v1/me/settings`，沿用 `ApiResponse` 和稳定错误格式。写请求继续要求 CSRF，目标账号只来自服务端 `AuthenticatedUser`，不接受客户端目标用户ID。

| 方法与后缀 | 请求 | 结果 |
| --- | --- | --- |
| `GET` | 无 | 昵称、当前有效邮箱/用户名、语言、绑定及注销能力 |
| `PATCH /profile` | `displayName` | 最新设置投影；更新会话展示资料 |
| `PATCH /preferences` | `locale` | 最新设置投影 |
| `POST /email-challenges` | `email,currentPassword` | `challengeId,expiresInSeconds,resendAfterSeconds` |
| `POST /email` | `email,challengeId,verificationCode,currentPassword` | 原子更新身份并消费挑战，清除当前登录 |
| `PATCH /username` | `username,currentPassword` | 更新身份并清除当前登录 |
| `POST /logout-all` | `currentPassword` | 递增版本并清除当前登录 |
| `POST /deactivate` | `currentPassword,confirmation=DELETE` | 逻辑注销并清除当前登录 |

冲突返回409（`EMAIL_ALREADY_BOUND` 或 `USERNAME_ALREADY_TAKEN`），不披露其他账户资料；当前密码错误返回403。登录失效返回401。SMTP不可用返回503，发送限流返回429，不伪造成功。具体错误码以实现为准。

## 安全与兼容边界

邮箱绑定使用既有 `VerificationEmailSender` 的独立绑定模板，不依赖阿里云控制台模板；保留现有 SMTP 环境变量和配置。只有SMTP投递模式、有效摘要密钥及客户端配置同时就绪时才开放邮箱绑定。邮件投递在数据库事务外执行且不自动重试；投递失败不退还已预留发送预算。

验证码有效5分钟、冷却60秒、最多5次错误尝试。默认每账户/每邮箱每小时5次、每IP每小时20次（邮箱/IP上限沿用已有配置）。挑战绑定账户、目标邮箱和服务端Session随机值，不能跨浏览器、账号或用途使用。错误次数独立提交，正确码消费与身份写入在同一数据库事务中；身份冲突回滚，不改变任何一方账户资源。注册验证码的原Redis存储和限流流程不变。

`AccountSessionFilter` 在安全上下文加载后、业务授权前检查数据库账户状态、注销标志、租户、身份归属与状态、平台角色及安全版本。数据库故障拒绝继续执行；Redis中的旧会话即使仍存在也无法绕过版本检查。展示资料变化会刷新会话最小投影。撤销针对后续请求，不声称中止已开始的模型调用；手机号绑定额外在云端核验后的账户锁事务内复核安全版本，拒绝在途的旧授权提交。

注销将账号设为 `DISABLED`、写入 `deleted_at`、撤销身份并递增版本，不物理删除租户、工作区、历史或原归属关系。最后一位活动平台管理员禁止自助注销，检查与更新使用同一事务锁。该功能不包含个人信息物理清除、保留期自动清理或账号合并；相关处理申请仍通过隐私政策中的联系渠道处理。

`local-mock` 的合成身份只提供只读设置投影；不装配真实账户设置服务、绑定/注销能力为关闭，写操作明确返回503，避免将合成主体写入业务数据库。正常开发连接真实数据库时可使用完整设置能力，无需修改生产配置文件结构。

## 部署核对

1. 正常发布流程由Flyway执行V46；旧序列化会话缺少身份或版本不匹配时会要求重新登录。
2. 使用既有SMTP配置及验证码摘要密钥，不将密钥写入源码。邮箱绑定能力关闭时其他设置和原认证流程保持可用。
3. 核对实际备案号、可收信联系渠道、协议与运营中的数据处理方式。提供协议入口不等于完成备案或个人信息处理的法律审查。
