# 自然增强实用性与成本收敛

本轮只修改自然增强的生成指导与模型内部记录布局，保持目标作品优先、无自动固定条款、不按职业或场景路由。充分需求保留有效表达；模糊需求只补与原定交付有关的实际缺口，不把重复要求、额外说明或新增作品当成增强收益。

默认继续NATURAL/4，第五版为已评测但未采用的候选。`DEFAULT_VERSION=4`与最新候选`VERSION=5`分开，普通增强和Plan只取已采用版本；受控评测及已保存历史可显式选择1—5，不将旧正文改为新协议。第四版指导按基线`d65558d2`完整冻结。候选Plan也使用该完整指导：出题最多八题、协议容量六十四题，不增加自动截断或新的拒绝阈值；确认后增强按显式选择的版本分发。

第五版最终生成把`quotes`与`requirements`／`additions`条目放在一起，不再要求模型另抄一组覆盖下标及同义摘要。HTTP适配器恢复既有`NaturalTaskUnderstanding`和`NaturalTaskReview`：下标来自条目位置；省略的要求诊断标签取首条来源原句，补充诊断标签取首条正文片段。该标签不是对其他原句的语义替代，全部来源、维度、缺口、作用、其他锚点及完整原始题答继续保留。

服务端仍核对来源原句、原始需求和每份真实回答的来源关联、敏感值、容量及维度；模型正文与平台组装后正文继续分别核对所有锚点。不同题干不因答案相同而合并，不能用缩短诊断标签证明语义等价。模型自报充分程度不用于绕过检查，平台也不自动补写模型遗漏的正文要求。

内部空集合可以省略，实际条目缺少引用或混合两版覆盖布局时明确失败。既有两次协议修复上限、缺失来源编号提示、失败计量、身份、Plan所有权与TTL、上下文隔离、历史和编辑契约保持。

候选5有实际确认回答的最终增强另传`requiredSourceIds`，只包含服务端生成的原始需求及逐份回答编号；不复写答案、补造出处或把原文拼入system。直接增强、旧版及Plan出题请求不受此清单修改。真实修正首答仍漏引，既有协议重试后才通过，不能以一次成功认定来源问题消除。

V20仅前向维护`optimization_record.result_metadata`注释中的版本说明，不增加数据库列、不回改V1—V19、不重写历史，本轮不应用迁移。前端产品源码和结构化增强不在本轮修改范围。

已完成的离线检查：六份历史真实响应通过实际HTTP适配器重排回放，正文、来源、维度、全部覆盖锚点和未决信息不变；字符投影节省不当作真实Token收益。最终受影响报告去重166项通过，旧三题断言、V4夹具版本及新增默认版本断言的夹具错误分别保留。来源标签取首句只减少诊断复述，不证明完整要求语义等价。

真实验证按[冻结协议](../testing/evidence/natural-utility-cost-2026-10-21/protocol.json)实际29/32次，含全部失败和修复，余3次已关闭；原始、第四版和第五版作品获得相同有效信息。五组直接增强Token下降24.8%，耗时仅降1.6%，确认后链路Token反增且仍有再确认风险；九份实际作品未证明稳定改善。依据冻结采用条件保留第四版默认，候选不是已发布能力。[报告](../testing/自然增强实用性与成本收敛-2026-10-21.md)保留全部限制，本条结束后不继续领取其他待办。
