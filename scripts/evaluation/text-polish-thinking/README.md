# 文章思考模式对照

run.ps1 -Phase inspect读取当前模型目录并核对既有合成账号，pilot执行冻结的16个任务。程序复用正式文章Provider，逐任务冻结输入、指导、执行快照和用量。协议修复计入账本，每次调用前预留两次预算。expand本轮无任务。

本轮总上限200，正常生成16次，禁止将未使用额度自动用于其他方向。原始回答和失败原件保留。protocol.json及protocol.sha256冻结源码和样本，启动时校验，已有结果跳过，关闭账本阻止续跑。

两臂同样发送temperature 0.2，但DeepSeek官方文档说明思考模式忽略该参数。供应商内部采样、额外输入计费和推理开销属于模式差异，不能宣称只隔离纯推理计算。执行快照记录实际发送值。

新文章为开发助手编写的六篇合成样本，在调用前冻结，未用于调试候选。两篇已见文章仅作回归。评阅者是同一开发助手，已经看到模式身份，不属于真人盲评。
