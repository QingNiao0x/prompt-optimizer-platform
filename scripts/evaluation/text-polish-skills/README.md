# 文章Skill同条件对照

本批为2026年11月16日的已关闭实验。用户后续明确授权总上限200次，执行协议限定本实验最多60次，实际使用12次。完整账本与原件位于docs/testing/evidence/text-polish-skills-2026-11-16。

prepare.py冻结24篇文章、48个配对生成任务、独立语义检查卡、源码哈希和分阶段条件。已有协议时拒绝覆盖。verify.py只做本地一致性检查，无模型调用。

run.ps1沿用既有受保护本机环境、合成账号、模型目录、正式Provider及并发计量。inspect仅核对模型和账号。pilot、expand要求明确授权、有效源码哈希和未关闭账本。expand还要求pilot-review中的通过决定及具体语言许可。每个任务先预留两次，再按审计结算，未获得审计时保守预扣并停止。已完成原件不会重新调用。

blind.py在生成后一次性制作匿名包，拒绝覆盖。先保存blind-review，再读取key解盲。本文档、语义答案卡、评测统计及采用判据不发送模型。

本批机制对照缺少明确阅读收益，未执行expand，也未切换默认。再次实验需要新的冻结协议与适用授权。prepare.py生成的初始授权状态为PENDING，收到本轮用户明确授权后才更新为APPROVED，原授权与自动审查经过记录在报告中。
